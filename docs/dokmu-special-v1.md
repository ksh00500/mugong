# 독무곡 보스 특별 모션

2026-10-06. 소림·천검산 다음으로 독무곡 보스 4명의 특별 행동 8종에 전용 원화를 연결한다. 이번 적용 대상은 로컬 빌드다.

| 보스            | 전용 모션                        |
| --------------- | -------------------------------- |
| 청린사왕        | 독검 청사 추격, 청사 독맥 전개   |
| 독의 묵칠       | 약왕 독병 투척, 약왕 독침 산개   |
| 오독낭자 연화   | 독화 부채 침우, 독화 자운 독무   |
| 만독곡주 사공염 | 만독 독주 삼연, 만독 해독초 시험 |

5개 원화 시점과 좌우 반전으로 8방향을 표시한다. 동작별 준비·힘 싣기·접촉·후속·회수·대기 6자세를 사용한다. 선택 원본 40개, 게임 텍스처 20개, 논리 프레임 240개다. 독무곡 전체 18행동 중 위 8행동을 새 원화로 표시하며 나머지 10행동은 기존 방향별 기본 원화를 사용한다.

## 원화와 프레임 규칙

- 기존 독무곡 원화를 인물·장비·색·몸 크기의 기준으로 사용한다. 무기와 쥔 손, 팔, 몸통을 함께 그린다. 검은 어깨에서 아래·가로로 베며, 독병을 놓은 손은 빈손이다. 부채는 쥔 손을 중심으로 펼치고 지팡이는 하나의 연속된 몸체를 유지한다.
- 선택 원본은 모두 2열×3행으로 각 자세에 공간을 확보했다. 초기 3열×2행의 과도하게 큰 인물, 경계 잘림, 뒤 방향에서 잘못 든 손 등을 포함하여 12개를 다시 제작했다. 선택 원본 40개의 경계 잘림·인물 연결·셀 중복 검사를 통과했다.
- 원본 인물 픽셀을 1:1로 복사하고 출력 프레임에 최소 32픽셀 투명 여백을 둔다. 프레임별 크기 맞춤이나 비율 변형은 하지 않는다. 모든 방향·자세의 게임 배율은 0.225다.
- 낮은 무기 끝이 발 기준점을 이동시키는 경우를 확인했다. 발 후보 좌표를 오프라인에서 구하고 20개 시점 표, 240개 자세를 직접 검토한 좌표를 저장했다. 게임은 저장한 좌표만 읽는다. HP바는 기본/특별 자세 전체의 최대 높이와 16픽셀 간격을 포함하는 고정 기준을 사용한다.
- 독침·독병·독안개 효과는 기존 게임이 실제 접촉 시점에 표시한다. 원화에 이펙트를 구워 넣거나 손에서 무기를 자동 추적하지 않는다.

## 전투 연결

공통 `bossMotionClock`을 통해 기존 준비·접촉·회수 시간을 그대로 사용한다. 사공염의 삼연격은 0.12·0.62·1.12초의 개별 접촉마다 준비 후 발사 자세를 표시한다. 독무곡의 독맥·독무·해독초 동작은 기존 코드에서 방어 유지가 아닌 특별 시전이므로 시전 후 회수한다. 피해·이동·판정·CC 면역·저장 규칙은 바꾸지 않는다.
