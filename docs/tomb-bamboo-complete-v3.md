# 고묘·죽림 전체 보스 행동

2026-10-18. 고묘 추가 11행동과 죽림 추가 12행동을 제작·교정하고 게임에 연결했다. 기존 주요 16행동을 보존해 두 지역 8보스의 실제 39키트 행동 모두 행동별 시퀀스를 갖는다. 추가 870논리 프레임, 지역 합계 1,350프레임이다. 전체 게임은 40보스·154행동·5,280논리 프레임이며 서역사막 10·혈마전 11·제갈 10, 총 31행동이 기본 그림을 사용한다.

실제 kit의 29추가 접촉마다 독립 6단계/5시점 시퀀스를 연결한다. 준비·힘 싣기·접촉·후속·회수·대기로 구성하며 적합한 기본/기존 특별 자세를 재사용한다. 같은 순간 암기 3발은 세 번 연격으로 만들지 않았다. 연청 세 번째, 월령·청비·노개·송월 두 번째 타격은 각각 별도 접촉 자세를 선택한다. 석문 석벽 명령은 활성화 후 복귀하고 실제 `guardTime`에서만 기존 방패 수세를 유지한다. 피해·CC·AI·접촉 시간·투사체 수·저장은 바꾸지 않았다.

새 선택 125물리 자세를 8아틀라스에 포장했다. 870장을 새로 그렸다는 뜻은 아니다. 준비/회수/READY 재사용을 프레임별 `choreographySource`로 기록한다. 기본 대기와 290논리 READY를 공유하고 원본별 공통 제작 계수로 종횡비를 유지한다. 곽기의 든 렌치는 무기 끝을 포함한 높이가 아닌 명시한 정수리–장화 355px로 시트 전체를 교정했다. 자세별 맞춤 축소는 없다. 고정 게임 배율 0.225·명시 발점·최소 32px 투명 여백·모든 기본/특별 자세를 포함하는 보스별 고정 HP바를 사용한다.

정면/후면 찌르기는 원근으로 짧게, 측면은 길게 그렸다. 곡괭이 날 중복·렌치 여분 팔·단도 손바뀜·검 방출 손·잘린 긴 무기는 탈락/보강 선택으로 교정했다. 미채택 후보와 원본/프롬프트를 보존한다. 초기 뷰어의 색 배경처럼 보인 부분은 숨은 RGB였고 실제 알파 합성은 투명했다. 전 GPU나 모든 관절의 완벽함을 인증하지 않는다.
