# 전투 가독성·맵 기연·후반 이동 쉼터

2026-10-21. 사용자 승인 추천 2·3·4번을 함께 구현했다. 기존 협공과 밸런스 수치는 유지하며, 실제 공격 정보를 읽는 표시와 정비 구간의 선택을 확장한다.

## 전투 표시

- 위험 장판의 실제 반경에 어두운 밑선·밝은 외곽선·안쪽 눈금을 겹쳐 배경과 아군 효과에서 구분한다. 눈보라 중심의 온기는 옥색 외곽선과 바깥 눈금으로 구분한다. 복잡한 이동/통로형 기믹은 기존 전용 도형을 유지한다.
- 일반 적의 실제 준비 동안 근접 부채꼴, 돌진 통로, 준비 사격 방향, 설치 반경을 표시한다. 이미 있는 공격 프로필·조준·시계를 사용한다. 사격 선은 방향 안내이며 탄의 전체 사거리/충돌 폭을 뜻하지 않는다.
- 준비 중인 원거리/설치 적이 실제 카메라 바깥에 있을 때 가장 가까운 최대 여섯 적의 방향을 가장자리 갈매기표로 표시한다. 대기 중인 적이나 미래 패턴을 미리 드러내지 않는다.
- 준비/공격 적 2명 이상, 적 탄 5개 이상 또는 효과 8개 이상이면 아군 장식 효과의 투명도를 55%, 아군 탄을 70%로 줄인다. 접촉 피드백과 적 탄은 유지한다. 피해·판정·효과 수명·공격 시간은 바꾸지 않는다.
- 표시 순서는 아군 장식 5001 → 적 탄 5003 → 위험 예고/경계 5004 → 화면 밖 방향 5006 → 인물 HP/상태 5007이다. 보스 준비 도형도 5004로 올린다. 두 그래픽 객체를 재사용하고 장면 종료 때 해제한다.

## 맵 기연

각 정비 구간에 `기연` 표식을 추가했다. 가까이 이동한 뒤 E로 열며, 표식 선택으로 실제 자동 접근도 가능하다. 대화 전에 멀리서 보상을 받을 수 없다.

| 종류 | 비용 | 보상 |
| --- | --- | --- |
| 약초 실험 | 현재 최대 HP의 18%, 올림 | 소형 회복약 2개 |
| 떠돌이 서생 | 18/22/26/30전 | 수련 비급 1개 |
| 버려진 보급함 | 10/13/16/19전 | 강화 재료 3개 |

비용·보상을 선택 전에 보여 주며, 약초 비용을 낸 뒤 HP는 1 이상 남아야 한다. 부족하면 사유와 함께 거래 버튼이 비활성화된다. 보상은 기존 미수납 물품으로 지급하며 가방에서 수납/사용한다. 출발할 때 미수납 확인이 유지된다.

`거래하기`와 `그냥 지나가기`만 최종 선택이다. 닫기는 선택을 소모하지 않는다. 여정 ID·웨이브·지역으로 종류를 결정하므로 이동·대화·새로고침으로 다시 뽑을 수 없다. 전투 RNG를 소비하지 않는다. 한 쉼터에서는 한 번만 지급/지불하며 선택을 저장한 뒤 완료 상태에 초점을 옮긴다. 닫으면 기연 표식으로 초점을 돌린다.

저장에는 선택적 `run.restEvents`만 추가한다. 4·9·14·19의 중복 없는 과거/현재 선택만 검증하며, 필드 없는 이전 저장도 그대로 읽는다. Store의 대화/거리 제한과 도메인의 거리/상태/비용/중복 검사를 모두 거친다. 선택은 기존 저장 완료 확인 경로를 사용한다. 실제 사용자 저장을 검사 데이터로 바꾸지 않는다.

## 후반 이동 쉼터

4·9·14·19 모두 같은 이동·접근 거리·서비스·출발 확인 규칙을 사용한다. 9·14·19는 현재 지역의 기존 전투 배경에 쉼터 영역과 길 표식을 덧그리며 10지역별 이름·색·NPC 배치를 적용한다. 첫 4웨이브는 기존 마당 원화를 유지한다. 공통 의원·상인·대장장이 원화와 기연의 코드 도형을 재사용하며 신규 지역/NPC 원화 제작과 구분한다.

WASD 이동, E 상호작용, I 가방, Tab/Enter 표식 탐색을 지원한다. 표식 선택은 원격 서비스를 실행하지 않고 실제 이동을 시작한다. 수동 입력은 자동 이동을 취소한다. 대화/가방/일시정지에서는 이동을 막고 전투 시계·피해·자원 변화는 멈춘다. 의원·상인·강화·출발의 비용/재고/다음 보스 정보는 기존 실제 규칙을 따른다. 선택 그림 로딩 실패는 원형 대체 그림과 표식으로 조작할 수 있으며 필수 서비스 입력을 막지 않는다.

## 검증과 경계

[이번 실행 결과·캡처](verification/rest-clarity-v1/README.md). 자동 상태/배치 검사, 실제 입력에 따른 저장 검사와 캡처 시각 검토를 구분한다. 10지역×4정비 도메인 검사는 지역별 접근 가능성에 대한 증거이며 40개 맵 모두의 수동 시각 검토를 뜻하지 않는다. 혼잡 전투 장면은 합성 배치로 렌더링을 확인하며 인간 생존율·장시간 성능 측정으로 해석하지 않는다. 새 기연 시나리오와 보상 밸런스의 인간 플레이 검토, NPC 전용 작업 모션, 사망 원인/기록 및 개인 Linux/Docker 서버 설치는 후속이다.
