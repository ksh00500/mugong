# 죽림 방향별 적 원화

죽림 7종의 방향별 원화를 제작하고 게임의 지역 5 경로에 적용했다. 로컬 빌드의 최종 검증 결과는 [검증 기록](verification/bamboo-family-v1/README.md)과 [검증 요약](verification/bamboo-family-v1/summary.json)에 기록한다. 원격 배포는 진행하지 않았다.

| 슬롯 | 인물             | 무기·동작 기준                                                         |
| ---- | ---------------- | ---------------------------------------------------------------------- |
| 0    | 죽림 단도 암살자 | 오른손 단도, 위·뒤 준비 → 아래·앞 베기 → 낮은 마무리                   |
| 1    | 죽림 암기수      | 오른손 암기 세 개, 어깨 준비 → 빈손 발사 → 허리에서 보충               |
| 2    | 죽림 함정꾼      | 왼손 장치 유지, 오른손 조작 → 목표 방향 배치 지시                      |
| 3    | 죽엽살수 청비    | 오른손 암기 투척, 왼손 예비 단도 방어                                  |
| 4    | 취봉객 노개      | 한 개의 긴 대나무 봉을 양손으로 잡아 내려 휘두르기, 술병은 허리에 고정 |
| 5    | 청죽검객 연청    | 오른손 직검, 뒤·위 준비 → 아래·앞 베기 → 회수                          |
| 6    | 죽림은사 송월    | 오른손 부채 뿌리 잡기, 아래·앞 쓸기 → 회수                             |

각 인물은 정면·정면 오른쪽·오른쪽·후면 오른쪽·후면의 다섯 원화 시점을 갖는다. 좌우 반전을 더해 전투의 여덟 방향을 표시한다. 각 시점은 대기·걷기 세 장·작은 피격·사망·공격 준비 두 장·타격/발사·마무리·회수·복귀의 열두 원화로 구성한다. 420장의 고유 그림을 35개의 전달 시트로 패킹했다.

원화는 내장 `image_gen.imagegen`으로 제작한다. 프롬프트와 원본 경로는 `source/bamboo-family-v1/provenance.json`에 보존한다. 봉은 무기와 몸이 들어갈 공간을 확보하기 위해 이동·공격 원화를 각각 여섯 장씩 나눠 제작한다. 실제 생성 배열이 요청 배열과 다르면 원화를 왜곡하지 않고 명시적인 원본 칸 좌표를 기록한다.

내보내기는 선택한 원본 RGBA를 1:1로 복사하고 인물별 고정 칸과 최소 32픽셀의 투명 여백을 둔다. 게임은 모든 프레임에 같은 0.225 배율을 적용한다. 몸·머리 크기나 무기 손이 잘못 나온 후보는 원화를 다시 제작하며, 무기 전체 경계에 맞춘 칸별 축소로 숨기지 않는다.

접지점은 원본 좌표로 저장하고 검수한다. HP바는 같은 인물의 가장 높은 살아 있는 원화 위로 고정 여유를 확보한다. 새로운 원화는 메시 변형 없이 재생하며 기존 보스의 CC·경직 면역과 공격 우선 표시 규칙을 유지한다.

검증은 자동 검사와 시각 검토를 구분한다. 원본 provenance·고유 그림·투명 여백·좌표와 단위 검사를 진행하고, 독립 Playwright 컨텍스트에서 Canvas/WebGL 및 모션 감소 설정의 모든 인물·방향·상태, 실제 일반 적 공격, 보스 연타 접촉 시점을 확인한다. 세 화면 크기의 로컬 빌드에서도 전투와 검토 페이지를 검증한다. 사용자 저장 데이터는 사용하지 않는다.

보스의 여러 기술은 인물별 대표 공격 원화를 접촉 시점에 맞춰 재생한다. 모든 개별 기술에 별도의 신규 원화가 생기는 범위는 아니다. 투사체·함정·전투 효과는 게임 시스템이 별도로 표시한다.

검토 중 노개의 준비 자세에 두 개의 봉이 그려진 후보, 송월의 잘못된 손 부채, 청비의 암기가 단도로 바뀐 후보는 제외했다. 노개 앞쪽 대각선의 발 기준은 가장 낮은 한쪽 발에 쏠리지 않도록 양발 중심으로 직접 기록했다. 청비 후면 중간 걷기의 큰 체격은 원본 체격을 유지하는 별도 교정으로 해결했다. 선택은 자세별 파일·칸으로 명시하며 다른 정상 자세를 통째로 덮어쓰지 않는다.

[로컬 검토 화면](http://127.0.0.1:5173/art/bamboo-family-v1/review.html)에서 인물·대기/걷기/공격/피격/사망과 여덟 방향을 비교하고, 일시 정지와 다음 프레임으로 확인할 수 있다.
