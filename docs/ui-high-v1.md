# UI·UX 높음 항목 수정

2026-10-20. 사용자 요청에 따라 감사 U06–U20의15항목을 구현·검증하고 `dist-ui-high-v1`을 로컬 http://127.0.0.1:5205/ 에 적용했다. 기준 커밋은 d927211599eeed67d65214278501eed0e37a2718이며 작업 브랜치는 `codex/ui-high-v1`이다. U01–U05의 기존 수정과 보통 U21–U24를 구분한다.

## 적용 내용

| 감사 | 구현 |
| --- | --- |
| U06 | 가방의 선택 물품에 따라 사용/착용/수납의 강조를 정한다. 상인은 목록에서 비교한 물품 하나를 구매하고, 정비의 출발은 주 행동으로 남긴다. |
| U07 | 전투 제한·저장 중·체력 가득 참·금전/재료/공간 부족·품절·모집 미선택을 행동 근처에서 안내한다. 비활성 버튼은 흐리게만 처리하지 않는다. |
| U08–U09 | 이름 입력·언어/흔들림·강화 대상·창고 검색/필터·비교 선택에 공통 입력 소재·경계·초점을 사용한다. 제목은 제목 서체, 설명과 수치는 본문 서체/줄높이와 고정 폭 숫자 역할을 사용한다. 작은 화면은 소유 컴포넌트의 밀도를 조정한다. |
| U10–U12 | 선택 물품의 이름·칸수·위치·효과/비교·행동 순으로 정리하고 하단 반복 정보를 없앤다. 수납/이동은 실제 목적지를 명시한다. 창고와 획득 물품은 보관 행 수와 중첩 총개수를 별도로 표시한다(영문은 stacks/items). |
| U13 | 장비 증감/피해/회복은 소수1자리, 공격 간격/배율/재사용은 소수2자리까지 표시하고 불필요한 `.0`을 제거한다. 저장 값과 전투 계산은 반올림하지 않는다. |
| U14 | 상인에서 기존 장비 비교 컴포넌트로 현재 연결/착용과 예상 효과·증감·비교 대상 무공을 확인한다. 구매 후 획득 물품으로 들어가는 기존 규칙과 가격/재고는 유지한다. |
| U15 | 실제40보스 키트에서 서로 다른 대응을 우선한 공격 유형2개를 추출해 다음 보스와 권고를 표시한다. 새 패턴/AI/수치를 만들지 않는다. 정비 설명은 내부에서 스크롤하며 버튼과 사유를 유지한다. |
| U16–U17 | 부채는 무공 선택, 리본은 현재 방어, 작은 메달은 비활성 무공의 재사용 확인으로 역할을 나눈다. 활성 붙잡힘/동결/출혈/중독/화상/회복량 감소/둔화/냉기를 실제 남은 시간·냉기 중첩으로 표시하고 종료된 상태는 제거한다. |
| U18 | 설정 창과 진입 이름을 `설정`, 소리 항목을 `음소거 · 사용 중/해제`로 정리한다. 언어/표시/음량 저장과 키보드 탭 전환을 유지한다. |
| U19 | 그림 다운로드 수와 전투 자료/장면 구성을 구분한다. 자료·장면 구성은 수치 없는 진행 표시이며 임의 진행률을 채우지 않는다. 움직임 감소에서는 이동 애니메이션을 생략한다. |
| U20 | 그림·전투 자료·장면 구성·그래픽 연결 실패를 구분한다. 실패한 ES 모듈을 브라우저가 기억하는 문제 때문에 전투 자료 실패의 재시도는 문서 재진입을 사용한다. 저장 열기 실패/쓰기 실패 안내를 나누고 원본 내보내기→최신 검증 사본 확인을 설명한다. |

새 라이브러리나 원화, 전투/밸런스 규칙, 저장 형식은 추가하지 않았다. 복구는 마지막 커밋과 같은 사본만 허용하는 기존 정책을 유지한다. 실제 사용자 저장은 테스트하지 않으며 독립 브라우저 컨텍스트의 검증 데이터만 사용한다.

## 검증과 실행

[검증 기록](verification/ui-high-v1/README.md)에 이번 실행과 한계를 기록한다. 타입/단위/브라우저 검사와 직접 시각 검토를 구분한다. 기존 큰 전투 mount 청크 경고는 남으며, 로딩 안내 개선을 다운로드/장면 구성 시간 단축으로 주장하지 않는다.

공개 배포와 main 병합은 별도다. 보통 U21–U24의 결과/빈 상태, 전체 미술 마감과 로비 원본 해상도 점검은 이 문서의 완료 범위에 포함하지 않는다.
