# 한눈에 보는 UI와 실제 그림 정렬 · 2026-09-29

가방 전체를 탭으로 나누던 구성을 제거했다. 무장 4×7, 일반 10×8, 선택 물품 정보, 전리품 또는 창고, 정리판을 한 작업 공간에 함께 표시한다. 공간이 좁으면 그림과 간격을 줄이고 레이아웃을 바꾼다. 화면 전체를 transform으로 축소하거나 필수 행동을 잘라 숨기지 않는다. 많은 물품은 해당 영역 안에서 페이지로 이동한다. 물품 정보/무인 정보 전환은 보조 정보만 바꾸며 가방과 전리품은 계속 보인다.

## 이미지와 실제 칸의 관계

기존 재질 그림에는 장식 테두리와 재봉선이 포함되어 있어 실제 패널과 칸 경계와 다른 위치에 보였다. 한지·옥·천·가죽을 테두리 없는 새 래스터 재질로 생성했다. 패널과 칸 경계는 HTML의 실제 좌표로 그린다. 물품 이미지는 점유 영역 안에서 비율을 유지하며 가운데 표시하고, 시트 이웃 그림은 노출하지 않는다. 각 칸의 가로·세로와 물품 시작 좌표를 자동 검사에 추가했다. 장식 질감을 실제 경계로 착각하는 문제와 정사각 칸이 조금 찌그러지던 문제를 함께 수정했다.

- 새 원본: [재질 PNG](../public/art/ui/materials-v2.png), [효과 PNG](../public/art/ui/effects-v2.png). 런타임은 같은 이름의 손실 없는 WebP를 쓴다.
- 생성 도구와 짧은 프롬프트: [그래픽 자산 기록](graphic-assets-v1.md#테두리-없는-재질과-담백한-효과--v2).
- 수납은 빈 공간을 찾아주는 `수납` 버튼, 선택 후 빈 칸 클릭, 드래그, 키보드로 가능하다. 회전·착용·사용·창고 이동·정리판 폐기 확인 흐름을 유지했다.
- 출전과 명부, 설정의 언어와 표시 옵션도 함께 보인다. 긴 무인 이름은 말줄임과 원문 title을 사용한다.
- 효과는 짧은 검흔, 작은 타격 조각, 옅은 방어 표시, 먼지로 교체했다. 화염·확대 폭발·회전 오라를 줄였다. 공격 범위·판정·피해량은 그대로다.

## 검증

자동 검사와 시각 검토는 구분한다. TypeScript/Vite 빌드 성공, 단위 검사 48개 통과. 전체 로컬 브라우저 52개 중 50개 통과, 공개 주소 전용 1개 제외, 작은 영어 로비의 남은 중복 여백 1개 실패를 수정했다. 수정 후 한국어·영어 반응형 검사 2개 모두 통과했다. 한국어 20개 크기×9개 상태와 영어 5개 크기×5개 상태에서 경계·스크롤·문구·버튼 겹침 실패가 없었다.

가방 1440×900, 1366×768, 1093×614, 800×600, 390×600에서 두 격자와 전리품·정리판이 함께 표시되고 수납·폐기 확인·닫은 뒤 초점 복귀가 동작했다. 드래그·회전·착용·소모품 사용 조건·창고 이동·저장 복원·성장 입력 보호도 기존 회귀 검사로 확인했다. 테스트 저장은 독립 Playwright 컨텍스트에만 기록했다.

직접 시각 검토에서는 1093×614 가방에서 그림 속 장식 테두리가 실제 칸과 따로 보이지 않는지, 작은 물품 그림과 선택 정보의 위치, 전리품과 정리판의 동시 표시를 확인했다. 실제 공격 캡처에서 작아진 검흔과 타격 효과를 확인했다. 작은 세로 창의 로비 캡처도 검토했다. 모바일 터치 전투 지원이나 서비스 출시 품질·접근성 인증을 뜻하지 않는다.

공개 연결에서 기존 큰 파일의 수신이 68초 이상 걸리는 경우를 발견했다. 원본·기존 WebP는 보존하고 `art/delivery-v1/`에 품질 90 전송용 WebP를 만들었다. 해상도와 alpha는 동일하며 RGB는 손실 압축이다. 사용 중인 그림 10개의 총 전송량은 11,789,984에서 3,229,706 bytes로 약 73% 줄었다. UI·로딩·실패 재시도·저장 복원 관련 13개 재검사를 모두 통과했다. [파일별 크기와 투명도 검사](verification/glance-v2/delivery-sizes.json), [전송용 그림 적용 후 검사](verification/glance-v2/delivery-result.json)에 기록했다.

공개 반영과 공개 주소 검사 결과는 [Daytona 배포 기록](daytona-deployment.md)에 둔다. 재질과 효과 파일 및 전송 경로를 변경해 이전 이미지 캐시와 구분한다. 사용자의 실제 저장은 변경하지 않는다.

무협 전투 HUD까지 적용한 최종 상태에서 로컬 전체 54개 통과, 공개 전용 1개 제외, 실패 0개를 확인했다. [최종 결과](verification/combat-hud-v2/full-result.json)와 [전투 HUD 기록](combat-hud-v2.md)을 따른다.
