# 가방 연결·전투 후 정리 흐름

2026-10-01. 현재 로컬 구현과 검증 기록.

## 무공과 무기의 연결

전투 중 가방을 열면 전투가 멈춘다. 무장 가방에 이미 수납한 호환 무기를 선택하고 무공 아래의 `연결` 버튼으로 바꿀 수 있다. 연결된 선택 무기는 `연결됨`으로 표시하고, 무공 아이콘 옆에는 연결 무기 그림을 표시한다. 이름은 아이콘의 안내와 접근성 이름으로 확인한다.

이전에는 전투 중 가방에서 연결 변경까지 차단했다. 이제 연결만 허용하고 물품 이동·사용·착용·자동 정리는 전투 후에 허용한다. 배우지 않은 무공, 일반 가방의 무기, 호환되지 않는 무기는 연결하지 않는다. 열린 가방 밖에서 전투 중 연결 명령을 보내면 거부한다. 한 무기를 여러 호환 무공에 연결하는 기존 규칙은 유지한다.

연결 결과는 저장 완료 후 성공 문구로 알린다. 저장에 실패하면 현재 결과를 보존하고 재시도로 저장한다.

## 전투 종료에서 다음 전투까지

1. 마지막 적 처치 후 웨이브 결과와 전리품을 저장한다.
2. 저장이 끝나면 별도 전투 종료 창을 거치지 않고 가방을 연다. 성장 선택이 남아 있다면 성장 선택을 마친 뒤 열린 가방으로 돌아온다.
3. 개별 수납·사용·착용 또는 `자동 정리`를 실행한다.
4. 가방 하단의 다음 웨이브 버튼으로 진행한다. 20웨이브는 `귀환`이다.

정리판에 남긴 물품은 수납하거나 폐기 확인을 마친 뒤 진행한다. 지면에 전리품이 남아 있으면 다음 진행 직전에 두고 갈지 확인하고, 취소하면 같은 가방으로 돌아온다. 정비 웨이브의 상점·치료·진행 화면은 유지한다.

전리품 단계에서 재실행하거나 로비에서 여정을 재개해도 가방으로 돌아온다. 전투 종료 저장이 실패하면 가방을 자동으로 열지 않고 저장 복구를 먼저 표시한다. 재시도에 성공하면 같은 전리품을 보여준다. 이전 생존 기록으로 되돌리지 않는다.

## 자동 정리

복잡한 최적화 없이 기존 `수납` 행동을 한 번에 실행한다.

- 무장·일반 가방 각각의 기존 물품을 면적이 큰 순서로 앞쪽 빈칸부터 배치한다. 회전 방향과 보관 영역은 유지한다.
- 기존 물품을 모두 배치할 수 있을 때만 해당 가방의 좌표를 바꾼다. 실패하면 기존 배치를 유지한다.
- 전리품·정리판 물품을 순서대로 수납한다. 무기는 무장 가방, 다른 물품은 일반 가방으로 넣는다. 중첩 물품은 기존 수납 규칙대로 한 개씩 꺼낸다.
- 수납 후 같은 기준으로 배치를 정돈하므로 다시 눌러도 배치가 계속 바뀌지 않는다.
- 공간이 부족하면 남은 물품과 개수를 원래 영역에 보존한다. 자동 폐기·사용·착용·창고 반출은 하지 않는다.
- 기존 물품 ID·전체 수량·연결·착용 장비를 보존하고 결과를 한 번 저장한다.

클릭·키보드로 실행할 수 있으며 전투 중에는 비활성화한다. 작은 화면에서도 두 격자·무인 정보·선택 정보·전리품/창고·정리판과 진행 버튼을 함께 표시한다. 한국어·영어·일본어·중국어 간체·번체 문구를 제공한다.

## 검증

검증용 저장은 Playwright 독립 브라우저 컨텍스트에만 넣는다. 사용자 저장은 변경하지 않는다.

- 도메인·저장 단위 검사: 16개 파일, 227개 통과. 연결 조건, 정리 반복 안정성, 물품 수량·ID·연결 보존, 가득 찬 가방의 잔여 수량, 저장 실패/재시도를 포함한다.
- 브라우저 자동 검사: 관련 9개 파일의 서로 다른 64개 사례 통과. 전체 브라우저 테스트 모음이 아닌 이번 변경과 관련된 회귀 검사다. 마지막 배치 검사는 24개를 실행해 모두 통과했다. 실제 캔버스 클릭으로 처치, 성장 후 가방 복귀, 호환 무기 연결과 저장, 자동 수납과 수량 보존, 잔여 전리품 진행 확인·취소, 최종 보스 처치·귀환, 드래그·착용·사용·창고, 다섯 언어를 검증했다.
- 배치 자동 검사: 1440×900·1366×768·1093×614와 추가 1920×1080·1000×620·1000×500·800×600·390×600에서 가방 핵심 영역과 버튼의 화면 경계·겹침·텍스트 넘침을 검사했다. 기존 전체 화면 가방 검사에서는 1024×768·390×844·602×546도 확인했다.
- 직접 시각 검토: 연결·정리 후 캡처의 1093×614·1366×768·1440×900 및 영문·일문 연결 상태와 1000×500 요약을 읽어 확인했다. 영문 `Linked`의 글자 단위 줄바꿈, 낮은 창의 선택 정보/전리품 겹침, 긴 입문 상태 문구의 무인 정보/전리품 겹침을 수정했다. 사용자 조작은 Playwright로 자동 수행했으며 별도 신규 사용자 관찰 조사는 하지 않았다.
- 가방이 로딩보다 먼저 열리는 경우 새로 생성된 뒤쪽 HUD에도 모달 격리를 적용했다. Shift 설명은 열린 가방에서만 나타나며, 가방을 닫으면 원래 조작 또는 전투 HUD의 가방 버튼으로 초점을 돌린다.

최종 `npm run build` 통과. TypeScript 검사와 Vite 프로덕션 빌드를 모두 마쳤다. 로컬 개발 화면은 기존 `http://127.0.0.1:5173/`에서 변경을 반영한다.
