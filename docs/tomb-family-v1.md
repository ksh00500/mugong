# 고묘 방향별 적 원화

고묘의 일반 적 세 종류와 보스 네 명을 제작하여 게임에 적용했다. 420장 원화와 35개 무손실 WebP 시트를 로컬 빌드에서 검증했다. 사용자 저장은 변경하지 않았으며 원격 배포는 하지 않았다.

| 인물 | 무기와 공격 기준 |
| --- | --- |
| 도굴 함정꾼 | 왼손 곡괭이 유지, 오른손 함정 장치 투척·빈손 발사·보충 |
| 창 수문장 | 하나의 창 축을 양손으로 잡고 목표 방향으로 찌르기·회수 |
| 쇠뇌병 | 오른손 방아쇠, 왼손 앞부분 지지, 조준·발사·작은 반동·장전 |
| 도굴두목 적호 | 한 자루 곡괭이를 양손으로 들어 아래·앞으로 내려찍기 |
| 묘지기 석문 | 왼팔 방패 유지, 오른손 망치 들어 내려찍기 |
| 기관장인 곽기 | 오른손 스패너로 아래·앞 쓸기, 왼팔 기관 장치 유지 |
| 고묘후인 월령 | 오른손 직검 위·뒤 준비 → 아래·앞 베기 → 회수 |

인물마다 직접 그린 다섯 시점과 시점마다 열두 자세, 총 420장의 고유 원화를 채택했다. 좌우 반전으로 전투의 여덟 방향을 표시한다. 자세는 대기·걷기 세 장·작은 피격·사망·공격 준비 두 장·타격/발사·마무리·회수·복귀다.

원본 RGBA와 그림 비율을 유지하고, 인물별 고정 칸에 최소 32픽셀 투명 여백을 더한다. 모든 프레임의 게임 배율은 0.225로 같으며 무기 경계에 맞춰 몸을 축소하지 않는다. 생성 결과의 배열이 요청과 다르면 실제 원화 칸 좌표를 명시한다. 잘못된 손·무기 구조·관절·공격 방향은 원화를 다시 제작하여 해당 자세만 선택한다.

접지점은 원본 좌표로 저장하고 시각 검수한다. HP바는 같은 인물의 살아 있는 자세 전체 위에 고정 여유를 둔다. 보스는 대표 공격 원화를 각 기술의 접촉 시점에 맞춰 재생한다. 각 기술별 신규 동작 전체를 별도로 만드는 범위는 아니며, 투사체·함정·전투 효과는 게임 시스템이 표시한다. 사망은 한 자세를 페이드하며 좌우 반전에서는 무기 손도 화면상 반전된다.

원본·프롬프트·선택 기록은 [원화 제작 기록](source/tomb-family-v1/README.md)에 보존한다. 잘못된 손과 관절, 창 축, 준비/타격 순서 및 생성 시 몸 크기가 바뀐 후보는 재제작하여 필요한 자세만 채택했다. 수문장의 접지점은 빨간 창술을 발로 판단하지 않도록 발바닥 좌표를 별도로 검수했다.

전체 단위 테스트 1,278개와 타입 검사·프로덕션 빌드가 통과했다. 브라우저 검사 8개는 Canvas/WebGL 및 움직임 감소 설정의 7,840개 상태·640개 보스 접촉 시점, 일반 적 24개 실제 발사/피해 사례, 세 해상도의 프로덕션 화면을 확인했다. 1440×900·1366×768·1093×614에서 고묘 원화 35개가 로드되고 브라우저 오류가 없었다. 자동 검사와 직접 시각 검수는 [검증 자료](verification/tomb-family-v1/README.md) 및 [완료 수치](verification/tomb-family-v1/summary.json)에 구분하여 기록했다.

[로컬 8방향 동작 검토](http://127.0.0.1:5173/art/tomb-family-v1/review.html)에서 인물·동작을 선택하고 각 프레임을 확인할 수 있다. 이번 적용으로 10개 지역의 적 원화 경로가 모두 방향별 새 원화로 교체됐다.
