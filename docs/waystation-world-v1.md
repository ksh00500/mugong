# 4웨이브 · 걸어 다니는 강호 쉼터

2026-10-20. 사용자가 NPC에게 가까이 가서 상호작용하는 방식을 선택했다. 기존 세 서비스의 규칙을 유지하면서 **첫 정비인4웨이브**를 실제 이동 맵으로 전환했다. 9·14·19웨이브는 기존 정비 카드를 유지한다. [검증 기록](verification/waystation-world-v1/README.md).

## 플레이 흐름

1. 3웨이브 전리품을 정리하고 다음으로 진행하면4웨이브 쉼터에 들어간다. 기존 무인의 원화·이동/방향 애니메이션으로 마당을 걷는다.
2. `WASD`로 이동한다. NPC와 출구의 표식은 마우스와 native Tab/Enter로 선택할 수 있다. 멀리서 선택하면 해당 대상 앞까지 실제로 걸어가고, 수동 이동 키를 누르면 자동 이동을 취소한다. 순간이동은 하지 않는다.
3. 인물/출구와 발 좌표 거리145 이내에서 `E`를 누르거나 가까운 대상을 선택하면 대화/확인 창을 연다. 멀리서는 치료/구매 창을 열 수 없다. NPC 발 주위에는38 크기의 고정 충돌 여유가 있다.
4. 의원은12전/최대45 회복, 대장장이는12전+재료2/장비 최대2회 강화, 상인은 실제 저장 재고·가격·장비 비교를 사용한다. 저장 명령이 성공한 뒤 완료 문구를 보여준다. 대화·가방·일시정지 중 이동과 공격을 차단한다.
5. `I` 또는 가방 버튼으로 물품을 관리한다. 첫 쉼터에서는 Tab을 NPC 표식의 키보드 접근에 사용하므로 가방 단축키 표시도I로 바꾼다. 대화를 닫으면 선택했던 표식으로 초점을 돌린다.
6. 오른쪽 아래 출구에서 다음 보스의 실제 행동·대응·체력을 확인한다. 출발을 눌러야5웨이브를 시작한다. 미수납 물품은 기존 확인 창을 거친다. 출구에 닿는 것만으로 전투가 시작되지는 않는다.

쉼터 이동은 고정340 속도이며 대각선도 같은 거리/초다. 방향은 실제 이동 벡터를 사용하고 마당 경계를 넘지 않는다. 전투 elapsed·적/탄·공격·궁극기·자원은 정비 이동으로 진행하지 않는다. 공격 키를 눌러도 정비 상태에서는 공격을 생성하지 않는다. 위치는 기존 fighter x/y와 체크포인트 저장을 사용하며 저장 형식을 추가하지 않는다. 대화와 자동 이동 목표는 일시적 UI 상태이고 저장하지 않는다.

## 화면과 원화

새 맵은 마당을 비워 두고 상단에 약방·노점·대장간, 오른쪽 아래에 출구를 배치했다. 인물은 기존 대화 초상과 같은 정체성의 독립 전신 PNG다. 명시된 원본 알파 하단을 발 원점으로 사용하고, NPC 세 명의 표시 높이는95 월드 단위로 고정한다. 플레이어를 원화에 맞춰 임의로 확대하지 않는다.

내장 ImageGen을 사용했고 [전체 프롬프트·참조·생성 파일](source/waystation-world-v1/prompts.json)과 [크기·발 원점·SHA](verification/waystation-world-v1/art.json)를 남겼다. 원본 PNG 바이트·비율을 유지하며 기존 정비 원화/제작 자료는 보존했다. 새4장 약8.51MB는 일반 Git/실행 manifest에 추가한다.

그림은 첫 쉼터 진입 때 선택적으로 요청하고 초기 로비/전투의 필수 그림 수에 더하지 않는다. 요청 실패 때는 단색 마당/간단한 인물 표식으로 이동과 거리 상호작용을 유지한다. 다운로드를 기다리며 서비스를 잠그거나 전체 게임 실패 화면으로 바꾸지 않는다. 원화가 늦어도 대상 이름/역할은 표시한다.

Phaser는 마당/인물/플레이어와 발 깊이를 그린다. DOM은 실제 Canvas 표시 영역을 ResizeObserver로 측정해 이름표와 이동 버튼을 같은 좌표에 둔다. 화면 전체 transform 배율을 사용하지 않는다. 동작 감소는 기존 캐릭터 설정과 이름표 전환에 적용하며 별도의 반복 맥동은 없다.

## 구현 경계와 후속

이번에는 NPC의 정지 전신과 플레이어 이동을 구현했다. NPC 걷기/망치질/립싱크, 기연의 무작위 등장·보상·대화 분기, 지역별 후반 쉼터 확장은 아직 없다. 상호작용 지점과 서비스 선택을 분리했으므로 이후 기연 대상/사물 지점을 같은 거리·입력 흐름으로 추가할 수 있다. 이번에 기연 보상을 임의로 추가하거나 기존 난이도를 변경하지 않았다.

`src/domain/waystation.ts`는 첫 쉼터 판정/지점/거리/이동을, `GameStore`는 접근·대화 잠금·임시 이동 목표를 소유한다. `WaystationScenery`는 선택 로딩과 원화 표시, `WaystationWorld`는 이름표·접근·대화 창을 맡는다. 기존 `PrepStop`에서 의원/대장장이/출구 부분을 재사용하고 상점은 `RestMarket`을 사용한다.

검증용 HTML trace가 Vite 감시 대상에 들어가 페이지가 다시 로드되는 로그를 확인해 `test-results*`, 검증 산출물, 로컬 임시 폴더를 감시에서 제외했다. 실제 게임 소스의 HMR은 유지한다.

## 재실행

개발 서버5225에서 `npx playwright test --config playwright.waystation.config.ts`를 실행한다. 독립 브라우저 저장만 사용하며 브라우저에 소스 모듈을 주입하지 않아 컴파일 빌드에서도 같은 테스트를 쓴다. `MUGONG_REST_URL`, `MUGONG_REST_MODE`, `MUGONG_REST_PROOF`로 주소·실행 증거를 분리한다. 이전 정비 카드 검사는9웨이브를 사용하도록 fixture를 갱신했고,4웨이브는 새 실제 이동 검사에서 담당한다.
