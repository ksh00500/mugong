# 개인 레이드 공통 효과 교정과 무공 동등성 조사

후속2026-10-24: 아래 감사 당시 남았던 당문·제갈의 개별 행동은 [후속 교정](tang-jegal-parity-v1.md)에서 구현·검증했다. 다른6무공과 향후 잡몹 전독은 남아 있다. 아래는 공통 효과 작업 당시의 범위를 보존한다.

2026-10-24. 온라인 개인 무인은 강호와 별도인 비무 전투 엔진으로 레이드에 출전하고 있었다. 연결 무기 판정 이후에도 타고난 특성과 일부 장비·보조 효과가 누락돼, 같은 무인의 설명과 실제 효과가 달랐다. 이번에는 공통 효과를 교정하고8무공의 개별 동작 차이를 조사했다. **개별 무공의 모든 단계/궁극이 강호와 같아진 것은 아니다.**

## 공통 효과

강호와 개인 레이드는 이제 같은 `fighter-combat-values`의 기본 공격력·이동 속도·받는 피해 수식을 사용한다. 근력·기민, 연결 무기, 착용 패옥·신발·도포, 배운 보조 무공·철벽을 반영한다. 강호의 수치는 추출 전과 같고 표준 체험·친선/순위전은 기존 별도 규칙을 유지한다. 개인 이동 예측도 서버와 같은 속도를 사용한다. 실제 공격 배율/모양은 아직 아래 개별 동작 차이를 가진다.

| 타고난 특성 | 개인 레이드에서 확인한 동작 |
| --- | --- |
| 불굴 | 층 전투마다 한 번 HP1 생존·0.6초 무적, 실제 잃은 HP만 피해 기록. 다음 사망은 기존 유품/영구 사망 경로 |
| 승부사 | HP35% 미만 기본 피해20% 증가 |
| 침착 |5초 무피해 후 충전20% 증가, 실제 피해로 초기화 |
| 재빠른 손 | 유효한 무공 전환 후 다음 기본25% 증가,4초 재사용 |
| 반격 본능 | 개인 무당 반격 성공 후 다음 기본35% 증가 |
| 유연한 몸 | 회피 후 보너스를 다음 기본 접촉에서 소비. 현재 레이드 보스는 제어 면역이므로 경직을 부여하지 않음 |
| 집중력 | 같은 적의 서로 다른 세 기본 공격 중 세 번째15% 증가. 같은 공격의 중복 접촉은 추가 카운트하지 않음 |
| 파죽지세 | 실제 처치에2초 이동 보너스. 새 층에서는 전투 특성 상태 초기화 |
| 약초 체질 | 소지 약품 회복25% 증가. 약리와 곱연산 |
| 내공 순환 | 유효한 궁극 사용에 최대HP5% 회복. 실패 요청/게이지 부족은 회복하지 않음 |

강건·괴력·경쾌·내공 확장·철벽·속공·약리·수비 숙달은 기존 공통 성장/무공 수치와 이번 공통 수식·약품 경로를 사용한다. 화산 이동/간격, 무당 재사용/충전, 천마 저체력/처치 회복, 삼재 피해/경감, 소림 경감/공격 경직 방지, 개방 사거리/공격 이동, 제갈 충전/처치 충전도 연결했다.

당문 보조 독은 다른 기본 무공에도 적용한다. 개인 공격의 독은 최대3/5중첩·0.5초 간격·3초 지속이며,5중첩에서는 지속 피해가 두 배다. 독 강도/시계는 선택 필드로 저장하므로 재접속 시 유지한다. 현재 레이드는 보스 한 명이라 처치 전독 대상이 없고, 향후 잡몹용 전독은 미구현이다. 개인 무당 반격은 실제 받은 피해 없이 내공을 반영한 반격 피해·충전과 다음 공격 특성을 준다. 개인 피격 무적과 공격 경직 방지도 연결했다.

모든 접촉은 기존 협동 엔진의 같은 틱 정산을 사용한다. 같은 틱 다중 피해/처치·회복의 순서까지 강호의 순차 판정과 같다는 뜻은 아니다. 처치 보조 효과는 마무리 틱의 마지막 유효 접촉 주인 한 명에게만 지급하며 사망한 공격자를 부활시키지 않는다.

## 새 무기 그림

경기장 원화는 시작 당시의 물품만 읽어, 이후 동료 합류나 새 무기 연결에 해당 그림이 없을 수 있었다. 이제 표시할 무기의 실제 원화를 한 번만 요청하고 완료 후 정확한 crop 프레임을 등록한다. 이미 있는 그림/권갑·암기 공용 아틀라스는 재사용한다. 준비되지 않은 새 무기를 이전 검으로 대체하지 않으며 실패는 기존 원화 오류/재시도 경로에 전달한다. 모든 무기를 미리 내려받는 방식은 추가하지 않았다.

## 8무공 개별 동작의 잔여 차이

| 무공 | 남은 차이/우선 구현 |
| --- | --- |
| 당문 | 기본3발 연계·한 공격의 중독 수 제한, 궁극의 중첩 비례 폭발/절반 소비 |
| 제갈 | 건진·곤진 배치/연결 진동, 궁극4진/7회 맥동. 현재 레이드는 단발/3발 투사체 |
| 화산 | 매화 중첩/연계와 궁극의 가까운 최대3대상 순차 베기. 현재 즉시 이동/폭발 |
| 무당 | 연계별 짧은 반격 창, 궁극의 강화 방어/연계. 수동 반격·충전은 이번 교정 |
| 천마 | 손실 HP 회수 풀·연계 HP비용, 궁극5초 자해/회수. 현재 고정 흡혈/폭발 |
| 삼재 | 단계6~10의 교대 보너스·세 번째 초식·관통 검기/유도/궁극 추가 검 |
| 소림 | 연계 원형 타격과 강화 중35% 추가 충격. 경감/경직 방지와5초 강화는 유지 |
| 개방 | A/B강화 배율·최대 충전/연계 흐름의 세부 판정. 혼란/밀침은 보스 면역 유지 |

이 목록을 미구현으로 보존하며 공통 효과 교정을8무공 완성으로 합산하지 않는다. 다음 구현은 당문·제갈의 개별 동작부터 진행한다. 실제 무공별 동작을 이식한 뒤 레이드 난이도를 재조정한다.
