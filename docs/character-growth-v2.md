# 캐릭터 중심 성장 v2

2026-10-03. 구현 근거는 `src/domain/character.ts`, `game.ts`, `support.ts`, `techniques.ts`, `recruitment.ts`이며 저장 이전은 `src/platform/save-migrations.ts`에 있다.

## 성장과 모집

- 모집권 3장 상한, 시간당 1장, 후보 3명 중 선택, 자금 100 구매는 유지한다. 후보의 성장 배율과 타고난 특성은 생성할 때 저장하며 재접속으로 다시 뽑지 않는다.
- 체질/근력/기민/내공은 각각 레벨당 10/5/3/5 × 개인 배율로 누적된다. 신규 후보 배율은 개별 0.8–2.0, 합계 4.5–5.5의 중앙 집중 분포로 조정했다([분포 규칙과 검증](recruitment-growth-distribution.md)). 레벨 상한은 두지 않는다.
- 체질: 최대 체력 120에 체질을 더한다. 성장으로 늘어난 최대 체력만큼 현재 체력도 증가한다. 근력: 기본 공격 내부 power에 근력 × 0.1 추가. 기민: 추가 이동 속도(상한 80)와 방어 재사용 시간에 적용. 내공: 반격/혈기탈취/궁극 피해 × (1 + 내공/250), 궁극 충전 보정에 적용한다.
- 기본 무인은 고정 1.0 배율이며 타고난 특성은 없다. 무공 숙련도는 사용자 요청대로 보류한다.

## 타고난 특성 10종

|특성|실제 동작|
|---|---|
|불굴|전투마다 치명상 한 번을 체력 1로 생존|
|승부사|체력 35% 미만에서 기본 공격 피해 +20%|
|침착|5초간 피해를 받지 않으면 궁극 충전 +20%|
|재빠른 손|무공 전환 뒤 다음 기본 공격 +25%, 재사용 4초|
|반격 본능|성공한 반격 뒤 다음 기본 공격 +35%|
|유연한 몸|실제 회피 뒤 다음 기본 적중 경직 +0.12초|
|집중력|같은 적에 서로 다른 기본 공격으로 연속 3회 적중 시 세 번째 피해 +15%|
|파죽지세|처치 후 2초 이동 속도 +15%|
|약초 체질|약품 회복 ×1.25|
|내공 순환|성공한 궁극 사용 시 최대 체력 5% 회복|

특성의 전투 중 상태는 저장한다. 불굴의 사용 여부 등 전투 단위 효과는 새 웨이브 전투가 시작될 때 초기화한다. 집중력은 발사 당시 공격 번호로 중복 탄 적중을 구분한다.

## 성장 특성과 무공 수련

- 성장 특성은 무공과 별개다. Lv.10/25/50에 중복 없는 후보 3개 중 하나를 선택한다. 최대 3개, 사망 시 해당 무인과 함께 사라진다. 후보를 저장하고, 여러 기준 레벨을 한 번에 넘으면 차례로 선택한다.
- 성장 특성 8종: 강건(최대 체력 +60), 괴력(근력 +30), 경쾌(기민 +20), 내공 확장(+40), 철벽(받는 피해 −10%), 속공(기본 공격 간격 −10%), 약리(약품 회복 ×1.25), 수비 숙달(방어 재사용 −15%).
- 무공은 레벨업으로 지급하지 않는다. 첫 출전 수련 1, 일반 전투 웨이브 완료 1, 보스 완료 3. 정비 웨이브에는 지급하지 않는다. 20웨이브 완주 기준 총 25를 얻는다.
- 새 무공 입문 비용 1. 승급 비용은 현재 성급과 같다(1→2 비용 1, 9→10 비용 9). 배운 무공 최대 4개. 2026-10-03 사용자 요청으로 삼재 상한을 10성으로 복원했다. 8성 궁극 개방, 9성 검기, 10성 이기어검이며 다른 무공은 5성 상한을 유지한다. 기존 저장의 성급을 변경하지 않는다.
- 수련 기회를 보관할 수 있다. 가방에서 무인 성장 정보를 열고 수련 버튼을 누르면 다시 선택한다. 보관된 포인트는 새 수련을 얻기 전까지 자동 창을 다시 띄우지 않는다.
- 경험치/성장 선택, 무공 선택, 전투 종료 가방은 공유 선택 상태로 제어한다. 성장 특성 → 무공 → 가방 순으로 처리하여 입력을 가리는 중첩을 막는다.

## 저장 호환과 검증

- 기존 무인의 장비, 체력, 경험치, 성급, 사망 상태는 유지한다. 개인 배율이 없던 무인은 이전 레벨을 성장 시작점으로 두어 소급 체력이 증가하지 않도록 한다. 이전 대기 무공 선택은 필요한 비용을 이전하고 보존한다. 기존 무인의 타고난 특성은 ID에서 결정하여 새로고침으로 바뀌지 않는다.
- 모집/성장/수련 선택은 기존 저장 완료 장벽을 이용한다. 전투 무공 전환의 자동 저장은 입력을 막지 않는다.
- 단위 검사: `tests/character-progression.test.ts`, `tests/hostile-movement-state.test.ts` 및 전체 회귀 검사. 브라우저: `tests/e2e/character-growth.spec.ts`, `recruitment.spec.ts`. 독립 브라우저에서만 테스트 상태를 사용한다.
- 1440×900, 1366×768, 1093×614와 다섯 언어의 캡처는 `docs/verification/character-growth-v2/`에 저장한다. 작은 화면의 무인 정보/장비가 획득 물품 영역에 겹치는 문제를 실제 캡처 검토로 찾아 간격과 아이콘 크기를 조정했다.
- 배율 분포, 수련 비용, 증강 수치는 초기 밸런스다. 장시간 실전 난이도의 적절성까지 검증한 것은 아니다.
