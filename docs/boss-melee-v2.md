# 보스 근접 개편 2차 · 2026-10-03

청하현 4명과 서역사막의 흑사마승 발타에 **24개 전용 행동**을 구현했다. 2차 완료 시점에는 10명·45개였고, 이후 [3~5차](boss-followup-v3-v5.md)에서 나머지 30명을 개편해 현재 40/40명·185개 행동이다. [2026-10-04 Daytona 배포](daytona-weapon-boss-v1.md) 완료.

## 주요 수치와 접촉 규칙

| 공격 | 범위 / 준비 / 접촉 / 회복 |
|---|---|
| 마대봉 내려베기 | 거리 240, 반각 0.38rad / 0.94초 / 발동 후 0.18초 / 0.85초 |
| 노진 직자 | 길이 365, 반폭 24 / 0.52초 / 0.09초 / 0.4초 |
| 노진 3연 찌르기 | 길이 305, 반폭 30 / 0.65초 / 0.1·0.6·1.1초 / 0.85초 |
| 철무 쇄겸 | 길이 355, 반폭 22 / 0.82초 / 0.14초 / 0.32초 |
| 한무극 축적 참격 | 거리 290, 반각 0.42rad / 1.08초 / 0.2초 / 1초 |
| 발타 황사 진각 | 주변 240 / 1.02초 / 0.28초 / 1초 |

나머지 값은 `src/domain/boss-melee.ts`를 원본으로 확인한다. 준비 마지막 약 0.23~0.4초에는 방향을 고정한다. 연타도 그 방향을 유지하므로 매 타격을 플레이어 위치로 순간 조준하지 않는다. 기존 피격 무적 0.45초를 유지하고 2·3연타의 접촉을 0.5초 간격으로 나눈다. 돌진은 실제 지나간 몸체 경로를 검사하며 순간이동하지 않는다.

호령·깃발도 다른 공격과 같은 준비/접촉 시계를 사용한다. 호령은 저장되는 `summoned`로 중복을 막고, 살아 있는 자기 깃발이 있으면 새 깃발 동작을 선택하지 않는다. 깃발의 강화는 소유자에만 적용하며 별도 잔류 가드 타이머를 주지 않는다. 두 기믹 모두 별도의 8초 자동 시전은 하지 않는다.

쇠사슬 그림은 실제 발동 때만 연결 고리와 무게추를 보여주고 회수한다. 향후 투사체 경로나 공격 범위를 미리 표시하는 선이 아니다. 끌기는 유효 피해 직후 한 번만 적용하며 장시간 흡인이나 새 포박 상태를 만들지 않는다.

## 원화·동작 결정

- 마대봉의 원문 설정에는 도끼가 있었지만 승인된 원화는 **큰 곡도**다. 이번에는 같은 인물·무기를 유지하고 실제 원화에 맞춰 현재 카탈로그를 곡도 강타로 갱신했다. 원본 기획 XLSX를 바꾼 것은 아니다.
- 청하현의 승인 원화 `public/art/animation-rebuild-v2/region-0.webp`에서 마대봉/노진/철무/한무극은 각각 3/4/5/6행, 발타는 `region-7.webp`의 5행을 사용한다. 0/1/2/3/4/5열은 대기/이동/준비/타격/피격/사망이다. 런타임은 격리된 프레임을 읽는다.
- 노진은 창 원화에 맞춘 직선 동작, 철무는 같은 쌍쇄 원화, 두 도 보스는 베기 동작, 발타는 권갑과 작은 장격 접촉 섬광을 사용한다. 창·주먹·도 연타의 동작 트랙을 구분했다.
- 앞 방향은 승인된 준비/접촉 그림, 뒤 방향은 같은 인물의 방향 그림과 연속 변형을 사용한다. 접촉마다 준비→타격→회복을 연결한다. **이번 5명의 원화를 새로 생성한 것은 아니다.**
- 원·부채꼴·조준선·카운트다운을 다시 추가하지 않았다. 실제 타격 잔상, 연결 고리, 지면 충격, 파괴 가능한 깃발만 표시한다.

## 저장 호환과 코드 위치

- `src/domain/boss-melee.ts`: 5명·24개 추가 행동의 이름/거리/시간/효과와 공통 물리 판정.
- `src/domain/game.ts`: 호령 접촉, 유효 적중 때만 사슬 끌기, 연타 접촉 시계.
- `src/domain/enemy-tactics.ts`: 전용 사거리 선택, 중복 호령·깃발 회피, 창 거리 확보, 큰 도격의 회복.
- `src/domain/boss-mechanics.ts`, `boss-encounters.ts`: 발타 원격 시전 제거, 저체력 추격, 소유자 한정 깃발 강화.
- `src/domain/catalogue.json`: 현재 공격 설명. `boss-attacks.ts`는 전용 키트의 순서를 연결한다.
- `src/game/hostile-motion.ts`, `effects.ts`: 창/도 연타 동작과 쇠사슬 발동 그림.
- `src/platform/save-validation.ts`, `src/domain/model.ts`: 사슬 효과 저장 타입. 새 저장 버전이나 사용자 데이터 초기화를 요구하지 않는다.

삭제된 시전을 진행 중인 구형 저장은 접근 상태로 복구하고, 구형 짧은 타격 저장은 진행 비율에 맞춰 새 접촉 시계로 환산한다. 기존 저장에 이미 놓인 사슬·모래벽은 만료까지 유지하되 재생성하지 않는다. 중간 연타/호령/깃발/끌기 이후 저장은 동일하게 재개한다. 실제 사용자 저장은 테스트에 사용하지 않는다.
