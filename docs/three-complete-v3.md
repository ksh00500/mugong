2026-10-18. 세 지역12보스의 남은31행동을 교정하고 실제 공격 시간에 연결했다. 기존24행동을 보존해 지역 합계55행동/2,130논리 프레임이다. 전체10지역40보스의 실제185키트 행동에 행동별 시퀀스가 연결되며 합계6,660논리 프레임이다. 이 수치는 독립 생성 그림 수가 아니다.

새22선택 원본의110물리 자세를12아틀라스에 담았다. 준비·회수·READY와 적합한 기존 특별 자세는 명시적으로 재사용한다. 46접촉마다 독립6단계 시퀀스를 선택하고, 접촉/접촉 유지에는 같은 그림을 사용한다. 실제 피해·사거리·접촉 시간·발사 수·추격 AI·저장 규칙은 바꾸지 않았다. 연살 `stance`는 실제 시전이며 유지 가드로 오인하지 않는다.

원본 비율을 유지하는 시트 전체 공통 제작 계수, 수동 발 중심110개,32px 투명 여백, 고정 전투 배율0.225, 보스별 고정 HP바 기준을 사용한다. 발타·연살의 공격 손, 소홍의 왼손 부채, 제갈현의 오른손 깃털부채를 교정했다. 새 그림도 원본5시점과 좌우 반전으로8방향을 만든다. 프레임별 자동 몸 맞춤이나 별도 무기 추적은 사용하지 않는다.

런타임 등록은 `src/game/boss-special.ts`, 지역별4새 시트 로드는 `src/platform/region-art.ts`, 실제 추가 자세는 `src/game/three-complete-frames.json`에서 관리한다. 기존 주요24행동의 좌표와 데이터는 바꾸지 않았다.
