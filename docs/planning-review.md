# 무공 기획 검토 보고

검토일: 2026-09-27

후속 정정: 이 보고 작성 뒤 최초 기획 공유 대화를 확인했다. 현실 7일 수명·영속 체력·두 가방·시장 방식은 사용자가 직접 제안한 내용임을 확인했으며, 사용자 의도와 이전 모델의 제안을 구분한 최신 분석은 [원대화 분석](original-conversation-analysis.md)에 기록했다. 아래 내용은 원대화 확인 전의 Drive 검토 이력으로 보존한다.

추가 사용자 정정: 강호는 매번 새 캐릭터를 생성해 0부터 시작한다. 20웨이브 성공 후 창고 장비를 활용해 PVP·레이드에서 성장한다. 아래 표의 ‘성장 고정’과 무공 성장 제한은 새 기획의 확정 규칙으로 사용하지 않는다. 이후 성장 범위는 확인 중이다.

이 보고는 기존 Google Drive 자료의 내용과 검토자의 해석을 정리한 참고 문서다. 원문에 ‘확정’이라고 적힌 항목도 이번 새 프로젝트에서 사용자가 다시 승인한 요구사항으로 취급하지 않는다. 기존 대화 원문을 확인하지 않았으므로 어떤 부분이 사용자의 직접 의도이고 어떤 부분이 이전 모델의 보충인지는 구분할 수 없다.

검토 후 사용자가 소모품의 전투 중 사용 금지, 별도 무장 가방에 무기 수납, 시장 화면의 구성, 화면 분위기와 배치 방향을 직접 정정·설명했다. 이 항목은 아래의 기존 문서 해석보다 우선한다. 최신 기준은 [사용자 확인 기획 방향](design-direction.md)에 따로 기록했다. 임시 정리판에 관한 표현은 처리 규칙을 확인 중이며 기존 보고의 ‘후속안은 실제 바닥’이라는 판단을 새 요구사항으로 채택하지 않는다.

## 1. 문서에서 읽히는 게임의 중심

계정의 정체성은 세가다. 플레이어는 강호에서 서로 다른 빌드를 가진 무인을 만들고, 완성된 무인으로 레이드·비무·생사결에 출전한다. 무인은 노화나 전투로 사라지고 창고 자산, 지역 해금, 명부 확장, 기록은 세가에 남는다.

가장 강한 감정은 좋은 빌드가 나온 무인에게 애착이 생긴 뒤, 그 무인을 어느 위험에까지 보낼지 결정하는 데 있다고 해석했다. 무공의 성장과 기연은 인물의 탄생을, 영속 체력과 생사결은 생애의 긴장을, 인물 기록은 죽은 뒤의 기억을 담당한다.

탑뷰 수동 액션, 런마다 형성되는 빌드, 실물 전리품 운반, 세가 운영, 온라인 거래와 대전이 함께 들어간 구상이다. 전체 범위대로라면 지속적인 서버·경제·대전 운영이 필요한 게임으로 해석된다.

## 2. 주요 시스템 요약

| 영역 | 문서상 방향 |
| --- | --- |
| 기본 루프 | 강호 20웨이브 육성 → 무인 완성 및 성장 고정 → 명부 등록 → 레이드·비무·생사결 → 귀환·회복·거래 → 노화·사망 |
| 세가의 영속성 | 자산·창고·명부·지역·기록 유지. 계정 영구 성장으로 직접 공격력·체력을 높이지 않는 원칙 |
| 강호 | 10지역 중 4지역, 지역당 5웨이브. 일반·사건 → 일반·기연 → 정예·위험 → 정비 → 보스 |
| 조작 | WASD 이동, Q/E 무공 전환, 좌클릭 초식, 우클릭 현재 무공 궁극 행동, Space 회피 |
| 무공 | 기본 8계열, 일반 Lv.1~5. 기본기 A → 패시브 → 기본기 B → 패시브 → 궁극기. Lv.3부터 A/B 교대 |
| 자원 | 공통 마나 없음. 무공별 게이지와 기본기 순서를 전환 후에도 유지. 개방은 취기 2칸으로 다음 기본기를 강화 |
| 삼재검법 | Lv.10까지 투자. Lv.8에 일반 완성형 수준, Lv.9 검기, Lv.10 이기어검으로 조작·전투 방식 변화 |
| 기연 | 성장 가속, 히든 무공, 영물, 인연 후속 사건. 무공 최대레벨을 넘기는 성장 없음 |
| 체력 | 위험 콘텐츠 사이 자동 회복 없음. 남은 HP로 귀환하며 비전투 소모품·정비 기회로 회복 |
| 수명 | 20웨이브 완료 후 현실 7일. 오프라인에서도 진행. 반로환 반복 사용의 효율 감소 |
| 레이드 | 1인 또는 2~4인. 완성 무인으로 5층 던전 공략. 무공 레벨 상승 없이 실물 희귀품 파밍 |
| 비무 | 사망·실물 손실·실제 HP 변화 없는 안전한 랭크 대전 |
| 생사결 | 실제 무인·착용품·가방을 거는 대전. 판돈·현상금·시체 루팅. 치명타 직전 자비로 살려주는 선택 |
| 평판 | 해당 런·무인의 이력. 선행은 안정성과 비용 절감, 악행은 즉시 약탈과 추격 위험 |
| 시장 | 품질이 다른 장비는 개별 매물. 표준 소모품·재료는 호가 거래소. 무인 거래는 금지 |
| 필드 가방 | 무기만 넣는 무장 4×7, 모든 전리품을 넣는 일반 10×8. 회전·수동 배치, 가방 안 중첩 불가 |
| 바닥·창고 | 바닥은 실제 월드 전리품. 창고는 단순 슬롯, 장비 개별 보관·표준품 중첩 |

세부 콘텐츠에는 기본 무공 8종, 기연 전용 히든 무공 5종, 지역 10개와 지역·페이즈 보스 40명, 사건 36개, 기본 장비 48종, 소모품·영물 15종, 레이드 4종과 전용 보상이 제안되어 있다. 명칭·수량·효과·확률은 새 프로젝트의 제작 확정 범위로 볼 수 없다.

히든 무공은 무형검결·흡기대법·금강불괴신공·답설무흔·벽력신장이다. 단순 희귀도 상승보다는 선판정, 자원 흡수, 큰 공격을 받아치기, 회피 연계, 충전 후 단발 공격처럼 전투 리듬을 바꾸려는 방향이다.

레이드의 차별화는 천뢰봉의 시간 예고, 만독천의 안전구역 확보, 금강사리탑의 기둥 소모·엄폐, 혈마성의 처치 순서다. 같은 기본 5층 구조 안에서 서로 다른 판단을 요구하려는 설계다.

## 3. 잘 살아 있는 부분 — 검토자의 판단

- 좋은 무인을 만들고 그 무인의 다음 출전을 고민하는 구조는 세가·로그라이크·경제·영속 사망을 하나의 감정으로 연결한다.
- 문파별 무공을 공격 속도나 색상만 바꾸지 않고 서로 다른 리듬으로 구분하려는 방향이 좋다. 화산의 기동 연계, 무당의 타이밍 반격, 천마의 최근 손실 체력 회수, 개방의 두 강화타 연계가 대표적이다.
- 생사결의 자비는 승리 보상을 일부 포기하고 상대를 살리는 선택으로 인연과 이야기를 만들 가능성이 있다.
- 기연을 별도의 거대한 퀘스트 UI 없이 행동과 후속 사건으로 연결하는 방향은 강호의 우연성을 살릴 수 있다.
- 필드에서는 운반 공간을 고민하고 귀환 후에는 쉽게 관리하도록 가방·창고의 역할을 나눈 점은 일관된 의도가 있다.
- 평소에는 절제하고 적중 순간과 초월 경지에서 강하게 표현하는 무공 연출 원칙은 판정 가독성과 세계관을 함께 지지한다.

## 4. 의도와 달라졌을 가능성이 있는 부분

다음은 확정적인 오류 판정이 아니라 사용자 의도를 다시 확인해야 할 지점이다.

### 현실 7일 수명

인물의 유한성과 세대교체를 만들지만, 접속하지 않아도 좋은 무인이 사라지므로 플레이 동기가 접속 압박으로 바뀔 수 있다. 반로환을 매일 소비해 오래 유지하는 구조는 애착을 경제력 문제로 옮길 가능성도 있다. ‘유한한 생애’의 취지와 ‘정확히 7일·오프라인 진행·반복 약 소비’라는 수치 규칙을 분리해서 판단할 필요가 있다.

반로환은 초반에 수명 연장이라고 설명하지만 상세표는 복용 횟수별 최대 잔여수명을 회복하는 방식으로 적혀 있다. 잔여시간에 더하는지, 정해진 시간까지 채우는지 구현 전에 명확히 해야 한다.

### 온라인 시장·협동·대전의 범위

여러 플레이어가 공유하는 경제와 실물 루팅, 영속 사망을 모두 넣으면 서버 판정, 재접속, 거래 동시성, 부정행위 대응까지 게임의 핵심 구현이 된다. 온라인 요소 자체를 빼야 한다는 뜻은 아니다. 원래 바라던 첫 플레이 경험에 이 전체 구조가 필요한지와 단계별 도입 순서를 다시 정해야 한다.

초기 무인·장비·회복품 공급, 강호 실패 시 손실과 반출, 매칭 대기시간과 무인 수명, 노화 도중 출전한 무인의 처리처럼 루프를 잇는 규칙도 구체화가 필요하다.

### 액션과 관리의 비중

무장 가방과 일반 가방을 모두 직접 포장하고, HP·수명·시장 매물을 관리하면 메타 플레이의 비중이 커진다. 공간 퍼즐을 즐기는 게임인지, 빠른 무공 액션 사이 짧게 전리품을 고르는 게임인지 목표가 분명해야 한다. 자동정렬 금지나 가방 수치도 그 목표를 확인한 뒤 선택할 규칙이다.

### 무공 전환의 실제 재미

공격 중 전환, 취소, 패시브 적용 범위, 이전 무공의 지속 효과가 어디까지 남는지에 따라 전투가 크게 달라진다. 예를 들어 독을 묻히고 소림으로 전환하면 생존과 지속 피해를 함께 얻는다. 이러한 조합을 의도하는지, 무공별 자원과 리스크를 어느 정도 분리할지 핵심 검증이 필요하다.

### 상세 수치와 콘텐츠 이름

다수의 수치가 아직 프로토타입 초안이다. 문서의 양과 ‘1차 완료’ 표기만으로 실제 손맛·성장 속도·경제 균형이 검증되었다고 볼 수 없다. 10지역·40보스·히든 5종 등의 목록도 창작 후보로 보존하되 제작 의무로 삼지 않는 편이 적절하다.

| 시각 | 긴 RPG 캐릭터 / 2~2.5등신 / 회화풍 8방향 | 현재 사용자 의도를 기준으로 다시 선택 필요 |

기획 개요에는 같은 번호가 여러 번 등장하고, 이전 결정이 남은 상태에서 후속 정정이 덧붙었다. 시트의 요약·백로그·개발구현도 상세 탭과 항상 같은 상태가 아니다. 후속안은 변경 흐름을 이해하는 근거로 사용했으며 사용자 의도의 최종 증거로 사용하지 않았다.

## 6. 기존 에셋에 대한 판단

새 프로젝트의 기본 에셋으로 재사용하지 않는 방향이 적절하다.

근거는 다음과 같다.

1. 초기 목록과 README가 최종 생산용 아트가 아닌 시각·카메라·규격 검증용 자료라고 명시한다.
2. 실제 확인한 컨셉 시트는 초상과 긴 체형을 포함하고, 후속 런타임·리깅 자료는 머리가 큰 체형과 다른 시점을 사용한다. 한 세트의 일관된 제작 기준으로 바로 묶기 어렵다.
3. 이동 시트는 방향·프레임별 포즈 변화를 담고 있으나, 자연스러운 연속 동작으로 쓰려면 보폭·실루엣·방향 간 정합성 확인이 필요하다. 정지 이미지의 완성도와 실제 애니메이션 품질은 별도로 판단해야 한다.
4. 환경 아틀라스의 바닥 조각은 가장자리에 식생·장식·비어 있는 영역이 포함되어 있다. 반복 바닥으로 바로 사용하면 연결과 반복감 문제를 처리해야 한다.
5. 개발 기록에는 머리·발 잘림, 프레임 오염, 손과 무기 이격, 어색한 이동, 투명화, 반복 바닥을 여러 번 복구한 이력이 있다. v0.7 시각 검증 실패도 명시되어 있다.
6. 후반 v1.0 문서 자체가 기존 v0.x를 보정하는 흐름을 끝내고 새 프로젝트·아트 파이프라인으로 재구축한다고 적는다.

색감, 무림 소재, 실루엣 아이디어는 참고할 수 있다. 캐릭터 디자인, 프레임, 피벗, 소켓, 맵 규격, HUD 좌표를 기존 자료에 맞춰 새 구현을 시작할 이유는 아직 없다. 모든 에셋이 불량이라는 전수 판정은 하지 않았다.

## 7. 개발 기록을 읽고 얻은 판단

초기에는 이동·회피·기본기·근접 적·궁수·첫 웨이브를 구축하는 흐름이었다. 이후 상당한 기록이 잘림, 무기 부착, 바닥 연결, 모션, HUD 구도 등의 수정에 쓰였다. 여러 단계의 문법·이미지 크기 검사가 통과했지만 실제 브라우저 실행은 미검증이라고 적혔고, 뒤에 실제 화면 실패와 재구축 기록이 이어진다.

가장 최근 기록도 레이아웃과 SVG 배경·HUD 적용, 임시 캐릭터 개선 수준을 설명한다. 따라서 문서상 배포 완료나 에셋 검사 통과를 핵심 게임 루프 완성으로 해석하면 안 된다. 실제 소스와 플레이를 검사하지 않았으므로 현재 게임의 재미나 작동 상태를 평가한 것은 아니다.

새 시작에서 우선 확인할 경험은 직접 공격과 회피의 손맛, 무공을 바꾸는 이유, 한 번의 전투 뒤 남은 HP와 전리품을 보고 다음 선택을 고민하는 감정이다. 세가·수명·경제가 이 경험에 어떤 의미를 더하는지 짧은 플레이로 검증하면 이후 범위를 결정하기 쉽다.

## 8. 새 프로젝트에서 다시 확인할 우선 항목

1. 가장 중요한 목표 감정: 무공 액션, 좋은 무인 만들기, 유한한 무인의 삶, 위험 파밍·거래 중 무엇을 중심에 둘지.
2. 실제 수명과 영속 사망을 어느 모드·상황에 적용할지.
3. 세가의 유지 요소와 강호 실패·완성 시 귀환 규칙.
4. 무공 전환·연계·패시브·지속 효과의 범위.
5. 카메라·체형·그림체·HUD의 원하는 모습.
6. 첫 플레이에서 필요한 온라인 요소와 나중에 넣을 요소.

기존 기획에서 이어받을 가장 강한 가능성은 ‘우연과 선택으로 좋은 무인이 태어나고, 그 무인에게 애착을 가지며 출전을 고민하는 경험’이다. 구체 시스템·수치·아트·엔진 결정은 그 경험과 사용자의 새 의도에 맞춰 다시 고를 수 있다.
