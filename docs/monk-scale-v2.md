# 소림 공격 전환 크기 보정 · 2026-10-04

앞선 보행 보정은 서 있는 몸 높이를 맞췄지만 공격·피격·사망에는 이전 추정 단위를 남겼다. CombatScene은 서로 다른 단위를 같은 해부학 기준으로 취급하여 보행에서 공격으로 바뀔 때 축소했다. 기존 단위 일치 검사만으로는 이 문제를 검출할 수 없었다.

## 변경

- 보행의 키 보정은 유지한다. 별도 `skullUnit`을 두어 전투·정지·반응 자세를 현재 방향 그림의 실제 두피 너비에 맞춘다. 무기, 권갑, 벌어진 팔, 누운 몸의 전체 폭을 캐릭터 크기로 취급하지 않는다.
- 소림 지역 원화 7세트와 정체성 교체 원화 2세트, 6개 시트의 135개 그림을 측정했다. 실제 지역의 일반 적 3종·보스 4종을 포함한다. 회수 자세도 보정하며 움직이는 회수는 기존 보행 보정을 사용한다.
- 스크립트는 노출된 두피 색을 기준으로 측정한다. 들어 올린 손·회색 승복·노출된 어깨가 섞이는 그림에는 검토한 범위를 적용한다. 회색 권갑 보행/피격의 옅은 두피는 `head-detail.png`의 원본 픽셀 윤곽으로 수동 확인했다. 머리카락이나 모자가 있는 다른 캐릭터에 이 검출기를 자동 적용하지 않는다.
- 새 이미지 생성이나 픽셀 편집은 필요하지 않았다. 판정, 이동, 보스 면역, 저장 데이터에는 변경이 없다.

## 검증과 범위

- 단위 검사 46파일·1,224개 및 프로덕션 빌드 통과.
- Canvas/WebGL에서 실제 7종 × 8방향 × 걷기·준비·타격·회수·피격·사망을 검사했다. 총 672개 렌더 표본이다. 소스의 두피 너비와 실제 Image 배율로 산출하며, 저장한 보정 단위끼리 일치하는지만 검사하지 않는다.
- 보행 크기 검사 2개와 10지역 공통 동작 검사 10개도 통과했다. 다른 지역의 검사는 경로·정체성·동작 선택 회귀 검사이며, 모든 캐릭터의 원화를 새로 해부학 측정했다는 뜻은 아니다.
- 위를 보는 봉병은 현재 걷기 높이 79.63, 준비 86.58, 타격 83.45이며 두피 너비는 모두 21.90이다. 숙이거나 누운 자세의 전체 높이를 서 있는 키로 강제하지 않는다.
- 정지 비교판의 Canvas/WebGL 앞·뒤·옆·후방 대각선과 16시점의 연속 재생 장면을 직접 확인했다. 물리 크기 수치 검사는 메시의 모든 화면 픽셀이나 원화 품질을 인증하지 않는다.

## 추가로 발견한 미해결 현상

WebGL 연속 재생에서 일부 정체성 교체 원화의 메시가 삼각형 조각처럼 깨지는 현상이 남아 있다. 같은 원화를 Image로 그리면 정상이며 Canvas 메시도 정상이다. 배치 강제 분리, 기본 사각형 경로, 삼각형 winding, UV 대신 기하 반전을 각각 비교했지만 해결되지 않았다. 이 실험들은 제품 코드에 남기지 않았다. 크기 검사는 통과했어도 이 현상까지 해결되었다고 주장하지 않는다.

[WebGL 메시 증거](verification/monk-scale-v2/sequence-09.png), [같은 원화의 일반 Image 비교](verification/monk-scale-v2/source-sprites.png). 메시 렌더 경로를 별도로 조사해야 한다.

독립 Playwright 컨텍스트와 5174 포트를 사용했다. 사용자 저장을 변경하지 않았다. 크기 수정 빌드는 로컬 `http://127.0.0.1:5173/`에 반영했다.
