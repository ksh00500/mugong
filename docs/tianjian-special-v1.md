# 천검산 보스 특별 모션

2026-10-06. 소림 다음 지역으로 천검산의 보스 4명에게 전용 모션 8종을 추가한다. 이번 작업은 로컬 적용이다.

| 보스 | 전용 모션 |
|---|---|
| 낙검객 우진 | 낙검 수세, 보법 찌르기 |
| 쌍검 백홍 | 회전 파고들기, 쌍검 주변 회전 |
| 검귀 무명 | 잔상 추격, 검귀 반격세 |
| 천검노인 백운 | 일선 검기 방출, 회풍 베기 |

5개 원화 시점과 좌우 반전으로 8방향을 표시한다. 각 동작은 준비·힘 싣기·접촉·후속·회수·대기의 6자세다. 총 40개 원본 시트, 20개 게임 텍스처, 240개 논리 프레임을 사용한다.

## 제작 규칙

- 기존 천검산 원화를 인물·장비·색·몸 크기 기준으로 사용한다. 무기를 든 팔과 몸을 함께 그린다. 검은 원화에 포함되며 별도 자동 추적 무기를 겹치지 않는다.
- 찌르기는 뒤쪽 갈비뼈에서 정면으로 내밀고, 베기는 어깨에서 아래·가로 방향으로 진행한다. 쌍검은 양손에 별도 손잡이와 검신을 유지한다. 발·골반·몸통의 회전을 함께 표현한다.
- 원본 셀의 인물 픽셀을 1:1로 복사하며 프레임별 크기 맞춤은 하지 않는다. 출력 프레임에 최소 32픽셀 투명 여백을 확보한다. 바깥 경계 잘림, 이웃 인물 연결, 누락, 중복 셀을 검사한다.
- 게임 배율은 모든 인물·자세·방향에서 0.225로 고정한다. 발 좌표를 프레임에 저장하고 HP바는 기본/특별 자세 전체의 최대 높이를 포함하는 고정 높이를 쓴다.
- 원거리 검기·잔상·타격 효과는 기존 게임 시스템이 실제 접촉 시점에 표시한다. 원화에 효과를 구워 넣지 않는다.

## 적용 범위

공통 `bossMotionClock`에 연결하여 기존 공격의 준비·타격·회수 시간을 그대로 소비한다. 반격 방어는 실제 `guardTime` 유지 시간을 따른다. 피해, 돌진 거리, 경직/CC 면역, 저장 규칙은 변경하지 않는다.

천검산의 전체 19행동 중 위 8행동에 새 전용 원화를 적용한다. 나머지 11행동은 기존 방향별 기본 공격 원화를 사용한다. 연속 공격의 개별 검초를 모두 새로 제작한 상태는 아니다.

원본/프롬프트: `docs/source/tianjian-special-v1/`.
경계 검사: `source-review.json`, 픽셀 복사·여백 검사: `export-review.json`, 발 좌표: `ground-anchors.json`.
검토 화면: http://127.0.0.1:5173/art/tianjian-special-v1/review.html

## 검증과 수정

타입 검사와 로컬 프로덕션 빌드, 단위 검사 248개와 브라우저 검사 16개가 통과했다. Canvas/WebGL, 일반 움직임/움직임 감소 설정, 1440×900·1366×768·1093×614 화면과 지역 전환 로딩을 독립 브라우저 저장으로 검증했다. 상세 결과와 캡처는 `docs/verification/tianjian-special-v1/`에 보관한다.

실제 캡처 검토에서 새 텍스처의 개별 프레임이 등록되지 않아 시트 전체가 표시되는 문제를 발견했다. `CombatScene`의 시작 로딩과 지역 전환 로딩에서 지역 이름 허용 목록을 제거하고, 원화 데이터에 등록된 정확한 텍스처 키로 프레임을 등록하도록 수정했다. 이제 브라우저 검사도 메타데이터뿐 아니라 Phaser가 실제로 사용하는 프레임 이름과 잘라낸 사각형을 비교한다.

접촉 시점이 늦은 공격에서 후속 자세를 건너뛰던 공통 시간 처리도 수정했다. 회수 시작에 후속 자세를 표시하며 공격 판정 시간은 유지한다. 기존 소림 특별 모션과 천검산 일반 적 원화도 함께 재검사한다.
