# 전투·자원 UI 피드백 v1

2026-10-18. 사용자 요청에 따라 UI/UX 개선을 우선했다. 한지·황동·옥색 그림 UI를 유지하면서 체력, 경험치, 궁극기, 방어 준비, 주요 버튼을 더 선명하게 구분한다.

## 체력 감소와 회복

체력을 다섯 칸으로 반올림하지 않는다. 다음은 시간에 따른 연출 단계다.

| 단계 | 현재 구현 |
| --- | --- |
| 실제 감소 | 숫자·실제 채움·접근성 값은 체력 변경 즉시 반영 |
| 접촉 강조 | 잃은 구간을 흰색으로 70ms 표시 |
| 피해 확인 | 타격 시점부터 180ms까지 흰색/밝은 금색 잔량 유지 |
| 잔량 회수 | 다음 420ms 동안 cubic ease-out으로 실제 체력에 수렴 |
| 안정 | 장식 반복 없이 현재 체력만 표시 |

한 번의 피해 연출은 총 600ms다. 연속 피해는 각 타격의 만료 시간을 보존해 예전 흰 막대가 계속 고정되지 않게 한다. 회복은 손실 잔량을 지우고 320ms 동안 청록색으로 구분한다. 인물·보스 교체와 최대 체력 변경은 기준을 새로 잡아 가짜 피격을 만들지 않는다. 위험 체력은 고정 30HP 대신 최대 체력의 25% 이하이며 글자와 초상 테두리로도 알린다.

플레이어·보스 HUD와 로비·가방은 공통 React Meter를 사용한다. 일반 적/보스 머리 위 막대도 같은 순수 HealthTrail 모델을 Phaser Graphics에서 그린다. 기존 5px 높이, 발 기준 고정 높이와 원화 간격을 보존한다. 흰 잔량 위에서도 숫자가 읽히도록 HUD 숫자 뒤에 작은 먹색 바탕을 둔다.

## 카메라와 타격 숫자

GDC의 trauma 접근을 참고한 `trauma² × smooth value noise`를 사용한다. 큰 피격·처치·반격·궁극 행동이 짧은 충격을 더하며, 한 시뮬레이션 배치에서는 가장 강한 사건 한 번만 더한다. 여러 적을 동시에 맞혀도 대상 수만큼 중첩하지 않는다. 일반적인 작은 공격마다 흔들지는 않는다.

강도는 끄기/약하게/보통이며 기본은 약하게(0.55)다. 보통의 이론상 상한은 렌더 화면 좌표로 가로 4.335px·세로 약 2.818px이고 마지막 충격 후 최대 약 304ms에 소멸한다. 회전·확대는 사용하지 않는다. HUD는 카메라 밖 DOM에 고정하고 포인터 조준에서 시각 오프셋을 빼 실제 조준을 보존한다. 일시 정지·가방·성장 선택·로딩에서는 원위치로 돌아간다.

타격 숫자는 처음 짧게 최대 1.14배 강조한 뒤 원래 크기로 돌아간다. 기존 수명과 합산 규칙은 유지한다. 게임 시간 정지나 입력 지연을 추가하지 않는다.

## 나머지 UI

- 체력은 따뜻한 주홍/홍색, 경험치는 금색, 궁극기는 청옥색으로 구분한다. 채움 위의 얇은 밝은 면과 짙은 빈 구간으로 대비를 만든다.
- 궁극 준비에는 한 번 지나가는 빛, 방어 준비에는 선명한 아이콘·초록 경계·체크 표시를 사용한다. 재사용 중에는 실제 남은 시간과 원형 채움을 유지한다.
- 레벨 변경에는 짧은 배경 강조, 로비 주요 행동과 성장 선택에는 옥색 명암·누름 상태·초점 테두리를 적용한다. 로비 선택 페이지도 색과 하단 선으로 표시한다.
- 화면 흔들림 설정은 별도 `mugong-feedback-v1`에 저장한다. 기존 게임 저장과 UI 설정을 덮어쓰지 않는다. 다른 탭의 저장 변경도 구독한다.
- 움직임 감소에서는 카메라, 피해 잔량, 자원 보간, 준비 빛과 숫자 확대를 제거한다. 실제 체력·준비 상태·숫자·색은 남는다. 높은 대비와 큰 글씨 옵션을 유지한다.

## 구현·검증 경계

새 라이브러리와 래스터 에셋을 추가하지 않았다. React는 매 프레임 다시 렌더링하지 않고 활성 피해 연출 동안 DOM의 채움 변환만 갱신한다. 전투 이동·피해·AI·CC·명중·저장 규칙과 기존 원화 배율은 변경하지 않았다.
