## 권장 수정 묶음

1. **즉시 보이는 문제/행동 보장:** U01–U05. 숫자 바탕·핵심 글씨, 모집 출전, 설명 가림, 종료 정리 오류.
2. **공통 컴포넌트:** U06–U13,U18. 버튼/입력/수치/선택/정보 반복을 먼저 통일해 화면별 임시 덮어쓰기를 줄인다.
3. **흐름과 정보:** U14–U17,U19–U21. 상인/정비 결정, 전투 정보, 로딩/복구/결과를 다듬는다.
4. **미술/전체 회귀:** U22–U24. 실제 원화 보존, 가용 화면 사용, 소유CSS 수정, 키보드/동작 감소를 유지한다.

흰 피해 잔량, 실제 체력 계산, 보스 반격/추격, 저장 정책과 가방4×7/10×8은 이번 검토만으로 변경하지 않는다.

## 검사 중 제외한 실패

초기 촬영fixture가 최대5레벨 무공의6레벨 후보를 직접 만들어 설명의undefined를 발생시켰다. 유효3→4레벨 후보로 교정한 뒤63캡처를 다시 남겼으며 정상 게임에서 발생하는 버그로 집계하지 않는다. 로딩fixture의ReactDOM 가져오기 및 캡처 스크립트 문자열 오류도 교정했다. 정상 일시 종료의setScroll 오류는 별도 실제버튼조작으로 재현했으므로 별개로 U05에 기록한다.
