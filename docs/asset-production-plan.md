# 무공 — 첫 전투 검증용 에셋 제작 계획

작성일: 2026-09-27

업데이트: 사용자가 카툰풍 검객을 승인하고 짧은 생성 요청으로 다시 디자인하도록 지시했다. [현재 디자인 기준](art-direction-cartoon-v1.md), [짧은 첫 요청문](chatgpt-asset-first-batch-v2.md), [짧은 전체 프롬프트 팩](external-asset-prompt-pack-v2.md)을 사용한다. 사용자가 ChatGPT에서 원본 이미지·영상을 만들어 가져오고 Codex가 프롬프트 작성·검수·게임 연결을 맡는다. 기존 회화적 검토 샘플은 비교 자료로 유지한다.

기준: [1차 게임 기획](game-design-v1.md), [사용자 확인 기획 방향과 화면 참고](design-direction.md).

화면 결합 기준: 사용자가 승인한 `../assets/concepts/cartoon-combat-wide-v2.png`의 맵·작은 캐릭터 축척과 `wireframes/mugong-first-draft.html`의 기존 UI를 사용한다. 컨셉 이미지에 그려진 임시 HUD는 교체한다.

현재 단계의 목적은 승인한 카툰풍 무협 화면에서 비례·시점·동작·무기 연결이 실제 플레이로 이어지는지 확인하는 것이다. 제작 범위와 검수 기준은 생성 요청에 모두 덧붙이지 않는다. 원화 시안과 이전 동작 샘플은 있지만 새 화풍의 다방향 플레이가 완성된 것은 아니다.

## 첫 검증의 범위

| 대상 | 첫 제작 범위 | 확인할 결과 |
|---|---|---|
| 플레이어 | 검을 사용하는 무인 한 명 | 참고 화면에 맞는 비례·의복 실루엣·카메라 각도 |
| 무기 | 검 한 자루 | 손잡이와 손의 접촉, 방향·동작에 따른 가림 순서 |
| 움직임 | 대기·걷기·기본 베기 | 같은 캐릭터로 이어지는 동작, 발 기준점, 클릭 방향의 공격 |
| 피격·사망 | 핵심 이동·공격 검증 후 추가 | 필요한 상태에 캐릭터가 사라지거나 다른 프레임이 섞이지 않음 |
| 적 | 근접 적 한 종류 | 플레이어와 같은 시점·축척, 공격 예고와 피격 가독성 |
| 배경 | 전투 공터 한 곳 | 중앙 전투 시야, 가장자리 식생·구조물, 캐릭터와 배경의 조화 |
| 효과 | 기본 검흔·적중 효과 | 공격 방향과 판정의 읽힘, 화면을 과하게 가리지 않는 표현 |
| HUD | 체력·현재 무공·궁극 게이지 | 움직이는 화면 위에서도 읽히는 상태 표시 |

인물·무공 이름과 정확한 프레임 수·이미지 크기는 이 제작 계획만으로 확정하지 않는다. 첫 검증에서는 정리된 무공 전체나 지역·보스 전체를 동시에 제작하지 않는다.

## 진행 순서

1. **플레이어 기준 원화와 검:** 승인한 카툰풍 검객의 비례와 실루엣을 게임의 비스듬한 탑뷰에 맞춘다. 움직임 제작에 사용할 기준 자세를 고른다.
2. **한 방향의 짧은 동작:** 대기·걷기·베기를 동일한 카메라와 비례로 만든다. 검과 손의 연결, 발 접지, 몸의 움직임, 공격 궤적을 확인한다.
3. **실제 게임 화면에서 재생·조작:** 웹 게임 실행 환경에서 이동과 클릭 방향의 공격을 확인한다. 렌더링 엔진·애니메이션 방식의 후보도 이 작은 구간으로 검증한다.
4. **방향과 상태 확장:** 한 방향의 품질 기준을 만족한 뒤 필요한 방향 및 피격·사망 상태로 확장한다. 방향별로 같은 무인의 체격과 의복이 유지되어야 한다.
5. **적·배경·효과 통합:** 근접 적과 전투 공터를 더해 판정·시야·축척·효과가 함께 읽히는지 확인한다.
6. **제작 규격 고정:** 검증한 카메라·축척·기준점·동작 방식·파일 구성으로 이후 다른 무공·무기·적을 제작한다. 아이템 아이콘·시장 장식·지역 전체 제작은 이후 진행한다.

## 에셋 검수 기준

- 모든 동작은 같은 발 기준점·축척·카메라를 사용한다. 프레임마다 캐릭터가 상하로 튀거나 크기가 변하지 않는다.
- 검의 손잡이 위치, 손과 팔의 자세, 몸 앞뒤의 가림 순서를 방향별로 확인한다. 이동·공격 때 무기가 몸과 분리되지 않는다.
- 실제 투명 배경, 충분한 여백, 정확한 프레임 경계와 참조 정보를 검수한다. 인접 프레임의 머리·발이 섞이거나 필요한 신체 부위가 잘리지 않는다.
- 대기·이동·공격·피격·사망 상태의 필요한 파일과 연결을 확인한다. 누락된 상태 때문에 무인이 투명해지는 결과를 허용하지 않는다.
- 공격의 시작·적중·마무리 자세와 판정 타이밍을 함께 본다. 정지 원화의 품질과 실제 움직임의 품질을 각각 검토한다.
- 배경은 중앙 전투 공간의 가독성을 확보하고, 캐릭터의 발 위치와 같은 시점에서 자연스럽게 보이도록 한다.
- 기존 Drive 런타임 에셋은 반입하지 않는다. 사용자 제공 이미지는 분위기·배치·비례의 참조다.

## 첫 완료 기준

원화 파일만으로 완료를 선언하지 않는다. **무인 한 명이 같은 전투 공간에서 걷고, 이동 방향을 바라보고, 클릭 방향으로 검을 베며, 검과 손이 자연스럽게 연결된 움직이는 샘플**을 첫 완료 결과로 삼는다. 그 결과를 본 뒤 전체 에셋 제작 규격과 수량을 확장한다.
