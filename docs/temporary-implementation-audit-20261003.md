# 임시 처리 조사 — 2026-10-03

후속 업데이트: 성장 특성 전용 그림, 모집 후보 초상 구분/저장, 리그 전환 보간, 사건별 효과음은 적용했다. 캐릭터 동작 시트도 전 지역·역할·주인공·기병·드론으로 재제작했다. 아래 표는 조사 시점 기록이며 최신 변경은 `docs/character-polish-v1.md`, `docs/animation-rebuild-v2.md`를 참고한다. 모든 방향별 독립 연속 원화와 키 원화+리그 보간은 구분한다.

현재 소스와 기존 감사 기록을 대조한 읽기 중심 조사다. 이번 조사에서는 게임 코드 변경이나 새 실행 검증을 하지 않았다. 아래는 확인한 잔여 항목이며 전체 게임에 버그가 없다는 판정은 아니다.

## 이미 해결된 항목과 정상 대체 처리

- 과거 감사의 반사·체력 교환·회전문·수리 드론·잡기·정화초 등은 후속 구현 기록과 현재 보스 모듈이 있다. 예전 미완료 표를 현재 상태로 재사용하면 안 된다. `docs/boss-mechanics-v1.md`, `src/domain/boss-mechanics.ts`를 우선한다.
- 이미지 실패 처리, 초점 복원 fallback, Canvas 리그 렌더러, 옛 저장 마이그레이션은 복구·호환 기능이다. 이름에 fallback이 있다는 이유로 임시 기능으로 분류하지 않는다.
- 여섯 무기 유형의 공통 `Item.kind === 'sword'` 분류는 실제 `weaponStyle`과 함께 해석해야 한다. 전부 검을 사용하는 더미라는 근거가 아니다.
- 제거된 정리판의 번역 문자열 및 옛 문서가 남아 있다. 문자열 존재만으로 현재 정리판 시스템이 다시 동작한다고 판정하지 않는다.

## 조사 한계

이번 조사는 소스·문서 대조다. 모든 캐릭터 프레임의 새 육안 검수, 40보스 반복 실전, 저사양 기기 성능 검증은 새로 수행하지 않았다. 위 목록은 현재 확인된 대체 구현과 잔여 작업이며, 실제 화면 결함이나 수치의 체감은 별도 검증이 필요하다.
