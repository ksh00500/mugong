# 지역별 전투 그림 v1

2026-09-30. 공통 배경과 적 그림을 신규 강호의 지역별 그림으로 교체했다. 카툰 세계·작은 캐릭터·넓은 전투 공간과 기존 무협 HUD를 유지한다.

## 적용 범위

배경 10장·일반 적 외형 30종·보스 외형 40종을 생성하고 실제 전투에 연결했다. 일반 적은 기존 근접·창·원거리 세 판정을 사용한다. 외형 추가를 신규 AI나 성장 보상으로 표시하지 않는다. 보스는 원본 표의 지역/단계와 bossId로 각각 선택한다.

| 지역 | 일반 적의 시각 역할 | 배경 |
| --- | --- | --- |
| 청하현 | 산적·표국 창병·쇠뇌 포졸 | 객잔/표국 마당 |
| 독무곡 | 독인·독곡 수위·가면 약사 | 약초밭과 독안개 공터 |
| 천검산 | 견습 검객·산문 수위·원거리 검객 | 절벽 비무대 |
| 설산 | 사냥꾼·설산 창병·궁수 | 눈과 얼음 공터 |
| 폐사 | 무승·봉 승병·돌팔매 승병 | 무너진 사찰 마당 |
| 죽림 | 매복 살수·죽창 수위·투척 살수 | 주막과 대나무 공터 |
| 고묘 | 도굴꾼·묘지기·쇠뇌 기술자 | 지하 석실 |
| 서역사막 | 곡도 도적·창 용병·궁수 | 대상 천막과 오아시스 |
| 혈마전 | 마교 교도·창 수위·쇠뇌 술사 | 붉은 전각 |
| 팔진고성 | 검/방패 수위·기관 창병·쇠뇌 기관병 | 고성 진법 마당 |

중앙은 기존 전투 판정 안에서 이동 가능한 바닥이다. 장식 장애물은 가장자리에 두고 실제 전장 소품·장판·예고는 별도로 그린다. 이전 저장의 옛 네 지역 경로는 기존 그림을 유지하며 사용자 기록을 바꾸지 않는다.

## 그림과 동작

4열×2행 시트의 앞 3칸은 일반 적, 다음 4칸은 보스다. 투명 여백을 실행 시 측정해 칸별 그림을 자르고 종횡비·발 기준점을 유지한다. 좌우 반전 때 기준점을 보정하고 가장자리 구분선은 제외한다. 천검산 원거리 적의 상시 검기는 생성 도구로 제거한 v2 시트를 사용한다.

이동 시 짧은 상하 움직임, 공격 준비의 뒤로 물러남/기울임, 공격의 전진/회전, 피격 반동, 사망의 0.38초 축소/회전/페이드를 연결했다. 화면에서 살아 있던 적이 죽었을 때만 사망 연출을 시작하고 저장 재개 때 죽은 적을 다시 연출하지 않는다. 움직임 줄이기에서는 이동/회전/반동/축소를 끄고 짧은 사망 페이드만 유지한다. 피해·체력·성장 판정은 바꾸지 않는다.

이 문서의 최초 적용은 개별 인물 한 자세의 변환 연출이었다. 이후 [자세 애니메이션 v1](enemy-motion-v1.md)에서 70개체의 걷기 두 자세·공격 준비·타격·피격·사망을 추가했다. 현재 로딩에는 동작/보정 시트도 포함된다. 방향별 전용 자세와 연속 중간 프레임·관절 애니메이션은 남는다.

## 생성과 로딩

기본 제공 image_gen으로 생성/편집했다. [생성 기록](source/region-art-manifest.json)에 최종 프롬프트·생성 원본 경로·선택 PNG·전달 WebP·크기/용량을 보존했다. 그림은 public/art/regions-v1/에 저장했다. 원본과 천검산 교체 전 그림도 지우지 않았다. [내보내기 스크립트](../scripts/export-region-art.mjs)는 동일 크기/투명도의 WebP 형식 변환만 수행한다.

최종 WebP 20장은 7,024,366바이트로 최초 PNG 20장 46,847,082바이트보다 약 85% 작다. 첫 진입은 공통 그림과 현재 지역 2장만 기다리고 다음 지역 2장은 전투 중 미리 받는다. 같은 파일의 진행/완료 요청은 공유한다.

지역 전환 때 그림이 준비되지 않았다면 로딩 화면과 준비 개수를 표시하고 시뮬레이션/입력을 멈춘다. 실패는 재시도를 제공하며 여정/무인 ID를 유지한다. 닫힌 장면에 늦게 완료된 요청은 렌더러를 수정하지 않는다.

- 최종 타입 검사 및 배포 빌드 통과.
- 직접 시각 검토: 10지역 모두 1093×614에서 일반 적/보스 분리, 시트 선, 발 위치와 바닥/예고/HUD의 겹침을 확인했다. 천검산은 1366×768·1440×900도 캡처했다. [캡처 폴더](verification/region-art-v1/)에 보존한다.

자동 검사, 캡처 시각 검토, 실제 사용자 대상 난이도/가독성 검증은 서로 다르다. 서비스 수준이나 접근성 인증을 주장하지 않는다. 이번 적용은 로컬이며 Daytona는 배포하지 않았다.
