# 혈마전 보스 특별 원화 — 로컬 검토 시안

2026-10-07. 사용자 지정으로 혈마전을 진행했다. 기본 대기의 머리·몸 크기를 그대로 둔 512×512 여섯 슬롯 기준판을 입력해 4보스·8패턴·5시점 원화40장을 생성했다. 준비 → 힘 싣기 → 판정 → 후속 → 회수 → 대기의 240논리 프레임을 20개 WebP로 내보냈다. 반전으로 8방향을 비교한다. **게임 등록·공개 배포 전의 원화 검토 단계다.**

| 보스 | 두 패턴 |
| --- | --- |
| 혈도객 적우 | 혈흔 추격참 · 혈도 혈지 깔기 |

준비·접촉·회수 시간은 실제 `boss-wave4.ts`, `boss-wave5.ts`와 맞췄다. 혈지·결박·인장은 유지 방어가 아닌 시전으로 표시한다. 연살의 돌파는 접힌 팔과 어깨, 진각은 발을 쓰도록 구분했다. 적우는 오른손 도·왼손 권갑 하나, 연살은 양손 권갑, 소홍은 현재 기본 원화와 같은 왼손 부채, 적천은 오른손 대도·빈 왼손을 유지한다. 투사체·장판·발광 효과는 별도 게임 효과이며 원화에 추가하지 않는다.

## 교정한 시안

수정 시안18장 중8개 시트의19자세를 선택했다. 연살 정면/앞사선의 중복 권갑, 소홍의 부채 손 바뀜·부채 소실, 적천의 무기 손/떠 있는 손잡이를 교정했다. 적우 뒷사선 시전은 손을 내리는 수정에서 팔이 중복되어, 양팔을 유지한 작은 무릎 굽힘·고개 숙임으로 바꿨다. 수정 중 배경 알파가 남아 인물이 서로 연결된 버전과 몸이 커진 버전은 선택하지 않았다. [전체 시도와 선택 목록](source/hyeolma-special-v1/generation-status.json).

프레임별 맞춤 축소 없이 원본 RGBA를 1:1로 분리한다. 최소32px 여백과 고정0.225 메타데이터를 사용한다. 일부 원화의 긴 도가 명목 슬롯 경계를 넘지만 인물끼리는 연결되지 않으며 연결 성분을 따라 전체 무기를 회수해 여백 있는 셀에 넣었다. 원본 슬롯마다32px 여백을 확보했다는 뜻은 아니다.

## 검토와 남은 적용 작업

[로컬 비교 화면](http://127.0.0.1:5173/art/hyeolma-special-v1/review.html)은 기본 대기와 특별 자세를 동일한 배율로 비교하고, 8방향·6자세를 직접 선택할 수 있다. 네 보스의 두 패턴 판정 캡처와 1093×614 화면을 직접 확인했다. 기준판 덕분에 서역사막 시안에서 보였던 큰 몸체 차이는 줄었지만, 240자세의 머리 치수·손 연결을 모두 수동 승인한 것은 아니다.

240발 좌표는 자동 추정이다. 검 끝·옷 끝을 접지점으로 잡을 수 있어 실제 신발/지지발 기준으로 수동 확정해야 한다. 그 뒤 기본/특별 전체 그림의 고정 HP바 높이를 검증하고 게임 등록·실제 공격 판정·Phaser Canvas/WebGL 검사를 진행한다. 적우 뒷사선 시전의 작은 동작도 실제 효과와 함께 판독성을 검토할 대상이다.

타입 검사·분리 빌드, 검토 UI144표본·움직임 감소 검사, 입력 해시120개·로컬 파일22개 일치 및240프레임의 원본 픽셀/여백 검사를 통과했다. 자동 검사는 해부학적 완성도를 보장하지 않는다. [이번 검증](verification/hyeolma-special-v1/README.md).
