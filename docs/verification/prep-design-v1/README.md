## 이번 검사

- 최종 전체 단위 **78파일·1,381개** 통과. 타입 검사 통과. 실제 런타임 파일1,062개·정적 참조796개·누락0·LFS포인터0. manifest 실행 미디어1,022개·1,187,887,771바이트 전체 SHA 검사 통과. 212모듈 배포 빌드 성공. 기존 큰 mount 청크 경고는 남는다.
- 최종 소스 정비 화면 **9검사**가 한 실행에서 통과했다. 세 해상도(1440×900,1366×768,1093×614)의 원화 로드/버튼/선택/보스 정보 배치, 실제 회복 저장과 완료 문구, 동작 감소, 상점/가방 키보드 개폐·초점 복귀, 그림 요청 실패 시 회복·강화를 포함한다. 작은 화면+큰HUD+고대비+동작 감소의 다섯 언어도 각각 검사했다.
- 기존 기능 회귀 **9시나리오**의 최신 결과는 초기8통과+로딩 단계 실패1건의 단독 재검사 통과다. 한 실행의9통과로 기록하지 않는다. 실제 회복/강화·구매/재고 저장·가방 수납/회전/착용/사용·다음 보스전·4/9/14/19정비·5언어·불가 사유·상태/설정/창고를 포함한다.
- 공용 초점 처리 변경 후 **별도4검사**(세 해상도 Tab/Shift+Tab·능력치 설명 전환, 중첩 폐기 취소/확인)가 한 실행에서 통과했다.
- 컴파일 빌드5229의 **9검사**와 실제 적용5205의 **별도3검사**도 통과했다. 이번 최종 브라우저 묶음은 소스9+기존회귀9+초점4+컴파일9+적용3의 **34시나리오**다. 중간 재실행·초기 실패를 통과 수에 더하지 않는다.

모든 검사는 독립 Playwright 브라우저 컨텍스트의 가상 저장을 사용했다. 실제 사용자 저장과 저장 형식·전투/밸런스 수치를 변경하지 않았다. 공개 배포·Docker 실서버 설치·main 병합은 이번 완료 범위가 아니다.

## 실제 발견과 교정

1. 큰 HUD에서 경험치 하단112–113px가 정비 시작106px와 겹쳤다. 정비 중 무인 상태 위치를 조정하고 각 HUD 정보 경계가 정비 시작보다 위인지 재검사했다. 숫자/행동을 숨기거나 화면 전체를 축소하지 않았다.
2. 1440의 빠른 가방 개폐에서 초점이 원래 버튼으로 돌아오지 않는 문제를 재현했다. 열기 저장이 아직 진행 중이면 원래 버튼이 disabled여서 기존 즉시 복귀가 대체 버튼으로 끝났다. 비활성 해제를 관찰해 복귀하고, 사용자가 다른 곳으로 옮김/새 대화상자/원래 요소 제거 시 취소한다. 최종 소스·컴파일·적용 검사와 별도 중첩 창/Tab 회귀로 확인했다.
3. 최초 전체 단위 실행은 브라우저와 동시에 실행해40보스 시뮬레이션이30초 제한을 넘겼다(1실패/1,380통과). 브라우저 실행과 분리하고 workers2로 실행한 최종 결과는 전부 통과다. 제품의 규칙이나 검사 시간 제한을 변경하지 않았다.
4. 기존 품절 시나리오 한 건은 서비스 조작 전에 그림 로딩 실패 화면에서 끝났다. 제품 변경 없이 같은 검사를 단독 재실행해 통과했다. 원인을 특정하지 못한 일시적 환경/로드 실패로 남기며 성공에 포함하지 않는다.

## 원화·시각 검토

새 PNG 네 장은 원본 바이트/비율을 유지한다. [알파·해시·크기](art.json), [전체 생성 프롬프트](../../source/prep-design-v1/prompts.json)를 보관했다. 기존 원화 삭제0. 새 그림은 정비에서만 요청하고 필수 초기 로딩 목록에 추가하지 않았다. 이 사실은 새 로딩 속도의 정량적 개선 측정과 구분한다.

1440 한국어 정비,1093 영어 큰HUD/고대비 정비,1093 한국어 상점,최종 적용1093 한국어 정비 캡처를 직접 열어 인물/문자/서비스/하단 행동/상단 정보 배치를 확인했다. 나머지 해상도·언어의 자동 경계/문자 넘침 측정과 모든 픽셀의 수동 승인을 구분한다. 모든 화면/언어/설정 조합, 실물GPU 장기 안정성, 자연 플레이 전체 밸런스 검증을 주장하지 않는다.

PNG·trace·큰 runner/simulation JSON은 로컬 증거이고 선택한 측정 JSON·이 요약을 Git에 보관한다. 재실행 방법과 경로 변수는 구현 문서를 따른다.
