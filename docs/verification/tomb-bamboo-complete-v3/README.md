- 새 8아틀라스 125물리 셀의 실제 RGBA 여백·경계·이웃 침범 검사 통과(`atlas-audit.json`). 최소32px, 최대4096 제한.
- 실제 Phaser `drawEnemy`에 39행동·8방향·준비/공격/복귀와 피격 피드백을 입력했다. Canvas/WebGL × 일반/동작 감소 × 2지역의 최신 8검사 통과. 50,144렌더 표본·1,440접촉·32실제 가드 유지 확인. 프레임 선택/flip/고정0.225/공격 우선/고정HP/잘린 텍스처/시뮬레이션 불변을 검사한다. 대량 표본은 로컬 `*-full.json`, `*-reduced.json`에 보존하며 Git에는 요약만 넣는다.
- 실제 kit185행동과 등록을 대조했다. 전체154행동/5,280논리 프레임, 고묘19+죽림20 전체 커버, 남은31개(`coverage.json`). 준비/후속 재사용과 새 물리 그림 수는 구분한다.
- 비교 캔버스1200×520의 전체 새 프레임/좌우 반전 경계 통과. 초기 노개 직자 오른쪽16.5px 잘림을 캔버스를 넓혀 수정했다.
- Vite 별도 빌드 `dist-tomb-bamboo-complete-v3`, 로컬5201. 기본 1,800kB 초과 청크 경고는 남는다. 최종 컴파일/3해상도 게임·비교UI 검사는 `validation-summary.json`을 따른다. 실제 사용자 저장을 변경하지 않고 독립 Playwright 컨텍스트만 사용했다.

## 직접 시각 검토

8인물×5시점의 READY/125새 자세 비교판을 직접 읽었다. 곽기 렌치 준비의 몸 확대를 원본 전체 공통 계수로 교정하고, 렌치 지면강타5시점의 발점을 무기 끝에서 신발로 수정했다. 정면/후면 직자의 원근과 측면 무기 길이, 청비의 왼손 단도/오른손 암기, 적호 곡괭이 날 중복, 월령 오른손 방출, 연청3연검을 확인했다.

실제 Phaser WebGL의 두 지역 판정판 4페이지와 연격2·3차, 곽기 렌치 힘 싣기 캡처를 읽었다. 넓힌1920×2400 캡처판에서 노개 긴 봉이 옆 인물과 겹치지 않도록 간격을 확보했다. 인물 조각·사각 발광 배경·HP바 침범은 이 캡처에서 재현되지 않았다. 모든 GPU, 전 프레임 관절 완벽함, 장시간 자연 플레이/원거리 밸런스를 인증한 검사가 아니다.

## 초기 실패와 수정

소스 검사 최초 실행은 샌드박스 임시 SSR 파일 rename `EPERM`으로 시작하지 못했다. 허용된 실행에서 전체1,307개를 다시 통과했다. 준비판에서 검출한 노개 직자 잘림은1200캔버스로 수정했다. 비교 HTML 생성이 끝나기 전에 빌드해 첫 컴파일 UI검사3개가 옛1000캔버스에서 실패했다. 생성 완료를 확인한 뒤 재빌드하고 최종8검사를 다시 실행했다. 최초 자산 검사는 갱신 중인 곽기 비교판 크기 때문에 실패했고 최종 manifest/전체2,745파일 SHA검증을 다시 통과했다. 실패를 성공 수에 합산하지 않는다.

## 배포와 보관

소스/메타데이터/프롬프트만 `codex/tomb-bamboo-complete`에 보관하며 미디어/LFS는 올리지 않는다. 실행용993·제작용1,752파일의 압축본/사이드카는 로컬 `.asset-bundles/`, 공개 배포·개인 서버 전송·main 병합은 하지 않았다. Git 커밋/최종 검사·사용 텍스처 SHA는 `validation-summary.json`, `public-dist.json`, `served-files.json`을 따른다.
