# 독무곡 7종 검증 기록

2026-10-05. 암기수·독창병·독폭탄술사와 청린사왕·독의 묵칠·오독낭자 연화·사공염을 로컬 배포에 적용했다. 테스트 상태는 Playwright 독립 브라우저 컨텍스트에만 넣었으며 실제 사용자 저장은 수정하지 않았다.

## 자동 검사

- 전체 단위 검사 `npx vitest run --maxWorkers 2 --testTimeout 15000`: 53개 파일, 1,253개 통과.
- `authored-dokmu.spec.ts`: Canvas/WebGL × 일반/동작 감소 설정의 네 검사 통과. 각각 7종 × 8방향 × 7상태 × 5시점 = 1,960개 기록, 합계 7,840개. 배율 0.225, 메시 비활성화, 시점·좌우 반전, 고정 HP바, 그림 상단 간격, 보스 피격에 공격 주기 유지 확인.
- 보스 18개 행동 프로필의 21개 접촉 × 8방향 = 168개씩, 합계 672개가 접촉 원화 2를 표시한다. 두 번째·세 번째 연격도 포함한다. 보스 행동별 독립 원화를 만들었다거나 모든 보스 판정을 실제 시뮬레이션으로 실행했다는 뜻은 아니다.
- `dokmu-release.spec.ts`: 실제 `tick`을 1/120초 간격으로 실행한 일반 적 3종 × 8방향 = 24개 판정 통과. 암기수는 전방 바늘 3발, 독폭탄술사는 독 착지 정보를 가진 투사체 1발을 발사 원화에서 방출하고, 독창병 피해는 접촉 원화와 일치한다. `actual-release.json`.
- `local-preview-dokmu.spec.ts`: 배포 빌드의 1440×900, 1366×768, 1093×614 세 검사 통과. 전투 입력, 새 WebP 35개 응답, 검토 화면 7종 선택·보행/공격·재생/정지·프레임 이동, 가로 넘침 확인. `production/`의 캡처와 JSON.
- 선택 원본 420자세에 경계 잘림·그림 공유·잘린 대체 연결 성분 없음. 원본 연결 픽셀 RGBA 1:1 복사와 최소 32픽셀 여백 검사 통과. 저장한 WebP 35개를 다시 디코딩한 패딩 검사도 통과. `docs/source/dokmu-family-v1`의 JSON 기록.

브라우저 검사 총 8개 통과. 네 행렬의 JavaScript 오류 기록은 비어 있고, 살아 있는 원화 상단과 HP바 아래의 최소 간격은 게임 좌표 약 11.225였다. Canvas/WebGL 보행·준비·접촉·회수 캡처 16개를 저장했다.

빌드 `npm run build` 통과. 확인한 배포 파일은 `main-C_UERIW_.js`, `mount-BOmChqkO.js`다. 테스트용 웹 서버가 종료된 뒤에도 볼 수 있도록 로컬 미리보기를 숨김 프로세스로 실행했고 실제 앱 브라우저에서 검토 화면이 열리는 것을 확인했다. 로컬 주소 `http://127.0.0.1:5173/`, 검토 페이지 `/art/dokmu-family-v1/review.html`.

## 실제 시각 검토

자동 검사와 별도로 Canvas 보행·접촉, WebGL 준비·접촉, 연화의 여섯 공격 자세, 1093×614 전투 캡처를 열어 확인했다. 무기와 손의 연결, 투척 뒤 빈손, 몸과 머리 비율, 앞뒤 시점, 접지와 HP바 간격을 비교했다.

긴 검·창·지팡이의 잘림, 독창병 사망과 인접 그림의 연결, 묵칠·연화의 준비 중 무기 손 바뀜은 해당 원화만 재생성했다. 선택 수정 목록은 `selected-corrections.json`의 17자세이고 암기수의 발사 뒤 두 자세는 `needle-release-v2.png`에서 추가 선택한다. 다른 그림과 붙은 묵칠 뒷모습 준비는 주변 행을 비운 별도 원화에서 선택한다. 그 비운 행은 게임에서 사용하지 않는다. 청린사왕 정면 접촉의 접지 제안이 한 부츠만 선택한 것은 두 부츠 사이 저장 좌표로 수정했다.

이 검토는 모든 관절과 머리 치수를 수치 인증한 것이 아니다. 생성 원화의 미세한 비율·시점 차이는 남을 수 있다. 사망은 단일 자세 페이드이고 보스 18개 행동은 인물별 기본 공격 주기와 기존 효과를 조합한다. 전체 독무곡 시트의 디코딩 RGBA 용량은 약 341.25MiB로 실제 GPU/브라우저 메모리와는 다르다. 사용하지 않는 이전 독무곡 메시 시트 네 개는 지역 로드 목록에서 제외했다.

원화·프롬프트·선택 수정안은 [원본 기록](../../source/dokmu-family-v1/README.md)에 있다.
