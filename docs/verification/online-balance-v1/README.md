2026-10-23. 변경 전 기준은 `b25cdd0ec9feed0715fbae75a48ae8a4cb53fbc7`이다. 실제 온라인 DB/사용자 IndexedDB에 테스트 계정을 만들거나 상태를 주입하지 않았다. 원화·이전 빌드를 보존한다.

- `before.json`, `after.json`: 같은 관측기·후보로 실행한48회 자연 도메인 전투,16개 표준 파티,4개 보상 없는 개인 엔진 관측,4개 실제 개인 저장/성장/귀환 관측. 기준 커밋의 두 전투 엔진을 esbuild 로더로 교체했다. 이전 브라우저 HP1 fixture와 별개다.
- `tests/raid-pressure.test.ts`: 사거리 밖 헛공격 방지, 추격 돌진의 조준 잠금/예고/회피와 회복, 이전 방 사본,8무공 개방 레벨, 미무장 자원 보존·엉뚱한 검의 미연결 우회 방지.13개다.

- `playwright.raid-pressure.config.ts`: 독립 메모리 서버에 자연 완주 무인 사본3개를 준비하고 실제 UI 로그인→개인 선택→출발→키보드 이동→정상 보스의 추격/돌진 예고→실제 피격/마우스 공격을 검사했다.1440×900·1366×768·1093×614 세 시나리오 통과, 보스 최대 HP는 모두1,600이었다. 무인 세팅/진입은 fixture이지만 전투 HP를 줄이지 않았다.
