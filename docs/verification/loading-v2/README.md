## 초기 실패·측정 보정

- 처음 동시6개 큐만 적용한 설산 첫 로딩이 느려졌다. 큐 수만으로 성능 향상을 주장하지 않고 필수12개/선읽기2개로 조정했으며, 사용하지 않는 구형 적 분석과 현재 외형 외의 행 처리를 제외한 뒤 다시 측정했다.
- JSON의 이질적인 키 타입·idle API 축소 타입·fixture 외형 타입 오류를 교정하고 최종 타입 검사를 통과했다. 빌드 명령이 이어서 성공한 것을 앞선 타입 오류의 성공으로 기록하지 않는다.
-20웨이브 측정 fixture가 목표 지역을 첫 칸에 둬 다른 지역을 측정했다. 지역을 실제 단계 칸에 넣고 `data-art-region`을 대조하도록 수정한 뒤 이전/개선 양쪽을 전부 재측정했다. 이전 중간 수치를 최신 결과에 합산하지 않는다.
- 전환 테스트의 JSON import에 Node용 `type: json` 선언을 추가했다. 첫10지역 루프는 같은 저장을 다시 여는 fixture 때문에 로비를 찾지 못했다. 지역별 독립 컨텍스트로 고친 뒤10지역/40보스가 통과했다. 실제 저장 검증은 완화하지 않았다.
- 픽셀 추출의 선택 행은 외형0/6 양쪽에서 기존 전체 행 방식과 실제 RGBA/치수가 같음을 확인했다. 프레임 크기를 임의로 줄여 로딩을 감춘 것이 아니다.
