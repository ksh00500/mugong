## 준비한 변경

현재 React19·Phaser4·Vite7 소스와 이전 GitHub main의 Phaser3 프로토타입을 구분한다. main 이력을 가져와 `codex/self-hosting-setup` 브랜치를 준비하고 기존 작업 파일을 체크아웃으로 덮어쓰지 않았다. main/기존 Vercel 운영 배포는 변경하지 않는다. 원화·런타임 바이너리는 Git LFS, 검증 영상/캡처·임시 빌드·개인 노트 사본은 Git 제외, 소스/프롬프트/검증 요약은 Git으로 관리한다. 원본 파일을 삭제하지 않았다.

README와 서버 설치/업데이트/복귀 문서, Docker 다단계 빌드·Nginx·Compose, LFS 포인터/리터럴 자산 확인, CI와 독립 브라우저 검사를 추가했다. Docker는 기존 dist와 분리해서 빌드하며, 기존 dist의 검토 화면을 이번 검사로 덮어쓰지 않는다.

## 이번 자동 검사

- 런타임891파일, 코드/메타데이터의 완전한 리터럴195경로 존재와 LFS 포인터0개 확인. 동적 템플릿 경로 전체의 정적 증명이라는 뜻은 아니다.
- 타입 검사와 분리 Vite 빌드:186모듈,8.61초 통과. main3,141.74kB로1800kB 초과 경고가 남는다.
- 전체 단위 검사: 최초62파일 중3실패(보스 원화 추가 전의 자산 개수56을 기대). 기본35/기존 특별20의 검사는 보존하고 새 접촉 텍스처 수를 명시하도록 수정했다. 재실행62파일1,295검사 통과(15.11초).
- Compose 구문 검사는 통과했다. 이 PC의 Docker Desktop은 시작 후에도 Linux 엔진 파이프에 연결되지 않아 로컬 이미지 빌드·Nginx 실행을 완료하지 못했다. 엔진 연결 실패를 이미지 구동 성공으로 기록하지 않는다. Linux GitHub Actions의 Docker 검증은 업로드 후 별도로 확인한다.
- 최초 브라우저 시도는 종료된5173프리뷰 주소로 접속해 실패했다. 다음 시도는 빈 주소 환경 변수 처리 문제로 실패해 수정했다. 독립5190프리뷰의 최종 결과와 캡처는 이번 폴더에 남긴다. Nginx 전용 HTTP 검사는 실제 Nginx일 때만 실행하며 Vite 프리뷰에서 통과한 것으로 합산하지 않는다.

GitHub 업로드/CI 결과는 원격 확인 후 별도 갱신한다. 개인 서버 SSH·도메인·TLS와 실제 운영 배포는 이번에 실행하지 않았다. 실제 사용자 저장은 테스트 상태로 바꾸지 않았다. 테스트는 독립 브라우저 컨텍스트만 사용한다.
