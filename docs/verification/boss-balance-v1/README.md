## 동일 조건 전후 비교

이전 커밋757ec71의 `src`를 별도 폴더로 추출해 **같은 검사 코드**를 실행했다. 현재 코드와 비교해120개 압박 시나리오(40보스×3입력 정책), 소림36개 실제 HP 결투(4보스×3정책×3seed)를 각각 기록했다.

압박 시나리오는45초 동안 플레이어/보스 HP만 매 프레임 보충한다. 레벨은 보스 단계×4, 양쪽 정책의 무기는1단계/품질80, 무공3레벨, 능력/갑옷/궁극/방어/소모품은 없다. 환경 증원은 제외하고 보스가 실제 소환한 지원군·설치·상태 이상·실제 투사체는 포함한다. 플레이어 공격/피격 cue에서 피해를 합산하므로 사망/처치 시간으로 해석하지 않는다.

고정 경로 사격의 평균 누적 피해는 약37.8% 증가했다. 이 정책의 무피격 보스는 이전1명/현재2명으로 **모든 보스·경로의 무피격을 없앴다는 결과는 아니다**. 기술을 읽은 회피를 강제 적중으로 없애지 않는다. 근접 반격 정책의 가한 피해는810.26→730.17로 감소해, 전 지역에서 근접/원거리 효율이 같아졌다고 주장하지 않는다. 이동·접촉/회복 변화와 공격 가능한 시간의 영향까지 확인할 후속이 남아 있다.

실제 HP 결투는 보충 없이120초 제한이다. 해당 약한 장비와 방어 없는 스크립트에서 소림 사격은12개 중 처치6→3, 사망6→9; 회피 후 접근은 처치6/사망6 유지; 근접 연타는12개 모두 사망이다. 같은 정책/초기 조건은 seed가 달라도 동일 결과일 수 있으며 독립 인간 표본/승률로 취급하지 않는다. 성공한 경우에만 `elapsed`가 처치 시간이고, 사망/시간 초과를 섞은 평균을 TTK로 표시하지 않는다.
