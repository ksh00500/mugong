# 서역사막 원화 검토 시안 검증

2026-10-07. **게임에 적용된 특별 모션 검사가 아닌 로컬 원화 비교 화면 검사**다.

## 이번 자동 검사

- TypeScript `--noEmit` 통과. 분리된 `.validation/desert-special-build` 프로덕션 빌드 통과, 184모듈. 기존 큰 번들 경고는 남아 있다.
- PNG 40장/240자세의 알파 연결 경계 감사를 기록했다. 일부 그림은 명목 격자선을 넘는다. 실제 원화 전체를 추출해 이웃 인물 공유·외곽 잘림 없이 20WebP/240프레임을 내보냈다. 구성 성분의 RGBA 복사 대조와 최소 32px 여백 확인: [내보내기](../../source/desert-special-v1/export-review-draft.json).
- 프롬프트·기준80개 입력 해시 일치, 원본/수정/미선택 PNG51개 SHA-256 보존, 검토 WebP20개·메타데이터·화면의 로컬 복사22파일 해시 일치: [파일 검사](file-integrity.json).
- 독립 Playwright 문맥에서 1440×900·1366×768·1093×614의 4보스×2패턴×6자세 = 144표본. 8캔버스, 선택/프레임 이동, 화면 가로 넘침 없음, 필수 조작 버튼 경계, 그림 응답과 실행 오류 없음. 움직임 감소 문맥의 초기 정지도 확인했다. [결과](browser-results.json).
- 8패턴 전체의 1440캡처와 1093캡처 1장, 총 9장을 보존했다. 브라우저 런타임 최초 경로 탐색 실패는 기존 설치 경로를 지정해 재실행했다. 설치/다운로드하지 않았다.

## 직접 시각 검토

생성 중 모든 반환 시트를 확인했고, 핵심 기준 원화 및 수정 대상 원본을 별도로 열었다. 발타 후속 장법/아르칸 무기 손/나야 회수 예비 환을 교정하고 변화가 반영되지 않은 수정본을 제외했다. 아사르·나야·발타·아르칸 접촉 1440캡처 4장과 1093캡처를 직접 열어 확인했다.

실제 같은 배율 비교에서 새 몸체가 기본보다 큰 문제가 확인됐다. 특히 발타와 나야의 크기, 일부 시점의 손/몸 회전, 240발점의 자동 제안은 추가 교정/검토가 필요하다. 고정 배율·픽셀 복사 통과를 미술 통일성 통과로 해석하지 않는다. 미리보기의 흐릿한 투명 RGB 배경은 실제 캔버스에 그려지지 않았다.

이번에 전체 게임 단위 검사, 피해 접촉, 특별 프레임 등록, 실제 전투 Canvas/WebGL·저장 재개·공개 서버를 검증하지 않았다. 이전 목진 검사의 1293단위/12브라우저 결과를 합산하지 않는다. 사용자 실제 저장은 읽거나 변경하지 않았다.
