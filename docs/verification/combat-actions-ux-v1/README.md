# 전투 행동 HUD 검증

2026-10-22~23. [구현](../../combat-actions-ux-v1.md) · [실행 요약](summary.json) · [로컬 제공 파일 대조](local-build.json).

최종 전체 단위는 한 작업자 실행의 **88파일/1,502개**가 통과했다. 공통 조건 변경에 따른 기존 전투/저장/지역 모션 회귀와 새 입력의 한 번 소비·방향·무기/게이지/개방/재사용/예약 한도·메뉴/무공 변경/화면 숨김/로딩/250ms 만료 취소를 포함한다. 앞선 병행 실행의 1개 시뮬레이션 시간 초과는 최종 성공 수에 합산하지 않는다.

타입 검사, 실제 런타임1,069파일/803참조/누락0/LFS0, 228모듈 빌드가 통과했다. 이미지 원본·전투 수치·저장 형식은 바꾸지 않았다.

브라우저 검사는 실제 사용자 저장과 분리된 Playwright 컨텍스트에서 합법적인 합성 저장을 검증한 뒤 사용했다. 적 HP/준비 시간을 크게 둔 조작 검사이므로 자연 플레이 난이도나 인간 승률의 증거가 아니다.

소스9·컴파일9·로컬3·아이콘12는 별도 실행이다. 초기 잘못된 시험 전제(비활성 클릭의 Playwright 자동 대기, 정비에서 숨겨진 전투 버튼, 천마와 검의 무기 비호환)는 고쳤으며 초기 실패/중단 실행은 최종 합계에 넣지 않는다. 모든 언어·설정·전투 상태의 완전한 조합 검사나 모바일 전체 지원을 주장하지 않는다.

1440 전투·600 전투·영어 큰 HUD 캡처를 직접 열어 배치를 검토했다. 자동 경계/수치/저장 검사와 직접 시각 검토는 구분한다. PNG/trace/원시 리포트는 로컬에 두며 경량 JSON과 이번 요약을 버전 관리한다. 이전 시뮬레이션 문서는 이번 테스트가 재생성한 값으로 덮어쓰지 않았다.
