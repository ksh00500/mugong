# 원화 크기 검증

2026-10-19. 이전 검사와 이번 실행을 구분한다. `inventory.json`·루트 PNG/Canvas·WebGL JSON은 교정 전 조사이며, `after/`는 이번 교정본이다. 같은 프레임을 같은 발 원점과 배율로 놓고 비교한다.

## 범위와 증거

- `scripts/audit-native-size.mjs`: 전체10지역70캐릭터의 READY 비교판,10,860논리 프레임 목록 및825개 서로 다른 특별 접촉 후보. 알파 경계 높이는 후보 정렬에만 쓰며 자동 몸 크기 판정이 아니다.
- `*-all.png`: 보스40종의 기본/특별/추가 전체 자세 비교판. 생성한 판 수와 직접 상세 검토한 판 수를 혼동하지 않는다.
- `*-calibration.png`, `*-ruler.png`: 제갈4보스의 원본 READY·적용 READY·준비/접촉/회수와 무기 외 신체 비교. 설산 창병·묵연 기본 전체60자세도 별도 비교했다. 직접 이미지 도구로 읽은 전후 비교와 별개로, 모든 프레임의 관절을 수동 측정한 것은 아니다.
- `atlas-audit.json`: 새13아틀라스100셀의 실제 알파 경계/32px 투명 여백/침범/비어 있는 셀/발 원점/해시 검사.
- `after/canvas-*.json`, `after/webgl-*.json`: 독립 브라우저의 실제 Phaser 렌더 선택/방향/등록/배율/발점/HP바 검사. 원본 사용자 저장에는 접근하지 않는다.
- `after/review-*.png`: 1440×900·1366×768·1093×614에서 원화 전후 비교 화면.

실제 실행한 최종 결과는 아래 최종 기록에 적는다. 상태 주입 렌더는 자연 전투 플레이테스트나 모든 실제 GPU 검증과 다르다. 몸을 숙이는 정상 자세, 머리카락/창끝의 길이 차이를 오류라고 판정하지 않는다.

## 초기 검사 실패와 수정

- 최초 감사 스크립트의 family 파일명 누락/비교판 캔버스 부족을 수정하고 다시 생성했다. 이는 게임 원화 손상이 아니다.
- 최초 빌드 명령의 `--outDir` 전달이 npm을 거치며 위치 인자가 되어 Vite 진입점을 찾지 못했다. 수정 전 빌드는 실패 기록이다.
- 샌드박스에서 Vitest 임시 모듈 rename EPERM으로4개 suite가 시작하지 못했다. 허용된 로컬 환경에서 재실행한24개 회귀 검사는 통과했다.
- 전체 검사 중3개 지역 추가 원화 dictionary에 재사용 경로를 중복 등록하여 기존12개 전용 아틀라스 계약과 맞지 않았다. 공유 경로는 기존 특별 원화/지역 인덱스에서 관리하도록 교정했다. 수정 전1,359통과/1실패는 최종 결과로 합산하지 않는다.
- 임시 서버 시작 대기/포트 충돌, 샌드박스 Vite SSR 모듈 전송 시간 초과가 있었다. 별도 전용 서버와 메모리 내 번들로 재실행했다. 실패한 실행을 검증 통과로 세지 않는다.
- 첫 소스 검사에서는 이전 시뮬레이션 증거 JSON 쓰기2개가 UNKNOWN 오류였다. 이번 전용 출력 폴더로 분리한 재실행이 통과했다. 이전 증거는 Git HEAD와 대조해 보존하고 이번 자료는 이 폴더에 따로 남겼다.
