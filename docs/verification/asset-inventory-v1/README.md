## 실제 변경

`codex/asset-inventory-v1`의 첫 업로드 커밋 `101947d8e316631e4028e63114ac251e0a808bb0`에 public 미디어1,018개(이미지1,011·소리4·폰트3, 1,177,933,670바이트)를 원래 경로/바이트 그대로 일반 Git으로 추가했다. 소스·그림을 함께 복제할 수 있다. 제작 미디어1,818개/2,672,062,428바이트는 외부 authoring 보관본과 전체 목록으로 유지한다. 유료/LFS 설정은 변경하지 않았다.

미참조 추정만으로 그림을 지우지 않았다. 정적 참조, 현재10지역/40보스 로딩 선언, 외형0–9/구형 appearance 없음, 아이템, 동적 음성/폰트/설명 그림, 비교/재출력 입력을 분류했다. 현재 실행 선언779·호환7·소스 참조95·검토/출력100·미확인37을 보존한다. 12개 동일 SHA 그룹도 경로 의존성이 있어 자동 삭제하지 않았다. [목록](../../asset-management/inventory.json).

이전 압축본11개를 삭제했다. 모든 내부 파일 크기/SHA가 현재 자료와 남긴 두 보관본에 포함됨을 검증했고, 고유/달라진 내부 파일은0개였다. 원화/생성본·실행 중인 dist·사용자 저장은 삭제하지 않았다. 18,431,739,045바이트(약18.4GB/17.17GiB) 확보. 압축본 메타데이터 사이드카는 이력으로 보존했다. [원본별 전체 대조](../../asset-management/archive-audit.json) · [실제 삭제 목록](../../asset-management/cleanup-result.json).
