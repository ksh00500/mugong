## 로컬 적용과 직접 검토

http://127.0.0.1:5205/ 에 새 빌드를 적용했다. [제공 파일 SHA256](local-deployment.json)의 index `ef7914dc5e5a6e428332652b4cac003e61fd7223b2782beaa5cd7e38f87fdbff`와 직접 연결된 JS/CSS가 빌드 파일과 일치한다. 개발5225·검증용 컴파일5229와 구분한다.

1093×614의 20웨이브 보스 HP4000 표시,9웨이브 의원16전/다음 보스1900 안내, 실제5205의 첫 의원12전/치료 후145HP·88전 캡처를 직접 열어 글자·막대·행동 배치를 검토했다. 전체 픽셀/언어 조합의 수동 검토나 장시간 인간 플레이 검증과 구분한다. PNG·trace는 로컬의 같은 증거 폴더에 보관한다.

IndexedDB는 Playwright 독립 컨텍스트의 검증용 데이터만 사용했다. 실제 사용자 저장을 열거나 시험 상태로 변경하지 않았다. 저장 형식·원화·히트박스는 바꾸지 않았다. 원래 저장된 보스 HP·상점 가격·재고·물품 파워의 로드 보존과, 다음 생성부터 새 규칙 적용을 별도 검사했다.

최초 제한 환경 Vitest 임시 파일 rename 오류는 권한이 있는 실행으로 재검사했다. 브라우저 reporter CLI 인자 오류와 새 검사의 잘못된 `progressbar` 선택자는 검사 코드에서 수정해 `meter`로 다시 실행했다. 초기 실행/중단은 통과 수에 포함하지 않는다. 최종 타입 검사가 지적한 검사용 불필요 `Enemy.speed` 필드도 제거했다. 제품의 표시/피해 규칙을 검사에 맞춰 바꾸지 않았다.

공개 배포·main 병합·개인 Linux/Docker 실서버 설치, 모든 무공 조합의 장시간 완주/실물GPU 검사는 이번 완료에 포함하지 않는다. 다음 조정은 실제 플레이의 사망 지점·보스 소요시간·선택 무공·회복약 잔량을 참고한다.

이번 세션에는 `basic_memory_remote` 도구가 제공되지 않았다. 지정 로컬 옵시디언 프로젝트 기억을 갱신하며 MCP 동기화 완료로 기록하지 않는다.
