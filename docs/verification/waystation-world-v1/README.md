# 첫 이동 쉼터 검증

2026-10-20. [구현·조작·원화](../../waystation-world-v1.md). `dist-waystation-world-v1`을 http://127.0.0.1:5205/ 에 적용했다. index SHA256 `1f502963f672a716175b938f414f7b45ffee9ebd620290c13f39b100fb1bc37e`와 새4장 제공 바이트가 빌드/원본과 일치한다. [적용 증거](local-deployment.json). 이전 카드 디자인의 검사를 이번 실행으로 합산하지 않는다.

## 흐름과 근거

| 경계 | 검사 |
| --- | --- |
| 화면 → 이동 | 실제 WASD·표식 Tab/Enter 접근, 대각선 단위 이동/방향·경계·NPC 발 충돌 |
| 접근 → 대화 | 거리 밖E는 열지 않음, 실제 접근 후E, 대상 표식으로 초점 복귀 |
| 대화 → 서비스 | 실제 heal/buySupply/refine 명령과 저장 HP/금전·재고·강화 결과 확인 |
| 가방/대화/일시정지 | 움직임 정지, 외부 가방에서 원격 강화/출발 우회 차단, 수동 입력으로 자동 이동 취소 |
| 저장 → 재개 | 같은 x/y를 기존 IndexedDB에 저장하고 새로고침 후 복구, 전투 elapsed0 유지 |
| 출구 → 보스 | 실제 보스 안내·미수납 확인 후5웨이브 전투, 일시 대화 상태 해제 |
| 그림 요청 실패 | 새4장 요청을 실패시켜도 마당/대상 표식과 실제 회복 가능 |

외부 API/DB는 추가하지 않았다. 저장 검사는 독립 Playwright 컨텍스트의 검증용 IndexedDB를 사용한다. 실제 사용자 저장은 변경하지 않는다.

## 자동 검사

- 최종 단위 **79파일·1,387개** 통과. 새 이동 규칙5개와 store의 거리/대화 잠금/서비스 명령 제한/출발 저장을 포함한다. 전투·원화·저장 형식 전체 회귀도 같은 실행에 포함했다. 타입 검사 통과.
- 런타임 파일 **1,066개·정적 참조800개·누락0·LFS포인터0**. manifest 실행 미디어1,026개·1,196,401,564바이트 전체 SHA 검사 통과. 실행 묶음ID `d12a2e595aa3055c`. 새 원화의 원본 바이트·알파·발 원점은 [art.json](art.json)을 따른다.
- 최종 소스 **13검사**가 한 실행에서 통과했다. 세 해상도의 실제 접근/회복/구매/강화/보스 출발3개, 이동 취소·메뉴 정지·위치 저장/복구1개, 선택 원화 실패1개, 다섯 언어+큰HUD+고대비+동작 감소의 작은 화면5개, 후반 정비9/14/19 보존3개다.
- 마우스나 프로그램 초점 주입 없이 native Tab→Enter→실제 접근→E→닫기 후 표식 초점 복귀를 **별도1검사**로 추가해 소스에서 통과했다. 소스13+1은 두 실행이며 한 실행14통과로 기록하지 않는다.
- 기존 정비/상점/가방 **9회귀**도 한 실행에서 통과했다. 새4웨이브는 맵 표식을, 후반 정비는 실제 카드를 측정한다. 이후 첫 쉼터의 가방 우회 제한과HUD 가방I/명시적 초점 복귀를 추가한 부분은 위 최종13검사에서 확인한다. 이전 회귀9개를 최종 변경 뒤 다시 실행했다고 기록하지 않는다.
- Vite **218모듈** 최종 배포 빌드 성공. 기존 큰 mount 청크 경고는 남는다. 컴파일5229에서 위13검사를 한 실행에서 통과했다. 실제 적용5205의 별도4검사(native Tab,1093 실제 서비스/출발,새 원화 실패,영어 큰HUD/고대비/동작 감소)도 한 실행에서 통과했다.

최신 브라우저 시나리오는 소스13+native Tab1+기존회귀9+컴파일13+적용4의 **40회 실행**이다. 중간 재검사와 최초 서버 미실행 접속 실패는 통과 수에 더하지 않는다. 실제 사용자 저장·저장 형식은 변경하지 않았고 공개 배포·main 병합·개인 Linux/Docker 실서버 설치는 이번 완료에 포함하지 않는다.

## 직접 검토·교정·한계

1093 마당·의원·대장장이,1093 영어 큰HUD/고대비 출구 캡처를 직접 열어 배치·크기·가독성을 확인했다. 첫 시안의NPC 높이150이 플레이어보다 지나치게 커 보여95로 교정했다. 이름표를 머리 위로 옮겨 접근하는 플레이어를 가리지 않게 했다. 세 해상도 자동 경계/문자 측정과 모든 픽셀의 수동 검토는 구분한다.

개발 서버5225가 종료되어 있던 최초 접속 실패는 서버를 시작해 해결했고 통과 수에 포함하지 않는다. 초기 화면 검증 중 생성된trace HTML이 Vite의 page reload를 유발하는 로그를 확인해 검증 산출물을 감시에서 제외했다. 입력/상태/저장 결과와 원화 파일 자체는 바꾸지 않는다.

NPC는 정지 전신이며 플레이어의 기존 이동 모션을 사용한다. NPC 걷기/망치질·기연 발생/보상·후반 지역 이동 쉼터는 미구현이다. 기존 카드9/14/19와 실제 전투/밸런스·저장 형식은 유지한다. 모든 상태/언어/배율 조합·실물GPU·장시간 자연 플레이의 완전한 검증을 주장하지 않는다. 공개 배포와 개인 Linux/Docker 실서버 설치는 별도다.

선택한 측정JSON·요약은 Git에, PNG·trace·큰 단위/시뮬레이션 자료는 로컬에 보관한다. 재실행은 `playwright.waystation.config.ts` 및 구현 문서의 환경 변수를 사용한다.
