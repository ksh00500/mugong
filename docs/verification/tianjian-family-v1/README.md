# 천검산 7종 검증 기록

2026-10-05. 검객·창 수문장·검기술사와 우진·백홍·무명·백운을 로컬 배포에 적용했다. 테스트 상태는 Playwright 독립 브라우저 컨텍스트에만 넣었으며 실제 사용자 저장은 수정하지 않았다.

## 자동 검사

- `authored-tianjian.spec.ts`: Canvas/WebGL × 일반/동작 감소 설정의 네 검사 통과. 각각 7종 × 8방향 × 7상태 × 5시점 = 1,960개 기록, 합계 7,840개. 고정 배율 0.225·메시 비활성화·시점과 좌우 반전·고정 HP바·실제 그림 상단 간격·보스 피격 시 공격 주기 유지 확인.
- 같은 검사의 보스 접촉: 19개 기술의 총 25개 접촉 × 8방향 = 200개씩, 합계 800개. 두 번째·세 번째 연격도 접촉 원화 2를 표시한다. 각 기술의 독립 원화를 제작했다는 뜻은 아니다.
- `tianjian-release.spec.ts`: 실제 `tick`을 1/120초 간격으로 실행한 일반 적 3종 × 8방향 = 24개 판정 통과. 검객·창 수문장 피해가 실제 접촉 원화와 일치했고 검기술사는 접촉 원화에서 전방 투사체 2개를 방출했다. `actual-release.json`.
- `local-preview-tianjian.spec.ts`: 배포 빌드의 1440×900, 1366×768, 1093×614 세 검사 통과. 전투 입력·새 WebP 35개 응답·검토 화면의 7종 선택·보행/공격·재생/정지·프레임 이동·가로 넘침 확인. `production/`의 캡처와 JSON.
- 선택 원본 검사: 420자세에서 경계 잘림·그림 공유·잘린 대체 연결 성분 없음. 원본 연결 픽셀 RGBA 1:1 복사와 최소 32픽셀 여백 검사 통과. 실제 저장 WebP 35개를 재디코딩한 패딩 검사도 통과. 자료는 `docs/source/tianjian-family-v1`의 JSON.

브라우저 검사 8개가 통과했다. 네 행렬의 JavaScript 오류 기록은 비어 있고 살아 있는 원화 상단과 HP바 아래 사이의 최소 간격은 게임 좌표 약 11.225였다. 행렬의 타격 캡처는 일반 근접 적의 0.09초 접촉과 원거리 발사 순간에 맞추었으며 준비 그림을 타격으로 표시하지 않도록 검증한다.

최종 단위 검사: `npx vitest run --maxWorkers 2 --testTimeout 15000`, 52개 파일·1,249개 통과. 앞선 기본 실행에서는 대량 방향 기하 검사가 5초 제한에 걸렸다. 해당 파일의 단독 실행은 10개 모두 통과했고 최종 전체 실행은 두 작업자와 15초 실행 제한으로 완료했다. 기하·배율·방향 검증 조건은 변경하지 않았다.

최종 빌드: `npm run build` 통과. 로컬 주소 `http://127.0.0.1:5173/`, 검토 페이지 `/art/tianjian-family-v1/review.html`.

## 실제 시각 검토

자동 검사와 별도로 Canvas 보행·타격, WebGL 준비·타격, 쌍검 백홍의 여섯 공격 자세, 1093×614 전투를 열어 확인했다. 원화의 손과 무기 연결·팔꿈치와 지지발·앞뒤 몸 크기·검/창의 확장·HP바 간격을 비교했다. 긴 검/창의 이웃 그림 연결과 외곽 잘림은 해당 원화를 재생성했고, 회색 부츠를 놓친 백운 접지점 등 5개를 저장 좌표에서 수정했다. 런타임 몸 배율은 변경하지 않았다.

이 기록은 모든 관절·머리 치수를 수치 인증한 것이 아니다. 생성 원화의 미세한 비율·시점 차이는 남을 수 있다. 사망은 단일 자세 페이드이고 보스 19개 기술은 인물별 기본 공격 주기와 기존 효과를 조합한다. 원본 픽셀 보존에 따른 전체 천검산 시트의 디코딩 RGBA 용량은 약 358.36MiB이며 실제 브라우저/GPU 메모리와 다르다. 표시하지 않는 이전 천검산 메시 시트 네 개는 지역 로드 목록에서 제외했다.

원화·프롬프트·선택 수정안은 [원본 기록](../../source/tianjian-family-v1/README.md)에 있다.
