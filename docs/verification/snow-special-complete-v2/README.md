렌더 검사는 실제 Phaser의 `drawEnemy`에 준비/타격/복귀와 접촉 시간을 주입한다. 저장/시뮬레이션을 바꾸지 않는 것을 확인하며 피격 피드백을 함께 넣어 공격이 가려지지 않는지 검사했다. 모든 보스를 자연 전투로 장시간 클리어한 검사를 뜻하지 않는다. Playwright 독립 컨텍스트만 사용했고 실제 사용자 저장은 바꾸지 않았다.

생성 원본 18선택 시트와 백설노괴 후면 탈락1개를 보존했다. 최초/실제 호출 프롬프트와 소스 SHA, 실제 배열, 접지 좌표는 `docs/source/snow-special-complete-v2/`에 있다. 한설 정면 배열은 프롬프트와 달리4×3임을 검출해 실제 배열을 채택했다. 백설노괴 후면 손이 등에서 보이는 오류는 재생성했다. 런타임 포장물의 숨은 RGB는 일부 이미지 뷰어에서 색 줄무늬처럼 보였으나 알파 합성 PNG와 실제 Canvas/WebGL 캡처에서 표시되지 않았다.

직접 시각 검토는 설란 시전, 한설 부채, 백설노괴 쌍장/진각, 목진 횡소의 발 표시 5시점 비교판과 실제 전체18행동 접촉/두 번째 접촉/준비/복귀 캡처를 포함한다. 소품 손 소유·방향·몸 비율·발점/HP바 간격을 비교했다. 모든 프레임의 관절을 수동 편집했다거나 해부학적 완벽함을 보장하는 것은 아니다. 준비/회수에는 기존 원화가 포함된다.

실행 중 발견한 검사 문제도 남긴다. 타입 추론에서 지역 manifest의 문자열 인덱스 문제가 생겨 반환 타입을 명시했다. 컴파일 검사 첫 시도는 같은 지역의 세 해상도에 이름이 중복돼 실행 전 실패했고, 수정 후에는 검사 스크립트가 잘못된 `dist-snow-special-complete-v2`를 읽어 파일 비교1개 실패/나머지6개 통과했다. 실제 출력 `dist-snow-special-v2`로 수정한 뒤 전체7개가 통과했다. 비교판은 긴 창과 HP바가 앞 행에 겹치지 않게 행 간격을 늘려4조합을 재실행해 통과했다. 직접 캡처에서 발견한 비교 UI의 빈 행동명·팔 잘림을 고치고, 연격 선택지를 실제 접촉 수로 제한했다. 빈 이름/undefined와 새 캔버스 크기를 검증하는 UI 검사를 추가했다. 초기 실패를 최종 성공과 합산하지 않는다.

증거는 `atlas-audit.json`, `served-files.json`, `validation-summary.json`, `local-region-3-*.json`, `boards/`, `3-*-windup.png`, `3-*-strike.png`, `3-*-second-contact.png`, `3-*-recover.png`, `review-*.png`다. 캡처와 대량 프레임 로그는 로컬 증거이며 Git에는 요약/해시와 텍스트 기록만 보관한다.
