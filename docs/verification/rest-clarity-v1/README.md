## 직접 시각 검토와 수정

소스/최종 로컬의 후반 쉼터, 작은 영어 기연 대화, Canvas/WebGL 전투 캡처를 직접 열었다. 지역 배경 위 NPC·기연·출구와 하단 조작, 비용/보상·행동·닫기, 겹친 장판 경계·공격 방향·HP 표시를 확인했다. 40가지 지역/정비 조합의 접근 자동 검사를 40개 맵 모두의 수동 시각 검토로 주장하지 않는다.

색이 붉지 않은 보스 충격도 있음을 검토해, 단순한 비적색 판별 대신 알려진 플레이어 기본/무공 색상만 흐리게 했다. 지역 보스 색상10종과 접촉·혼잡하지 않은 효과를 보존하는 회귀를 추가했다. 약초 비용과 HP 사이의 소수점 차이도 검사해 실제1 HP를 남기도록 했다.

첫 소스 실행은 초기 화면 연결 오류 상태에서 실패해 중단했다. 별도 브라우저에서 정상 연결을 확인한 뒤 소스14개 전체를 다시 실행했다. 최초 실패/중단 수는 통과 합계에 포함하지 않는다. 로컬 프리뷰 교체 직후 첫 SHA 확인은 서버가 수신하기 전의 `ECONNREFUSED`였으며, 준비 완료 후 다시 요청해 아래 제공 파일을 확인했다.
