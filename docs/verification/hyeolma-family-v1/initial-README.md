# 혈마전 로컬 적용·검증

2026-10-05. 일반 적 3종과 보스 4종을 방향별 원화로 연결했다. 원화 교정 일부는 이미지 생성 한도로 미완료이며 아래에 구분한다. 실제 사용자 저장은 수정하지 않고 Playwright 독립 컨텍스트에서만 테스트 상태를 사용했다.

## 자동 검사

- 전체 단위 검사: 54개 파일, 1,257개 통과. 빌드 `npm run build` 통과. 배포 파일은 `main-B5noUk-6.js`, `mount--2POXoI9.js`.
- Canvas/WebGL × 일반/동작 감소: 네 검사 통과. 각각 7종×8방향×7상태×5진행 시점=1,960개 기록, 합계 7,840개. 고정 배율 0.225, 메시 비활성화, 방향과 반전, 고정 HP바와 최소 간격, 보스 피격 시 공격 유지 확인. 살아 있는 원화와 HP바 아래 최소 간격은 게임 좌표 약 11.225.
- 보스 19개 행동의 24개 접촉×8방향=192개씩, 합계 768개가 접촉 프레임을 선택한다. 연격의 두 번째·세 번째 접촉을 포함한다. 모든 보스 행동을 실제 시뮬레이션으로 실행한 검사나 행동별 독립 원화 제작은 아니다.
- 일반 적 3종×8방향=24회 실제 `tick` 검사 통과. 혈도병 베기와 암살자 돌진 피해는 접촉 프레임에서 발생하고, 혈지 술사는 혈지 착지 정보를 가진 전방 투사체를 발사한다. `actual-release.json`.
- 로컬 배포 빌드 1440×900, 1366×768, 1093×614 세 검사 통과. 전투 입력, WebP 35개 응답, 검토 화면의 7종 선택·보행/공격·재생/정지·프레임 이동, 가로 넘침을 확인했다. `production/`에 캡처와 JSON을 저장했다.
- 선택 420프레임의 잘림·모호한 연결·의도하지 않은 그림 공유 없음. 원본 RGBA 1:1 패킹·32픽셀 이상 여백 검사와 WebP 35개 재디코딩 검사를 통과했다. 의도적인 자세 재사용은 명시한 원본과 이전 프레임이 정확히 일치할 때만 허용한다.

브라우저 검사 총 8개 통과. 네 행렬의 JavaScript 오류는 없었다. 상세 수치는 `metrics.json`, 각 행렬의 JSON과 보행·준비·접촉·회수 캡처 16개에 있다. 로컬 서버는 `http://127.0.0.1:5173/`, 검토 페이지는 `/art/hyeolma-family-v1/review.html`이다.

## 실제 시각 검토와 미완료 원화

Canvas 보행·준비·접촉, WebGL 접촉, 소홍의 준비·접촉 비교, 1093×614 전투 캡처를 별도로 열어 확인했다. 무기/손 연결, 칼끝, 접지, 앞뒤 시점과 HP바 간격을 검토했다. 자동 검사는 관절의 자연스러움이나 머리 치수 통일성을 인증하지 않는다. 생성 원화의 미세한 비율과 시점 차이는 남을 수 있다.

혈도병 보행·피격에서 빠진 칼, 혈지 술사의 접촉에서 사라진 소품, 긴 칼끝과 모서리 잘림은 선택 프레임을 다시 그렸다. 소홍 앞 대각선과 옆모습의 준비는 부채 손이 유지되는 가슴 높이 자세로 교정했다. 사용할 수 없는 불투명 배경과 몸 방향이 반대인 수정안은 채택하지 않았다.

추가 생성 요청이 `429 usage_limit_reached`로 종료되어 소홍 정면·뒤 대각선의 공격과 뒤쪽 준비 원화 교정은 완료하지 못했다. 부채 손이 바뀌는 그림은 제외하고 기존 대기·보행·준비 자세를 임시 조합했다. 해당 시점은 충분한 부채 휘두르기 동작으로 완성한 상태가 아니다. 연살 뒷모습 피격은 대기를 재사용한다. 적천 옆모습의 잘린 접촉은 온전한 후속 자세를 접촉·후속 동안 유지한다.

420개 논리 프레임은 402개 원본 그림을 사용한다. 18개 재사용과 추가 제작 대상은 `docs/source/hyeolma-family-v1/selection-summary.json`, 정확한 원본 셀은 `generation-jobs.json`에 기록했다. 소홍 임시 조합은 검토 화면에도 표시한다. 전체 시트의 디코딩 RGBA 용량은 약 337.73MiB이며 실제 GPU/브라우저 메모리 수치와는 다르다. 이전 혈마전 메시 시트 네 개는 지역 로드 목록에서 제외했다.

원화와 프롬프트는 [제작 출처](../../source/hyeolma-family-v1/README.md), 적용 범위는 [혈마전 기록](../../hyeolma-family-v1.md)에 있다.
