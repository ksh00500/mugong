# 독무곡 특별 모션 검증

2026-10-06. 보스 4명 × 특별 동작 2종 × 원화 시점 5종 × 자세 6종 = 240논리 프레임. 5시점과 좌우 반전으로 8방향을 표시한다. 독무곡 18행동 중 8행동에 새 특별 원화를 적용하며 나머지 10행동은 기존 방향별 기본 원화를 사용한다.

## 자동 검사

- 타입 검사와 최종 프로덕션 빌드 성공. 전체 단위 검사 1,291개 통과: `unit-results.json`. 전체 검사를 단일 작업자로 순차 실행했다.
- 특별 모션 Canvas/WebGL × 일반/움직임 감소 설정 4검사 통과: `canvas-full.json`, `canvas-reduced.json`, `webgl-full.json`, `webgl-reduced.json`. 46,848개 시간 표본과 실제 접촉 320개(합계 47,168개)를 확인했다. 고정 배율 0.225, HP바 높이와 간격, 방향/반전, Phaser가 실제 사용하는 프레임 이름·사각형, 피격 표시 중 공격 자세, 저장 불변을 검사했다.
- 기본 인물 7명 회귀 검사 4개 통과: `basic-regression/`. 상태 표본 7,840개와 접촉 672개를 검사했다. 새 특별 모션이 없는 동작의 기본 원화와 죽음·피격 표시를 포함한다.
- 소림 장면에서 독무곡 원화를 추가로 불러오는 지역 전환 검사 1개 통과: `runtime-region.json`. 실제 텍스처에 등록된 240개 프레임의 이름과 사각형이 일치하고 전투 저장 내용은 유지됐다. 최종 소스 브라우저 검사 합계 9개 통과.
- 최종 프로덕션 전투/검토 화면의 1440×900·1366×768·1093×614 검사 3개 통과: `production/verification-*.json`. 각 화면에서 특별 텍스처 20개 로딩, 보스 4명/행동 8종 선택, 정지·프레임 이동, 가로 넘침과 실행 오류를 검사했다. 최종 브라우저 검사 합계 12개 통과.
- 원본 40개 경계·셀 연결·중복 검사 통과: `../../source/dokmu-special-v1/source-review.json`. 원본 SHA-256과 복사본 일치는 `generation-records.json`에, 원본 픽셀 보존과 최소 32픽셀 여백은 `export-review.json`에 기록했다. 게임 텍스처 20개와 `dist` 복사본의 바이트 일치도 확인했다.
- 독립 agent-browser 세션에서 검토 화면이 로드되고 8개 Canvas, 보스·패턴 선택, 정지·프레임 이동 버튼이 표시됐다. Vite 오류 표시가 없었다: `browser-gut-check.png`. 실제 페이지 실행 오류는 Playwright의 `pageerror` 수집 결과로 별도 확인한다.

## 실제 시각 검토

240개 발 기준점을 표시한 20개 원화 시점 표를 직접 확인했다: `../../source/dokmu-special-v1/ground-review/`. 낮은 검 끝 때문에 지면 좌표가 옆으로 끌리던 경우를 발 기준으로 수정해 저장했다. 게임에서는 좌표 추정이나 프레임별 크기 맞춤을 하지 않는다.

Canvas의 준비·접촉·회수 전체 방향 표, WebGL의 접촉·회수 표, 기본 인물 Canvas/WebGL 접촉 표, 1440/1093 검토 화면과 1093 전투 화면을 직접 확인했다. 손과 무기의 연결, 방향, 몸 크기, 발 위치, HP바 간격, 셀 침범을 검토했다. 이는 저장된 캡처와 검사 범위에 대한 검토이며 모든 플레이 상황에 대한 보증은 아니다.

## 재실행 기록

초기 전체 단위 검사를 빌드/원화 처리와 동시에 실행했을 때 일부 기존 대량 검사가 5초 제한에 걸렸다. 또 한 번의 기본 병렬 실행에서는 방향 모션 검사만 시간 제한에 걸렸다. 단일 작업자·파일 순차 실행으로 전체 1,291개가 통과했다. assertion 실패는 없었으며 시간 제한이나 게임 규칙을 완화하지 않았다.

초기 브라우저 소스/프로덕션 검사 두 실행이 같은 Playwright 결과 폴더를 사용해 trace 파일이 사라지는 ENOENT 오류가 발생했다. 병행 실행에서 WebGL 시작도 한 번 30초 제한에 걸렸다. 소스/프로덕션 결과 경로를 분리하고 실행을 순차로 바꾸었다. 최종 소스 검사 9개와 프로덕션 검사 3개는 모두 통과했다. 초기 실행은 최종 통과 수에 포함하지 않는다.

검사는 Playwright 독립 컨텍스트에만 테스트 저장을 만들었다. 실제 사용자 저장은 변경하지 않았다. 이번 변경은 로컬 빌드에 적용한다.
