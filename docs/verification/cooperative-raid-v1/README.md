## 실제 여러 브라우저의 조작

테스트는 독립 브라우저 컨텍스트와 별도 SQLite를 사용한다. 사용자 브라우저/저장·온라인 DB는 테스트 데이터로 바꾸지 않는다. 전환 검사의 첫 층 보스 HP만40으로 낮춘 **서버 생성 fixture**를 사용했으며 공개 입력/환경 변수로 이 설정을 켤 수 없다. 실제 조작/판정/다음 층 규칙과 fixture HP를 구분한다.

1. 1440×900·1366×768·1093×614 두 계정: 가입/표준 선택→방 코드→양쪽 그림/대전 준비→방장 출발→실제 공격 접촉/아군 무피해→클리어→한 사람 준비 후 다른 사람 귀환→남은 준비 취소→다음 층1인 스케일→기록/포기. 독립 오프라인 테스트 저장 객체의 전후 일치를 확인했다.
2. 독립 브라우저4개: 나중 참가자가 기존 준비를 취소하고 네 명이 같은 보스/방을 본다. 재로드 후 같은 도전 ID로 복구한다. 규칙창을 열어도 서버 틱이 계속 진행한다.1093×614에서 파티/보스 HUD·행동·하단 버튼 경계를 검사했다.
3. 그림 요청을 실패시켜 준비 버튼을 막고 같은 솔로 방에서 재시도해 출발했다.
4.1093×614에서 다음 층 카운트다운 중 준비 취소→이전 클리어 층의 정비→재준비/다음 층을 실제 클릭했다. 최종 UI 재실행에는 결과의 유효 피해 수치와 저장 표시도 확인했다.

## 기본 수치·시뮬레이션

fixture와 다른 독립 서버를 기본 규칙으로 실행했다. 두 브라우저가 실제 보스 최대HP **2,640**(1600×1.65)에 피해를 주고 `cleave`/`charge`의 서로 다른 준비를 관측했다. 표식/피해가 발생하는 전장에서 PNG를 촬영했고 HP2565.24, pageerror0을 기록했다. 이는 정상 HP의 짧은 전투/예고 검사이며 인간 완주/체감 밸런스 검증은 아니다.

기본 수치의 별도 결정적 자동 전투 관측은1/2/3/4인으로 실행했다. **2인·4인5층 완료**, 1인1층·3인4층 후 전멸이었다. [관측 원본](normal-probe.json). 정비에서만 실제 회복약을 사용하며 HP·피해·무공·보스 수치를 변경하지 않았다. 단순 이동/공격 정책 한 가지의 결과이므로 플레이어 승률·무공 간 공정함으로 해석하지 않는다. 전환 단위 검사에서 보스HP를0으로 놓고5층 상태/동시 KO 경계를 확인한 것과도 구분한다.

서버/엔진 검사는 팀 필터/탄 관통·실제 손실에 따른 피해 귀속, HP/게이지/회복약 유지·전투 중 약 금지, 파티 재확인/카운트다운 취소, 단계/시간 제한·동시 보스/전원KO, 변조/이전 revision 거절·비무와 중복 출전 금지·재접속/로그아웃을 확인한다. DB는 계정별 원장/중복 결과/체크포인트 단조 증가·Elo 유지, 실제 임시 파일 재열기·스키마1 계정 유지·중단 기록 무효를 검사했다. 기존 비무의 DB 쓰기 실패 재시도 검사도 이번 전체에 포함했다. 레이드만의 DB 실패 주입/90초 실시간 지연/손실·대규모 부하 행렬을 완료한 것은 아니다.

## 직접 시각 검토·로컬 적용

이번 전투/정상 수치 돌진 예고·최종 결과·로비1093×614 PNG를 직접 열었다. 보스 층/시간의 어두운 글자 대비를 높였고 아군 준비 사격을 긴 적 예고선처럼 그리지 않게 했다. 동료 표식은 녹색 계열, 보스는 주황색으로 구분한다. 반환한 무인을 전장에 남은 안전한 인물처럼 표시하지 않는다. 자동 경계 검사와 직접 시각 검토를 구분하며 전언어/전캐릭터 신규 전수 검토·접근성 인증을 주장하지 않는다. 새 원화는 생성하지 않았다.

실제 로컬은5205의 `dist-cooperative-raid-v1`, 서버8787이다. 기존 서버를 종료한 후 기존 DB/WAL/SHM의 존재 파일을 비공개 위치에 복사하고 백업을 읽기 전용 `quick_check=ok`로 확인했다. 스키마2는 기존 계정/비무 표를 유지하고 레이드 표만 추가한다. 실제 데이터 값을 문서/기억에 기록하지 않는다. 검증용5227/5228/8788(fixture)·5229/8789(기본 규칙)와 실제 온라인 DB는 분리했다.

디스크 공간을 보존하기 위해 새 로컬 빌드만 public 디렉터리 junction을 공유했다. 원본/과거 빌드/원화를 삭제하지 않았다. **이 출력은 서버 배포용 압축본이 아니다.** Docker는 실제 public 파일을 포함해 빌드하도록 유지한다. 이번 Docker 데몬 조회도10초 안에 응답하지 않아 CLI만 중지했다. 최신 레이드 Docker 이미지/실행·Nginx→WS·집 Linux/Cloudflare 공개 주소는 검증하지 못했다. 과거 비무 이미지 성공을 이번 Docker 성공으로 합산하지 않는다. 원격 CI 성공/계정 결제 잠금 해소·main 병합도 주장하지 않는다.
