## 초기 실패와 수정

- 보스 확대와 함께 공격 원점까지 높인 초기안에서 기존 창 옆 판정·송월 대나무 반사2단위가 실패했다. 원점을34px로 복원하고 대상 보스의 캡슐만 확대한 후 전체1,368개가 통과했다. 기존 검사의 기대를 느슨하게 바꾸지 않았다.
- 샌드박스 Prettier가 기존 파일 일부를 UNKNOWN으로 쓰지 못했다. 허용된 정상 권한에서 재정렬했고 타입/스냅샷을 다시 확인했다.
- 검증 config 폴더가 Vite 작업 디렉터리가 돼 최초 서버가 시작되지 않았다. cwd를 명시해 수정했다.
- 제갈에는 실제 zone 투척 기술이 없어 비교 fixture의 field 선택이 실패했다. 실제 독병 장판을 가진 독무곡으로 옮겨4종 비교를 통과했다.
- 추격의 짧은 전진은 실제 경로 피해가 없다. 초안의 돌진 통로를 제거하고 실제 종점 무기 형태만 예고하도록 교정·검증했다.
- 소스 전용 검사가 기본 경로에 쓴4시뮬레이션 결과는 이번 source-simulation/에 복사하고 이전 문서의 결과는 HEAD로 보존했다.

Canvas/WebGL은 로컬 Chromium/SwiftShader 경로다. 실물 GPU·장시간/저사양 플레이·개인 서버 네트워크는 별도다. 상태 표시가 모든 보스에 새로운 체력 페이즈를 만들지는 않는다. 기계 장치의 별도 회전/개폐 원화는 유지하며 실제 경고가 있는 일반 위험 장판만 원형 표시한다. 원격CI·개인 서버 공개 배포·main 병합은 이번 완료 범위가 아니다.
