# 제갈 7종 검증 기록

2026-10-04. 로컬 전용 배포를 검증했다. 모든 테스트 저장은 Playwright의 독립 브라우저 컨텍스트에만 넣었다. 사용자의 실제 저장은 수정하지 않았다.

## 자동 검사

- `authored-zhuge.spec.ts`: Canvas/WebGL × 일반/감소된 동작, 네 검사 통과. 각 검사에서 7종 × 8방향 × 7상태 × 5시점 = 1,960개 기록을 남겼다. 원본 배율 0.225, 메시 비활성화, 방향·좌우 반전, 고정 HP 바, 실제 원화 상단과의 간격, 보스 피격 중 공격 자세 유지 등을 확인했다.
- 같은 검사의 `contacts`: 보스 18개 행동의 총 24개 접촉 × 8방향 = 192개 기록씩. 연타의 두 번째·세 번째 접촉도 타격 그림을 표시한다. 모두 별개 원화 시퀀스를 생성했다는 뜻은 아니다.
- `zhuge-release.spec.ts`: 실제 `tick`으로 일반 적 3종 × 8방향 = 24번 판정을 진행했다. 기관병의 설치탄 1개와 gate 착지 설정, 쇠뇌병의 전방 3발, 창 문지기의 지연된 실제 피해가 접촉 그림과 일치했다. `actual-release.json`.
- `local-preview-zhuge.spec.ts`: 배포 빌드의 1440×900, 1366×768, 1093×614 세 검사 통과. 제갈 35개 WebP 응답, 전투 입력, 검토 화면의 7종 선택·보행/공격·정지/프레임 이동과 가로 넘침을 확인했다. `production/`의 캡처·JSON.
- `zhuge-startup.spec.ts`: Canvas/WebGL 두 검사 통과. 기존 제갈 메시 아틀라스를 불필요하게 로드하지 않고 새 시트 35개를 등록했다. 원화 준비 후 초기화는 이 환경에서 Canvas 1,039.7ms, WebGL 3,038.9ms였다. WebGL preload 1,928.4ms, create 1,078.5ms. `startup/`의 JSON. 개발 서버·자동화 브라우저에서의 단일 측정이며 모든 기기의 지연 보장은 아니다.

브라우저 검사 총 10개가 통과했다. 네 동작 행렬의 JS 오류 기록은 비어 있고, 살아 있는 그림 상단과 HP 바 아래 사이의 최소 간격은 게임 좌표에서 약 11.225였다. 소스 경계·공유 그림 검사와 원본 RGBA 보존·최소 32픽셀 전달 여백 검사는 `docs/source/zhuge-family-v1`의 JSON에 따로 있다.

## 실제 시각 검토

자동 결과와 별도로 실제 캡처를 열어 비교했다. Canvas 타격 7종×8방향, WebGL 보행·준비·회수 7종×8방향에서 인물의 크기·무기 방향·외곽·지면 위치·HP 바 여유를 검토했다. 정면 창끝이 부츠보다 아래로 내려가는 네 원화 접지점은 발 기준으로 보정한 뒤 다시 캡처했다. 1093×614 배포 전투와 1366×768 검토 화면도 직접 확인했다.

이 검토는 모든 원화의 관절·머리 치수를 수치 인증한 것이 아니다. 생성 원화의 미세한 비율 차이는 남을 수 있다. 사망은 단일 자세 페이드, 보스는 인물별 기본 동작과 기존 공격 효과를 조합한다. 원본을 보존하기 때문에 전체 제갈 시트의 디코딩 후 RGBA 용량은 약 387MiB이며 실제 GPU/브라우저 메모리는 별도로 달라진다.

최종 빌드: `npm run build` 통과. 최종 단위 검사 전체 51개 파일·1,245개 통과. 역할별 선택·보스 우선순위·지역 시트 구성·공통 배율/여백·모든 보스 접촉 노출과 기존 소림 선택 검사를 포함한다.
