두 번째 타격의 접촉별 시계/방향을 실제 렌더링에서 검사한다. 750개 전부가 새 원화는 아니다. 761물리 셀은 준비/대기 중복 셀과 기본36개, 새 접촉5개를 포함하므로 독립 그림 수로 해석하지 않는다.

자동 검사 후 12보스의 다섯 시점 전체 비교판, 아사르·아르칸의 열 개 확대 발점판, 실제 게임 Canvas/WebGL 접촉/준비/복귀 캡처와 세 화면 크기를 직접 비교했다. 나야의 새 두 번째 접촉에서 발광 사각형/옆 프레임 유입이 보이지 않고 오른손 회수·왼손 공격이 구분되는지 확인했다. 직접 검토는 해부학적 완벽함이나 장시간 플레이테스트 완료를 뜻하지 않는다.

초기 단위 실행은 샌드박스 임시 Vite 파일 rename EPERM으로 시작하지 못했고, 허용된 실행에서 다시 검사했다. 발점 내보내기 도중 실행한 전체 검사에서 READY 루트 불일치1개가 발생해 내보내기 완료 후 재실행했고1,298개 통과했다. 타입 검사에서 JSON union의 테스트 표현 두 곳을 수정했다. 실제 빌드는 `check:assets`·타입 후 Vite를 별도 출력 `dist-three-special-v2`로 실행했다. 1,800kB 초과 청크 경고는 남는다.

원본 사용자 IndexedDB를 바꾸지 않았다. `seedRegion`은 Playwright 독립 브라우저 컨텍스트만 사용한다. 일반 런타임으로 실전 모든 패턴을 끝까지 플레이한 검사가 아니라 실제 Phaser 렌더 경로에 공격 상태·접촉 시간을 주입한 검사와 컴파일 게임 입력 검사를 조합한 것이다. 피해·AI 밸런스 변경은 없다.

증거: `atlas-audit.json`, `served-files.json`, `validation-summary.json`, `local-region-*.json`. 대량 프레임 JSON·단위 원본 보고서·PNG는 이 폴더의 로컬 증거이며 Git에서는 제외한다. 세 지역의 캡처는 `*-windup.png`, `*-strike.png`, `*-recover.png`, `local-region-*.png`, `review-*.png`다. 공개 배포·개인 서버 업로드·main 병합 검사는 하지 않았다. 이전 GitHub Actions 결제 차단도 이번 로컬 성공으로 해소됐다고 기록하지 않는다.
