- 로컬 실행: http://127.0.0.1:5188/ · 갤러리: http://127.0.0.1:5188/captures/

## 이번 확인

첫 시도는 5173 포트가 다른 프로젝트를 제공해 로비 선택자 확인에서 실패했다. 그 프로세스에 손대지 않고 5188 포트로 변경했다.

5188 촬영 첫 묶음은 9개 통과, 죽림 1개 실패였다. 삼재 궁극기의 개방 레벨이 8인데 촬영용 무공을 5로 두었던 것이 원인이다. 게임 규칙을 바꾸지 않고 촬영용 레벨을 개방 조건에 맞춰 죽림만 재실행했으며 1개 통과했다. 최신 지역별 유효 결과는 10개이며, 전체 10개를 수정 후 재실행했다고 기록하지 않는다.

모든 유효 촬영에서 해당 지역 연결·준비 완료·궁극기 준비 상태 소모·브라우저 예외 없음·미디어 HTTP 오류 없음을 확인했다. 경험치는 레벨 누적 기준에 맞춰 15/80로 설정했다. 개방의 궁극기는 강화 예약 후 평타로 발동했다. 타입 검사를 통과했다.

20장 모음과 청하현/소림 원본을 직접 시각 검토했다. 모든 프레임의 관절이나 전체 모션 품질을 승인한 검사는 아니다. 별도의 최신 게임 빌드는 만들지 않고 기존 `dist-validation-hosting` 컴파일 본을 사용했다. 공개 배포·GitHub 업로드·추가 특별 원화 제작은 이번 작업에 포함하지 않는다.
