# 설산 로컬 적용 검증

2026-10-05. 일반 적3종·보스4종의 420개 방향별 기본 자세를 적용했다. 세부 수치는 `summary.json`, 선택 원본과 출처는 `../../source/snow-family-v1/selected-art-audit.json`에 기록한다. 자동 검사와 직접 시각 검토는 구분한다.

## 자동 검사

- 최종 빌드와 전체 단위57파일·1,270개 통과(`build.log`, `unit.json`).
- 원본420개 누락·잘림·이웃 연결·의도하지 않은 그림 공유0건. 최종 선택59개 PNG는 생성 도구 원본과 바이트가 같고 프롬프트·출처를 보관했다. 420개 그림의 RGBA 해시는 모두 다르다. 총81개 생성 후보 중 탈락 원본도 보존한다.
- 원본 RGBA 1:1 패킹 후35개 lossless WebP를 재디코딩해420프레임과 최소32px 투명 여백을 검사했다.
- Canvas/WebGL × 일반/줄인 움직임4개 검사 통과. 각각7종×8방향×7상태×5진행도=1,960개, 합계7,840개 상태다. 공통배율0.225·방향/반전·메시 비활성화·고정HP바·보스 피격 시 공격 자세 유지가 대상이다. 살아 있는 자세의 실제 HP바 하단과 불투명 그림 상단 간 최솟값은약11.22px였다.
- 보스18행동의21접촉×8방향=168회씩, 합계672회에 접촉 원화를 선택한다. 모든 보스 행동을 실제 시뮬레이션으로 끝까지 실행한 검사는 아니다.
- 일반 적3종×8방향=24회 실제 tick 검사에서 창 돌진 피해, 빙술사1발과 냉기 지대 착탄 설정, 궁수1발을 실제 발사·타격 순간의 원화와 비교했다(`actual-release.json`).
- 로컬 배포본1440×900·1366×768·1093×614의3개 검사 통과.35개 WebP 응답·전투 이동·검토 화면7종 선택·걷기/공격·정지/프레임 이동·가로 넘침·페이지 오류를 검사하고 `production`에 캡처와 JSON을 저장했다.

브라우저 총8개 통과. localhost 소켓 제한 때문에 브라우저 검사는 샌드박스 밖의 독립 Playwright 컨텍스트에서 실행했다. 실제 사용자 저장은 변경하지 않았다. 외부 서버 배포는 수행하지 않았다.

## 직접 시각 검토

7개 인물의60자세 비교표(`contact`)를 열어 머리·몸통 크기, 무기 손과 손잡이 연결, 관절, 발 기준선을 비교했다. 창병 정면의 일부 자세가 과하게 커진 후보를 제외하고12자세를 같은 기준으로 다시 생성했다. 각 자세의 원본 픽셀을 보존하며, 시점의 원근 단축과 구부린 자세로 인한 실루엣 차이는 남는다.

긴 창이나 모피가 발보다 내려가는 자세는 그림 최하단 대신 실제 발 기준점을 사용한다. 정면 창병의 걷기·준비·후속4자세는 한쪽 가장 낮은 발을 따라 좌우로 이동하지 않도록 양발 사이 기준점으로 교정했다. 자동 접지 좌표 제안은 신발 색에 대한 추정이며 직접 검토 결과는 `manual-review.json`에 남겼다.

실제 Canvas·WebGL의 대기·접촉·피격 비교 캡처, 세 해상도의 전투·검토 화면, 한설의 준비2·타격·후속·회수·복귀6개 캡처를 직접 열었다. 검사한 캡처에서 무기 잘림·이웃 그림 혼입·HP바 겹침은 보이지 않았다. 보스의 피격 반응은 공격 자세를 대체하지 않는다.

이 검토는 해부학이나 모든 신체 치수를 수치 인증하지 않는다. 일부 보스 특수 행동은 대표 공격 주기를 공유하고 사망은 한 자세의 페이드다. 반대쪽3방향은 좌우 반전이며 무기 손의 화면 위치도 함께 바뀐다.
