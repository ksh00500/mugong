## 실패와 경계

초기 새 원화 단위는 보스 보상을 일반 상품 생성기로 만들려다1실패해 실제 bossReward fixture로 고쳤다. 초기 이미지 실패 브라우저는 Phaser 기본3회 요청을1회로 가정해1실패했으며 제한 재시도 후 안정성을 검사하도록 수정했다. TypeScript는 브라우저 전용 절대 import를 검사에서 문자열 동적 import로 바꿨다. 첫 격리 서버는 ws를 통째로 번들링해 Node require 오류로 시작하지 못했고 해당 브라우저 실행을 중단했다. 패키지를 external로 바꾸고 API health 확인 뒤3개를 모두 재실행했다. 실제 서비스 오류를 고친 것처럼 기록하지 않는다.
