# 천검산 특별 모션 검증

2026-10-06, 로컬 적용. 보스 4명 × 전용 동작 2종 × 원화 시점 5종 × 자세 6종 = 240프레임. 5시점과 좌우 반전으로 8방향을 표시한다. 천검산 19행동 중 새 전용 원화는 8행동이며, 나머지 11행동은 기존 기본 원화를 사용한다.

## 자동 검사

- 타입 검사·프로덕션 빌드 성공. 단위 검사 248개 통과: `unit-results.json`.
- 특별 모션 Canvas/WebGL × 일반/움직임 감소 설정 4검사 통과. 47,104개 상태 표본과 실제 접촉 256개, 고정 배율·HP바 간격·방향·프레임 사각형·저장 불변 검증: `canvas-full.json`, `canvas-reduced.json`, `webgl-full.json`, `webgl-reduced.json`.
- 천검산 기본 인물 7명 회귀 검사 4개 통과: `basic-regression/`. 상태 표본 7,840개와 접촉 800개를 검사했다.
- 기존 소림 특별 모션 회귀 검사 4개 통과: `../shaolin-special-v1/`.
- 로컬 프로덕션 전투/검토 화면 1440×900·1366×768·1093×614 검사 3개 통과: `production/verification-*.json`. 새 텍스처 로딩, 검토 화면 조작, 가로 넘침, 브라우저 실행 오류를 검사했다.
- 지역 전환 로딩 검사 1개 통과: `runtime-region.json`. 소림을 불러온 장면에서 천검산 텍스처를 추가하고 240개 프레임의 실제 이름과 사각형을 검증했다. 전투 저장 내용은 유지됐다. 합계 브라우저 검사 16개가 통과했다.
- 원화 검사: `../../source/tianjian-special-v1/source-review.json`의 선택 원본 40개에 경계 잘림·이웃 인물 연결·누락이 없었다. `export-review.json`에 원본 해시, 픽셀 보존, 최소 32픽셀 여백을 기록했다. 게임 배율은 프레임 전체에서 0.225로 고정한다.

## 실제 캡처 검토

Canvas의 준비·접촉·회수 전체 방향 표, WebGL의 접촉·회수 표, 기본 인물 Canvas/WebGL 접촉 표, 1440/1093 검토 화면과 1093 전투 화면을 직접 확인했다. 검과 손의 연결, 발 위치, 자세별 몸 크기, HP바 간격, 이웃 셀 침범 여부를 검토했다. 이는 해당 캡처와 테스트 범위의 검토이며 모든 플레이 상황에 대한 보증은 아니다.

## 발견한 문제와 재검증

초기 캡처의 `rejected-whole-sheet.png`는 새 텍스처의 개별 프레임이 등록되지 않아 시트 전체가 표시된 실패 증거다. 시작 로딩과 지역 전환 로딩의 지역 이름 허용 목록을 제거하고 정확한 원화 키로 프레임을 등록하도록 수정했다. 검사도 Phaser가 실제 사용하는 프레임 이름과 잘라낸 사각형까지 비교하도록 강화했다. 최종 캡처에는 개별 인물만 표시된다.

처음 시작 시간 제한과 별도 검사 서버 시작 제한에 걸린 실행은 완료 결과에서 제외했다. 마지막 WebGL 실행의 `ERR_NETWORK_CHANGED`는 코드 요청이 중단된 실패였으며, 같은 검사를 다시 실행해 통과했다. 지역 전환 테스트의 잘못된 함수명은 실제 `loadRegion` 호출로 수정했다.

실제 사용자 저장은 수정하지 않았으며, 브라우저 검사는 Playwright 독립 컨텍스트에만 테스트 저장을 생성했다. 공개 서버에는 배포하지 않았다.
