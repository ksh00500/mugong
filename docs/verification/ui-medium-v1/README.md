## 검사 중 발견·교정

1. 다섯 언어 검사에서 숨겨진 소리 탭의 음소거 스위치까지 선택하던 준비 오류를 `:visible`로 교정했다. 제품 오류가 아니다.
2. 과거 비급 검사가 레벨 상승만으로 무공 선택을 기대했다. 현재 수련점은 전투 보상 규칙이므로, 경험치/레벨 저장·수련점0·허위 선택창 없음으로 전제를 교정했다. 게임 규칙을 바꾼 것은 아니다.
3. 가방의 **실제 Tab 버그**를 재현했다. 능력치 설명의 focusout/unmount 도중 임시 body 초점을 유실로 판단한 MutationObserver가 닫기 버튼으로 되돌렸다. 복구 판단을 다음 animation frame으로 묶고 해제 시 취소했다. 세 해상도 Tab/Shift+Tab·무공 설명·닫기 복귀와 기존 상세 검사에서 재검증했다. `focus-before.json`과 `source/tab-stat-tooltip-*.json`에 전후 증거를 남겼다.
4. 만석 창고 검사의 과거 `가방으로 F` 이름을 실제 `일반 가방에 수납 F`로 교정했다. 물품 보존과 비활성 동작을 재검사했다.
