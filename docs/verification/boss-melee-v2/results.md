# 보스 근접 개편 2차 검증 · 2026-10-03

## 자동 검사

- `npx vitest run --maxWorkers=1 --reporter=dot`: **40개 파일·979개 검사 통과**. 최종 단독 실행으로 확인했다. 기존 `directional-motion.test.ts`의 대량 기하 검사는 빌드와 동시 실행할 때 5초 제한에 걸렸으므로 테스트 제한을 늘리지 않고 부하를 분리했다.
- `npm run build`: TypeScript 검사와 Vite 배포 빌드 성공.
- `npx playwright test tests/e2e/boss-melee.spec.ts --config playwright.polish.config.ts --reporter=line`: **13개 브라우저 검사 통과**. 1차 보스 5명의 회귀 검사도 포함한다.
- 2차 24개 행동 × 8방향 × 준비/접촉/회복 = **576개 렌더 상태**. 1차 포함 총 1080개 상태에서 실제 지역/전용 텍스처, 유한 크기, 실제 진각 피해/둔화, 저장 검증과 동일 재개 결과, 페이지 오류 없음을 검사했다.
- 단위 검사는 각 30초 전투 순환의 공격 선택, 모든 공격의 팔방 물리 판정, 좁은 창/사슬의 측면 빗나감, 연타의 접촉별 피해와 저장 재개, 무적·거리 이탈, 적중 시만 둔화/끌기, 대회전 후방 적중의 바깥 방향 넉백, 호령 2명·1회 제한·경험치 예산, 깃발 1개·소유자 한정·거리 이탈/파괴 해제, 창 거리 확보, 저체력 추격, 구형 시전/연결 저장 호환을 포함한다.
- 실제 브라우저의 기믹 검사에서 철무에게 맞은 플레이어는 1200→1020으로 끌려갔고 지속 흡인 오브젝트/탄은 생성되지 않았다. 노진의 기는 1개였고 파괴 후 피해 배율은 0.45→1로 복귀했다. 마대봉은 준비/접촉 후 본체와 증원 2명만 남겼다.

`*-render.json`은 렌더 상태와 판정/저장 결과, `*-mechanic.json`은 위 기믹 결과다. 화면은 `*-windup.png`, `*-strike.png`, `*-slam.png`, `*-mechanic.png`에 기록했다. 원거리 발사 제거 검사는 보스 본인의 소유 투사체를 대상으로 한다. 증원된 일반 적의 고유 공격까지 없애지 않는다.

테스트 데이터는 도메인 독립 상태 또는 Playwright 독립 브라우저 컨텍스트에만 주입했다. 실제 사용자 저장을 지우거나 테스트 상태로 바꾸지 않았다. 테스트용 체력 100000과 고정 위치는 게임 데이터/밸런스에 반영하지 않았다.

## 실제 화면 검토

- 승인 원화 연락표 `docs/verification/animation-rebuild-v2/region-0-actions.png`, `region-7-actions.png`를 열어 무기와 인물 대응을 확인했다. 마대봉은 도끼가 아닌 큰 곡도라서 현재 공격 이름/설정을 이에 맞췄다.
- 마대봉의 준비/베기, 노진의 창 타격/깃발, 철무의 준비/실제 사슬 연결, 한무극의 준비/베기, 발타의 장격/진각 캡처를 육안으로 확인했다.
- 동일한 인물·복식·무기가 유지되는지, 연결 고리와 파괴 가능한 깃발이 보이는지, 실제 진각 충격에 원형 윤곽선이 없는지 확인했다. 전투 HUD를 가리지 않았다.
- 자동 검사는 모든 렌더 상태를 기록했지만 모든 프레임을 육안으로 심사한 것은 아니다. 이번에 5명의 원화를 새로 생성한 것도 아니다. 앞 방향은 승인된 동작 그림을 사용하고 뒤 방향은 같은 인물의 방향 그림/연속 변형을 유지한다.
