# 소림 전체 원화 적용 검증

2026-10-04. 모든 저장 변경은 Playwright 독립 컨텍스트의 테스트 데이터에만 적용했다. 사용자 브라우저의 실제 저장에는 접근하지 않았다. 로컬 배포는 기존 `127.0.0.1:5173` production preview, 개발 검사는 별도 5174 origin에서 수행했다.

자동 검사:

- 단위 검사 전체: 50파일 1,241개 통과. 최종 지역 목록 변경 뒤 영향받는 원화/지역 검사 10개를 재검사해 통과.
- 원본 분리/내보내기: 30시트, 360그림, 동일 RGBA 연결 픽셀 보존, 원본 바깥 잘림 거부, 최소 여백 32픽셀. 모든 캐릭터/자세 배율 0.225. 원본 시트와 SHA-256은 `docs/source/shaolin-family-v1/export-review.json`.
- 소림 전체 행렬: Canvas/WebGL × 일반/동작 줄이기 각각 7종 × 8방향 × 7상태 × 5샘플 = 1,960개, 총 7,840개. 실제 알파 픽셀의 상단으로 HP바 간격을 검사했다. 전체 WebGL 일반 동작의 최소 간격은 11.225 월드픽셀. 4보스 16행동의 모든 접촉을 8방향으로 검사한 기록은 렌더 모드별 168개다. 피격이 공격 자세를 대체하지 않는 것도 검사했다.
- 실제 시뮬레이션의 권갑 즉시 피해·돌 즉시 발사와 접촉 그림 일치: 각 8방향. 기존 봉 승려의 실제 피해 접촉 8방향과 일반/동작 줄이기 행렬도 재검사했다.
- 기존 소림 보행 크기·공격 전환·전 지역 검사 중 소림 7종·실제 이동/공격과 HP바 검사.
- production: 1440×900, 1366×768, 1093×614에서 새 30시트의 HTTP 200/캐시 304 정상 응답, 전투 이동, 7종 선택과 동작 변경, 8canvas 및 가로 넘침 없음 확인. 기존 봉 미리보기도 확인. 총 6개 production 검사 통과.
- 최신 빌드: `main-Bf4hd17g.js`, `mount-_fpqEIvN.js`. public/dist의 무진 옆모습 WebP SHA-256 일치 확인.

개발·production 검사를 동시에 실행한 마지막 검사에서 공통 `test-results` 폴더 정리로 WebGL 동작 줄이기의 trace 저장이 ENOENT로 실패했다. 프레임/간격 검사는 완료되고 오류 기록은 없었으나 결과 보존도 검증의 일부이므로 해당 검사를 별도 `test-results-shaolin-family-final`에서 재실행했다. production 설정도 `test-results-production`으로 분리했다.

실제 시각 검토:

- Canvas 일반 보행·접촉 및 WebGL 일반 준비의 7종×8방향 캡처를 직접 검토했다. 밝은 바탕에서 외부 광채, 다른 칸의 그림 섞임, 몸/무기의 잘림을 보이지 않았으며 발과 지면·HP바가 분리되어 있다.
- production `review-1440.png`, `combat-1093.png`를 직접 확인했다. 무진의 8방향 실루엣과 투명 여백, 작은 화면의 전투 핵심 행동을 확인했다.
- 자동 배율 검사는 생성 원화 자체의 모든 관절·해부학 비례가 완벽하다는 인증은 아니다. 몸이 숙여지면 높이가 바뀌며, 고정 픽셀 배율은 원화의 포즈 차이를 그대로 보여 준다. 사망은 한 자세의 페이드, 보스는 행동별 판정/효과에 공통 준비·접촉·회수 원화를 연결한다.

로딩 측정:

사용하지 않는 구형 소림 4시트를 지역 manifest에서 제거했다. `docs/verification/combat-startup-v1/shaolin-family-final-*-profile.json`의 이미지 완료 후 ready까지 Canvas 1,786.1ms, WebGL 4,080.8ms; create는 각각 1,771.5ms/1,935.8ms. 네트워크/이미지 다운로드 이전 시간은 이 수치에 포함하지 않으며, 테스트 장치에서의 측정이다. 새 이미지의 디코딩/업로드 비용이 있으므로 모든 장치에서 같은 시작 시간을 보장하지 않는다.
