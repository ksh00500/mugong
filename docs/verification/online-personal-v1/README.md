# 온라인 개인 무인 검증

2026-10-23. 원본/이전 빌드와 실제 사용자 저장을 보존한다. 모든 가입·상태 주입은 독립 테스트 DB/브라우저에서만 실행한다.

## 검사와 증거

- `tests/online-personal.test.ts`: 서버 모집, 엄격한 의도 검증,20웨이브 도메인 전환, 소유권/장비/수명, 성장 중복 방지, 유품 회수와 원래 주인 반환, 실패 롤백, DB 재시작.
- `tests/online-server.test.ts`: 실제 인증 HTTP/WS로 모집·성장·서버 이동·일시정지·다른 창 접속과 변조 거절.
- `tests/online-safety.test.ts`: 실패한 미확정 사망을 소켓 교체 뒤 같은 결과로 확정, 그동안 이전 상태 조회 금지, 예약/방 삽입 실패의 동시 롤백, 대기 취소/만료, 레이드 만료 시 자기 장비/운반 유품 반환과 확정 사망 보존.
- `tests/raid-recovery.test.ts`: 실제 서버를 종료/재생성한 뒤 인증 세션·개인 방·무인ID·HP·잠금을 같은 사본으로 복구.
- `playwright.online.config.ts`:1440×900·1366×768·1093×614에서 개인 명부/가방→출전→실제 공격→정비 성장 보류/가방→귀환→온라인 창고 이동. 새 계정의 모집→첫 성장→서버 이동→새로고침을 검사하고 로컬 IndexedDB가 생성되지 않았는지 확인한다.

브라우저 fixture의 등록 무인은 서버 도메인 전환으로 준비했고 **첫 보스 HP는1**이다. 실제 타격과 서버 정산을 검사하지만 정상 난이도 완주율/인간 플레이 결과가 아니다. 공개 서버에 fixture API/환경 우회는 제공하지 않는다. 자연20웨이브를 브라우저로 완주한 검사도 아니다.

최신 전체 단위/컴파일 브라우저·기존 UI 회귀·실제 로컬 적용 결과와 SHA는 `summary.json`, `local-build.json`에 기록한다. 실패/중단한 이전 실행을 최신 통과에 합산하지 않는다. raw JSON·PNG·trace는 로컬 증거로 보존한다.

## 남은 검증

정상 수치 개인1~4인5층과 전 무공·아이템 조합, 다수 계정 부하/망 지연·손실, 실제 디스크/전원 장애와 백업 복원 훈련, 실물GPU/인간 밸런스, Docker/Nginx-WS 및 집 Linux/Cloudflare 공개 경로는 이번 기본 흐름 검사와 별도다. SQLite는 현재 Node22의 experimental 경고를 출력한다.
