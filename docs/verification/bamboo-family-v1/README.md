검증 대상은 죽림 일반 적 3종과 보스 4종의 새 방향별 원화와 런타임 선택이다. 최종 결과는 [summary.json](summary.json), 직접 검토한 자료와 판단은 [manual-review.json](manual-review.json)에 기록한다. 자동 검사와 시각 판단을 구분하며 사용자 저장은 사용하거나 변경하지 않았다. 원격 배포는 하지 않았다.

## 직접 시각 검토

선택한 원본 및 7인물의 5시점×12자세 비교판을 같은 배율로 열어 체격·관절·무기·접지점을 검토했다. 공격·걷기 자세에 따라 전체 그림 높이가 달라지는 정상적인 굽힘과 무기 확장을 몸 자체의 축소와 구분했다. 노개의 한 개 봉, 청비의 오른손 암기/왼손 예비 단도, 송월의 오른손 부채를 교정했고 잘못 나온 후보는 사용하지 않았다.

[비교판 폴더](contact/)와 [프로덕션 캡처](production/)에 증거를 보존했다. 실제 Canvas/WebGL 대기·타격·피격, 세 크기의 전투·검토 화면, 공격 6단계 캡처를 직접 확인했다. 마지막 청비 후면 걷기 교정본도 패킹 후 비교했다. 해부학과 미술 품질은 시각 판단이며 해시·연결 영역 자동 검사로 보장하는 항목이 아니다.

## 범위와 한계

보스의 여러 기술은 인물별 대표 공격 원화를 기존 접촉 시점에 맞춰 재생한다. 기술마다 독립된 신규 원화를 그린 것은 아니다. 투사체·함정·VFX는 게임 시스템에서 별도로 표시한다. 사망은 한 자세를 페이드하며, 5원화 시점을 좌우 반전하여 8방향으로 사용한다. 반전 방향에서 화면상의 손 위치도 반전된다.

원화는 1:1 RGBA 패킹, 최소 32px 여백과 고정 0.225 게임 배율을 사용한다. 프레임별 크기 보정이나 무기 경계에 맞춘 축소는 없다. 생성 원화의 미세한 옷 주름·팔레트 차이는 남을 수 있으며 완전한 동일 그림을 주장하지 않는다.
