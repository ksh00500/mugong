# 정비 구간 디자인 · 강호 쉼터

2026-10-20. 4·9·14·19웨이브의 실제 의원·상인·강화 서비스를 새로운 쉼터 배경과 NPC 원화로 연결했다. [검증](verification/prep-design-v1/README.md).

## 화면과 행동

- 의원은 옥색, 상인은 황토색, 대장장이는 구리색으로 구분한다. 역할·인물·서비스 설명·가격·가능 여부를 함께 보여준다. 권장 치료는 테두리와 문장으로 표시한다.
- 위에는 지역·정비 웨이브·소지금, 아래에는 다음 보스의 실제 두 행동과 대응법, 가방·출발 버튼을 둔다. 주 행동은 출발 한 개다.
- 회복과 강화는 저장 명령이 성공한 뒤 완료 문구를 표시한다. 240ms의 짧은 이동/투명도만 사용하며 동작 감소 환경에서는 정지한다.
- 상점에도 같은 상인 원화와 인사말을 연결했다. 기존 물품 비교·재고·가격·구매·획득 물품 보관 흐름을 유지한다.
- 1440×900,1366×768,1093×614에 맞춰 초상 높이와 간격을 바꾼다. 좁은 높이에서는 인사말/도장만 생략한다. 선택 장비/효과 영역은 필요한 경우 내부 스크롤하며 서비스 버튼·다음 행동은 계속 표시한다. 화면 전체 배율 축소는 없다.
- 정비 중 상단 무인 상태를 위로 옮겨 큰 HUD의 경험치까지 쉼터와 겹치지 않게 한다. 전투 중 HUD의 위치는 유지한다.
- 가방을 열자마자 닫으면 열기 저장이 끝나기 전이라 원래 버튼이 비활성일 수 있다. 비활성 해제를 기다려 초점을 돌려주며, 그동안 사용자가 다른 곳으로 옮겼거나 새 창을 열면 복귀를 취소한다.

현재는 **NPC 원화가 있는 서비스 화면**이다. 필드에서 걸어가 대화하는 방식이나 NPC 걷기·망치질 애니메이션은 구현 범위가 아니다. 치료12전·회복45 상한, 강화12전/재료2·최대 두 번, 저장 재고와 다음 보스 전환은 기존 규칙을 사용한다.

## 원화와 로딩

내장 ImageGen으로 다음 원화 네 장을 제작했다. 전체 프롬프트/생성 결과 파일명은 [prompts.json](source/prep-design-v1/prompts.json)에 보존한다.

| 실행 원화 | 크기 | 용도 |
| --- | --- | --- |
| [waystation.png](../public/art/prep-waystation-v1/waystation.png) | 1860×846 | 낮의 산중 쉼터 배경 |
| [physician.png](../public/art/prep-waystation-v1/physician.png) | 1222×1287 | 약초를 든 의원, 투명 배경 |
| [merchant.png](../public/art/prep-waystation-v1/merchant.png) | 1145×1374 | 물품/주판을 든 상인, 투명 배경 |
| [blacksmith.png](../public/art/prep-waystation-v1/blacksmith.png) | 1145×1374 | 망치를 든 대장장이, 투명 배경 |

원본 비율과 PNG 픽셀을 유지한다. 새 원화 네 장은 약9.95MB이며 첫 로비/전투 필수 로딩 목록에 넣지 않는다. 정비 컴포넌트를 표시할 때 일반 이미지 요청으로 받는다. 다운로드/디코딩을 기다리느라 서비스를 막지 않으며, 요청 실패 시 인물만 생략하고 종이색 배경과 제목·서비스를 유지한다. 셀 간 침범이 생기는 시트 구조는 사용하지 않는다.

`asset-manifest.json`에 네 실행 파일과 SHA256을 추가했다. 기존 제작 원본/실행 원화를 삭제하거나 바꾸지 않았다. 새 그림은 일반 Git 파일이며 LFS가 아니다. 크기·알파·해시 결과는 [art.json](verification/prep-design-v1/art.json)에 기록한다.

## 재현

소스 서버5225에서 `npx playwright test --config playwright.prep-design.config.ts`를 실행한다. 독립 브라우저 저장에 검증용 정비 상태만 넣고 실제 UI를 조작한다. 브라우저 소스 모듈 주입을 사용하지 않으므로 같은 검사를 컴파일 빌드에서도 실행한다. `MUGONG_PREP_DESIGN_URL`, `MUGONG_PREP_DESIGN_MODE`, `MUGONG_PREP_DESIGN_PROOF`로 실행 주소/증거를 분리한다.

기존 정비·상점·가방 회귀는 `MUGONG_PREP_DESIGN_SUITE=regression`과 `--grep '정비 서비스|정비와 다섯|품절 재고|high UI: preparation|high UI: five languages'`를 사용한다. `MUGONG_COMBAT_PREP_UI_PROOF`, `MUGONG_HIGH_PROOF`도 이번 폴더로 지정한다. 수동 캡처 검토와 자동 측정의 범위는 검증 문서에 구분한다.
