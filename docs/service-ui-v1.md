# 서비스 UI 고도화 · 2026-09-28

현재 구현된 로비 → 강호 전투 → 성장 선택 → 전리품·가방 → 창고·명부 경로를 한 시각 체계로 다듬었다. 세계관은 한지·옥색·황동·주홍 인장을 유지하고, 전투 중에는 움직이는 지도와 분리되는 짙은 HUD 표면을 사용한다. 외부 게임의 그림이나 UI 요소를 복제하지 않고, 정보 배치와 선택 흐름의 원칙만 참고했다.

이 표의 게임별 원칙은 공개 화면과 게임 설명을 보고 이 프로젝트에 맞게 **추론한 디자인 판단**이다. 공식 개발자의 의도를 주장하는 설명은 아니다.

## 화면에 적용한 변화

- **로비:** 출전 버튼을 한 화면의 주 행동으로 유지하고, 진행 중인 여정과 명부 상태를 바로 아래에서 읽는다. 창고·기록·안내는 짧은 행동 이름으로 유지한다.
- **전투:** 한지 패널을 옥빛 어두운 표면으로 바꿔 숲 지형과 분리했다. 체력·경험치·웨이브·무공·궁극·전환 슬롯의 숫자와 레이블을 키웠다. 전투 메시지는 중앙 아래의 작은 칩으로 묶었다.
- **성장:** 카드의 무공 종류, 이름, 단계, 설명, 효과, 방어 행동, 선택 영역을 같은 순서로 배치했다. 입력 보호 1초와 잠금 상태 표시는 유지한다.
- **가방·창고:** 무인·무장·일반 가방·물품 정보의 네 영역을 분명히 나눴다. 전투 중 읽기 전용 상태와 로비에서 창고 연결 상태를 상단에 표시한다. 물품 종류에 맞지 않는 행동을 숨기고, 가능한 배치와 선택 상태를 색과 선으로 구분한다.
- **공통 조작:** 보이는 포커스, 충분한 버튼 크기, 짧은 입력 반응, 시스템 움직임 줄이기 설정을 적용했다. 로비와 일시 정지에서 큰 HUD 글씨·높은 대비를 선택하고 브라우저에 저장한다.

기본 색상 조합의 계산 대비는 HUD 보조 글씨 10.49:1, 성장 설명 7.06:1, 가방 본문 6.66:1, 로비 보조 글씨 7.16:1이다. 화면 이미지·알파 합성·개별 상태에 따라 실제 픽셀 대비는 달라질 수 있으므로 검토 이미지를 함께 확인한다.

## 확인 결과와 다음 품질 관문

TypeScript·Vite 빌드와 Playwright 전체 13개 경로가 통과했다. 화면 설정의 저장·새로고침·일시 정지 접근을 별도 브라우저 경로로 확인했다. 로비는 1440, 1366, 1024, 390px에서 가로 넘침을 검사했다.

이 변경은 현재 구현된 화면의 UI 품질을 높인다. 출시 판정에는 실제 플레이어 사용성 검사, 다양한 그래픽 성능 환경, 키보드만 사용하는 전체 가방 수납 흐름, 더 많은 화면 비율에서의 검토가 추가로 필요하다. 레이드·비무·시장 등 아직 구현되지 않은 서비스 화면은 이 문서의 완료 범위가 아니다.
