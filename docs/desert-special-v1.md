# 서역사막 보스 특별 원화 — 검토 시안

2026-10-07. 사용자 지정 지역을 우선해 내장 imagegen으로 4보스·8패턴·5시점의 원화 40장을 생성했다. 한 장에 준비·힘 싣기·판정·후속·회수·대기 6자세를 담는다. 수정 시안 10장과 최초 경계 불량 시안 1장도 보존했다. 20개 검토용 WebP에 240논리 프레임을 픽셀 1:1로 분리했으며 반전으로 8방향을 비교한다. **원화 생성 및 로컬 검토 단계이며 게임에 등록하거나 공개 배포한 상태는 아니다.**

| 보스 | 제작한 두 패턴 |
| --- | --- |
| 황사도적왕 아사르 | 모래 도적 돌진참 · 사풍 발굽 모래 |
| 쌍환무희 나야 | 사막 무희 직선 귀환환 · 사막 무희 근접 환격 |

| 대막도왕 아르칸 | 금사 왕도 회전 · 오아시스 퇴로 봉쇄 |

실제 키트 `boss-wave4.ts`, `boss-wave5.ts`, `boss-melee.ts`의 준비·접촉·회수 시간을 읽었다. 모래 활성화와 퇴로 봉쇄의 `stance`는 유지 방어가 아닌 시전이다. 아사르는 보병이며 말·발굽을 그리지 않았다. 나야는 환 방출 때 빈손, 발타는 무기 없는 어깨 타격·발 진각, 아르칸은 한 자루 대도의 내려 베기와 빈손 명령을 구분했다. 효과·투사체·장판은 캐릭터 그림에 굽지 않았다.

## 선택한 교정과 미선택 수정본

- 발타 앞사선 돌진의 후속 장법을 접힌 팔/어깨 타격으로 바꾸고 마지막 대기를 열린 손바닥으로 고쳤다.
- 아르칸 뒷사선 시전 후속에서 가까운 손의 대도를 유지하고 먼 빈손으로 명령한다. 정면 준비 자세의 무기 손은 해당 자세만 반전한 수정 원화를 선택했다.
- 나야 뒷사선·뒷모습 회수의 빈손과 예비 환 소유를 고쳤다. 후면은 여러 부분 수정이 반영되지 않아 마지막 해당 자세 반전본을 선택했다.
- 요청한 변화가 나타나지 않은 수정 시안은 채택하지 않았다. 총 5개 수정 시트에서 6자세만 사용하고 나머지 노출은 기존 생성본을 유지한다. [선택·미선택과 수정 프롬프트](source/desert-special-v1/generation-status.json).

## 적용 전 남은 미술 검토

직접 캡처 비교에서 새 몸체가 기존 기본 원화보다 크게 보인다. 공통 배율과 RGBA 복사 검사는 생성된 몸 치수의 일치를 보장하지 않는다. 특히 발타와 나야를 포함해 머리·몸 크기를 기준 원화와 다시 맞춰야 한다. 프레임별 런타임 축소로 숨기지 않는다.

나야 앞사선 투척의 몸 회전/팔 연결과 뒷사선 힘 싣기 자세는 추가 검토 대상이다. 연환격의 두 실제 접촉은 현재 공통 시계가 같은 접촉 그림을 재생한다. 왼손 두 번째 타격 전용 접촉 그림과 선택 규칙은 아직 없다. 240개 발 좌표는 자동 제안이며 무기 끝/옷 끝을 발로 잡은 후보를 직접 검토해야 한다. 서역사막 전체 18행동 중 이번 8행동 외 나머지 10행동은 기본 원화 재사용 범위다.
