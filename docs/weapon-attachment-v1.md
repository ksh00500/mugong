# 주인공 무기 부착 감사 · 2026-10-03

사용자 요청: 10종 외형 × 모든 공격 모션/프레임 × 전체 무기 조합에서 무기가 실제 손에 붙는지 검토하고 수정한다. 현재 무기 종류는 **검·도·암기·권갑·봉·부채 6종**, 장착 가능한 원화는 **일반 18개 + 보스 보상 10개 = 28개**다. 로컬 검증 후 [2026-10-04 Daytona에 배포하고 공개 동작을 검증했다](daytona-weapon-boss-v1.md).

## 확인한 원인과 변경

- `CombatScene.applyRosterPose`가 모든 캐릭터에 동일한 임시 좌표를 사용했다. 소매·얼굴·허리에 무기가 붙는 경우가 있었다. `src/game/hero-grips.ts`에 10종 × 방향 원화 8개/동작 원화 6개의 손바닥/손목 기준점 140개를 정의했다. 격자 전체의 비율이 아니라 **격리된 실제 그림 내부 UV**다. 원화 대조 후 공격 준비의 얼굴 위치, 뻗은 손의 손끝 위치 등도 보정했다.
- 좌우 반전은 원본 손 UV에 한 번 적용한다. 무기 위치는 `ContinuousActor.localPoint`로 **실제로 그려진 삼각형**을 보간한다. Canvas 4×6 / WebGL 8×12 메시의 차이, 자세 전환 리그, 몸체 회전과 원점을 모두 따라간다. 분석식 `rigPoint`만 재계산하면 실제 삼각형 위치와 작은 오차가 생길 수 있다.
- 무기 회전을 원화 행 번호에서 추정하지 않는다. 준비→타격→회수의 실제 전투 동작과 진행률로 연속적인 궤적을 계산하고 몸체 회전도 더한다. 부채는 위를 향하는 원화 축을 사용한다. 검·도·봉·부채 각각 19개 원화의 손잡이 원점은 `src/game/weapon-grips.ts`에 명시했다.
- 묶음 암기/독침함, 권갑 한 쌍의 가방 그림을 그대로 손에 들던 문제를 제거했다. 전투에는 **낱개 암기 4종·한 손 권갑 5종**의 새 투명 그림을 사용한다. 가방의 물품 원화/이름/효과/저장은 그대로다. 텍스처 식별자는 실제 장착 물품 ID를 유지한다.
- 10종 외형의 피격 때도 무기를 손에 붙인다. 사망 시에는 기존처럼 숨긴다. 뒤쪽에서 옷/머리에 가려지는 손은 무기도 몸 뒤에 둔다. 감소된 동작 설정에서는 무기의 장식적인 회전 보간을 생략한다.

## 원화·파일 관리 규칙

1. 몸체 외형은 무기나 능력치를 결정하지 않는다. 원화는 `public/art/hero-roster-v1`의 외형 ID를 유지한다. 변경한 원화의 해당 방향/동작 기준점을 반드시 함께 재검토한다.
2. 손 UV는 **반전 전·타이트한 프레임 기준**, 무기 손잡이 원점은 **각 물품 그림 기준**이다. 서로 다른 좌표계를 합치거나 캐릭터/무기 전체에 하나의 임시 원점을 적용하지 않는다.
3. 무기 그림의 진행 축과 손잡이, 앞/뒤 가림을 따로 검토한다. 가방 그림이 묶음/상자/한 쌍이면 전투용 단일 그림을 별도로 사용한다. 새로운 장착 물품에 검토된 원점이 없으면 잘못된 공통 위치로 대체하지 않고 목록 검사가 실패해야 한다.
4. 신규 그림은 built-in `image_gen`으로 제작했다. 원본 PNG·정확한 프롬프트는 `docs/source/held-weapons-v1`에 보존한다. 배포용은 알파를 보존한 `public/art/held-darts-v1.webp`, `held-gauntlets-v1.webp`다. `scripts/export-held-weapons.mjs`는 포맷 내보내기만 수행한다.
5. 검사 자료는 `docs/verification/weapon-attachment`에 둔다. 실제 사용자 저장을 수정하지 않는다. 이 검증은 Playwright의 독립 컨텍스트만 사용한다.

## 검사 범위와 한계

실제 전투의 9개 동작 상태(대기·이동·준비·타격·회수·궁극기·방어·피격·사망)는 7개 연속 시퀀스로 검사한다. 한 조합마다 대기 3개 시점, 이동 48프레임, 기본 공격 18프레임, 궁극기 37프레임, 방어 19프레임, 피격 9프레임, 사망 24프레임 = **158프레임**이다. 감소된 동작 설정에서는 7개 시퀀스의 시작/끝과 공격 접촉 시점 **15개**를 추가한다.

**10 × 28 × 8 × (158 + 15) × 2개 렌더러 = 775,040개 상태**의 검증 구성이다. 독립 판정은 실제 메시의 UV 삼각형에서 원본 손 기준점을 찾아 보간하고, 회전/위치를 적용해 무기 손잡이와 비교한다. 사망은 무기 숨김을 확인한다. 60fps 시간선의 이산 검사이며 임의의 연속 시간 전체나 모든 프레임에 대한 사람의 육안 인증을 뜻하지 않는다.

원화 140개와 손잡이 그림 28개는 기준점을 표시한 화면으로 대조했다. 실제 Phaser WebGL 비교 화면은 **10 × 6 × 8 × 공격 준비/접촉/회수 3개 = 1,440개 자세**다. 몸체를 다시 그린 대체 캔버스가 아니라 실제 렌더 메시와 무기 스프라이트를 복제해 캡처한다. 원화는 기존의 유한한 자세 그림과 연속 리그를 조합한다. 이 작업으로 캐릭터 몸체의 모든 자세를 새로 제작한 것은 아니다.

### 최종 검증 결과

- `npm run build`: 타입 검사와 프로덕션 빌드 통과.
- `npx vitest run --maxWorkers=1 --reporter=dot`: 42개 파일, 1,158개 테스트 통과.
- 무기 부착·10종 외형·방향별 동작 관련 Playwright: 12개 테스트 통과. 가방을 열었을 때 전투 동작 정지와 Canvas/WebGL 회귀 검사도 포함한다.
- 775,040개 상태의 자동 검사에서 실패 0개. 손 기준점과 무기 손잡이의 최대 거리 오차는 약 `2.34e-13` 월드 단위로, 판정 기준 `0.01` 미만이다. 상세 결과는 이 디렉터리의 `canvas-0.json`, `canvas-1.json`, `webgl-0.json`, `webgl-1.json`에 기록했다.
- 육안 검토: 원화 기준점 140개, 실제 장착 그림 28개와 10종 외형의 공격 비교 화면 10장을 대조했다. 비교 화면의 1,440개 자세와 자동 검사 775,040개 상태는 서로 다른 검증 자료다.
