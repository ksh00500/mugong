# 다음 단계 UI 시안

2026-09-30. 실행 경로: 개발 서버의 `/next-stage/` (`next-stage/index.html`). 현재 게임의 `/`와 저장 데이터는 사용하지 않는다. 수치·무인·전리품·파티원은 모두 **화면 검토용 예시**이며 온라인 매칭이나 자산 정산을 수행하지 않는다.

## 화면과 조작

| 화면 | 확인할 점 |
| --- | --- |
| 출전 선택 | 강호를 완주한 뒤 레이드·비무·생사결의 목적, 보상, 위험을 구분한다. |
| 레이드 준비 | 5층 경로, 1~4인 파티 예시 전환, 무인의 HP·수명, 사망·유품 반환 규칙을 한 화면에 둔다. |
| 비무 준비 | 순위 경기이고 경기별 성장·자산 보상이 없음을 출전 전에 보여준다. |
| 생사결 준비 | 판돈과 사망·장비 손실을 보여주고 별도 확인 창을 거친다. |
| 전투 HUD | 기존 무협 HUD의 상단 상태, 부채 무공, 궁극기, 방어 재사용 배치를 넓은 카툰 전장 위에서 비교한다. |
| 레이드 층간 정비 | 무장 4×7·일반 10×8, 무인 요약, 선택 물품, 개인 전리품/유품, 정리판, 귀환·다음 층 준비를 함께 표시한다. 클릭 후 버튼 또는 드래그로 예시 물품을 수납한다. 동료 귀환 예시는 준비 상태를 취소한다. |
| 결과 | 레이드 귀환, 비무, 생사결에 필요한 결과 정보의 위계를 비교한다. |

스타일은 현행 `DESIGN.md`의 한지·옥·황동 토큰과 `public/art/delivery-v1/` 그림을 쓴다. 별도 CSS는 `src/next-stage/next-stage.css`이며 실제 게임의 소유 CSS를 덮어쓰지 않는다. 시안에서 위험 버튼·매칭 버튼은 실제 온라인 기능처럼 작동하지 않고 다음 시안 화면만 연다.

## 검증과 남은 연결

`npm run build`, `npm test`, `npx playwright test tests/e2e/next-stage.spec.ts`를 실행한다. Playwright는 독립 브라우저 컨텍스트에서 1440×900, 1366×768, 1093×614를 검사한다. 결과 캡처는 `test-results/next-stage-*.png`에 저장한다. 가방의 칸 비율, 화면 밖 핵심 버튼, 전리품 수납, 드래그 위치, 파티 인원 변화, 생사결 확인을 검사한다. 캡처는 직접 눈으로도 확인해야 한다.

아직 실제 파티·매칭·서버 정산, 실제 무인·가방 데이터 연결, 다섯 언어 문구, 각 모드의 완성된 그래픽 에셋은 없다. 시안 방향이 정해지면 실제 명부/자산 모델과 모드 정책을 연결하고, 문구는 기존 현지화 체계에 편입한다. 온라인 위험 출전은 서버의 잠금·정산 검증 뒤에만 제공한다.
