# 전장 효과·설치물 점검

이 문서는 **개편 전 조사 기록**이다. 같은 날 후속 구현한 현재 효과는 [전장 구역 효과 v2](field-effects-v2.md), 남은 범위는 [전체 시스템 점검](system-completeness-audit-20261002.md)을 따른다.

2026-10-02. 기획 문구보다 현재 실행 코드를 기준으로 정리했다. 이번 작업은 조사·보고이며 게임 규칙과 이미지는 변경하지 않았다.

## 먼저 확인한 두 가지

- **흙먼지·모래**: 직접 피해, 플레이어 감속, 실명 판정이 없다. 서역 전체 모래바람은 14초 중 마지막 4초에 그림을 표시하며 일부 일반 적의 발사 방향을 최대 약 7.4도 흐트러뜨린다. 보스 황사도적왕의 작은 모래 구역은 연막 오브젝트를 모래 그림으로 표현한 것으로, 보스 자체를 2.5초 동안 반투명하게 만들 뿐 그 안의 플레이어에게 상태 이상을 주지 않는다. 기획의 ‘시야 감소’는 실제 시야 시스템으로 구현되지 않았다.
- **독 보스가 설치하는 꽃**: 만독곡주 사공염의 정화초다. 발동한 꽃에 접근하면 한 번 사용되어 현재 독 지대 전부, 해당 보스의 독 지뢰, 플레이어의 이동 둔화·회복 감소를 없앤다. 체력을 회복시키거나 이후 독을 막지는 않는다. 원문은 ‘정화초 파괴 유도’지만 실제로는 공격으로 파괴할 수 없고 접촉으로 사용한다.

## 그림별 실제 기능

아래 피해는 장비·방어·무적 적용 전의 기본값이다. 같은 그림이라도 환경 구역과 보스 설치물의 구현이 달라 수치가 다르다. 공격 범위 미리보기와 테두리는 제거된 상태이고 실제 발동한 그림만 표시한다.

## 개선이 필요한 지점

1. **의미 없는 구역처럼 보임**: 먼지·연막은 플레이어에게 직접 효과가 없고, 보스 반투명 효과는 바닥 구역에 들어갔는지와 무관하다. ‘먼지 구역에 들어가면 무슨 일이 일어나는지’라는 기대와 실제 구현이 어긋난다.
2. **같은 그림, 다른 효과**: 냉기와 눈보라 연막, 독 웅덩이와 독 지뢰, 위험 봉인과 적 깃발, 아군 진법과 보스 안전지대가 혼동된다.
3. **기획 이름과 구현 차이**: 화상·취기·실명·독 중첩·실제 반사·체력 교환·회전문은 이름/설정과 동일한 독립 기능으로 구현되지 않았다.
4. **꽃의 사용법**: 공격해 파괴하는 기획에서 접촉 사용으로 각색했지만 그림과 설명이 이를 충분히 전달하지 못한다. 꽃은 회복품처럼 보이지만 체력은 회복하지 않는다.
5. **제거한 예고를 말하는 설명**: `encounterHint`의 기본 문구가 여전히 ‘예고된 범위를 피하세요’다. 현재 범위 미리보기가 없으므로 문구가 맞지 않는다.
6. **체감 피드백 부족**: 구역 이름·상태 이상·발동·해제의 표현이 실제 효과와 충분히 연결되지 않았다. 단위 검사 통과만으로 실제 플레이의 이해도를 주장할 수 없다.

추천 방향은 피해 구역, 이동 방해, 유리한 물체, 적 강화의 네 역할을 그림으로 구분하는 것이다. 먼지는 전장 연출로 한정하거나 ‘보스 은폐’와 명확히 연결하고, 정화초는 접촉 정화 물체로 정리한다. 화염·술·눈보라처럼 이름만 다른 공통 피해 구역은 효과를 차별화하거나 불필요한 종류를 줄인다. 공격 범위 테두리를 다시 추가하는 방식은 추천하지 않는다.
