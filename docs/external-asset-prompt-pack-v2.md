# 무공 — 짧은 에셋 프롬프트 팩 v2

2026-09-27. 카툰풍과 간결한 생성 요청으로 다시 작성했다. v1 장문은 이전 제작 기록이며 현재 복사 요청에 사용하지 않는다.

기준: 승인한 [카툰풍 검객](../assets/concepts/cartoon-swordsman-v1.png), [새 디자인 기준](art-direction-cartoon-v1.md). 각 요청에 해당 기준 이미지를 첨부한다. 아래 블록 하나만 복사하며 공통 장문을 추가하지 않는다. 한 번에 한 대상·한 동작을 만든다.

## 캐릭터

```text
첨부한 그림의 선과 명암을 유지해 새 무협 무인 한 명을 그려줘. [복장과 주무기]가 특징인 전신 캐릭터, 편안한 준비 자세, 투명 배경으로.
```

## 대기

```text
첨부한 무인이 편하게 서서 가볍게 숨 쉬는 짧은 반복 영상을 만들어줘. 외형은 유지하고 카메라는 고정, 배경은 단색으로.
```

## 공격

```text
첨부한 무인이 [무기]로 자연스럽게 한 번 공격하고 원래 자세로 돌아오는 짧은 영상을 만들어줘. 같은 캐릭터와 화풍, 고정된 카메라, 단색 배경으로.
```

## 걷기

```text
첨부한 무인의 자연스러운 걷기 동작을 반복 가능한 짧은 영상으로 만들어줘. 인물은 화면 가운데 유지하고, 같은 외형과 화풍, 고정된 카메라, 단색 배경으로.
```

## 피격

```text
첨부한 무인이 한 번 맞아 짧게 움찔하고 준비 자세로 돌아오는 영상을 만들어줘. 같은 외형과 화풍, 고정된 카메라, 단색 배경으로.
```

## 사망

```text
첨부한 무인이 자연스럽게 쓰러지는 짧은 영상을 만들어줘. 같은 외형과 화풍, 고정된 카메라, 단색 배경으로.
```

## 다른 방향

```text
첨부한 캐릭터를 같은 게임 시점에서 [방향]을 바라보는 전신으로 그려줘. 같은 외형과 화풍, 같은 크기, 투명 배경으로.
```

## 무기·아이템

```text
첨부한 카툰풍에 맞춰 [물품] 한 개를 그려줘. 선명한 실루엣과 단순한 명암, 물건 전체가 보이는 투명 배경으로. 글자와 숫자는 넣지 말아줘.
```

## 근접 적

```text
첨부한 검객과 같은 화풍과 게임 시점으로 [무기]를 든 산적 한 명을 그려줘. 어두운 복장으로 구분되는 전신, 준비 자세, 투명 배경으로.
```

산적은 첫 적 시안 소재다. 최종 적 이름과 종류를 이 요청만으로 확정하지 않는다.

## 전투 배경

```text
첨부한 카툰풍에 맞춰 멀리서 내려다보는 탑뷰의 넓은 무협 [장소]를 그려줘. 중앙은 넓고 단순한 전투 공간, 주변은 간결한 식생과 구조물로. 캐릭터와 UI는 넣지 말아줘.
```

## 검흔

```text
첨부한 카툰풍에 어울리는 날렵한 흰 검흔 하나를 그려줘. 선명하고 간결한 곡선, 투명 배경으로.
```

## 적중 효과

```text
첨부한 카툰풍에 어울리는 작고 선명한 검 적중 효과 하나를 그려줘. 짧은 흰 섬광과 약한 금빛 불꽃, 투명 배경으로.
```

## UI 장식

UI는 앞서 승인한 와이어프레임을 유지한다. 아래 요청이 필요하면 기존 UI 참고를 첨부한다. 카툰풍 캐릭터나 줌아웃 이미지 속 임시 HUD를 UI 기준으로 사용하지 않는다.

```text
첨부한 기존 UI 디자인에 맞춰 무협 게임의 빈 [패널 테두리/버튼 테두리/구분선] 하나를 그려줘. 같은 선과 재질을 유지하고 글자와 아이콘은 넣지 말아줘.
```

격자·수량·가격·품질·체력 수치와 버튼의 기능은 코드로 만든다. 해당 숫자와 전체 UI 구조를 물품 이미지에 함께 생성하지 않는다.

## 진행 순서

검객 준비 자세 → 한 번 베기 → 걷기 → 대기·피격·사망 → 방향 확장 → 적·배경·아이템·효과. 첫 동작을 확인하기 전 전체 방향과 많은 무인을 동시에 제작하지 않는다.

결과의 정체성·접지·손 연결·동작·여백·알파·크기는 Codex에서 검수한다. 실패하면 실제 문제 하나만 다음 요청에 추가한다. 특정 몸 관절의 회전 순서·여섯 자세 목록·고정 프레임 수·많은 제외 조건을 초기 생성 요청에 넣지 않는다.
