# 소림 보스 특별 모션 — 로컬 적용

2026-10-06. 전체 보스의 실제 공격 시간을 읽는 공통 모션 연결을 추가하고, 소림 4명의 특별 모션 8종을 제작했다. 이번 적용은 로컬 빌드다.

| 보스 | 새 전용 자세 |
|---|---|
| 파계승 공허 | 진각, 어깨 돌진 |
| 철나한 도원 | 잡기, 권갑 반격 방어 |
| 금강두타 불명 | 범종 타격, 진각 |
| 폐사주지 무진 | 선장 반격 방어, 연환봉 |

5개 원화 시점에 좌우 반전을 적용해 8방향을 표시한다. 준비·힘 싣기·접촉·후속·회수·대기의 6노출을 갖는다. 합계 240논리 프레임이며 선택된 독립 원화 셀은 236개다. 불명 진각의 정면 외 4시점은 실제 접지 자세를 판정과 후속에 유지한다. 발을 든 중간 그림을 판정에 쓰지 않는다.

## 원화 규칙과 교정

- 승인된 소림 원화를 인물·장비·시점·크기 기준으로 사용하고 내장 `imagegen` 도구로 20개 시트를 생성했다. 추가 편집 1회로 불명 정면의 누락된 준비 자세와 접지 자세를 교정했다.
- 무기/관절/몸체는 한 그림에 연결되어 있다. 무진 선장은 하나의 직선 봉에 양손을 두며 아래에서 떠올리는 동작 대신 가슴 높이의 밀기와 횡소를 사용한다.
- 발 구르기, 어깨 돌진, 양손 잡기, 교차 권갑 방어, 범종의 아래 방향 타격을 구분한다. 원화에 발광이나 이펙트를 넣지 않는다. 기존 전투 이펙트는 실제 전투 상태가 관리한다.
- 원화 인물 픽셀을 1:1로 복사해 무손실 WebP로 포장한다. 최소 32픽셀 투명 여백이며 몸체/무기 확장에 따른 프레임별 배율 조정은 없다. 원본 경계 잘림, 연결된 이웃 인물, 누락, 무단 셀 재사용을 검사한다.
- 인물별 모든 방향·자세에 배율 0.225를 적용한다. 발 좌표는 프레임에 저장하고 HP바는 기본/특별 자세 중 최대 높이를 포함하는 고정 기준을 쓴다. 플레이어의 현재 70% 배율은 유지한다.

## 실제 게임 연결

`bossMotionClock`은 기존 `enemyAttack`의 초 단위 접촉 목록을 소비한다. 40명·185행동의 판정 시간과 동일하며 연환봉의 세 타격 사이에 다시 힘을 싣는다. 렌더러는 전투 시간이나 저장 데이터를 변경하지 않는다.

잡기 성공은 실제 잡기 오브젝트의 `stage=1` 유지 시간에 손을 닫은 자세를 유지한다. 방어는 실제 `guardTime`이 남은 동안 유지한다. 새 공격의 준비·타격과 사망은 방어 유지보다 우선한다. 범종 자세는 기존 범종 설치 접촉 시점에 연결하며, 이후 종의 예고·파괴·울림 규칙은 기존 전투 상태를 따른다.

기존 보스의 경직/CC 면역과 작은 피격 반응을 유지한다. 피격은 특별 공격 원화를 교체하지 않는다. 전용 원화가 없는 행동과 다른 지역은 기존 방향별 원화를 사용하면서 공통 접촉 시간 연결을 쓴다. 나머지 지역의 특별 자세 제작은 후속 범위다.
