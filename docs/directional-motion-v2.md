# 팔방 연속 동작 구현

주인공과 지역 일반 적 30종·보스 40종에 적용한다. 게임 판정은 기존 시뮬레이션이 소유하고 애니메이션은 렌더러의 일시 데이터다.

- 적의 앞/앞오른쪽/오른쪽/뒤오른쪽/뒤 그림을 추가한다. 좌측 세 방향은 반전하여 팔방으로 사용한다. 앞과 뒤를 좌우 반전으로 대신하지 않는다.
- 주인공은 기존 팔방 자세를 유지하고 이동·준비·접촉·회복·방어·피격·사망을 연속 키프레임 타임라인으로 연결한다.
- 지역 적은 새 방향 그림을 공통 2D 메시의 팔·다리·몸통 변형으로 움직인다. 기존 여섯 자세 시트는 이전 경로의 대체 그림으로 유지한다. 새 방향 경로는 중립 그림을 변형해 동작을 만든다. 연속 프레임은 실행 시 키프레임을 보간하며, 수천 장의 개별 손그림 프레임을 생성한 방식은 아니다.
- 걷기 주기는 개체별 이동 거리에서 진행한다. 가방·정지·성장·지역 로딩 중에는 타임라인도 멈춘다. 피격 뒤 원래 행동으로 복귀하며 사망이 가장 우선한다.
- 준비/접촉은 실제 공격 시뮬레이션을 따른다. 애니메이션 때문에 입력·피해 발생·투사체·회피 판정을 지연하지 않는다.
- 발 기준점과 인물 배율을 유지한다. 방향 전환에서 크기가 뛰지 않게 하며 감소된 모션에서는 의미 있는 자세만 남긴다.
- 새 지역의 방향 시트도 실제 로딩 개수·재시도·다음 지역 준비에 포함한다. 원본 그림과 생성 기록을 남기고 기존 파일을 덮어쓰지 않는다.

## 적용 결과

10개 방향 시트의 5열×7행, 350개 그림을 등록했다. 앞·앞대각선·옆·뒤대각선·뒤를 그렸으며 좌측 방향은 반전한다. 생성 도구가 뒤대각선을 반대 방향으로 그린 칸은 실제 그림을 확인해 지역·인물별 반전 기준으로 보정했다. 주인공의 팔방 그림도 같은 동작 시계에 연결했다.

`src/game/directional-motion.ts`는 거리 기반 걷기, 방향 경계의 흔들림 방지와 행동별 키프레임을 담당한다. 준비 끝→타격 시작→후딜 시작에서 팔·몸통 값이 연속으로 이어진다. 걷기는 위치 이동에서만 진행하고 순간이동·넉백은 주기를 건너뛰지 않는다. 데이터와 피해 판정은 `src/domain`에 남아 있다. 팔과 다리의 가중치를 따로 계산하므로 그림 전체를 좌우로 흔들거나 크기를 주기적으로 바꾸는 효과와 구분된다.

`src/game/continuous-actor.ts`는 WebGL에서 8×12 메시 격자, Canvas에서는 4×6 격자를 사용한다. Phaser 4의 Mesh2D에는 기본 Canvas 렌더러가 없어 삼각형의 같은 UV·정점으로 그리는 Canvas 경로를 추가했다. UV의 세로 기준 차이도 보정했다. 메시를 개체별로 재사용하고 사망 제거·씬 종료 때 해제한다.

새 방향 파일은 합계 7,664,452바이트의 WebP다. 현재·다음 지역만 기존 준비/재시도 흐름에 포함한다. 생성 PNG, 전달 WebP, 생성 기록은 `public/art/direction-v2`, `docs/source/direction-motion-manifest.json`, `docs/source/direction-motion-calibration.json`에 보관한다. 원본 생성 파일은 생성 도구의 경로에도 그대로 남겼다. 변환은 `scripts/export-direction-motion.mjs`, 그림 조각 검사는 `scripts/audit-direction-layout.mjs`다. 후자는 Node 22에서 `--experimental-strip-types`와 `MUGONG_SHARP_PATH`로 실행한다.

## 검증

- 단위 검사 13개 파일·196개 통과: 팔방/반전, 방향 경계, 이동 거리/순간이동/정지, 단계 사이 연속성, 변형 범위, 감소된 모션, 사망 발 기준점과 다섯 열 추출을 포함한다.
- 브라우저 검사 38개 통과: 지역 동작 19개, 팔방 연속 동작 14개, 기존 타격감 5개. 뒤대각선 보정 뒤 연속 동작 14개를 다시 실행했다. 70종×8방향의 실제 그림 등록·반전·정점 변화, 주인공 행동, 가방 정지, WebGL/Canvas, 로딩/재시도와 실제 피해 시점을 확인했다. 전투 화면은 1093×614, 1366×768, 1440×900에서 확인했다.
- 실제 시각 검토: 생성된 10시트의 행·인물·전신을 확인했다. 죽림의 한 인물이 누락된 6행 시트가 자동 분할에서 7행처럼 등록되는 문제를 발견해 재생성했다. 존재·알파 개수만으로는 검수가 부족하므로 조각 높이 검사도 추가했다. 실제 전투 캡처에서 인물·배경·HUD, 앞/옆/뒤와 뒤대각선, 잘림을 확인했다. 검수 이미지와 실제 WASD·공격·궁극·방어 입력 시연은 `docs/verification/directional-motion-v2`에 있다.

이 방식은 방향 그림을 변형하는 런타임 애니메이션이다. 옷·무기가 몸을 가리거나 새로 드러나는 실루엣까지 다시 그리는 동작별 수작업 프레임 애니메이션과는 다르다. 프레임률 보장이나 서비스 수준 인증을 뜻하지 않으며, 특수 무기별 세부 손동작은 이 공통 리그 위에서 추가 조정할 수 있다.
