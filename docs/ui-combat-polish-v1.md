# 전투 연출·UI 개선 1차

2026-09-28. 사용자가 첫 플레이의 순서를 승인하고 가방·창고 연결, 공격 동작·타격 이펙트, HUD·가방·버튼 디자인을 요청해 반영했다.

## 가방과 창고

귀환한 무인의 로비 가방에서 ‘창고 함께 보기’를 눌러 같은 창에 창고 물품을 펼친다. 물품을 선택하거나 드래그하여 가방의 수납 위치를 지정한다. 가방의 ‘창고로’ 버튼을 누르면 창고 목록이 열리고 보관 위치 및 이동 안내를 표시한다. 창고에서 시작해도 같은 가방 화면을 사용한다. 중첩 물품은 한 개씩 꺼내며 다시 넣으면 합쳐진다. 무기를 창고로 옮기면 해당 무공 연결이 해제되고, 꺼낸 뒤 연결을 다시 지정할 수 있다.

강호에서는 창고 자산을 들여올 수 없다. 화면뿐 아니라 명령 처리에서도 전투 종료 후 반입을 막는다. 로비에 귀환한 무인이 없으면 창고는 보관 목록만 보여준다.

검·도포·신발·장신구·약병·비급·광석은 직접 만든 SVG 그림으로 표시한다. 검의 회전 방향과 수납 칸에 맞춰 그림 비례를 바꾼다. 포인터 아래에 물품 전체 크기의 배치 미리보기와 수납 가능·공간 부족 상태를 표시한다. 두 가방의 사용 칸 수와 선택 물품의 현재 위치를 보여준다.

## 전투

기존 방향별 키프레임에 준비·타격·회수 시간을 맞추고 짧은 몸 기울임과 전진·회수를 더했다. 피격 시 적의 작은 반동과 명도 변화, 피해 숫자, 25ms 타격 멈춤, 타격음을 표시한다. 플레이어 피격 시 짧고 작은 카메라 흔들림을 사용한다. 이 이동은 렌더링 표현이며 충돌 좌표와 공격 거리·대미지 수치는 바꾸지 않는다. 타격 멈춤은 전투 진행에도 적용하며 저장에 남기는 상태는 아니다.

베기는 꼬리가 좁아지는 색면과 밝은 날, 찌르기는 뾰족한 검로, 타격은 불꽃, 방어는 보호막, 궁극기는 두 겹의 충격파로 구분한다. 화산은 꽃잎 조각을 더하고 무공별 색을 유지한다. 검기·이기어검 투사체에는 검의 날과 손잡이, 화살에는 촉과 잔상을 표시한다. 공격 및 타격음은 외부 음원이 아닌 Web Audio 합성이다.

OS의 움직임 줄이기 설정에서는 몸 기울임·반동·카메라 흔들림·타격 멈춤·숫자 이동·UI 입장 애니메이션을 줄인다. 전투를 이해하는 데 필요한 공격 궤적과 예고는 계속 표시한다.

## UI

종이 바탕·옥색 주요 버튼·황동 선·붉은 인장의 공통 디자인을 HUD·로비·성장 카드·가방·창고·확인 창에 적용했다. 버튼의 호버·눌림·비활성·키보드 포커스, 창 입장, 카드 선택 피드백을 통일했다. HUD의 초상·레벨·체력·경험치, 준비된 궁극기, 선택한 무공을 더 명확히 표시한다. 큰 관리 창은 제목과 닫기 버튼을 상단에 유지한다. 정리판 폐기 확인에서는 포커스를 확인 버튼 안에 제한한다.

전리품을 두고 진행하는 확인도 브라우저 기본 대화상자 대신 물품 목록과 ‘돌아가서 챙기기’·‘전리품 두고 진행’ 버튼을 가진 게임 내 창으로 바꿨다.

## 검증

- 규칙·저장 테스트 27개 통과. 창고 중첩 왕복 및 강호 반입 금지 검증 추가.
- 브라우저 시나리오 10개 통과(31.2초). 창고→무장 가방→창고→새로고침 복원, 실제 베기·타격·피해 숫자·HUD 표시 검증 추가.
- TypeScript 검사 및 프로덕션 빌드 성공.
- 1440×900, Chromium 153, SwiftShader/Canvas에서 적 9명 표시 평균 약 60.0FPS. 화산 반복 베기·타격 불꽃·피해 숫자·타격 멈춤을 표시한 120프레임 표본은 약 59.5FPS. 짧은 자동 측정이며 모든 기기와 최다 투사체 상황의 지속 성능을 보장하지 않는다.
- 기존 방향 시트를 사용하는 상태이며 새 무공별 전용 중간 원화나 보스 전용 동작 시트를 생성한 것은 아니다. 추가 동작 원화는 다음 에셋 품질 확장에서 교체할 수 있다.
