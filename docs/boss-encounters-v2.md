# 보스 특수 행동과 전용 전리품 v2

2026-09-30. 업로드한 원본의 보스 패턴과 드롭 표를 대조해, v1의 공통 공격 조합 위에 실제 특수 행동과 파훼 방법을 연결했다. 기존 사용자 저장은 삭제하거나 테스트 데이터로 바꾸지 않았다.

## 실제 전투 변화

| 계열 / 보스 | 추가 행동과 대응 |
| --- | --- |
| 청하표두 | 깃발 주변 방어 강화. 깃발을 공격해 파괴하면 강화가 끝난다. |
| 백면포두·빙잠녀·철나한·흑사마승·홍의마녀 | 예고 이후 철쇄/실/흡인으로 당긴다. 거리 벌리기나 무적 회피로 연결을 끊는다. 빙사는 이동을 둔화하고 혈사는 회복량을 줄인다. |

| 천검산·폐사 | 일정 시간 피해를 줄이는 자세. 반격 자세의 정면을 공격하면 되돌아오는 투사체를 발사한다. |

| 하북패도·천검노인·혈마제자 | 저체력 추격 강화, 단계 강화 또는 자해 후 일정 시간 공격 강화. |
| 설원창객·빙궁주 | 파괴 가능한 얼음과 이동 둔화. 빙궁주가 온기 구역의 위치를 바꾼다. |
| 죽엽살수·백설노괴·황사도적왕 | 짧은 은폐와 연막 영역. 외형은 반투명으로 남아 공격 위치를 읽을 수 있다. |
| 청죽검객·묘지기·팔문 계열·대막도왕 | 예고 뒤 실제 이동을 막는 파괴 가능한 벽과 추가 위험 영역. |
| 기관장인·기관사 | 공격으로 부술 수 있는 쇠뇌. 조준 방향을 고정한 후 1초 준비하고 쏜다. 기관이 남으면 수리한다. |
| 고묘후인 | 폭발하는 가짜 보물상자. 공격으로 파괴하거나 범위 밖으로 피한다. |
| 혈도객·홍의마녀·혈마교주 | 피 지대 적중 시 보스 회복, 연결과 표식에 따른 회복량 감소. |
| 팔진노사 | 위치가 바뀌는 안전지대. 초록 영역 밖에는 예고 후 피해가 생긴다. |

전장 소품은 새 카툰 그림을 사용하고, 바닥의 원·선·준비 시계는 실제 판정을 설명한다. 방어 자세와 광폭 상태는 적 위에 별도 표시한다. 상시 전투 설명은 비웠으며, 오브젝트나 회복 감소가 있는 동안만 짧은 대응 문구를 보여준다.

소품의 내구도·소유 보스·위치·준비 시간·수리 및 발사 시점, 연결·이동 둔화·회복 감소를 저장한다. 보스를 처치하거나 웨이브를 바꾸면 해당 오브젝트를 정리한다. 전장 오브젝트는 최대 12개로 제한한다. 깃발의 강화 영역과 물품 본체의 피격 크기를 구분해, 영역 전체가 깃발의 피격 판정이 되지 않게 했다.

## 무공과 충돌 수정

- 매화난무는 가까운 세 적 사이로 실제 이동하며 순서대로 벤다. 남은 대상과 대기 시간을 저장하므로 재실행 시 같은 순서로 이어진다.
- 혼취된 일반 적은 가까운 다른 적을 향해 공격한다. 해당 투사체는 무인에게 피해를 주지 않으며 다른 적을 처치하면 정상 경험치를 처리한다. 보스는 동료 공격으로 전환하지 않는다.
- 적 투사체의 무인 충돌이 내부 적 반복문의 조건에 연결돼 있던 분기를 분리했다. 적 숫자와 관계없이 무인 충돌을 처리한다.
- 적끼리의 처치나 지속 피해로 성장 선택을 열면 같은 프레임의 나머지 피해와 시간이 멈추게 했다.

## 전용 전리품과 가방

40보스 각각 원본 드롭 표 안의 이름 있는 물품 하나를 추가한다. 기존 무장·회복품·비급은 유지하고, 추가 물품은 비급 경험치를 늘리지 않는다. 물품에는 출처 보스를 저장하고, 선택 정보에서 이름·효과·출처를 확인한다. 새 이름과 출처 문구는 다섯 언어에 번역했다.

고유 무장은 해당 무기 그림, 기타 전리품은 철쇄·옥패·독낭·독 구슬·빙잠사·기관핵·지도·혈정 그림을 사용한다. 각 보스마다 모든 장비의 개별 그림을 새로 만든 것은 아니다. 같은 유형의 일부 물품은 그림을 공유한다.

재료 중첩 조건은 종류뿐 아니라 이름·품질·능력·무장 종류·보스 출처를 비교한다. 독낭과 만독주처럼 같은 재료 분류의 다른 물품을 합치지 않는다. 기존 회복품과 비급은 동일 조건에서 계속 중첩할 수 있다.

작은 화면에서 품질·크기·효과가 붙어 보이던 정보 배열을 두 열의 이름/수치 행으로 정리했다. 수납·착용 버튼, 두 격자, 전리품과 정리판을 함께 유지한다.

## 원본을 각색한 부분과 남은 범위

특수 행동은 원문을 현재 탑뷰 판정에 맞게 각색했다. 사슬은 별도 사슬 물리 대신 저장된 연결 영역, 빙벽·석문·대나무는 파괴 가능한 장애물, 정화초는 접근 정화, 기관 수리는 쇠뇌 복구로 구현했다. 별도 수리 드론이나 회전문·대나무 반사 물리까지 그대로 구현한 것은 아니다. 혈마교주의 체력 교환은 회복 감소 표식과 흡혈 지대로 적용했다.

이후 지역 배경·일반 적 30종·보스 40종 외형을 [지역 그림 v1](region-art-v1.md), 개별 걷기·공격 준비·타격·피격·사망 자세를 [자세 애니메이션 v1](enemy-motion-v1.md)에서 적용했다. 방향별 전용 자세와 공격 중간 프레임, 원본 전체 희귀 확률 드롭 표와 반로환·감정·제작 시스템, 온라인 레이드·비무는 남아 있다. 방어·회복·피해 수치는 추가 실제 플레이로 조정해야 한다.
