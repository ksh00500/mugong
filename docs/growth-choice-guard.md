# 성장 카드 오입력 방지

강호 전투에서 마지막 공격으로 레벨업하면 무공 카드가 화면 가운데 나타난다. 이때 누르고 있던 공격 입력이나 곧바로 이어지는 클릭으로 무공을 잘못 고르지 않도록 카드 세 장을 1초간 비활성화한다. 카드 위에 남은 초와 짧은 진행 막대를 표시한다.

잠금이 풀리기 전에는 카드 선택 명령이 호출되지 않는다. DOM 버튼의 비활성 상태와 클릭 처리 시각 검사를 함께 사용한다. 성장 창은 먼저 창 자체에 초점을 둔다. 잠금 중에는 Tab으로 카드에 접근할 수 없고, 잠금 후 Tab을 누르면 첫 카드에 접근한다. 공격에 쓰던 Space 키가 새 카드에 자동으로 눌리지 않게 카드 자동 초점은 사용하지 않는다. 연속 레벨업으로 카드가 새로 나오면 대기 시간도 다시 시작한다. 로비의 수련 선택에도 같은 보호를 적용한다.

전투 중 실제 공격으로 첫 레벨업을 만든 브라우저 검사에서 카드가 1초간 비활성화되고 새로고침 후에도 다시 잠기며, 이후 정상 선택되는 것을 확인했다. 최종 보스 이후 이어지는 여러 선택과 명부 등록도 확인했다.
