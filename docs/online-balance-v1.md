# 온라인 정상 수치 관측과 레이드 추격 교정

2026-10-23. 개인 무인 저장 이후 첫 밸런스 관측이다. 보스 HP·공격 피해·층 보상·캐릭터 배율을 변경하지 않고, 실제 무기 판정과 보스의 거리 판단을 교정했다. 인간 난이도 조정 완료를 뜻하지 않는다.

## 바뀐 동작

- 레이드 보스는 거리260 밖에서310/초로 추격하고, 가까이서는185/초로 접근한다. 이전에는 항상145/초였다. 플레이어와 비무의 이동 속도는 유지한다.
- 베기210·방어 베기155·돌진320·사격/표식650의 시도 거리까지 접근한다. 준비 시계가 끝났다는 이유만으로 사거리 밖에 근접 공격을 낭비하지 않는다.
- 거리420 밖 추격이1.25초 이상 계속되면 기존 직선 돌진을 선택할 수 있다. 조준은 예고 시작 때 잠그며 기존1.05초 예고·300거리 돌진·1.1초 정지 회복을 유지한다. 원거리 플레이어의 필중 피해를 강제하지 않는다.
- 개인 무인의 기본·방어·궁극은 현재 무공에 **연결된 호환 무기**가 필요하다. 기존 기본 공격은 무공 인자 없이 검 소지만 검사해서, 다른 무기를 제대로 연결해도 검이 없으면 막히고 반대로 검 소지만으로 미연결 무공이 허용될 수 있었다.
- 개인 궁극은 기존 무공별 개방 레벨도 서버가 확인한다. 미개방/미무장 요청은 게이지·재사용을 소비하지 않는다. 표준 친선/순위전의 수치와 규칙은 유지한다.
- 새 추격 시계는 선택 필드로 읽으므로 이전 개인 방 사본을 계속 복구할 수 있다. DB 스키마나 실제 사용자 기록을 바꾸지 않는다.

## 관측과 판단

고정12 seed×선호 무공4종의48회에서14개 무인이 정상20웨이브를 완주했고,13회는 첫 보스에서 끝났다. 모집 후보와 고정 가상 UTC 시각을 재현 가능하게 준비하고 실제 전투·성장 선택·무기/장비·소지 약·정비 이동/유료 서비스로 진행했다. 시작 후 HP·XP·적 체력·전리품·웨이브/단계를 수정하지 않았다. 기존 강호 규칙을 이번에 바꾸지 않았으므로 전후48개 결과가 같다.

이 결과는 경고 시계와 적 위치를 읽는 고정 반응형 봇의 표본이다. 네 선호 무공의 우선순위일 뿐 다른 무공을 배우지 않는 고정 단일 빌드도 아니며, 인간 승률·전체 지역/전 특성의 균형을 뜻하지 않는다. 이를 근거로 강호 전체 HP나 보상을 일괄 조정하지 않았다.

선별된 생존 명부의 앞1~4명으로 실제 개인 예약·층 보상·성장·약 사용·귀환을 메모리 SQLite에서 실행했다. 이번 네 파티는5층을 완주했고 마지막 출전 잠금도 해제됐다. 1인은128.68초,2인은94.03초,3인은91.57초,4인은93.12초였다. 정비 선택은 자동 처리하므로 사람의 실제 소요 시간과 다르다. 1인 누적 피해는396.22→436.63으로 늘었지만3~4인 일부 피해는 줄었다. 단조로운 난이도 상승을 주장하지 않는다. 파티 배치·모든 무공 효과 동등성·인간 조작을 먼저 검증해야 추가 HP/경제 조정의 근거가 된다.

완주 은전은 기존대로 개인당100이며, 지급은 기존 트랜잭션을 사용한다. XP/비급/수련·약 소비도 실제 규칙이다. 상품/강화/모집의 장기 경제 균형과 무한 반복 수익률은 이번 네 파티로 인증하지 않는다.

## 재현

```sh
npm run probe:online-balance -- .local-preview/online-balance/after.json
npm run probe:online-balance -- .local-preview/online-balance/before.json b25cdd0
```

두 번째 명령은 현재 관측기에서 그 커밋의 레이드/공통 전투 엔진만 교체한다. 완전한 과거 체크아웃 실행은 아니다. 출발 후보·성장·강호 엔진은 같다. 생성한 무인 사본과 메모리 DB는 실제 계정/로컬 IndexedDB를 사용하지 않는다.
