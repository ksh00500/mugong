# 보스 고유 기믹 구현 v1

2026-10-02. 사용자가 `boss-mechanic-rebuild-list.md` 전체 방향을 승인한 뒤 구현한 **로컬 강호 전투**의 현재 규칙이다. 원문 명칭/콘셉트는 `src/domain/catalogue.json`, 아래 시간·수치는 이번 구현에서 정한 값이다. 사람의 난이도 검증이나 온라인 구현 완료를 뜻하지 않는다.

## 공통 기반

- `src/domain/boss-mechanics.ts`: 고유 물체 생성·시간 상태·이동 구간 충돌·반사·반응 행동. `boss-encounters.ts`의 일반 장판과 별도 처리한다. 설치물의 소유자 사망·수명 종료 시 제거한다.
- `EncounterObject.mechanic/age/stage/anchorX/anchorY/target`, `Enemy.armourTime/staggerTime/reactionTime/observedAttack`, Fighter 냉기·동결·출혈·잡기, 투사체 반사 이력은 선택적 저장 필드다. 옛 유효 저장을 허용하면서 새 필드의 잘못된 값은 거부한다. `src/platform/save-validation.ts`.
- 전투 종료/성장 선택에서 잡기와 진행 중 교환을 취소한다. 가방·정지·숨김에서는 전투 시간이 진행되지 않는다. 새 웨이브에 상태를 초기화한다.
- 체력 교환은 두 HP와 `Run.exchangeSeq`를 한 시뮬레이션 단계에서 바꾼다. `src/platform/store.ts`가 이 번호의 변화를 중요 저장 장벽으로 확인하며 일반 1초 저장 간격을 기다리지 않는다. 교환 도중 과거 HP로 롤백하거나 두 HP를 별도 저장하지 않는다.

## B 및 공통 표현

- 백운 `2-4`: HP 절반 이하 실제 발사체 반경 12→25, 그림 크기 2배. 단순 광폭과 별도.
- 무명 `2-3`: 새 플레이어 공격 시작을 관측해 거리 420 안에서 추격 준비. 준비 0.65초·반응 쿨타임 2.5초, 즉시 피해 없음.
- 설란/한설과 냉기: 적중 시 냉기 최대 3중첩, 지속 3초, 세 번째 적중은 동결 0.65초 후 중첩 초기화. 회피 무적 동안 누적 안 됨, 실제 회피/온기가 누적 해제, 온기는 동결도 해빙. 움직임/공격 구속은 저장된 동결 상태를 사용.
- 백설노괴/청비: 발동한 눈보라/연막 안에서 은폐 유지, 접근 상태에서는 측면으로 잠복 이동. 실제 발자국/발사체가 위치 단서다. 전체 화면을 검게 가리거나 화면 밖 즉시 타격을 추가하지 않음.
- 도원/불명: 기본 적 피격 경직과 별도 슈퍼아머 구간. 슈퍼아머는 피해 무효화가 아니며 방어 피해 배율과 분리한다.
- 불명: 공격 가능한 종의 준비→타격 사건→밝은 종 효과음·충격→광폭 4초/슈퍼아머 3초. 준비 중 종 파괴로 차단. 보스에 대한 기존 폐사 시간 주기 피해 강화는 제거, 일반 적의 지역 주기는 유지.
- 무진 `4-4`: 반격 조건에서 전용 손바닥 장풍 투사체를 발사, 검기 그림 재사용 제거.
- 노개 `5-2`: 접근 좌우 비틀기와 회복 중 후퇴, 기존 봉 공격 연계. 노개/술병객의 실제 착탄 구역도 술로 바꿔 직접 폭발 피해 없이 취기 효과를 사용.
- 적호/곽기: 주기적으로 켜지고 꺼지는 실물 함정 발판, 곽기는 중앙에서 회전 이동하는 칼날 3개와 이동 구간 접촉 피해. 기관/드론과 물체 소유권 공유.
- 적우 `8-1`: 실제 베기 적중 시 출혈 3.2초, 독과 별도 저장·그림·3 피해/0.8초. 연살 `8-2`: HP 35% 미만 광폭 유지, 공격 피해/이동과 회복 시간 단축.
- 제갈현 `9-4`: 건/곤의 방향·그림·외부 피해 7/10을 구분하며 안전 진이 연속 이동. 플레이어 진법과 다른 금빛/옥빛 문양을 사용.
- 연화 `1-3`: 독침(전용 바늘+잔류 중독), 독분(노란 가루·피해 7/0.9초+둔화), 독무(초록 안개·피해 4/0.9초+중독/회복 감소). 공통 봉인·사슬 대체 제거.
- 적 깃발은 실제 깃발 그림만 사용하며 위험 봉인 장판을 그리지 않는다. 드론·종은 내부 종류가 flag여도 깃발 방어 강화로 계산하지 않는다.

## 그림과 소리

내장 imagegen으로 생성하고 alpha를 보존한 두 아틀라스를 `public/art/boss-mechanics-v1.png`, `public/art/boss-fields-v1.png`에 저장했다. Phaser에서 프레임으로 등록하며 전체 아틀라스를 물체 하나처럼 표시하지 않는다. 정화초 파괴처럼 물체의 그림 출처가 바뀔 때 기존 actor의 텍스처도 교체한다. 냉기/출혈 그림은 프레임 정리 중 삭제되지 않도록 생명주기를 별도로 확인했다.

프롬프트는 각각 다음 구성이다: **“4열 3행 투명 무협 카툰 게임 소품: 대나무/쓰러진 대나무/성문/석문/모래벽/수리 드론/회전날/오아시스/발판/종/정화 꽃/장풍”**, **“4열 2행 투명 바닥 이펙트: 독분/독무/플레이어 건·곤/보스 건·곤/얼음/출혈”**. 자세를 복잡하게 나열하지 않았다. 소품의 기울기·회전·투명도는 저장된 상태에서 그리며 움직임 줄이기에서는 장식 회전을 끈다.

종·반사·교환은 실제 사건에서 소리 큐를 낸다. 기존 합성 효과음 풀/음량 설정을 재사용하며 종은 짧고 밝은 음색이다. 전투 도형·공격 범위 예고를 복원하지 않는다. 상황 문구는 한국어/영어/일본어/간체/번체를 모두 연결했다.

## 검증과 남은 조정

최종 TypeScript/Vite 빌드와 단위 검사 26파일 466개가 통과했다. 보스·구역·창고·웨이브 회귀 브라우저 검사 65개가 통과했으며, 마지막 문 개폐/반사 타이밍 수정 후 관련 22개를 다시 실행해 모두 통과했다. 두 브라우저 검사 수를 서로 독립된 전체 시나리오 수처럼 합산하지 않는다.

자동 단위 검사는 성공/차단, 실제 피해·움직임·폭, 소유자 사망, 저장 재개 결정성, 드론 중단, 교환 중요 저장, 독립 상태를 검사한다. 브라우저 검사는 실제 Phaser 텍스처/프레임, 페이지 오류, 작은 화면, 가방/창고/웨이브·번역을 검사한다. 증거는 `tests/boss-mechanics.test.ts`, `tests/store.test.ts`, `tests/e2e/boss-mechanics.spec.ts`, `docs/verification/boss-mechanics-v1/`.

수동 시각 검토는 회전문·오아시스·드론·독무 및 상태/장풍 캡처에서 시행했다. 자동 통과와 사람의 플레이 평가는 구분한다. 40보스·8계열 조합의 장시간 인간 플레이, 저사양 실제 기기 성능과 난이도 수치 조정은 후속 검토다. 온라인 레이드/PVP 구현과 공개 재배포는 이번 범위에 포함하지 않았다. 실제 사용자 저장은 테스트에 사용하지 않았다.
