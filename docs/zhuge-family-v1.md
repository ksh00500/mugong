# 제갈 · 팔진고성 전체 방향·동작 적용

2026-10-06 추가: 기관병 앞 대각선의 후속·회수와 진괄 측면 사망의 원화 분리 오류를 재제작하여 로컬에 반영했다. [수정·검증 기록](zhuge-boundary-v2.md). 아래 내용은 최초 적용 기록이며, 현재 선택 원본은 프레임 manifest와 generation-jobs.json을 따른다.

2026-10-04. 일반 적 기관병·창 문지기·쇠뇌병과 보스 개문수 양기·기관사 묵연·팔문장군 진괄·팔진노사 제갈현을 새 원화로 적용했다. 기존 지역 구성과 공격 판정·보스 패턴은 유지한다.

인물마다 정면·앞 대각선·측면·뒤 대각선·후면을 12자세로 제작했다. 총 35개 원화 묶음, 420장이다. 좌우 반전으로 8방향을 표시한다. 12자세는 대기, 세 보행 자세, 작은 피격, 사망과 공격 준비·최대 준비·타격/발사·후속·회수·복귀다.

## 무기와 선택

| 인물 | 원화의 도구와 기본 동작 |
| --- | --- |
| 기관병 | 팔괘 기관함을 들고 다른 손으로 작동·방출 |
| 창 문지기 | 하나의 창을 양손으로 준비·찌르기·회수 |
| 쇠뇌병 | 쇠뇌 조준·발사·재장전 |
| 개문수 양기 | 단일 봉을 양손으로 준비·밀어내기·회수 |
| 기관사 묵연 | 반복 쇠뇌 조준·발사·회수 |
| 팔문장군 진괄 | 긴 창을 양손으로 준비·찌르기·회수 |
| 팔진노사 제갈현 | 깃털 부채를 펴고 내밀어 술법을 방출 |

기관병과 쇠뇌병은 게임에서 모두 `kind=archer`다. 이제 `authoredEnemyArt`는 보스 ID를 먼저 구분하고, 일반 적은 역할을 구분해서 다른 도구의 원화가 섞이지 않게 한다.

## 크기·접지·HP 바

원본 픽셀은 리사이즈하지 않고 RGBA 값을 그대로 전달한다. 같은 인물의 모든 방향·자세는 공통 전달 칸을 쓰며 최소 32픽셀 투명 여백을 갖는다. 게임에서는 원본 종횡비와 배율 0.225를 고정한다. 무기 외곽에 맞춘 프레임별 배율 조정이나 몸 메시 변형을 사용하지 않는다.

접지 좌표는 원화별 저장값을 사용한다. 자동 제안의 최하단에는 창끝이 포함될 수 있다. 창 문지기·진괄의 정면 타격/후속 네 그림은 검토한 발 위치로 지정했다. 기록은 원화 폴더의 `ground-anchor-review.md`에 있다. HP 바는 모든 살아 있는 자세 중 최대 높이에 여유를 둔 고정 위치다.

기관 설치탄과 쇠뇌는 준비가 끝나는 즉시 발사 그림을 표시한다. 창 문지기는 기존 0.09초 접촉에 맞춘다. 보스 18개 행동의 접촉 시간마다 타격 그림을 표시하며 2~3연타도 회수 그림에 가리지 않는다. 보스 피격은 공격 자세를 바꾸지 않는다.
