# 창고와 단축키 v1

2026-10-02. 세가 창고를 가방과 별개의 전체 화면으로 분리했다. 무인 요약·가방 격자·무공을 숨기는 CSS 처리가 아니라 렌더링 자체를 하지 않는다. 현재 종이·아이템 그래픽을 유지하며 검색, 종류 필터, 페이지 이동, 선택 물품 정보 및 가방으로 보내기를 제공한다.

## 조작

| 조작 | 결과 |
| --- | --- |
| Ctrl+클릭 / Ctrl+Enter | 해당 물품 바로 이동 |
| 선택 또는 물품에 초점을 두고 F | 가방 → 창고(로비), 가방 → 획득 물품(강호), 창고·획득 물품 → 가방 |
| T | 가방 자동 정리와 획득 물품 수납 |
| R / Esc | 기존 회전 / 닫기 |

Mac의 Meta+클릭/Enter도 지원한다. Shift 상세 설명과 별개다. 창고의 가방으로 버튼은 화면을 닫거나 가방을 열지 않는다. 창고 물품은 저장 상태·수량·개별 ID를 기존 이동 명령으로 처리한다. 수납 공간 부족, 강호 진행 중, 귀환한 무인 없음에서는 창고에서 가방으로 이동하지 않는다. 격자·행동 버튼과 키보드·드래그는 기존 이동 알고리즘을 공유한다.

## 검증

- 타입 검사와 프로덕션 빌드.
- 단위 검사: 406개. 빠른 이동에서 중첩 수량 보존, 회전·수납 종류, 만석 시 무변경, 전투 제한을 포함한다.
- 독립 Playwright 컨텍스트에서 3개 해상도 × 5개 언어: 창고만 렌더링, 목록 페이지·검색, Ctrl+클릭/F 이동, 저장 복원, 초점 복귀와 화면 경계/영역 겹침 검사.
- 가방 양방향 이동, 획득 물품 이동, T 자동 정리, 만석과 무인 없음 상태를 검사한다.
- 기존 가방·드래그·착용·사용·전투 입력 격리 흐름을 재검증한다.
- 캡처: `docs/verification/storage-shortcuts-v1/`. 캡처를 직접 열어 한국어·영어 작은 화면의 검색칸·선택 정보·행동 버튼·페이지 배치를 확인했다. 자동 검사는 사용자 플레이 테스트나 접근성 인증을 의미하지 않는다.

검증은 사용자 저장을 지우거나 바꾸지 않는 별도 브라우저 컨텍스트에서 수행했다.

로컬 브라우저 시나리오 30개와 공개 빌드 시나리오 4개를 확인했다. 개발 서버 갱신과 브라우저 세션 중단으로 영향받은 검사는 갱신 종료 후 다시 실행해 통과했다. [Daytona 배포 기록](daytona-storage-shortcuts-v1.md)을 함께 본다.
