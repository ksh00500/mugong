# 플레이어 표시 크기 50% · 2026-10-06

이 문서는 최초 50% 적용·배포의 기록이다. 현재 로컬 배율은 사용자 피드백에 따라 [70%로 재조정](player-size-v2.md)했다.

사용자가 적에 비해 플레이어가 크다고 보고 현재의 절반 정도를 요청했다. 외형 10종과 외형 번호가 없는 구형 저장 캐릭터의 전투 표시 너비·높이를 기존의 50%로 조정했다. 로비 일러스트·초상화·HUD·적의 크기는 이번 조정 대상이 아니다.

`src/game/player-visual.ts`의 공통 표시 배율은 0.5다. 대기·보행·공격·궁극·방어·피격·사망의 원화 선택이 끝난 후 몸체에 한 번 적용한다. 각 프레임의 원본 비율과 발 기준점을 유지하고, 무기 경계에 맞춰 프레임을 제각각 축소하지 않는다. 6종 장착 무기의 길이와 검광, 손까지의 거리, 그림자, 공격 때 표시상 전진량도 같은 비율로 줄였다. 공격 시간·이동 속도·피해·공격 범위·피격 판정·저장 데이터는 바꾸지 않았다.

Canvas/WebGL의 독립 브라우저에서 변경 전 원본 표본을 먼저 확보했다. 외형 10종과 구형 저장, 6무기, 8방향, 일반/움직임 감소 설정, 대기·보행·8개 공격 노출·궁극·방어·피격·사망의 **29,568개 상태**를 전후 비교했다. 몸체와 보이는 무기의 너비·높이, 몸체 기준 손의 위치가 50%이고 원화 선택·반전·발 원점·무기 각도가 같음을 확인했다. 전후 비교 4개 테스트가 통과했다. 원본 이미지 픽셀을 다시 축소하거나 생성하지 않았다.

전체 단위 테스트 1,278개와 타입 검사·프로덕션 빌드가 통과했다. 최초 단위 실행은 제한된 임시 경로의 EPERM으로 정상 로드되지 않았다. 이후 많은 수치 검사와 브라우저를 함께 실행할 때 기존 기하 검사 하나가 기본 제한 시간에 걸려, 실행 작업자 2개와 제한 20초로 전체를 다시 검증해 통과했다. 크기 비교의 반복 단언은 전체 표본을 빠른 수치 비교로 바꿨고, 이전 테스트 서버가 종료된 재시도는 새 테스트 포트에서 다시 실행했다. 이 환경 재시도와 실제 크기 비교 결과를 구분한다.

직접 시각 검토는 보라색 외형의 변경 전/후 전투 화면과 Canvas의 두 외형, WebGL의 변경 후 전투 화면을 확인했다. 자동 검사는 전체 상태를 비교하지만 모든 상태를 사람이 개별 육안 검수했다는 뜻은 아니다. 실전 난이도 조정 결과도 아니다. 원거리 대응과 로비 고해상도 작업은 별도다.
