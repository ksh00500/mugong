# 캐릭터 에셋 관리와 동일성 승인

2026-10-03. 관련 문서: [기존 동작 시트](enemy-motion-v1.md), [방향 시트](directional-motion-v2.md).

2026-10-04 플레이어 기본 공격의 현행 원화·손 기준점·8방향 연결은 [플레이어 베기 v1](hero-slash-v1.md)을 따른다. 외형 10종의 준비·타격·회수 150개를 새로 제작했고, 나머지 동작은 기존 승인 경로를 유지한다.

2026-10-04 현행 규칙과 후속 보정은 [적 외형·동작 정합성 v3](hostile-consistency-v3.md)를 따른다. 아래 승인 철회와 뒤쪽 동작 미지원 설명은 과거 이력이다. 현행 경로는 `region-art.ts`, `assets.ts`, 승인 명부와 해부학 크기 보정 JSON을 함께 확인한다.

최신 후속 작업은 [캐릭터 동작 원화 재제작 v2](animation-rebuild-v2.md)다. 10지역의 여섯 자세, 주인공 기본 40칸과 반응 16칸, 역할·교체 인물·기병·드론을 새 시트로 연결했다. 아래 승인 철회와 v1 적용 설명은 당시 기록이며 현재 파일 경로는 `src/platform/character-identities.json`과 `src/platform/assets.ts`, `region-art.ts`를 우선한다.

## 확인한 결함과 현재 적용

천검산 낙검객 우진의 `public/art/enemy-motion-v1/2-motion-v2.webp` 3행(0부터 계산)은 준비 자세에서 검은 머리·흰 치마형 의상으로 바뀌지만 첫 자세는 회색 머리·검은 외투다. 동일 시트의 같은 행이라고 동일 인물이 보장되지 않는다. 기존 크기·경계·프레임 검사 통과는 캐릭터 동일성의 증거가 아니다.

현재 모든 일반 적 및 보스의 별도 동작 원화 사용 승인을 철회했다. `src/game/hostile-pose.ts`의 승인 집합은 비어 있다. 이동·준비·타격·회복·피격·사망은 같은 방향 원화를 유지하며 기존 역할별 관절 동작으로 표현한다. 전투 판정과 타이밍은 유지한다. 이것은 잘못된 인물 전환을 차단한 조치이며 모든 원화를 보정 완료했다는 뜻이 아니다. 방향 그림 자체의 방향 간 동일성, 주인공 원화, 전용 역할과 기병의 원화 검토는 별도 미완료 작업이다.

## 필수 관리 규칙

- 인물 식별자는 보스 `boss:<bossId>`, 일반 적은 지역과 역할을 함께 기록한다. 같은 무기나 숫자 행이라는 이유로 다른 인물의 자세를 재사용하지 않는다.
- 인물마다 승인된 기준 원화 하나와 얼굴·머리색/머리끈·복장·색상·장비 목록을 기록한다. 준비 자세에도 얼굴, 의상, 무기가 같아야 한다.
- 원본, 전달 파일, 프레임 행, 방향, 기준점, 배율, 버전, 생성 참고 이미지, 검토 결과를 함께 기록한다. 비밀값과 인증정보는 기록하지 않는다.
- 기존 원본을 덮어쓰지 않는다. 수정본은 새 버전으로 보존하고 사용 경로를 명시적으로 교체한다. 파일 존재만으로 자동 승인하지 않는다.
- 원화 승인에는 같은 인물의 이동 방향과 여섯 동작을 나란히 놓은 비교표 및 실제 전투 캡처가 필요하다. 머리색·복장·무기 차이를 자세 차이로 처리하지 않는다.
- 자동 검사: 파일 로딩, 행/열 연결, 프레임 경계, 투명도, 발 기준, 배율, 전 상태의 인물 식별자 유지. 시각 검사: 얼굴·의상·장비·자세의 자연스러움. 두 결과를 구분한다.
- 승인되지 않은 자세는 동일 인물의 방향 원화와 관절 동작을 사용한다. 타인의 원화로 대체하지 않는다. 승인 집합에 추가하기 전 근거 비교표 경로를 남긴다.

## 남은 검토

70개 지역 행과 역할 전용 4행, 기병, 주인공의 방향/동작 비교를 인물 단위로 검토하고 수정 원화를 제작해야 한다. 기존 `docs/verification/animation-calibration-v7/` 비교표는 크기 검사용이며 동일성 승인 자료로 취급하지 않는다. 승인 없는 모든 인물이 안전 경로로 렌더링되는 정책은 단위 검사로 검증한다.

## 2026-10-03 원화 전수 비교 후 적용

현재 등록된 지역 원화 70행(일반 30행·보스 40행), 전용 역할 4행, 기병 1행, 주인공 40프레임을 기준 그림과 방향/동작 비교표에서 검토했다. 명백한 인물 변경과 장비 소실을 확인한 3행은 `public/art/hostile-identity-actions-v1.png`로 재제작했다. 낙검객 우진(2-1), 폐사 돌 투척 승려(4지역 2행), 폐사 지팡이 노승(4-4)이다. 이 세 행은 원본 행 대신 전용 교체 행을 직접 연결한다. 원본은 보존한다. 나머지 행은 검토 후 동작 사용을 복구했다. 앞선 일괄 승인 철회는 이제 아래 승인 기록으로 대체한다.

`src/platform/character-identities.json`은 70행의 승인 상태·지역·슬롯·검토 근거·교체 경로를 기록한다. `src/game/hostile-pose.ts`는 이 기록에 없는 인물을 동작 원화로 전환하지 않는다. 일반 적의 승인은 전역 역할명이 아닌 지역과 그림 행으로 구분한다. 전용 역할 4행과 기병, 주인공은 독립 식별자로 승인 기록을 분리했다.

새 원화 생성은 기본 imagegen을 사용했다. 프롬프트는 세 인물을 지정하고 6열(대기·걷기·준비·타격·피격·사망), 동일 얼굴·머리색·복장·장비, 투명 배경을 요구했다. 첫 결과의 가장자리 무기 잘림 때문에 투명 여백을 늘리는 보정을 한 번 더 수행했다. 출력 선택본은 위 프로젝트 경로에 복사했다.

검토 범위는 현재 존재하는 원화의 동일성이다. 뒤쪽 3방향 전용 공격 원화는 여전히 없으며 방향 원화의 관절 동작을 사용한다. 모든 캐릭터의 모든 방향을 새로 그렸다는 의미는 아니다. 원화의 세밀한 표정 차이와 장식 단순화가 완전히 동일한 픽셀이라는 보장도 하지 않는다. 지역 역할 일부가 기존 그림 행을 공유하는 문제는 별도의 디자인 다양성 과제다.
