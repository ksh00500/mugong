# 강호 드랍·장비·정비 구현과 검증

2026-10-01. 사용자 요청에 따라 강호의 실제 플레이 순환을 구현하고 검사했다. 온라인 레이드·비무는 별도 범위다. 업로드 원문의 10지역 테마와 40보스 고유 물품 이름을 유지한다. 수치 원본은 게임 코드이며 [92개 물품 목록](items-v1.md)과 [JSON](source/items-v1.json)은 코드에서 생성한다.

## 구현 기준

- 검·도·독침·권갑·봉·부채 6종을 각각 입문/정련/희귀의 3단계로 제공한다. 무기 종류는 8계열 무공의 호환 규칙과 일치한다. 새 무공 입문 시 수련 무장 지급은 계속한다.
- 도포·신발·패옥 3슬롯의 단계별 장비와 10지역 특산 장비/재료를 정의한다. 등급은 품질과 별개이며, 수치·칸 크기·판매가·효과를 데이터로 관리한다. 장비는 개별 물품, 소모품/재료는 보관 영역에서만 중첩한다.
- 일반 전투는 회복품·지역 재료와 지역 가중치 장비를 준다. 보스는 현재 무공에 맞는 무장, 경험치 20 비급, 회복품, 보스 고유 물품을 보장한다. 고유 재료 보스도 장비 보상을 별도로 얻는다.
- 드랍은 런의 저장된 난수를 사용하고 전투 종료 시 한 번만 확정한다. 새 난수 재굴림, 소환 적 경험치·드랍 파밍, 전투 중 사용은 금지한다.
- 정비의 의원·상인은 금전과 한정 재고를 쓴다. 지역 상인은 회복품·현재 무공용 무장·특산 장비를 판매한다. 비급 판매는 없어 경험치 총량을 늘리지 않는다.
- 정비에서 재료를 판매하거나 수납/착용한 장비를 강화할 수 있다. 강화는 금전과 재료 두 개, 장비당 최대 두 번이다. 행동의 비용·현재 수치·다음 수치를 실행 전에 보여준다. 비용 부족이나 불가능한 상태는 물품·재화를 변경하지 않는다.
- 강호 완주 목표 Lv.13~16, 네 무공 상한, 20웨이브 이전 귀환 불가, 현실 7일 수명, 사망 손실을 유지한다. 완주에서 남은 런 금전을 세가에 정산하고 최근 결과를 기록한다. 정리판 물품과 미수납 전리품 확인은 생략하지 않는다.
- 기본 UI는 짧은 이름·수치·행동 위주다. 품질·등급·강화·출처는 선택 물품 정보에 둔다. 정비 장터는 요청할 때만 열어 전투 화면을 가리지 않는다. 한국어·영어·일본어·간체·번체를 함께 제공한다.

## 물품 구성과 획득

| 분류 | 수 | 제공 방식 |
| --- | ---: | --- |
| 검·도·독침·권갑·봉·부채 | 18 | 각 종류 3단계, 지역 가중치 드랍과 현재 무공에 맞춘 보스/정비 무장 |
| 도포·신발·패옥 | 9 | 슬롯별 3단계, 일반 전투 드랍 |
| 지역 특산 장비 | 10 | 지역의 희귀 드랍 및 정비 상인 |
| 지역 재료 | 10 | 전투 종료마다 1~2개, 정비에서 강화/판매 |
| 회복품 | 4 | 체력 35·50·70 회복, 설산은 설삼 50; 대환단은 15·20웨이브 보스 |
| 수련비급 | 1 | 보스마다 경험치 20, 총 80; 판매하지 않음 |
| 보스 고유 물품 | 40 | 해당 지역·단계 보스가 지급, 원문 이름 유지 |

일반 전투에서 회복품과 지역 재료를 보장한다. 세 번째 전투의 장비는 확정이며 다른 일반 전투의 장비 확률은 55%다. 무기·도포·신발·패옥 가중치는 지역마다 다르다. 전반은 입문/정련, 후반은 정련/희귀 중심이며 후반 일반 전투에서 지역 특산품이 섞인다. 보스는 일반 회복·재료와 별도로 현재 무공용 무장·비급·고유 물품을 보장한다. 드랍이 확정된 뒤 재실행이나 추가 tick으로 재추첨하지 않는다.

등급은 일반·정련·희귀·영웅, 품질은 드랍 때의 초기 수치 변동이다. 장비 강화는 12전+일반 재료 2개를 쓰고 효과 +1·품질 +10(최대 120), 장비당 두 번까지다. 고유 보스 재료는 자동 강화 비용으로 소모하지 않는다. 판매는 수납 또는 정리판에 있는 재료만 가능하며 중첩 수량 전체를 판매한다. 무기/방어구 매입·제작·접두 효과는 이번 구현에 없다.

정비 상인의 회복품은 재고 3개(8전, 후반/설산 12전), 현재 무공용 무장은 1개(전반 20전, 후반 32전), 지역 특산 장비는 1개(26전)다. 의원은 12전에 체력 45를 회복한다. 재고·금전·물품 변경은 저장되며 비용 부족·중복 구매·금지 상태의 요청은 전부 변경 없이 실패한다.

## 강호의 마무리

Lv.0 새 무인 → 무공 성장 → 전투/전리품 → 정비 → 네 번째 보스 → 미수납/정리판 확인 → 저장된 완주 결과 → 세가 명부/가방으로 이어진다. 완주 결과는 저장 성공 뒤에만 표시한다. 체력·무공·수납 물품을 유지하고 남은 금전은 세가 자금으로 기록하며, 그때부터 현실 7일 수명이 시작된다. 재실행에서 정산/명부/수명을 중복 적용하지 않는다. 세가 자금은 현재 누적 기록이며 이 버전에는 자금 지출처를 추가하지 않았다.

사망은 이번 무인과 물품·금전 손실을 유지한다. 최근 10개 완주/사망 결과를 보관하고 기록 창에서 최신 결과와 세가 자금을 확인한다. 기존 version 1 저장에 새 필드가 없으면 그대로 읽으며 이전 물품을 새 물품으로 덮어쓰지 않는다. 이전 보스 재료/약은 정체성을 추론해 같은 물품과 중첩할 수 있다.

## 검증 결과

- `npm test`: 12파일, 186개 통과. 10지역×4보스 단계 보상·6종 호환·200시드의 기본/지역 52종 출현·비급 80XP와 Lv.13~16 범위·거래/강화 원자성·고유 재료 보호·중첩·오래된 저장·완주/사망 정산을 검사했다.
- 실제 전투 시뮬레이션은 HP·적·경험치를 수정하지 않고 이동/공격/방어/성장/착용/소비/정비 명령을 사용한다. 시드 123/222/777 모두 완주했고, 각각 Lv.14/14/15, 강화 3/3/4회, 남은 금전 409/398/371전이었다. [실제 기록](verification/gangho-completion-v1/simulation-123.json)을 남겼다. 이는 자동 입력 경로 검증이며 인간의 승률·난이도 검증은 아니다.
- 브라우저 회귀 47항목에서 45개가 먼저 통과했다. 오래된 회전 버튼 이름과 단일 무기 선택 전제는 수정하고 관련 흐름을 재검사했다. 최종 수정 후 관련 10항목 전부 통과했다. 정비 구매/사용, 강화 두 번과 재료 소모, 판매, 장비 교체, 재실행 재고/장비/금전, 완주 저장/명부/수명, 가방/일시정지의 전투 입력 격리를 조작했다.
- 1440×900·1366×768·1093×614에서 정비와 가방 행동이 화면 안에 표시되는지 경계/스크롤 크기를 자동 검사했다. 한국어·영어·일본어·간체·번체의 장터/강화 정보/완주/기록도 1093×614에서 검사하고 캡처했다. 작은 기록 창의 잘림을 발견해 컴포넌트 소유 CSS에서 수정했다.
- 캡처의 실제 시각 검토는 한국어 기록 창, 영어 완주, 작은 장터/가방, 재실행 로비를 대상으로 했다. 자동 경계 검사와 직접 캡처 검토를 구분하며 서비스 수준이나 접근성 인증을 주장하지 않는다. [증거 폴더](verification/gangho-completion-v1/)에 이미지·조작 결과·시뮬레이션을 보관한다.
- TypeScript/Vite 빌드를 확인했고, 5173 개발 서버를 다시 실행해 로비 버튼·그림·오류 오버레이와 런타임 오류를 별도 브라우저에서 확인했다. 실제 사용자 저장은 삭제/변경하지 않았고 모든 테스트 상태는 별도의 검증 브라우저에만 넣었다.

## 남은 조정

핵심 강호 순환은 구현했다. 남은 강호 작업은 인간 플레이로 드랍 빈도·강화/의원 가격·지역별 난이도를 조정하고 개별 물품 그림을 확장하는 것이다. 92개 물품마다 새 그림을 생성한 것은 아니며 현재 종류별 그림을 공유한다. 온라인 레이드·비무, 제작·시장 거래·수명 연장약은 별도 단계다.
