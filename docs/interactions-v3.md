# 로비·가방 조작 개선

2026-09-29. 사용자 요청: 로비 상단 hover 이상 수정, 선택 후 빈 칸 클릭 이동 제거, 드래그와 버튼으로 이동 통일, 실제 브라우저에서 전투와 관리 흐름 검증.

## 수정

- 로비 메뉴와 소리·설정 버튼은 hover/누름에서 위치를 이동시키지 않는다. 현재 메뉴 표시를 유지하고 종이·옥·황동 계열 배경과 경계만 전환한다. 키보드 초점과 움직임 줄이기를 지원한다. 소유 파일은 `src/ui/lobby-controls.css`다.
- 물품 클릭은 선택·정보 확인만 한다. 빈 칸은 초점을 받지 않고 hover 강조나 배치 행동이 없다. 드래그 중에만 수납 가능 위치와 그림 미리보기를 제공한다.
- `수납`은 첫 빈 공간에 자동 배치한다. 검은 `일반 가방으로`/`무장으로` 버튼으로 보관 영역을 바꾼다. 정리판·창고 이동은 버튼과 실제 드래그를 지원한다. 키보드는 Tab과 Enter/Space로 같은 버튼을 실행한다.
- 드래그는 선택 물품과 독립적인 물품·방향·잡은 칸 스냅샷을 사용한다. 최종 놓은 좌표에서 충돌·경계·종류를 검사한다. 실패 사유를 표시하고 다음 드래그에서 오래된 실패 안내를 비운다. 영역 밖에 놓으면 변경 없이 미리보기를 해제한다.
- 가방 안 물품의 R/회전 버튼은 현재 위치에서 즉시 반영한다. 공간이 없으면 사유를 보여주고 원래 방향을 유지한다. 전리품·정리판·창고에서는 수납할 방향을 정한다. 회전된 크기는 그림·정보·툴팁에 일치시킨다.
- 이전 저장에서 가방 안에 중첩 물품이 있을 때 이동이 겹친 복사본을 만들던 오류를 수정했다. 가방 안 중첩 물품은 수량을 보존해 통째로 옮기며, 창고·정리판에서 꺼내는 물품은 기존처럼 하나씩 수납한다. 실제 사용자 저장을 테스트 데이터로 바꾸거나 지우지 않았다.

## 검증

- `npm test`: 70개 통과. 중첩 물품 이동의 수량 보존·중복 방지를 추가 검증하고 기존 전투·저장·다국어 검사를 유지했다.
- 전체 Playwright: **77개 통과, 공개 배포 전용 4개 제외, 실패·불안정 재시도 0개**. [전체 결과](verification/interactions-v3/full-result.json). 전투 타격·회피·반격·Q/E·성장·사망 저장·컨텍스트 복구·다국어·연속 화면 크기 변경을 포함한다.
- 마지막 안내 초기화와 회전 툴팁 수정 후 해당 Playwright **5개 재검증 통과**. [최종 결과](verification/interactions-v3/final-targeted-result.json). 추가 검사에 도포 이름을 잘못 적은 테스트를 실제 콘텐츠 이름으로 바로잡은 뒤 통과했다.
- `npm run build`: 최종 TypeScript 검사와 프로덕션 빌드 통과. [배포 파일 정보](verification/interactions-v3/release.json).

자동 브라우저 검사는 독립 컨텍스트의 실제 마우스 드래그와 키보드 입력을 사용했다. 선택 없이 드래그, 잡은 칸 유지, 정상·충돌·경계·종류 제한, 영역 밖 취소, 회전, 정리판·창고 왕복, 키보드 버튼 이동과 초점 복귀, 재실행 후 수량 보존을 확인했다. 전투에서 공격·이동을 누른 채 가방에 진입하고 닫아도 입력이 남지 않으며, 관리 창 뒤의 Q/E 전환이 실행되지 않는 것을 관찰했다.

자동 검사와 별개로 아래 실제 캡처를 직접 읽어 상단 hover 영역, 가방의 두 격자·정보·보관 영역·버튼 배치, 전투 HUD를 시각 검토했다. 별도 사람이 장시간 플레이한 결과나 접근성 인증을 의미하지 않는다.
