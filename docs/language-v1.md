# 언어 지원 · 2026-09-28

로비 제목을 ‘강호에 나서세요’로, 진행 중 여정은 ‘여정을 이어가세요’로 바꿨다. 설정에서 한국어, English, 日本語, 简体中文, 繁體中文을 선택할 수 있다. 언어를 못 읽는 사용자도 설정을 찾을 수 있도록 언어 선택 레이블에 영어 `Language`를 함께 표시한다. 영어 화면에서는 중복 표시하지 않는다.

## 적용 방식

- `src/platform/i18n.ts`: 브라우저 언어 우선순위, 선택 저장, 화면 갱신과 변수 치환.
- `src/platform/messages.ts`: 한국어 원문을 키로 하는 네 언어 번역. 한 문장에 포함된 변수는 언어별로 순서를 바꿀 수 있다.
- `mugong-language-v1`: `auto` 또는 언어 코드만 저장하는 localStorage 설정. 기존 게임 저장과 UI 표시 설정은 보존한다.
- 브라우저 언어 우선순위에서 지원하는 언어를 고른다. 미지원 언어만 있으면 영어. `zh-Hant`, TW/HK/MO는 번체, 나머지 중국어는 간체.
- 수동 선택이 자동 감지보다 우선한다. 자동 감지 중 브라우저 언어 변경 이벤트와 다른 탭의 언어 설정 변경에도 반영한다.
- 메뉴, 생성·기록·안내 창, 전투 HUD, 성장 카드, 가방·창고, 물품·무공 설명, 상태 문구, 접근성 이름, HTML `lang`, 문서 제목을 번역한다.
- 캐릭터의 사용자 입력 이름은 번역하지 않는다. 게임 규칙·ID·아이템 배치·저장 형식은 바꾸지 않는다. 기본 물품/무공 이름은 표시할 때 번역한다.
- 한국어·영어는 기존 로컬 서체, 일본어·중국어는 운영체제 CJK 서체를 우선한다. 영어 가방 제목과 칸 수는 두 줄로 표시한다.

## 검증

자동 검사: 프로덕션 빌드 성공, 단위 테스트 30개, 로컬 브라우저 테스트 25개 통과. 번역 누락과 변수의 일치, 언어 우선순위·지역 코드·미지원 언어 처리, 수동 선택 우선·새로고침 복원·자동 감지 복귀를 검사했다.

5개 언어 각각 1366×768, 1440×900, 1093×614에서 로비·설정·생성 창의 핵심 행동과 화면 밖/스크롤 넘침을 검사했다. 1093×614의 전투 가방에서 물품 선택·사용 제한·설정 접근도 확인했다. 기존 18개 게임 흐름 검사는 수납·회전·착용·창고 이동·폐기 확인·성장·저장 복원을 포함한다. 모든 게임 검증 데이터는 독립 Playwright 브라우저에만 생성했다.

수동 검토: 실제 Codex 브라우저에서 한국어→영어 즉시 변경, 한국어 자동 감지 복귀와 설정의 초점 유지·레이블 변경을 확인했다. 한국어·영어·일본어 설정 및 영어 가방 캡처를 시각적으로 검토했다. 자동 검사가 놓친 영어 가방 제목/칸 수 겹침을 수정했고 일본어 페이지 화살표의 글꼴 높이 넘침도 수정했다. 전문 번역가의 감수나 접근성 인증을 받은 결과는 아니다.

로컬 화면 증거는 `verification/language-v1/`, Daytona 화면 증거는 `verification/language-v1-daytona/`에 보관한다. 공개 배포에서도 출전→전투→가방→저장복원 및 5개 언어 설정, 수동 선택·감지 복귀, 미지원 언어 처리의 8개 검사가 통과했다. 실제 공개 페이지를 새로고침해 새 제목과 5개 언어 옵션이 나타나는 것도 확인했다. 배포 릴리스는 `/srv/mugong/releases/20260928-language-v1`다.
