# 전장 구역 효과 개편

후속 갱신: [보스 기믹 v1](boss-mechanics-v1.md)에서 냉기 누적/동결·출혈, 정화초 공격 파괴와 국소 정화, 술 투척 착탄의 실제 술 효과를 추가했다. 아래는 효과 v2 당시 값이며 변경된 행동은 후속 문서를 우선한다.

2026-10-02. 사용자 요청에 따라 보스 먼지와 공통 함정 피해를 실제 효과로 분리했다. 이전 조사 문서 `field-effects-audit-20261002.md`는 **변경 전 기록**이며, 현재 수치는 이 문서와 실행 코드가 기준이다.

## 현재 규칙

피해 수치는 방어·장비·무적 적용 전이다. 피해 후 공통 무적 시간이 있으므로 겹친 구역의 모든 피해가 동시에 합산되는 것은 아니다. 동일한 중독/화상 접촉은 지속 시간을 갱신하며 중첩 수를 쌓지 않는다.

| 효과 | 현재 실행 규칙 | 벗어난 뒤 |
| --- | --- | --- |
| 보스 모래 먼지 | 이동 속도 55%. 직접 피해 없음 | 즉시 이동 방해 해제 |
| 보스 연막 | 기본 공격의 재사용 시간 회복 속도 65% | 즉시 회복. 입력을 지연시키거나 무작위로 빗나가게 하지 않음 |
| 보스 눈보라 | 냉기 4 피해/1초, 구역 이동 배율 70%, 적중 시 짧은 둔화 | 적중 둔화 0.6초 이내 해제 |
| 독 웅덩이 | 4 피해/0.8초, 적중 시 중독 2.4초·짧은 둔화 | 중독 3 피해/0.8초가 남은 시간 동안 지속 |
| 독뢰 | 접촉 시 12 피해와 중독, 한 번 폭발 후 제거 | 중독 잔류. 회피한 폭발은 중독을 남기지 않음 |
| 화염 | 9 피해/0.65초, 적중 시 화상 1.6초 | 화상 4 피해/0.8초가 남은 시간 동안 지속 |
| 술 웅덩이 | 직접 피해 없음. 이동 둔화 2초 갱신 + 구역 안 공격 재사용 회복 65% | 이동 둔화만 잠시 남음. 방향 반전 없음 |
| 가시/기관 지뢰 | 접촉 시 16 피해와 0.8초 둔화, 한 번 작동 후 제거 | 추가 반복 폭발 없음. 투척 함정의 최초 착탄 피해는 별도 |
| 위험 진법 | 7 피해/1.2초, 적중 시 0.8초 둔화 | 영역에서 나가면 주기 피해 중단 |
| 혈지대 | 6 피해/0.9초. 소유자가 살아 있으면 실제 손실의 60%만큼 회복 | 독 상태 없음. 환경 착탄 혈지대도 동일 |
| 봉인 | 8 피해/1초, 실제 적중 시 회복량 감소 5초 | 회복 감소 잔류 |
| 보스 안전지대 | 영역 밖 8 피해/1초, 안에서는 이 피해 없음 | 체력 회복 구역은 아님 |

보스가 먼지·연막·눈보라 구역 **안에 있을 때만** 짧은 은폐 상태를 갱신한다. 준비 시간이나 구역 밖에서는 설치만으로 은폐하지 않는다. 서역 전체 모래바람과 죽림 전체 연막은 기존 전장 연출로 남으며 위의 작은 보스 구역과 구분한다.

설산의 기본 추위·냉기 구역·피격 둔화 등 서로 다른 이동 배율은 기존 계산 구조에서 중첩될 수 있다. 표는 각 효과의 독립 배율이고 최종 이동 속도를 보장하는 수치가 아니다. 사람의 반복 플레이를 통한 수치 조정은 남아 있다.

정화초 접촉은 독 구역·해당 보스 독뢰·이동 둔화·회복 감소와 새 중독/화상을 제거한다. 체력을 생성하지 않는다. 중독/화상은 전투 진행 시간만 사용하므로 가방·성장 선택·일시 정지·전투 종료에서 진행하지 않는다. 새 웨이브에서 초기화하고 저장 후 이어갈 수 있다. 새 필드가 없는 과거 저장은 그대로 허용한다.

## 구현 위치

- `src/domain/field-effects.ts`: 공통 접촉 프로필, 중독·화상 시간과 주기 피해.
- `src/domain/boss-encounters.ts`: 설치물 의미 해석, 모래/연막 배율, 일회성 함정, 정화·은폐·문구.
- `src/domain/environment.ts`: 환경·착탄 구역에도 같은 프로필 적용, 혈지대 실제 손실 기반 흡혈.
- `src/domain/game.ts`: 전투 시간의 상태 갱신과 공격 회복 배율, 혈탄 소유자 보존.
- `src/domain/boss-attacks.ts`, `region-enemies.ts`: 혈교 투척의 독 재사용을 혈지대로 변경.
- `src/domain/model.ts`, `src/platform/save-validation.ts`: 선택적 상태 시간과 혈지대 소유자 검증.
- `src/game/zone-art.ts`: 시뮬레이션과 동일한 의미 해석으로 기존 구역 그림 선택.
- `src/platform/encounter-messages.ts`: 실제 상태·이탈 문구, 한국어와 네 번역.

공격 예고 원·부채꼴·조준 선·테두리는 다시 추가하지 않았다. 기존 래스터 구역 그림을 사용하며 새 이미지 생성 작업은 하지 않았다.

## 검증

최종 결과: `npm test` 25파일·419개 통과, TypeScript/Vite 빌드 통과. 보스·신규 구역·창고·웨이브 브라우저 최종 회귀 48개 모두 통과. 별도 적·가방·성장 검사도 수행했다. 중간 창고 검사 하나는 소스 갱신 중 페이지 재로드로 중단됐으나 소스 변경을 멈춘 최종 실행에서 통과했다.

`tests/field-effects.test.ts`는 발동 전/후·이탈, 독뢰 일회성, 술과 화염 차이, 환경 함정, 회피/피해 차단, 혈지대 흡혈, 정화, 구역 소유자 사망, 과거 저장/잘못된 저장, 결정적인 저장 재개를 검사한다.

`tests/e2e/field-effects.spec.ts`는 독립 Playwright 컨텍스트에서 실제 Phaser 그림·HUD 문구·이동 거리·공격 회복·이탈을 확인하고 `docs/verification/field-effects-v2/`에 캡처와 수치를 저장한다. 시각 검토는 모래와 화염 캡처를 열어 구역·캐릭터·HUD가 함께 표시되고 기하학적 테두리가 없는 것을 확인했다. 사람이 모든 보스를 반복 플레이해 난이도를 검증했다는 뜻은 아니다.
