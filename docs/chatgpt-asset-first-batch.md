# ChatGPT에 보낼 첫 에셋 요청문

이전 장문 요청의 기록이다. 사용자는 카툰풍과 짧은 프롬프트를 승인했으므로 현재 제작은 [v2 짧은 요청문](chatgpt-asset-first-batch-v2.md)을 사용한다. 아래 내용을 새 생성 요청에 그대로 보내지 않는다.

작성일: 2026-09-27. 사용자가 영상 생성도 가능한 환경이라고 알려준 조건으로 작성했다. 도구의 특정 해상도·투명 영상·FPS 지원을 전제로 하지 않는다.

우선 **기준 무인 이미지 한 장과 베기 영상 한 개**부터 받는다. 외형을 정한 뒤 같은 원화를 계속 첨부한다. 걷기는 베기를 확인한 뒤 진행한다. 아래 코드 블록은 각각 그대로 복사할 수 있는 완결된 요청문이다.

## 1. 기준 무인 이미지

첨부: 사용자가 처음 제공한 전투 참고 이미지. 지금 검사 외형을 이어가고 싶으면 `assets/hero/swordsman-reference-v1.png`도 외형 참고로 첨부한다. 둘의 역할을 아래 요청대로 구분한다.

```text
무협 탑뷰 수동 액션 게임에 사용할 검사 캐릭터 기준 이미지를 만들어줘.

첨부한 전투 화면은 회화적인 분위기와 카메라 시점 참고야. 화면의 글자·UI·수치·배경 구성을 복사하지 말아줘. 별도의 검사 이미지를 첨부했다면 얼굴·머리·복장 참고로만 사용해줘.

한 명의 성인 무인만, 머리부터 양쪽 발과 검 끝까지 온전히 보이는 전신으로 그려줘. 자연스러운 인체 비율과 날렵한 체격, 묶은 검은 장발, 낡은 흰 도포와 짙은 속옷·바지, 차분한 붉은 허리띠, 실용적인 손목 보호대와 천 신발. 옷과 장식은 움직일 수 있을 정도로 간결하게.

카메라는 약 40도 내려다보는 비스듬한 탑뷰로 고정해줘. 머리 윗면과 어깨가 보이고 다리는 시점에 맞게 짧아 보이도록 해줘. 인물은 화면 오른쪽 아래, 남동쪽을 바라봐. 정면 인물화나 눈높이 카메라로 바꾸지 말아줘.

양발로 균형 잡힌 준비 자세. 한 손에 작고 실용적인 직검을 쥐고 다른 손은 균형을 잡는 자세. 검은 좁은 강철 칼날, 작은 오래된 황동 가드와 짙은 손잡이. 검과 손이 확실히 닿아 있어야 하고, 주손은 이후 모든 동작에서도 같은 해부학적 손으로 유지할 기준이야.

절제된 먹선과 붓질, 의복과 금속의 회화적인 재질. 부드러운 왼쪽 위의 빛. 작은 게임 크기에서도 실루엣이 잘 읽히도록 해줘.

실제 투명 배경으로, 넉넉한 여백을 둔 원본 이미지가 필요해. 바닥·그림자·배경 후광·검기·잔상·글자·로고·격자·스프라이트 시트는 넣지 말아줘. 여러 자세를 한 장에 넣지 말고 기준 자세 한 장만 만들어줘. 큰 머리의 귀여운 캐릭터, 과장된 무기와 갑옷은 제외해줘.
```

파일명 예시: `hero_master_se_v1.png`. 원본 PNG를 받는다. 아직 검을 분리하거나 캐릭터를 여러 부위로 나누지 않는다.

## 2. 한 번 베는 영상

첨부: 위에서 고른 **기준 무인 이미지 한 장**. 여러 후보를 함께 첨부하지 않는다.

```text
첨부한 무인이 남동쪽으로 직검을 한 번 베고 원래 준비 자세로 돌아오는 짧은 동작 영상을 만들어줘. 게임 애니메이션 동작 검토용이야.

얼굴·체격·머리·복장·주손·검 길이·빛 방향을 첨부 이미지와 동일하게 유지해줘. 카메라는 첨부와 같은 비스듬한 탑뷰, 위치와 각도와 화면 크기를 끝까지 고정해줘. 인물과 검 끝이 화면 밖으로 나가면 안 돼. 확대·줌·카메라 회전·장면 전환은 없어야 해.

동작은 반드시 한 번의 공격이야:
1. 잠깐 균형 잡힌 준비 자세를 보여줘.
2. 무게를 뒷다리에 싣고 허리와 어깨를 감으며 검을 주손 쪽 어깨 뒤로 당겨. 팔만 들고 몸통은 그대로 두는 자세는 피해야 해.
3. 뒷발로 밀고 앞다리로 무게를 받으며, 허리 → 어깨 → 검을 쥔 팔 순으로 힘이 이어져 남동쪽 앞 공간을 빠르게 사선으로 베어.
4. 칼날이 적중 지점을 지난 뒤에도 허리와 어깨가 이어서 회전하고 검이 분명하게 끝까지 지나가야 해. 머리와 옷자락은 몸의 회전보다 조금 늦게 따라와.
5. 균형을 회복하며 천천히 원래 준비 자세로 돌아와. 검은 처음부터 끝까지 같은 손에 있어야 해.

준비는 짧지만 읽히고, 실제 베는 순간은 훨씬 빠르게, 마무리와 복귀는 구분되게 해줘. 전 구간이 같은 속도인 느린 검 흔들기, 공격 반복, 검을 쥔 손 바뀜, 검 길이 변화, 발 떠 있음, 접지한 발의 미끄러짐, 몸과 옷의 변형은 피해야 해.

처음과 끝에 준비 자세가 유지되는 짧은 여유를 둬. 가능하면 약 2~3초 안에 한 동작을 보여줘. 길이 제한이 있다면 한 번 공격한 뒤 남은 시간은 준비 자세로 유지해줘. 느린 영상이면 내가 나중에 속도를 조정할 것이므로 검을 휘두르는 중간 자세가 분명해야 해.

투명 영상 출력이 가능하면 투명 배경, 불가능하면 질감과 그림자 없는 완전히 균일한 단색 배경을 써줘. 환경·적·피격 효과·검기·잔상·입자·모션 블러·글자·UI를 넣지 말아줘. 검과 손, 허리와 발의 움직임 자체를 볼 수 있어야 해.
```

파일명 예시: `hero_slash_se_reference_v1.mp4` 또는 도구가 제공한 원본 영상 형식. 원본 파일과 가능하면 해상도·FPS를 받는다. 이 영상은 먼저 동작을 검수할 자료다. 투명 프레임 추출 가능 여부와 별도 검 연결 방식은 파일을 본 뒤 결정한다.

## 3. 걷기 루프 영상

베기와 외형·시점이 맞은 뒤 요청한다. 첨부는 같은 기준 무인 이미지다.

```text
첨부한 무인의 남동쪽 걷기 동작을 반복 가능한 짧은 영상으로 만들어줘. 게임에서 위치 이동과 합성할 동작 자료이므로 인물의 중심은 화면 가운데 유지하고, 캐릭터가 화면 밖으로 걸어 나가지 않도록 해줘.

첨부와 같은 얼굴·체격·복장·머리·주손·검 길이·빛 방향을 유지해줘. 비스듬한 탑뷰 카메라는 고정이고, 인물은 계속 남동쪽을 바라봐.

오른발과 왼발이 확실히 번갈아 나가고 무릎과 발목이 자연스럽게 움직여야 해. 두 발이 같은 자세로 붙어 있거나 허공에 뜨지 않게 해줘. 몸통은 안정적으로, 어깨와 골반은 약하게 반대로 회전하고 빈 팔은 걸음과 반대로 흔들려. 검은 같은 손으로 몸 옆에 안정적으로 들고, 머리와 옷자락은 걸음에 약간 늦게 따라오도록 해줘.

달리기·공격·검 휘두르기는 하지 말고 보통 속도의 걷기만 보여줘. 시작과 끝의 자세가 자연스럽게 이어지는 루프가 필요해. 너무 큰 상하 흔들림, 얼굴과 의복의 변형, 손 바뀜, 검 길이 변화, 발이 끊기거나 사라지는 현상은 피해야 해.

머리·양쪽 발·검 끝이 전부 보이도록 여백을 유지해줘. 가능하면 약 2~3초 안에 완전한 걸음 주기를 보여줘. 투명 영상이 가능하면 투명 배경, 불가능하면 질감과 그림자 없는 균일한 단색 배경으로 만들어줘. 바닥·배경·그림자·글자·효과·모션 블러는 넣지 말아줘.
```

파일명 예시: `hero_walk_se_reference_v1.mp4`.

## 가져온 뒤 진행

원본 기준 PNG와 원본 베기 영상부터 확인한다. 동작이 맞으면 걷기·대기·피격·사망과 방향을 확장한다. 최종 게임에 사용할 캐릭터·무기 분리, 투명 배경·프레임 추출·기준점·재생 타이밍은 실제 결과를 보고 정한다. 단일 영상만으로 무기 교체와 전체 방향 애니메이션이 완료되었다고 보지 않는다.

적·배경·아이템·효과·UI 장식을 포함한 전체 공통 기준과 후속 프롬프트는 [전체 프롬프트 팩](external-asset-prompt-pack-v1.md)에 있다.
