# 무공 디자인 시스템

## Overview

한 명의 무인이 강호를 거쳐 세가에 이름을 남기는 카툰 무협 게임. 로비와 관리 창은 옅은 한지, 먹빛 글자, 옥색 행동 버튼, 황동 구획선, 작은 주홍 인장을 공유한다. 전투는 그림이 우선이며 HUD는 읽기에 필요한 면적만 차지한다. 화면별로 새로운 시각 언어를 만들지 않는다.

## Colors

- `canvas`와 `paper`는 넓은 배경과 카드 면이다. 같은 밝기의 표면을 반복하지 말고 한 단계씩 구분한다.
- `ink`는 제목, `ink-secondary`는 설명, `ink-muted`는 보조 정보다. 옅은 종이 위에서 흐릿한 베이지 글씨를 피한다.
- `jade`는 해당 화면의 가장 중요한 행동에 쓴다. 호버는 `jade-hover`, 선택 배경은 `jade-light`다.
- `brass`는 숫자·장식·구획에, `cinnabar`는 인장·위험 신호에 사용한다. 체력과 경험치는 고정된 의미색이다.
- 전투 HUD는 `combat-surface` 위에 `combat-text`를 사용한다. 움직이는 숲 배경 위에 종이색 반투명 패널을 올리지 않는다. 고대비 설정은 표면을 더 어둡게 하고 황동 경계선을 강화한다.
- 정보 전달은 색만으로 하지 않는다. 텍스트와 모양·상태를 함께 표시한다.

## Typography

- 제목과 캐릭터 이름은 로컬 `Gowun Batang` 400/700, 버튼·본문·수치·설명은 로컬 `Gowun Dodum` 400을 쓴다. 두 서체는 OFL 라이선스로 `public/fonts`에 포함한다.
- 큰 제목 72px, 창 제목 36px, 소제목 27px, 본문 21px, 짧은 설명 18px, 공간이 제한된 레이블 16.5px가 기본이다. 화면별 기존 변형에도 150% 글자 크기를 적용한다.
- 숫자는 같은 맥락에서 같은 자리·단위로 표시한다. 체력은 현재/최대, 웨이브는 현재/20, 남은 수명은 일·시간이다.
- 장식적인 한자는 제목·인장·배경에 한정하고 조작 설명에는 사용하지 않는다.

## Layout

- 4px 기본 간격을 8·12·16·24·32·48px로 늘린다. 관련 정보는 8~12px, 그룹 사이는 16~24px 이상 둔다.
- 데스크톱 로비는 출전/초상/명부의 3열이다. 폭이 좁아지면 명부를 아래로 내려가며 버튼을 세로로 배치한다. 노트북 높이가 낮으면 장식과 여백을 먼저 줄인다.
- 가방은 무장 4×7, 일반 10×8의 공간 규칙을 화면에서 명확히 유지한다. 칸 크기는 가용 공간에 맞추고 이름·효과·행동은 선택 물품 정보에 표시한다.
- 전투 장면의 중앙은 이동과 적 예고를 위한 공간으로 비워 둔다. HUD는 가장자리에서 체력·무공·웨이브를 우선 보여준다.
- 성장 선택은 세 장을 같은 폭으로 정렬하고, 카드별 무공명·성장 단계·효과·방어 동작·선택 행동 순으로 읽히게 한다. 가방은 전체 화면 작업 공간이다. 큰 화면에서는 무인·무장 4×7·일반 10×8·물품 정보를 함께 보여주고, 좁은 화면에서도 두 가방과 전리품은 함께 두고 선택 물품 정보는 아래로 옮긴다. 무인 세부 정보만 선택 물품 정보와 전환한다.

## Elevation & Depth

두꺼운 그림자보다 종이의 명도 차이와 1px 황동 선으로 계층을 만든다. 로비 배경의 숲 그림은 약하게 깔아 글자 읽기를 방해하지 않는다. 현재 선택과 포커스는 그림자만으로 표현하지 말고 선·배경·외곽선을 쓴다.

## Shapes

패널 14~20px, 버튼 10~14px, 아이템 7px의 부드러운 모서리를 쓴다. 체력·경험치 게이지와 소리·도움말 같은 원형 버튼만 둥글게 한다. UI 선과 아이콘은 얇고 일정하게 유지한다.

## Components

- **주요 버튼:** 옥색 바탕, 밝은 글자, 기본 66px 이상 높이. 가방 행동은 54px, 닫기는 60px 등 컴포넌트별 150% 기준을 적용한다. 한 화면에서 명확한 주 행동 하나를 둔다. 비활성 사유를 문구나 도움말로 알려준다.
- **보조 버튼:** 밝은 종이 바탕과 황동 선. 선택·호버·키보드 포커스가 구별되어야 한다.
- **패널:** 제목, 핵심 수치, 설명, 행동 순서다. 의미 없는 장식 문구보다 웨이브·체력·수명 등의 실제 상태를 먼저 배치한다.
- **창:** 배경보다 밝게, 닫기 버튼을 오른쪽 상단에 유지한다. 열 때 초점을 내부로 옮기고 닫을 때 연 버튼으로 돌린다. Esc 닫기와 Tab 순환을 지원한다.
- **가방 칸:** 비어 있음·수납 가능·수납 불가·선택을 색과 테두리로 구분한다. 물품 이름은 칸이 좁으면 자세히 보기에도 표시한다.
- **HUD:** 체력은 붉은 계열, 경험치는 청록, 선택 무공은 짙은 외곽선이다. 전투 중 가방은 정보 확인만 가능하다고 명시한다.
- **상태 문구:** 저장 중·완료·실패를 실제 저장 상태와 연결한다.
- **성장 카드:** 강호 전투 중 카드가 나타나면 1초 동안 선택을 잠그고 남은 시간을 보여준다. 공격 입력이 이어져도 선택되지 않아야 한다. 연속 성장 선택은 매 카드마다 새로 잠근다.
- **화면 설정:** 로비와 일시 정지에서 전투 HUD 큰 글씨와 높은 대비를 바꿀 수 있다. 설정은 브라우저에 저장한다. 시스템의 움직임 줄이기 설정에서는 비필수 UI 애니메이션을 끈다.
- **움직임:** 버튼 입력 반응은 110~150ms, 카드 입장은 200~350ms 범위에서 사용한다. 읽기와 전투 입력을 늦추는 장식 애니메이션은 넣지 않는다.

## Do's and Don'ts

- 신규 화면은 이 문서의 글자·색·간격 토큰을 먼저 사용한다.
- 텍스트를 그림에 얹을 때 대비를 확인한다. 배경 일러스트를 진하게 만드는 대신 읽기 층을 확보한다.
- 작은 화면에서 가로 스크롤을 만들지 않는다. 데스크톱 게임의 터치 조작이 구현된 것으로 오해시키지 않는다.
- 레이드·비무·시장 등 아직 없는 기능을 누를 수 있는 메뉴로 표시하지 않는다.
- 사용자에게 실재하지 않는 캐릭터별 초상·실시간 기록·온라인 저장을 암시하지 않는다.

형식 참고: [Google Labs DESIGN.md 명세](docs/reference/design-md-spec.md) (원본은 Apache-2.0, [라이선스](docs/reference/design-md-LICENSE.txt)). 서체: [Gowun Batang](https://github.com/google/fonts/tree/main/ofl/gowunbatang), [Gowun Dodum](https://github.com/google/fonts/tree/main/ofl/gowundodum), 포함된 각 OFL 라이선스를 확인한다.

전체 화면 적용과 검토 이미지는 [서비스 UI 고도화](docs/service-ui-v1.md)에 기록한다.

## 전체 화면과 부드러운 구성

로비와 전투는 브라우저 가용 화면을 채운다. 전투의 플레이 가능 영역은 비율을 유지해 잘리지 않는다. 가방·창고는 `100dvh` 작업 공간이며 헤더, 두 적응형 정사각 격자와 선택 정보, 함께 보이는 보관 영역, 상태 바 순서로 배치한다. 칸 크기는 가용 높이와 폭에서 계산하며 화면 전체에 CSS 배율 축소를 사용하지 않는다. 많은 물품과 명부는 페이지 버튼을 사용한다. 물품을 선택하면 정보와 행동이 같은 화면에서 바뀐다. 화면 설정에서 브라우저가 지원하면 네이티브 전체 화면도 사용할 수 있다.

기본 조작 반응은 180ms easing으로 통일한다. 넓은 옅은 배경, 완만한 모서리와 가벼운 그림자로 부드러운 느낌을 만든다. 초점과 선택 경계는 명확하게 남긴다.

## 실제 그림 그래픽 · 2026-09-28

물품·무공·메뉴 아이콘은 `public/art/ui/`의 PNG 그림 에셋을 사용한다. 한지·옥·천·가죽 표면을 로비·HUD·가방·창고·선택 카드·버튼에 적용한다. 가방은 천 수납 공간으로 표현하며 정사각형 칸은 배치 판단을 위한 안내선이다. 전투 효과는 그린 검기·타격·방어·광역 PNG 스프라이트로 표시한다. 아이콘을 단순 선 그림이나 유니코드 문양으로 대체하지 않는다. 생성 출처·프롬프트와 적용 방식은 [그림 에셋 문서](docs/graphic-assets-v1.md)에 둔다.

## 언어

한국어·영어·일본어·중국어 간체·번체를 지원한다. 한국어는 고운 서체를 유지하고 일본어·중국어는 운영체제의 해당 언어 서체를 우선 사용한다. 텍스트는 그림에 굽지 않는다. 영어처럼 길어지는 이름은 줄바꿈과 영역 배치로 처리한다. 가방 영역 이름과 칸 수는 영역 폭에 맞춰 줄바꿈하며 페이지 화살표는 언어별 글꼴 높이에 영향을 받지 않게 한다. 로비 제목은 ‘강호에 나서세요’, 이어하기 제목은 ‘여정을 이어가세요’다.

## 150% 가독성 기준 · 2026-09-29

기존 CSS의 글자 크기를 1.5배로 올렸다. 기본 본문 14→21px, 보조 글자 12→18px, 창 제목 24→36px를 기준으로 쓴다. 언어별·좁은 화면의 글자 토큰에도 동일한 비율을 적용한다. 메뉴·행동의 그림 아이콘은 24→36px, 출전 버튼은 76→114px, 기본 행동 버튼은 44→66px, 가방 물품 행동은 36→54px 높이다. 닫기·탭·HUD는 해당 컴포넌트의 기존 크기에 맞춰 큰 조작 영역을 확보한다.

`src/readability.css`는 큰 컴포넌트가 들어갈 공간을 만든다. 로비는 큰 출전 행동과 명부를 우선 배치한다. 가방은 두 격자·선택 물품 정보·전리품(로비에서는 창고)·정리판을 한 화면에 함께 표시한다. 가방의 4×7/10×8 규칙은 그대로이며 사용 칸 수·분모·남은 칸과 사용량 막대를 표시한다. 정사각 격자와 세계 카메라를 일괄 확대하지 않는다. 무공 성장 카드는 그림·이름을 같은 줄에 두고 플레이 특성을 짧게 표시한다. 전체 설명은 카드 도움말과 접근성 설명에 유지한다. 좁은 화면은 후보별 페이지로 전환한다.

검증과 화면은 [UI 확대와 가방 개선](docs/readability-bag-v2.md)에 기록한다.

## 텍스트와 로딩 · 2026-09-29

150% 글자 크기를 유지하며 제목·이름의 줄바꿈, 본문 대비, 같은 폭 숫자를 적용한다. 실제 화면은 무손실 WebP 그림을 사용하고 원본 PNG를 보존한다. 시작과 전투 로딩은 한지 표면·큰 제목·실제 준비 개수·복구 행동을 사용한다. 폰트는 화면 진입을 막지 않는다. 적용·검증은 [텍스트와 로딩 개선](docs/text-loading-v3.md)에 기록한다.

## 블록 배치와 간격 · 2026-09-29

`src/layout.css`의 4·8·12·16·24·32·48px 간격 토큰을 공유한다. 화면 여백·패널 안쪽·정보 묶음·조작 사이를 구분한다. 제목과 본문 시작선, 로비 메뉴·작업 영역·하단 관리의 시작선을 맞춘다. 설정과 안내는 데스크톱 두 열, 좁은 화면 한 열이다. 성장 선택은 후보 수에 맞는 같은 폭 열과 같은 행동 줄을 쓴다. 낮은 로비에서는 개별 무공 설명을 가방으로 옮기고 체력·수명·페이지·가방 행동을 유지한다. [배치 점검과 검증](docs/layout-spacing-v3.md)을 따른다.


## 한눈에 보는 가방 · 2026-09-29

사용자의 최신 요구에 따라 전리품을 별도 전체 화면 탭으로 나누던 방식을 폐기한다. 무장 4×7·일반 10×8·선택 물품·전리품/창고·정리판을 함께 표시한다. 부족한 공간은 그림과 여백, 반복 설명부터 줄인다. 작은 가방 칸에 이름을 억지로 넣지 않고 선택 정보에 표시한다. 150% 수치는 화면 전체를 지배하는 강제 배율이 아니라 가독성 기준으로 사용하며 좁은 화면에서는 구획과 조작을 함께 볼 수 있게 조정한다.

전투 효과는 `effects-v2.webp`의 얇은 검흔·작은 타격 조각·짧은 방어 표시·먼지로 구성한다. 금빛 폭발·용 오라·불꽃 문양은 사용하지 않는다. 공격 판정과 적 공격 예고는 유지한다. 구현과 실제 검증은 [한눈에 보는 UI](docs/glance-ui-v2.md)에 기록한다.


## 이미지와 실제 구획의 일치

재질 이미지에 패널 테두리·모서리 장식·칸 경계를 굽지 않는다. `materials-v2.webp`는 재질만 제공한다. 수납 칸은 패딩·간격 없이 같은 크기의 정사각형으로 배치하고 실제 칸의 경계에만 선을 표시한다. 물품 선택 테두리와 배치 미리보기는 실제 점유 영역을 따른다. 전체 화면 배경 그림을 늘려 내부 선을 구획처럼 쓰지 않는다. 물품 그림은 점유 박스 중앙에 비율을 유지해 놓고 이웃 아이콘이 노출되지 않게 시트 구역을 자른다. 자동 좌표 검사 외에 실행 화면에서 이미지의 테두리·재질 대비·중심을 직접 확인한다.

전투 HUD는 초상 상태판·종이 리본·펼친 부채·옥 장식 게이지의 별도 투명 래스터를 사용한다. 장식과 내용·클릭 영역을 분리하고, 먹선이 없는 실제 그림 안쪽에 텍스트를 배치한다. v2의 반복 사각 프레임 방식을 교체했다. 상단 상태는 작게, 하단은 부채꼴 무공·궁극기·방어 재사용의 세 영역으로 구성한다. 전투 가림을 줄이는 크기는 일괄 150% 확대보다 우선한다. [전투 HUD 기준과 검증](docs/combat-hud-v3.md)을 따른다.

## 타격과 위험 표시

검흔·접촉 표시·소리는 실제 판정 시점에 맞춘다. 반동으로 게임 전체나 입력을 멈추지 않는다. 적 예고의 범위와 패턴은 판정과 같은 데이터에서 읽고, 범위는 바닥에, 공격 시간은 적 그림 위에 표시한다. 내 피해·반격·방어·회복은 결과가 구별되어야 한다. 빠른 점멸·큰 폭발을 피하며 실행 중 움직임 줄이기 변경도 반영한다. [전투 연출과 검증](docs/combat-feel-v1.md)을 따른다.
