# 무공 UI·UX 기준

전체 구현 검토와 저장·중첩 창 입력 수정: [2026-09-29 검토 기록](docs/audit-v1.md). 대화상자는 최상위 창만 입력 대상이며 배경을 격리한다. 폐기 확인·성장 창 동안 가방 회전 단축키를 처리하지 않는다. 만체력에서는 약 사용을 비활성화하고 사유를 표시한다.

시각 토큰과 서체는 [DESIGN.md](DESIGN.md)에 둔다. 이 문서는 화면의 정보 순서, 문구, 조작 및 상태 표현을 정한다.

## 화면별 목적

전투 HUD의 최신 구조는 [무협 HUD](docs/combat-hud-v3.md)를 따른다. 왼쪽 아래의 펼친 부채 안에서 Q/E와 클릭으로 무공을 전환하고, 가운데 아래에 궁극기, 오른쪽 아래에 실제 방어 재사용을 표시한다. 상단은 간결한 상태와 가방/일시 정지를 제공한다. 텍스트는 그림의 먹선과 장식이 없는 면에 배치하고, 그림의 경계와 실제 클릭 영역을 함께 확인한다.

타격감과 가독성은 [전투 연출](docs/combat-feel-v1.md)을 따른다. 공격 준비와 접촉, 적의 공격 방향과 남은 시간, 내 피해와 실제 방어 성공을 구별한다. 회피는 행동 표시이며 공격 회피 성공을 추정하지 않는다. 빠른 클릭은 다음 전투 프레임까지 유지하고 관리 창에서는 비운다. 연출 때문에 이동·방어 입력을 늦추거나 판정 범위를 바꾸지 않는다.

| 화면          | 가장 먼저 알아야 할 것                 | 주 행동                  | 세부 정보의 위치                                     |
| ------------- | -------------------------------------- | ------------------------ | ---------------------------------------------------- |
| 첫 로비       | 새 무인은 Lv.0부터 20웨이브를 완주한다 | 새 무인으로 출전         | 이름·장비 반입 규칙은 생성 창, 조작은 강호 입문 안내 |
| 이어하기 로비 | 무인 이름, 현재 웨이브·레벨·체력       | 강호 이어하기            | 진행 중 가방은 강호 화면                             |
| 귀환 로비     | 명부의 무인, 남은 체력·수명·무공       | 무인 선택 또는 가방 열기 | 물품 배치는 가방과 창고                              |
| 전투          | 적, 내 체력·현재 무공, 다음 행동       | 이동·공격                | 상세 무공 설명은 성장 카드와 가방                    |
| 전리품·가방   | 남은 공간과 수납 결과                  | 줍기·배치·진행           | 폐기 위험은 닫을 때 확인                             |
| 성장 선택     | 세 무공의 차이와 현재 선택 가능 시점   | 한 장 선택               | 카드 세부 수치와 설명                                |

## 첫 로비의 정보 위계

1. 제목과 `새 무인으로 출전` 버튼이 첫 시선에 들어온다. `Lv.0`과 `20웨이브`는 한 번만 보여준다.
2. 명부가 비어 있으면 등록 조건을 한 문장으로 알려준다. 명부에 무인이 있으면 상태와 가능한 행동을 보여준다.
3. 창고·기록·안내는 짧은 행동 이름으로 노출한다. 자세한 수치와 규칙은 해당 화면에서 확인한다.
4. 저장 상태는 짧게 표현한다. 오류가 있으면 성공 상태와 구분하여 회복 행동을 안내한다.

같은 규칙을 제목, 소개문, 버튼 설명, 카드, 하단 링크에 되풀이하지 않는다. 한 요소가 이미 설명하는 정보라면 옆의 문구를 줄인다. 분위기는 초상·색·여백·서체로 전달하고, 장식 문장 때문에 실제 행동이 밀리지 않게 한다.

## 문구와 상태

- 버튼은 결과를 말한다: `새 무인으로 출전`, `강호 이어하기`, `창고로`, `선택하기`.
- 빈 상태는 무슨 일이 일어나면 채워지는지 한 문장으로 설명한다. 예: `20웨이브를 완주하면 이곳에 등록됩니다.`
- 상태 문구는 상황에 따라 바뀐다. 첫 로비에 귀환 무인의 수명 규칙을 상시 표시하지 않는다.
- 동작을 설명하는 본문은 필요할 때 열 수 있는 안내·모달에 둔다. 위험한 결과나 되돌릴 수 없는 선택은 결정 직전에 밝힌다.
- 숫자·단위는 짝지어 표현한다. 진행 상태에는 `7 / 20 웨이브`처럼 분모를 함께 보인다.
- 아이콘 버튼은 보이는 텍스트가 없어도 한국어 접근성 이름을 제공한다. 비활성 버튼은 가능한 조건을 `title`이나 인접한 안내에서 확인할 수 있어야 한다.
- 물품을 선택했을 때 해당 물품에 실제로 가능한 행동을 우선 보여준다. 사용·착용·창고 이동 등 관련 없는 버튼을 빈 공간 채우기로 나열하지 않는다.

## 입력과 반응

- 공격으로 레벨업한 직후 성장 카드는 **1초** 잠근다. 잠금 중 버튼은 비활성화하고 남은 시간과 막대를 표시한다. 창 전체가 아닌 선택지만 막고, 카드가 풀릴 때까지 공격 입력이 선택으로 이어지지 않게 한다.
- 대화상자를 열면 초점을 안으로 옮기고 Tab 이동을 그 안에 둔다. 닫으면 원래 작업 흐름으로 돌아간다.
- 클릭 가능한 영역과 보이는 영역을 일치시킨다. 키보드 초점은 항상 보이게 한다. 작은 아이콘만 있는 버튼은 충분한 터치 영역을 제공한다.
- 로딩·저장·실패 상태를 색만으로 구분하지 않는다. 짧은 문구를 함께 사용한다.
- 움직임을 줄이도록 설정한 환경에서는 비필수 애니메이션을 줄인다.
- 화면 설정의 큰 HUD 글씨와 고대비 선택은 로비와 일시 정지에서 접근할 수 있고, 브라우저를 다시 열어도 유지된다.

## 적용 전 확인

새 화면이나 문구를 추가할 때 첫 3초 안에 주 행동을 찾을 수 있는지, 같은 설명이 여러 곳에 있는지, 빈·진행 중·오류 상태에서 다음 행동이 있는지 확인한다. 데스크톱과 좁은 화면에서 글자 잘림, 버튼 크기, 초점 이동을 점검한다.

참고: [Vercel Labs Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/README.md)의 상호작용·콘텐츠·접근성 원칙을 이 게임에 맞춰 선별했다. 원문은 [docs/reference/web-interface-guidelines.md](docs/reference/web-interface-guidelines.md), 라이선스는 [docs/reference/web-interface-guidelines-license.txt](docs/reference/web-interface-guidelines-license.txt)에 보관한다.

## 배율 축소와 스크롤 없이 가방 사용

- 무장 4×7·일반 10×8·선택 정보·전리품/창고·정리판을 함께 보여준다. 물품을 선택해도 보관 영역과 격자를 숨기지 않는다.
- 1366×768·1440×900·1093×614에서 수납·회전·사용·착용·창고 이동·닫기가 모두 보인다. 좁은 창에서는 그림과 여백을 줄이고 선택 정보를 아래에 둔다.
- `수납`으로 적합한 가방의 첫 빈 공간에 즉시 넣는다. 원하는 위치는 드래그 또는 선택→빈 칸 클릭으로 정한다. R 회전, 방향키→Enter 배치도 제공한다.
- 보관 물품이 많으면 각 영역 안에서 페이지를 이동한다. 다른 영역을 열기 위해 작업 화면 전체를 바꾸지 않는다.
- 상태·무공 연결·착용 장비 등 무인 세부 정보는 선택 정보 영역에서 확인한다. 이때도 가방과 전리품은 유지한다.
- 정리판 물품이 남으면 닫을 때 폐기를 확인한다. 전투 중에는 이동·사용·착용을 막는다. 보이지 않는 세부 정보에는 초점이 가지 않는다.

공개 참고 문서와 적용 범위: [UI·UX 가이드 목록](docs/reference/ui-ux-guides.md).

## 그림 에셋을 적용할 때

그림은 정보를 보조한다. 이름·효과·수치·행동은 실제 텍스트로 표시하고, 아이콘 그림 자체는 초점을 받지 않는다. 투명 그림 시트는 영역을 자르고 비율을 유지해 이웃 물품이 보이지 않게 한다. 작은 창에서는 그림 크기를 줄이되 선택·수납·닫기 버튼은 유지한다. 고대비 설정에서는 복잡한 표면 재질을 줄이며 그림 물품은 유지한다.

## 수납과 드래그

가방 칸의 점유량은 중첩 개수가 아니라 실제 면적이다. 드래그는 처음 잡은 칸을 기준으로 배치하며 가능 위치에는 그림과 초록 경계, 불가능 위치에는 붉은 경계를 표시한다. 수납·착용·창고 이동 결과는 즉시 갱신한다. 저장으로 비활성화된 버튼이나 숨겨진 세부 정보에 초점이 남으면 창 안의 보이는 조작으로 옮긴다. 닫으면 원래 버튼으로 복귀한다.

검증 데이터는 Playwright 독립 브라우저에서만 사용한다. 최신 화면·검증은 [한눈에 보는 UI](docs/glance-ui-v2.md)에 기록한다. 이전 [가방 확대 기록](docs/readability-bag-v2.md)의 전체 화면 탭 방식은 더 이상 사용하지 않는다.

## 언어 선택

첫 실행은 `navigator.languages`의 우선순위에서 지원하는 언어를 찾는다. 한국어 브라우저에서는 한국어로 표시한다. 지원 언어가 하나도 없으면 영어로 표시한다. 중국어는 Hant/TW/HK/MO를 번체, 그 외를 간체로 구분한다. 로비와 일시 정지의 설정에서 자동 감지 또는 5개 언어를 고를 수 있다. 직접 선택한 언어를 브라우저 감지보다 우선하며 별도 설정 키로 저장한다. ‘자동 감지’로 되돌리면 현재 브라우저 언어를 다시 적용한다.

언어는 즉시 바뀌며 게임을 다시 시작하지 않는다. 화면·접근성 이름·문서 언어·탭 제목을 함께 바꾼다. 캐릭터 이름, 물품 ID, 보유 자산과 진행 상태를 번역하거나 다시 저장하는 방식으로 처리하지 않는다. 무공·물품의 기본 이름과 설명은 표시할 때 번역한다. 언어마다 작은 해상도의 핵심 행동을 확인하고 사용자 실제 저장에 검증 데이터를 넣지 않는다.

## 텍스트·로딩의 상태와 복구

전체 무공 설명은 클릭·키보드로 열고 닫으면 연 버튼으로 초점을 돌린다. 짧은 화면의 카드 선택은 유지하며 긴 설명만 읽기 스크롤을 허용한다. 수납 실패는 충돌·경계·종류 제한으로 구별한다. 상태 안내는 말줄임표로 숨기지 않는다.

시작 안내는 JS 이전에도 언어에 맞춰 보인다. UI 그림과 전투 그림의 실제 준비 개수를 표시한다. 느린 연결에는 설명을 제공하고 실패에는 재시도·새로고침을 제공한다. UI 그림이 실패하면 기본 화면으로 관리 기능을 사용할 수 있다. 필수 전투 자료가 준비되지 않았으면 전투를 진행하거나 입력을 받지 않는다. 복구 시 저장과 무인 ID를 유지한다. 상세: [텍스트와 로딩 개선](docs/text-loading-v3.md).

## 배치와 간격의 확인

큰 글자 적용과 전체 UI·UX 완료는 다르다. 실제 버튼 영역이 겹치거나 다른 블록에 침범하지 않는지 빈 상태·귀환 상태·전투·성장·보관 상태에서 확인한다. 낮은 로비의 무공 세부 정보는 가방에서 확인하고 체력·수명·명부 페이지·가방 열기는 유지한다. 긴 읽기 내용의 스크롤에서 일반 창 제목과 닫기를 상단에 유지한다. 자동 배치 검사, 직접 시각 검토, 신규 사용자 조작 검토를 구분한다. [배치 점검 기록](docs/layout-spacing-v3.md)을 따른다.
