# 혈마전 방향별 원화 적용

일반 적 3종과 보스 4종을 독립 원화로 표시한다. 5시점×12자세×7인물=420개 프레임을 좌우 반전해 8방향에 사용한다. 방향/동작별 자동 배율 보정과 변형 메시 대신 인물·무기가 함께 그려진 원화를 선택한다.

| 인물 | 실제 역할과 기본 공격 원화 |
|---|---|
| 혈도병 | 혈도 내려 베기 |
| 혈영 암살자 | 짧은 단검 돌진 찌르기 |
| 혈지 술사 | 혈지 설치를 위한 손 시전 |
| 혈도객 적우 | 혈도 내려 베기·반대쪽 권갑 방어 |
| 혈마제자 연살 | 양 권갑·몸통 회전 정권 |
| 홍의마녀 소홍 | 부채 준비·발사·회수 |
| 혈마교주 적천 | 혈도 준비·접촉·회수 |

인물별 공통 프레임과 최소 32픽셀 투명 패딩, 고정 배율 0.225를 사용한다. 손·발 기준점은 저장 좌표이며 HP바 높이는 모든 살아 있는 자세를 포함한 고정 여유로 계산한다. 기존의 혈지 술사→보스 행 공유를 분리하여 역할이 다른 도구 그림을 사용하지 않게 한다.

보스 19개 행동의 기존 판정·출혈·흡혈·체력 교환·혈지·투사체를 유지한다. 연격의 각 접촉은 해당 프로필 시각으로 표시한다. 인물별 기본 공격 주기를 공유하는 구조이며, 19개 행동마다 별도 원화 세트를 제작한 것은 아니다.

원본과 프롬프트는 [제작 출처](source/hyeolma-family-v1/README.md), 자동 검사와 실제 화면 검토는 [검증 기록](verification/hyeolma-family-v1/README.md)에 기록한다. 로컬 검토 화면은 `/art/hyeolma-family-v1/review.html`이다.

## 마지막 원화 교정 완료

2026-10-05. 생성 한도로 남았던 교정을 내장 image_gen.imagegen으로 재개했다. 20자세를 교체하고 임시 재사용 18개를 모두 해소했다. 53개 선택 원본 시트에서 서로 다른 420개 그림을 사용한다.

- 소홍 정면·뒤 대각선·후면은 부채를 같은 손으로 준비·타격·후속·회수한다. 측면 최대 준비도 초기 준비와 다른 그림을 사용한다.
- 연살 후면의 피격은 양발을 고정한 작은 반응이다. 보스 공격 중에는 피격 그림으로 전환하지 않는다.
- 적천 측면의 타격은 여백이 넓은 독립 원화에서 칼끝을 완성하고, 기존 후속과 구분한다. 과대하게 생성된 후보는 다시 원본 신체 크기에 맞춰 교정하고 런타임 배율은 0.225로 유지했다.

선택 원본 RGBA 1:1 패킹·최소32픽셀 투명 여백·발 좌표와 고정 HP바를 검증했다. 단위1,261개·브라우저8개·빌드가 통과했다. 실제 사용자 저장은 변경하지 않았다. 자세별 선택은 제작 폴더의 final-accepted.json, 이전 선택은 generation-jobs.before-final.json에 보존한다.

보스19개 행동별 전용 원화 시퀀스와 사망 연속 프레임은 이번 범위가 아니다. 자동 검사는 관절·신체 치수의 수치 인증과 구분한다.
