# 무공 UI·UX 고도화 전략 v3

작성: 2026-09-29. 이번 문서는 다음 개발의 제안이며, 실행 완료 보고가 아니다. 현재 UI 코드나 게임 규칙은 변경하지 않았다.

## 목표와 근거

현재의 큰 글자와 조작 영역을 유지하면서, 화면마다 플레이어가 보고 판단하고 행동하는 순서를 명확하게 만든다. 카툰 무협 캐릭터와 잘 맞는 그림 UI를 만들고, 가방 배치와 전투 시야를 우선 확보한다.

`DESIGN.md`, `UX.md`, `docs/reference/ui-ux-guides.md`, 현재 코드와 최근 검증 캡처를 검토했다. 실제 새 사용자 플레이테스트나 새 배포 검증을 수행한 것은 아니다.

| 관찰한 부분                                                  | 다음 설계의 목표                                                   |
| ------------------------------------------------------------ | ------------------------------------------------------------------ |
| 글자와 버튼 확대 후 전투의 상하단 패널도 넓게 보인다         | 읽는 글자는 크게 유지하면서 중복 문구·패널 여백·장식 면적을 줄인다 |
| 카툰 캐릭터에 비해 UI의 황금 테두리와 사실적인 재질이 강하다 | 동일한 윤곽·색면·그림자 규칙으로 캐릭터와 UI의 인상을 맞춘다       |
| 로비 상단 메뉴와 하단 바로가기에 창고·기록이 반복된다        | 전역 이동과 현재 상태의 주 행동을 구별해 중복 경로를 정리한다      |
| 새 무인 출전과 명부의 귀환 무인이 동시에 표시된다            | 신규 생성·진행 중 이어하기·귀환 무인 관리의 의미를 구별한다        |
| 가방의 큰 상단 제목과 여섯 탭에 비해 격자가 작다             | 가방 격자를 주 작업 공간으로 두고 관련 영역을 묶어 전환한다        |
| 9개 CSS 파일이 순서대로 적용된다                             | 토큰과 공통 컴포넌트의 소유권을 정해 화면별 덮어쓰기를 줄인다      |

## 유지할 제품 기준

- 현재 적용한 150% 글자와 주요 조작 영역을 기본으로 유지한다. 공간이 부족하면 레이아웃과 정보 노출 방식을 바꾼다.
- 전투의 캐릭터 크기·카메라·맵 크기를 UI 작업으로 바꾸지 않는다.
- 무장 가방 4×7, 일반 가방 10×8, 전투 중 물품 이동·착용·소모품 사용 금지 등 현재 게임 규칙을 유지한다.
- 로비의 관리 기능과 전투 중 가방 확인을 구별한다. 미구현 레이드·비무·시장을 작동하는 메뉴로 노출하지 않는다.
- 데스크톱 1440×900, 1366×768, 1093×614에서 핵심 작업은 배율 축소나 페이지 스크롤 없이 가능해야 한다.
- 긴 설명과 접근성 확대의 예외는 필요한 읽기 스크롤을 허용한다. 핵심 행동을 감추지 않는다.
- 실제 사용자 저장은 변경하지 않고, 검증 데이터는 독립 브라우저 컨텍스트에만 넣는다.

## 시각 방향

카툰 무협의 실루엣과 단순한 색면을 UI에도 적용한다. 밝은 한지와 짙은 옥색, 먹빛 글자, 주홍 강조를 유지하고, 큰 금속 장식은 주 행동과 특별한 보상에 집중한다.

일반 패널은 얕은 명도 차이와 간결한 그림 테두리로 구분한다. 글자가 놓이는 부분의 종이·천 질감은 약하게 만든다. 물품 그림은 실제 에셋으로 유지하며, 동일한 윤곽 두께·광원 방향·색 농도로 정리한다. 수납 격자의 선은 배치 판단에 필요한 기능으로 남긴다.

글꼴은 먼저 현재 고운 서체의 행간·굵기·숫자 정렬을 정돈한다. 제목에는 바탕체, 효과·버튼·수치에는 읽기 쉬운 본문 서체를 사용한다. 새 서체 도입은 한 화면 비교 후 판단하고 일본어·중국어의 폰트 대체도 검증한다.

## 화면별 설계

### 로비

첫 로비, 강호 진행 중, 귀환 무인 보유의 세 상태를 각각 설계한다.

- 첫 로비: 새 무인 생성과 출전을 가장 강하게 보여준다. 명부 등록 조건은 한 문장으로 안내한다.
- 진행 중: 실제 무인 이름과 웨이브를 주 행동 주변에 표시하고 이어하기를 강조한다.
- 귀환 후: 선택한 무인의 체력·수명·무공과 가방 관리가 연결되게 한다. 새 무인 생성은 별도의 명확한 행동으로 둔다.
- 창고·기록은 한 곳에서 일관되게 접근하고, 설정·소리는 같은 자리를 유지한다.
- 좁은 화면은 장식 초상과 배경보다 주 행동·선택 무인·남은 수명을 우선한다.

완료 판단: 처음 보는 사용자가 세 로비 상태에서 다음 행동과 그 행동의 대상을 설명할 수 있는지 확인한다.

### 전투 HUD

시선 순서는 적의 공격과 이동 공간 → 내 체력 → 현재 무공과 방어·기공 상태 → 웨이브다.

- 좌측 상단: 체력과 레벨. 초상은 크게 읽어야 할 수치를 밀어내지 않는 크기로 사용한다.
- 우측 상단: 웨이브, 가방, 일시 정지. 큰 빈 패널을 만들지 않는다.
- 하단: 현재 무공·방어·기공 상태와 네 무공 전환을 하나의 정보 흐름으로 정리한다.
- 지역명은 진입 시 표시하고 상시 큰 패널로 유지하지 않는다. 보스전에는 별도의 보스 체력을 표시한다.
- 미개방 기능 설명은 정지·가방 등 상세 화면으로 옮기고, 전투에서는 상태를 짧게 보여준다.
- 낮은 체력·방어 성공·기공 준비를 색, 형태, 짧은 피드백으로 구별한다. 지속 점멸은 피한다.
- 전투 가방은 확인 전용 상태를 분명히 표시한다.

완료 판단: 동일한 전투 프레임에서 전후 HUD를 겹쳐 비교하고, 적과 공격 예고가 UI 아래에서 가려지는 위치를 확인한다. HUD 면적 감소는 글자를 작게 만들어 달성하지 않는다.

### 가방·창고·전리품

수납·보관과 무인 상태를 상위 영역으로 묶고, 수납 영역 안에서 일반·무장·전리품·정리판·창고를 구별한다. 탭 묶음은 클릭 증가와 격자 면적을 함께 비교한 후 확정한다.

- 넓은 화면의 전리품 정리는 현재 가방과 전리품을 함께 보며 할 수 있는 구성을 우선 시안으로 만든다.
- 1093×614에서는 가방 격자와 물품 행동을 우선하고, 보관 영역은 페이지 전환으로 접근한다.
- 헤더와 보조 문구의 중복 공간을 줄여 격자 칸 확대를 시도한다. 1093 화면의 일반 가방 칸은 48 CSS px를 초기 목표로 삼되, 다국어와 큰 행동 버튼이 함께 들어가는지 검증 후 확정한다.
- 점유 칸, 전체 칸, 남은 칸을 한 곳에서 표시한다. 남은 칸이 많아도 형태 때문에 들어가지 않는 경우를 구별한다.
- 실패 사유는 `다른 물품과 겹칩니다`, `가방 경계를 벗어납니다`, `이 가방에는 수납할 수 없습니다`처럼 구체적으로 표시한다.
- 선택 정보에 그림·이름·크기·효과·현재 위치를 표시하고 가능한 행동을 우선 제공한다.
- 현재 드래그의 잡은 칸 유지, 배치 미리보기, 클릭 배치, R 회전, 방향키·Enter 대안을 유지한다.
- 드래그로 다른 탭을 열 때는 짧은 호버 확인과 표시를 검토해 탭을 스쳐 지나가는 오작동을 줄인다. 클릭 전환은 즉시 반응한다.
- 빠른 창고 이동은 드래그 외에 명시적 버튼을 제공한다. 이동 후 선택 물품과 도착 위치를 확인할 수 있게 한다.
- 폐기 확인에는 대상·개수·결과를 표시한다. 전투 규칙과 전리품 귀속을 바꾸는 자동 정리·일괄 획득은 별도 기능 설계 후 판단한다.

완료 판단: 줍기 → 회전 → 수납 → 착용 또는 사용 → 창고 이동 → 폐기 취소 → 닫기 흐름의 입력 횟수와 잘못된 시도를 기록한다. 공간 부족 상황도 포함한다.

### 성장 선택

- 세 후보는 같은 순서로 무공명·현재 대비 변화·플레이 특성·방어 또는 기공 효과를 보여준다.
- 처음 배우는 무공과 기존 무공 강화의 차이를 명시한다.
- 효과를 긴 소개문에 묻지 않는다. 실제 적용될 수치가 준비된 경우 현재 → 변경 후로 비교한다.
- 네 무공을 모두 채운 뒤 새 무공이 나오지 않는 규칙을 유지한다.
- 현재 1초 입력 보호를 유지하고, 잠금 표시와 해제 상태를 명확하게 한다.
- 연속 공격, 키 누름 유지, 연속 성장에서 오선택이 발생하지 않는지 검증한다. 보호 시간 변경은 별도 조작 검토 후 결정한다.
- 상세 설명은 마우스 호버에만 의존하지 않고 클릭·키보드로도 읽게 한다.

### 공통 피드백과 설정

모든 버튼·탭·물품에 기본, 호버, 누름, 선택, 키보드 초점, 비활성, 처리 중, 실패 상태를 정의한다. 선택과 초점을 같은 표현으로 처리하지 않는다.

수납·착용·창고 이동은 해당 물품 가까이에 결과를 보여주고, 저장 실패는 짧은 안내와 회복 행동을 제공한다. 복구 가능 범위는 실제 저장 로직과 일치시킨다.

UI 반응은 우선 120~180ms, 창 전환은 180~240ms로 비교한다. 명시한 속성만 전환하고 입력을 기다리게 하지 않는다. 움직임 줄이기를 존중한다. 효과음은 시각 피드백을 보조하며 무음에서도 상태를 알 수 있어야 한다.

설정에는 기존 언어·대비·전체 화면·소리를 유지한다. UI 크기와 전투 HUD 크기 옵션은 글자 확대의 기본값과 역할이 중복되지 않도록 정리한 뒤 확장한다.

## 디자인 시스템과 코드 정비

현재 문서는 YAML의 모서리 값과 본문의 모서리 값, 움직임 시간에 차이가 있다. 다음 구현 전에 이 값을 한 기준으로 정리한다.

- 색·글자·간격·모서리·높이·움직임·레이어를 CSS 변수로 관리한다.
- 버튼, 탭, 패널, 상태 막대, 물품 정보, 페이지 이동, 대화상자의 공통 규격을 만든다.
- 화면별 스타일은 로비·전투·가방·성장 선택의 배치에 집중한다.
- 기존 9개 스타일 파일은 화면별로 이동하며 중복을 제거한다. 전체 UI를 한 번에 갈아엎지 않는다.
- `DESIGN.md`는 시각 규격, `UX.md`는 조작과 상태, 이 문서는 작업 순서와 판단 기준을 맡는다.
- 새로운 패널·버튼 그림은 영역 크기에 맞춰 늘어날 수 있는 방식으로 제작하고 텍스트를 이미지에 굽지 않는다.

| 4    | 로비·성장 선택과 그림 통일        | 상태별 로비, 후보 비교, 공통 버튼·패널·피드백 완성                            |
| 5    | 다국어·입력·배포 검증             | 자동 검사 결과, 직접 시각 검토, 사용자 조작 결과, 공개 배포 확인을 각각 기록  |

HUD와 가방을 먼저 진행한다. 가장 오래 보고 가장 많이 조작하는 두 화면에서 기준을 확정한 뒤 로비와 나머지 화면으로 확대한다. 시안 비교를 개발의 중간 산출물로 만들고, 기본안 제작을 진행하기 위해 추가 승인을 반복 요청하지 않는다.

## 검증과 합격 기준

아래 사용자 조작 지표는 다음 검토의 목표다. 이미 달성한 성과로 표시하지 않는다.

- 로비에서 새 사용자 3~5명이 첫 주 행동을 약 3초 안에 찾는지 확인한다.
- 가방에서 처음 보는 사용자가 안내 후 30초 안에 물품 선택·회전·수납을 수행하는지 확인한다.
- 기본 작업에 필요한 클릭과 탭 전환을 현재 버전과 비교한다. 줄어든 횟수와 새로 생긴 혼동을 함께 기록한다.
- 3개 필수 화면 크기 × 5개 언어에서 필수 행동과 전체 격자를 확인한다.
- 독립 브라우저에서 명부 없음/많음, 빈 가방/가득 찬 가방, 긴 이름, 공간은 남지만 형태가 맞지 않는 상태, 긴 효과, 많은 창고 물품, 저장 실패를 검증한다.
- 마우스·키보드 각각으로 수납·회전·착용·사용·창고 이동·폐기·취소·닫기를 실행한다.
- 전투 중 이동·사용 금지, 네 무공 제한, 선택 잠금, 저장 복원을 회귀 검사한다.
- 빌드·단위·브라우저 자동 검사와 직접 캡처·조작 검토를 구별한다. 새 사용자 플레이테스트가 없으면 그 사실을 기록한다.
- 공개 배포에서는 새 빌드가 보이는지, 그림·폰트·전투 모듈 로딩과 저장 복원이 정상인지 확인한다. 결과는 서비스 품질이나 접근성 인증으로 표현하지 않는다.

후속 전략의 최우선 결과는 큰 글자가 유지되는 동시에 전투 시야와 가방 작업 공간이 더 넓어지는 것이다.

## 텍스트·로딩 적용 현황 · 2026-09-29

추가 요청에 따라 가독성·다국어 숫자·전체 무공 설명·수납 사유 안내와 그림 준비·실패 복구를 구현하고 공개 배포했다. [적용 내용과 검증](text-loading-v3.md)을 따른다. 이 기록은 위 실행 순서 전체의 완료를 뜻하지 않는다. HUD·가방 시안 통일과 새 사용자 조작 지표는 후속 전략에 남아 있다.

## 배치·간격 적용 현황 · 2026-09-29

현재 구현된 주요 화면의 공통 여백·패딩·정보 묶음·행동 정렬을 적용하고, 귀환 명부와 하단 관리 영역의 겹침을 고쳤다. 설정·안내의 데스크톱 두 열 배치와 일반 창의 고정 제목·닫기도 적용했다. [배치 기록](layout-spacing-v3.md)에 자동 검사·직접 시각 검토와 남은 범위를 구분한다. 신규 사용자와의 발견성·오조작·작업 시간 측정은 아직 실행하지 않았다.
