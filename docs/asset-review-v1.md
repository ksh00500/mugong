# 첫 검사 에셋 검토

작성일: 2026-09-27

## 제작 결과

기본 내장 image_gen으로 새 검사 기준 이미지, 몸체 걷기 4프레임, 몸체 베기 4프레임, 독립된 검 PNG를 제작했다. 생성 프롬프트 전체는 `../assets/prompts.md`에 있다. 기존 Drive 런타임 에셋은 사용하지 않았다.

처음 생성한 통합 시트는 프레임 간 여백과 걷기 변화가 부족했다. 별도 걷기 시트는 검을 쥔 손이 변경되는 문제가 있었고, 손 변경만 요청한 수정으로도 해결되지 않았다. 미채택 시도를 그대로 최종 에셋으로 쓰지 않고, 검을 몸체에서 제거한 뒤 손 기준점에 별도 검을 연결했다.

## 실행 가능한 검토 화면

`../prototype/index.html`은 외부 라이브러리 없는 Canvas 2D 검토 샘플이다. 최종 게임 엔진·서비스 스택을 확정하는 코드는 아니다. 선택된 원본 PNG는 프로젝트 안에 저장되어 있고 네트워크 이미지에 의존하지 않는다.

- 대기 자세와 걷기·베기 루프를 재생한다.
- 멈추기·프레임 앞뒤 이동·느리게·크기 변경·손과 발 기준점 표시가 가능하다.
- 캔버스에 초점을 두면 WASD/방향키 이동, 클릭/Space 베기, R 초기 위치로 돌아간다.
- 검은 프레임별 손 기준점을 회전축으로 쓰며 같은 손에 유지된다. 손 원본 영역을 검 위에 그려 손잡이 가림을 시험한다.

## 현재 한계

남동쪽 원화 한 방향을 검토하는 단계다. 다른 방향 이동 시 원화 방향이 변하지 않으며 클릭 방향은 방향선으로만 표시한다. 다방향 조작·공격 판정이 완성된 게임으로 설명하면 안 된다.

걷기·베기는 각각 4개의 생성 키프레임으로, 옷자락과 체격의 변화 및 동작의 끊김이 남아 있다. 대기는 베기의 회복 자세를 사용하며 별도 호흡 동작은 없다. 손 연결 좌표와 발 기준점도 이후 원화 보정 때 함께 재검수한다.

배경은 축척을 보기 위한 임시 코드 바닥이며 최종 배경 원화가 아니다. 적·피격·사망·강호 진행·멀티플레이·가방·공격 판정은 아직 연결하지 않았다.

다음 단계는 이 시안에서 시점·외형·게임상 크기를 검토한 뒤, 동작 일관성과 중간 프레임을 다듬고 방향을 확장하는 것이다. 이 파일만으로 전체 에셋 완료나 양산 준비 완료를 선언하지 않는다.
