# 소림 전체 방향·동작 적용

2026-10-04. 봉 승려에 이어 권갑 승려·돌투척 승려와 보스 공허·도원·불명·무진을 적용했다. 소림 7종은 420장의 방향별 원화와 좌우 반전으로 8방향을 표시한다.

`src/game/authored-enemy.ts`에서 소림 지역의 역할/보스 슬롯별 원화와 자세를 선택한다. `CombatScene`은 Phaser Image로 원화를 직접 표시하며 이 7종에는 몸 메시 변형·무기 경계에 따른 체형 맞춤을 하지 않는다. 배율 0.225와 원본 종횡비를 고정하고 프레임별 명시 지면 좌표를 사용한다. HP바는 해당 캐릭터의 모든 살아 있는 방향·자세 중 최대 높이에 여유를 둔 고정 위치이며 실제 표시된 상단도 확인한다.

권갑 승려의 즉시 피해와 돌투척의 즉시 발사에서는 준비가 끝나는 순간 접촉 그림을 표시한다. 봉 승려는 기존 지연된 0.09초 접촉을 따른다. 보스는 정의된 각 접촉 시간의 직전 0.035초부터 직후 0.06초까지 접촉 그림을 노출해 2~3연타가 회수 자세에 가려지지 않는다. 보스 피격은 공격 자세를 바꾸지 않고 짧은 색 변화와 기존의 작은 반응만 사용한다. 기존 보스 CC/경직 면역 규칙은 유지된다.

검토 페이지: `/art/shaolin-family-v1/review.html`. 캐릭터 7종을 선택하고 대기·걷기·공격·피격·사망을 8방향으로 비교한다. 원본과 동일한 픽셀 비율을 게임 두 배 크기로 표시한다. 원화·프롬프트·내보내기 기록은 `docs/source/shaolin-family-v1`, 검사 증거는 `docs/verification/shaolin-family-v1`에 있다.

자동 검사와 실제 시각 검토는 별개다. 자동 검사는 방향 선택·원본 RGBA 보존·여백·공통 배율·HP바와 원화 간격·피격 중 공격 유지·연타 노출을 검사한다. 실제 캡처에서는 밝은 배경에 합성된 7종×8방향의 보행·준비·접촉·회수를 비교해 투명 배경과 지면 정렬을 확인한다. 사망은 한 자세의 페이드이고 모든 보스 행동마다 별도의 원화 시퀀스가 있는 것은 아니다. 다른 지역은 기존 렌더링을 사용한다.
