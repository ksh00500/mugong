# 능력·특성 접두 아이콘 · 2026-10-03

## 사용자 요청과 구현

모집 카드와 가방 무인 요약에 체질·근력·기민·내공·특성의 그림 아이콘을 텍스트 앞에 배치한다. 기본 화면에는 수치와 이름만 남기며, 설명은 아이콘에 마우스를 올리거나 키보드 초점을 옮기거나 클릭할 때 표시한다. 기존 `무인의 성장` 설명 대화상자는 제거했다.

| 그림 | 표현 | 설명의 근거 |
|---|---|---|
| `constitution.webp` | 붉은 옥 심장 | 체질의 최대 체력 증가 |
| `strength.webp` | 천으로 감싼 주먹 | 근력의 기본 공격 피해 증가 |
| `agility.webp` | 평평한 녹색 천신과 짧은 띠 | 기민의 이동 속도·방어 재사용 시간 |
| `inner.webp` | 푸른 기운의 옥 구슬 | 내공의 궁극 피해·충전량 |
| `trait.webp` | 자주색 옥패와 매듭 | 실제 타고난 특성의 이름·효과 |

특성 그림은 10개 특성에서 공유하는 범주 아이콘이다. 설명은 고정 문구가 아니라 해당 무인의 `TRAITS` 값을 사용한다. 이미 습득한 성장 특성은 기존 전용 그림으로 나란히 표시하며 각각의 이름·효과도 설명으로 제공한다. 아이콘 자체는 능력치나 특성을 추가하지 않는다.

수련의 획득 방법은 무공 제목 옆 두루마리 아이콘에 배치하고, `수련 N →` 버튼으로 성장 선택을 바로 연다. 수련 선택·비용·자동 저장 규칙은 변경하지 않는다. 기존 성장 방식의 무인은 새 성장 프로필로 강제 변환하지 않는다.

## UI 관리 규칙

- `src/ui/CharacterInfo.tsx`: 네 능력의 공통 설명과 `InfoPrefix`. 설명은 활성 대화상자 내부 포털에 렌더링하고 화면 경계 안에 배치한다. 다른 아이콘을 열면 이전 설명은 닫는다. 초점을 빼앗지 않는다.
- `src/ui/RecruitmentDialog.tsx`: 카드 선택 버튼과 설명 버튼을 형제 요소로 둔다. 설명 클릭이 모집 후보 선택으로 이어지지 않으며, 후보는 Enter/Space로 선택할 수 있다.
- `src/ui/CharacterProfile.tsx`: 능력·타고난 특성·성장 특성과 직접 수련 행동. 수련은 `Inventory.tsx`의 무공 제목 옆에 둔다.
- `src/ui/character-info.css`: 아이콘과 설명. `src/ui/growth.css`: 프로필 밀도. `src/ui/recruitment.css`: 모집 카드. `src/ui/inventory-controls.css`: 무공 제목과 수련 배치. 진입점은 `src/ui.css`다.
- 기본 상태에서는 설명이 보이지 않는다. 열린 설명에서 Esc는 설명을 닫고 현재 모집/가방 대화상자를 유지한다. 마우스가 떠나거나 초점이 이동하면 닫힌다.
- 한국어·영어·일본어·간체·번체 설명은 `src/platform/messages.ts`와 기존 특성 번역을 사용한다. 영어의 좁은 가방 표시는 CON/STR/AGI/QI이며 설명 제목에는 전체 이름이 나온다.
- 1093×614에서는 특성과 성장 그림을 가능한 한 같은 줄에 두고 여백을 줄인다. 가방 규격·필수 행동은 유지하며 화면 전체를 축소하지 않는다.

## 에셋 제작과 재사용

내장 `image_gen`으로 5개를 각각 생성했다. 투명 PNG 원본은 `docs/source/character-info-v1/`, 배포용 128×128 WebP는 `public/art/character-info-v1/`에 보존한다. `manifest.json`은 저장소 내부 원본만 참조한다. `scripts/export-character-info.mjs`는 원본을 보존하고 투명 여백 제거·크기 맞춤·WebP 포장만 수행한다. 화면에 이름이나 숫자를 그림으로 굽지 않는다.

생성 프롬프트 세트의 방향: 무공 게임의 기존 채색 물품 아이콘에 맞는 독립 그림, 투명 배경, 작은 크기에서도 구별되는 단일 실루엣, 먹선과 절제된 명암, 장식 프레임·글자·숫자 없음. 체질은 붉은 옥 심장, 근력은 천을 감은 주먹, 기민은 굽과 금장 버클이 없는 녹색 천신, 내공은 청록 기운의 옥 구슬, 특성은 자주색 옥패와 길상 매듭이다. 원본을 임의로 재도색하거나 SVG 대체 그림으로 바꾸지 않는다.

그림 검토용 모음: `docs/source/character-info-v1/review.png`. UI 캡처와 검사 결과는 `docs/verification/character-info-v1/` 및 기존 `docs/verification/character-growth-v2/`에 기록한다. 자동 배치·조작 검사와 실제 이미지 검토를 구분한다.
