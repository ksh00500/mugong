# 보스 근접 개편 1차 · 2026-10-03

후속: [2차](boss-melee-v2.md)와 [3~5차](boss-followup-v3-v5.md)까지 구현했다. 현재 40/40명·185개 행동. 아래 첫 묶음의 수치와 설명은 1차 기록이다.

사용자 요청: 원거리 컨셉을 가진 보스는 유지하되 무기·인물과 무관한 반복 발사를 줄인다. 한 명씩 구현 품질을 확인하기 위해 묶음별로 진행한다.

## 이번에 구현한 범위

40명 중 폐사 4명과 죽림의 취봉객 노개, 총 5명. 나머지 35명은 아래 **검토 방향**이며 아직 구현 완료가 아니다. 기존 원거리 보스를 일괄 근접화하지 않았다. `catalogue.json`의 해당 5명 공격 설명도 현재 구성으로 갱신했다. 원본 기획 파일을 수정한 것은 아니다.

| 보스 | 실제 공격 구성 | 대응과 특징 |
|---|---|---|
| 파계승 공허 | 정권 / 어깨박치기 / 좌우 취권 / 취승 진각 | 찌르기는 옆으로, 박치기는 경로 밖으로 회피. 술병을 플레이어 발밑에 자동 설치하지 않음 |

거리 단위는 1920×1080 전투 좌표계다. 대상 몸체 반경 18을 판정에 더한다. 윤곽선이나 예고 원은 그리지 않는다. 원형 판정은 내부 충돌 계산이며 화면에는 실제 타격 순간의 무기 잔상/지면 충격만 표시한다.

## 동작과 전투 규칙

- 준비 → 마지막 방향 고정 → 실제 접촉 → 회복. 발사나 장판에 의존하지 않는 물리 판정(좁은 직선/부채꼴/주변 원형)을 사용한다.
- 2연타 접촉은 0.5초 간격, 3연타는 0.1/0.6/1.1초. 기존 피격 무적 0.45초를 유지하므로 각 타격을 따로 피해야 한다. 긴 연타의 회복까지 한 프레임에서 즉시 처리하지 않는다.
- 승인된 동일 인물의 준비/타격 원화와 전용 연속 동작 트랙을 사용한다. 실제 접촉 시점에 타격 그림을 표시하고 각 연타 사이 준비 그림으로 돌아간다. **이번에 5명의 원화를 새로 생성한 것은 아니다.**
- 공허·도원·불명의 권갑 공격은 작은 접촉 섬광을 사용하고, 선장을 든 무진과 봉을 든 노개는 무기 잔상을 사용한다. 검/봉처럼 길게 뻗는 칼날 그림을 주먹 공격에 쓰지 않는다.
- 지면 타격의 둔화는 실제 피해가 들어온 경우만 적용. 거리 이탈·무적 회피·완전 방어에 둔화를 강제로 붙이지 않는다.
- 큰 회전/진각 뒤에는 최대 0.5초 정지 회복 구간이 있고 이후 다시 스텝을 밟는다. 노개의 후퇴는 직자 뒤에 한정한다.
- 이 5명의 독립적인 8초 특수 시전은 중단한다. 잡기·종·금강 자세는 전용 공격의 접촉으로 시작한다. 일반 적과 다른 35명의 특수 기믹은 유지한다.
- 저장에는 연타 접촉 횟수/돌진 경로/타이머를 기록. 이전 저장의 삭제된 시전은 접근 상태로 전환, 구형 짧은 근접 strike는 남은 진행 비율을 새 접촉 시간으로 환산한다. 사용자 저장을 삭제하지 않는다.

## 코드 위치

- `src/domain/boss-melee.ts`: 5명 각 공격의 이름·범위·준비/접촉/회복·효과, 물리 판정.
- `src/domain/boss-attacks.ts`, `campaign.ts`, `combat.ts`: 기존 40명 카탈로그와 전용 공격 프로필 연결.

- `src/game/hostile-motion.ts`, `hostile-pose.ts`, `effects.ts`: 접촉과 일치하는 동작/원화/무기 효과.
