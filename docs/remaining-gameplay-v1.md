# 사망 기록·기연·NPC 작업·지역별 로딩·집 서버 준비

2026-10-22. 사용자 지시 “남은거 다 진행해”와 Linux Docker + Cloudflare 환경에 맞춘 구현이다. [이번 검증](verification/remaining-gameplay-v1/README.md), [서버 설치](home-server-cloudflare.md).

## 실제 전투 기록

사망/완주 결과와 로비 세가 기록에서 마지막 피해 원인, 실제 누적 HP 손실, 회복약 사용, 웨이브별 전투 시간·피해, 최근 12회 피격, 무공별 발동 횟수, 종료 시 무공/회복약 잔량을 본다. 피해는 방어·감면·무적·불굴 처리 후 실제 HP 감소분이다. 근접/투사체/설치/환경/상태 피해를 구분하고 알려진 보스의 이름을 연결한다. 정확한 공격자를 알 수 없으면 일반 유형으로 표시한다. 전사 후 소멸할 물품은 소멸 전에 잔량을 기록한다.

선택적 combatReport를 기존 여정과 정산 기록에 저장한다. 최근 피격12·완료 웨이브20개로 크기를 제한한다. 이전 저장은 그대로 읽으며, 중간부터 수집한 여정에는 관측 시작 시점을 표시한다. 과거 기록에 상세 정보가 없으면 복원한 것처럼 꾸미지 않는다. 대화 안에서는 내용만 스크롤하며 닫기는 유지한다. 한국어·영어·일본어·중국어 간/번체를 연결했다.

## NPC 작업 모션

의원은 약을 갈고, 상인은 주판을 세고, 대장장이는 집게와 망치로 작업한다. [제작 정보](source/waystation-work-v1/generation.json). 새 투명 PNG3장, 각2172×724의4프레임이다. 몸통 기준 배율은 인물마다 고정하고 프레임별 발점만 명시해 원화 자체의 위치 편차를 보정한다. 프레임마다 그림을 가득 채우도록 확대/축소하지 않는다.

실제 회복/구매/판매/강화 저장이 성공한 뒤 대화를 닫으면1.6초 동안 준비→접촉→복귀를 재생한다. 저장 중 먼저 닫은 경우에도 성공 확인 후에만 시작한다. 동작 감소 설정은 접촉 자세 한 장을 표시한다. 선택 원화는 낮은 우선순위로 읽으며 실패하면 기존 인물로 서비스한다. 이동 애니메이션이나 모든 지역별 전용 NPC 제작 완료를 뜻하지 않는다.

## 현재 지역만 모션 데이터를 읽기

기존 거대한 mount에 포함되던10지역 기본/특별 모션 표를 지역별 동적 청크로 분리했다. 브라우저는 현재 지역의 기본 가족 표와 특별 표를 각각 하나씩 준비하고, 완료 후 그림을 등록한다. 다음 지역도 같은 준비 경로를 사용한다. 중복 요청은 합치며 실패는 재시도 가능하다. 모듈 요청 실패는 전체 준비 재시도로 처리해 브라우저의 실패한 ESM 캐시를 다시 쓰지 않는다.

원본 표는 검사용 data 모듈에 유지한다. `node scripts/build-special-regions.mjs`로 특별 지역 표를 재생성한다. 원화 위치/배율/발점/공격 시간과 판정은 이 분리로 변경하지 않는다. Node 감사/단위 검사는 모든 표를 읽고 브라우저는 현재 표만 읽는다. ES2022 빌드를 사용한다. mount는5,461.89KB→444.98KB(약91.9% 감소)이며 이것을 전체 로딩 시간 감소율로 해석하지 않는다.

## 밸런스 관측과 배포 경계

40보스×8무공320결투는 실제 HP, 회복약2개,120초 제한, 고정 성장/장비 단계와 반응형 원형 이동/사거리 정책으로 실행했다. HP를 보충하지 않았고 환경 규칙도 유지했다.256보스 처치·64사망·시간초과0, 가상 총6,496.17초다. 사람의 승률이나 자연20웨이브 완주율이 아니다. 이번에는 이 정책의 승률만 보고 밸런스 수치를 다시 바꾸지 않았다. 이제 실제 플레이의 사망/회복약/소요시간을 수집할 수 있다.

Docker의 비루트 Nginx·읽기 전용 실행, health/cache/missing-asset 응답과 독립 브라우저 저장을 검증한다. 집 서버용 Compose는 외부 웹 포트를 열지 않고 Cloudflare Tunnel에서 내부 web:8080으로 연결한다. 토큰은 서버 파일에만 둔다. 실제 집 서버 주소·도메인·Tunnel 연결은 제공되지 않았으며 로컬 Docker 성공과 실제 공개 배포를 구분한다. 사람의 장시간 밸런스·실물 GPU 전수 검사·미확인 이전 원화 삭제도 완료로 합산하지 않는다.
