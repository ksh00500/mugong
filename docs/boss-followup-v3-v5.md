## 공통 규칙과 수정한 문제

- 준비 → 접촉(최대 3회) → 회복 → 거리 선택. 40명 모두 별도 8초 자동 시전을 사용하지 않는다. 준비 후반의 방향/표적 고정을 설치 기믹에도 전달한다.
- 원거리 기술의 최소 거리를 선택뿐 아니라 실제 공격 시작에서도 검사한다. 적절한 기술이 없으면 스텝으로 재배치한다. 목진/진괄은 창 거리를 확보한다.
- 탄도 실제 접촉 시점에 발사한다. `bossShots`를 프로필과 실제 발사에서 공유한다. 3연사는 0.5초 간격/방향 고정. 탄종은 현재 기술 정의에서 결정한다. 귀환탄은 최소 1초, 최대 1.6초 전진 후 귀환한다.
- 지정한 `cast/throw/shoot/slash/thrust`가 공통 `fan/hazard`보다 우선한다. 검기를 부채 시전, 쇠뇌를 마법 시전으로 처리하던 우선순위 오류 수정.
- 빙침의 직접 타격은 피해와 1.6초 둔화. 독검/혈도의 중독·출혈, 흡혈·밀기·끌기·강타 둔화는 실제 피해가 들어올 때만 적용한다. 완전 방어/무적에는 부가 효과 없음.
- 안전 진법·회전문/석문·반사/낙죽·회전날·가열 발판·오아시스/모래벽은 자기 보스의 이전 같은 설치를 교체한다. 수리 드론 활성 1개, 일반 객체 12개/구역 8개 상한 유지. 과거 저장의 이미 생성된 설치는 기존 수명으로 처리한다.
- 내부 원/부채꼴/직선 충돌은 화면에 공격 범위 윤곽선으로 그리지 않는다. 새 조준선/카운트다운도 추가하지 않는다.

## 아트·검증 범위와 남은 작업

승인된 같은 캐릭터의 방향 원화/6개 동작 그림을 사용했다. 정면 준비/접촉 그림과 후방 리그를 실제 기술 시간에 연결한다. 독무곡 보스의 검/독병/부채/지팡이, 설란의 빙옥, 한설의 부채, 적호의 곡괭이, 석문의 방패/망치, 곽기의 렌치, 양기의 봉, 진괄의 창, 묵연의 쇠뇌를 확인했다.

이번 작업은 패턴·모션 선택·접촉 연결이다. 새 원화 생성이나 모든 중간 프레임의 수작업 재제작을 수행한 것은 아니다. 당시 별도 미완료였던 **10종 주인공 × 모든 프레임 × 6종 무기의 손 위치 감사**는 후속 [무기 부착 작업](weapon-attachment-v1.md)에서 처리한다. 장시간 실전의 압박·회피 여유·처치 시간도 추가 튜닝이 필요하다.

원본 파일: `boss-kit.ts`(구조/발사), `boss-wave3/4/5.ts`(개별 정의), `boss-melee.ts`(통합/판정), `game.ts`/`combat.ts`(실제 발동), `enemy-tactics.ts`(거리/이동), `boss-encounters.ts`/`boss-mechanics.ts`(설치), `src/game/hostile-motion.ts`/`hostile-pose.ts`(모션). 도메인 파일은 모두 `src/domain/` 아래다.

`node scripts/sync-boss-patterns.mjs`는 설명과 정의를 비교한다. `--write`를 붙이면 `catalogue.json`의 패턴명을 동기화한다. `tests/boss-followup.test.ts`와 `tests/e2e/boss-followup.spec.ts`에 실제 순환·효과·저장·브라우저 검증이 있다. [검증 결과](verification/boss-followup-v3-v5/results.md).
