# 서역사막·혈마전·제갈 특별 모션 게임 적용

2026-10-18. 검토 시안이던 세 지역의 **12보스·24행동·750논리 프레임**을 로컬 게임에 연결하고 실제 Phaser Canvas/WebGL에서 검증했다. 기존 17보스·75행동·2,610프레임과 합쳐 **29보스·99행동·3,360프레임**이다. 750장은 새로 그린 원화 수가 아니다. 기존 교정 시안과 기본 대기를 재사용하며 이번에 선택한 새 그림은 제갈 기본 방향 36개와 나야 두 번째 접촉 5개다.

다섯 원화 시점을 반전해 여덟 방향으로 표시한다. 공격 시계는 실제 키트의 준비·접촉별 시간·회복을 사용하며 판정이나 저장 데이터를 그림에 맞춰 바꾸지 않는다. 보스 피격 피드백도 특별 공격 자세를 덮지 않는다. 시전은 방어 유지로 잘못 분류하지 않는다.

## 교정한 내용

- 서역사막 특별 시안의 큰 몸체는 캐릭터별 공통 계수 약 0.809~0.848로 제작 단계에서 한 번 보정했다. 각 자세에 다른 맞춤 배율을 적용하지 않는다. 준비와 복귀 끝은 기본 READY의 같은 픽셀·발점을 사용한다.
- 혈마전은 몸체가 이미 가까워 특별 동작 원본의 크기 1:1을 유지했다. 발 표시 비교판으로 기존 제안 좌표를 검토했다.
- 제갈 묵연·진괄·제갈현의 기본 앞사선 이동/공격 36자세를 오른쪽 앞사선으로 교정했다. 특별 모션으로 바뀌며 얼굴 방향이 뒤집히는 원인을 함께 제거했다. 진괄의 잘린 창끝과 머리 위로 든 찌르기 준비는 별도 두 자세 원화로 교체했다.
- 나야 두 번째 근접 접촉은 왼손 환, 오른손은 뒤로 회수한 다섯 시점 그림을 사용한다. 두 번째 준비는 양손 가드로 돌아오며 첫 타격의 오른팔 올리기를 반복하지 않는다. 두 번째 후속과 회복 초반에도 두 번째 접촉 그림을 유지한다.
- 아사르·아르칸의 일부 자동 발점이 낮은 칼끝을 따라갔다. 확대 눈금 비교 후 특별 자세 24개와 기본 READY 10개 좌표를 신발 기준으로 교정했다. 실제 좌표는 [ground-corrections.json](source/three-special-install-v2/ground-corrections.json)에 있다. 다른 10보스도 발 표시 비교판을 검토했다.
- 양기·진괄의 명령은 현재 그림에 일관된 왼손 무기 지지·오른손 명령을 채택했다. 최초 프롬프트의 반대 손 계획을 완성 기준으로 삼지 않았다. 묵연은 오른손 쇠뇌 지지·왼손 명령, 제갈현은 오른손 부채 흐름을 비교했다.

런타임 배율은 모두 **0.225**, 가로세로 비율을 유지한다. 생성된 새 시트도 READY 기준으로 시트 전체에 같은 제작 계수를 적용한다. 원본은 보존하며 보정된 결과를 원본 RGBA 1:1 복사라고 주장하지 않는다. Hyeolma의 기존 동작은 원본 크기를 보존한다. 각 프레임은 최소 32픽셀 투명 여백, 명시한 사각형과 발점을 사용한다. 긴 무기 때문에 몸체를 프레임마다 줄이는 코드와 런타임 알파 스캔은 없다. HP바는 기본/특별 전체 자세를 포함하는 보스별 고정 높이다.
