# 플레이어 대각선 이동 방향 · 2026-10-04

## 원인과 수정

플레이어의 실제 이동 판정은 `src/domain/game.ts`에서 입력 벡터의 각도로 올바르게 정했다. 오류는 렌더 소스 선택에 있었다.

- `CombatScene.applyRosterPose`가 모든 외형에 같은 방향 표를 사용했다. 두 번째 시트의 뒤 대각 원화는 첫 시트와 반대쪽을 바라보므로 NE/NW가 뒤집혔다.
- 앞 대각 보행에 사용하는 행동 A0/A1 두 그림은 일부 외형에서 서로 반대 방향이었다. 보행 반주기마다 얼굴 방향이 바뀔 수 있었다.

`src/game/hero-directions.ts`에서 외형 10종의 원본 그림을 검토해 방향·반전 표를 명시했다. 보행은 8방향 방향 원화에 연속 리그를 적용한다. A0/A1을 보행 소스로 번갈아 선택하지 않는다. 정면·측면·앞/뒤 대각 그림을 각각 유지한다. 무기의 손 기준점도 같은 소스 뷰를 따른다. 적의 전투 중 옆걸음·뒷걸음 규칙은 수정하지 않았다.

## 검증

- 단위 검사에서 10종 × 8방향 및 외형별 반전 예외를 검사했다.
- `tests/e2e/hero-walk-directions.spec.ts`: Canvas/WebGL 각 10종 × 8방향 × 실제 입력 40틱 = 총 6,400개 표본, 4개 테스트 통과. 마우스 조준을 이동 반대편에 두어 보행 방향이 입력을 따르는지 확인했다.
- 한 보행 주기에서 소스·반전이 유지되고, 리그의 걸음 변화가 존재하며 손 부착 오차가 허용치 이내인지 검사했다.
- 원본 방향 시트와 [실제 Canvas 비교표](verification/hero-walk-directions/Canvas-1.png)를 시각 검토했다. 머리·몸체 방향이 보행 반주기마다 반대로 바뀌지 않는다. 자동 검사만으로 원화의 미적 자연스러움을 보장하지 않는다.

그림과 JSON은 `docs/verification/hero-walk-directions/`에 있다. 실제 사용자 저장은 변경하지 않았다. 설산 환경의 냉기 동결이 테스트 입력을 막지 않도록 테스트 컨텍스트의 환경 오브젝트만 제거했다.
