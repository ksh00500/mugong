## 피격 좌표

시뮬레이션 인물 x/y는 발 접지점이다. 기존 투사체 원·근접 부채꼴은 이 점을 검사해서 몸통을 통과한 공격이 빗나갈 수 있었다. `combat-body.ts`의 고정 세로 캡슐을 일반 적·보스·플레이어에 공통 적용한다. 방향이나 공격 프레임의 이미지 여백에 따라 판정을 확대/축소하지 않는다.

- 발보다 34px 위가 무기/발사 기준점이다. 일반 적 캡슐 축은 발보다 52~18px 위/반지름18, 플레이어52~18/20, 보스62~18/22, 기마76~18/22다. 캡슐의 양 끝에는 반지름만큼 여유가 있다.
- 투사체는 이전→현재 위치의 선분 전체와 캡슐 거리를 검사해 빠른 탄의 관통 누락을 막는다. 플레이어와 적의 탄·귀환탄·근접 부채꼴·돌진을 같은 기준에 연결한다.
- 수동 조준도 같은34px 기준이며 카메라 충격 오프셋 보정을 유지한다. 탄 그림 자체는 투사체 좌표에 그린다.
- 진각·지면 원형 피해·설치물·투척 착지 지점은 계속 지면 좌표다. 폭탄의 발사 높이만 바꾸고 착지 속도를 재계산한다. 무적·방어·보스 경직/CC 면역은 기존 규칙을 유지한다.

## 난이도 첫 조정

| 항목 | 이전 v3 | 현재 v4 |
| --- | --- | --- |
| 단계별 보스 HP |630/1050/1540/2100|900/1500/2200/3000|
| 일반 적 HP 계수 |1.155|1.65|
| 일반 적 피해 계수 |0.84|1.2|
| 보스 피해 계수 |0.945|1.35|
| 일반 웨이브 적 수 |3+floor(wave/3)|4+floor(wave/3)+floor((wave-1)/5)|

기존 70% 완화를 되돌린다. 공격 준비·회수 시간, 이동 속도·패턴·추격 AI는 이번 수치 변경으로 단축하지 않는다. 웨이브 경험치 총예산은 적 수가 늘어도 동일하게 분배한다. 이미 저장된 적의 HP는 로드할 때 다시 곱하지 않으며 다음 생성부터 새 수치를 쓴다. 자동 생존/압박 시뮬레이션은 장시간 인간 플레이의 최종 난이도 판정과 구분한다.

## 정비 화면

임시 일괄 버튼 영역을 `PrepStop`으로 교체했다. 별도 걸어 다니는 NPC 필드나 새 NPC 그림을 만든 작업은 아니다. 기존 물품 원화를 사용하는 실제 서비스 화면이다.

- 의원: 현재/최대 HP, 실제 회복 예정량 표시. 회당12전·최대45HP, 꽉 차면 비활성화. 기존 UI가 `hp >= 120`으로 막던 버그를 공통 `healingOffer`로 교정했다.
- 상인: 남은 재고와 용도, 실제 정비 상인 창으로 연결. 구매·가격·재고는 기존 여정 저장을 사용하며 재진입/새로고침에 보충하지 않는다.
- 강화: 보유 장비 선택, 현재→다음 효과·재료 수 표시.12전+일반 강화 재료2개, 최대2회라는 기존 규칙과 실제 명령을 사용한다.
- 다음 보스: 다음 지역/단계의 실제 보스 이름·HP, 현재 무공의 무장 누락 경고. 가방 수납/닫기 후 초점 복귀, 미수납 물품 확인을 거쳐 다음 웨이브로 진행한다.
- 1440×900·1366×768·1093×614에서 핵심 행동을 전체 화면 축소 없이 제공한다.5언어, 금전 부족·품절·강화 한도·완전 회복 상태를 구분한다. 영어 지역명이 장식 밖으로 줄바꿈되던 HUD 너비도 교정했다.

차감과 효과는 실제 명령으로 적용하며, 치료·강화 완료 안내는 저장 완료를 기다린다. 실제 사용자의 IndexedDB를 수정하지 않고 독립 브라우저 컨텍스트로 검증한다. [검증 기록](verification/combat-prep-v1/README.md).

## 적용 범위

소스 브랜치는 `codex/combat-prep-v1`, 컴파일 로컬 게임은 http://127.0.0.1:5205/ (`dist-combat-prep-v1`)이다. 검증용5207도 같은 출력이며 기존 원화/이전 빌드 디렉터리를 보존한다. 동일5205 origin의 사용자 저장은 변경하지 않는다. 공개 배포·개인 서버 전송·main 병합은 하지 않았다. 기존 40보스185행동6,660논리 프레임과 외부 에셋 묶음은 변경하지 않았다. 실기기·장시간 자연 전투와 원거리 최종 밸런스는 후속이다.
