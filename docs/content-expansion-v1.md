# 원본 콘텐츠 확장 v1

이 기록은 최초 확장 시점의 상태다. 이후 보스 특수 행동·고유 전리품·매화난무·혼취 변경은 [v2 적용 기록](boss-encounters-v2.md)을 따른다.

2026-09-30. 업로드한 [02_시스템 및 콘텐츠 설계.xlsx](source/02_시스템%20및%20콘텐츠%20설계.xlsx)의 무공·무공상세·강호·강호상세·보스계획·보스상세를 기준으로 적용했다. 추출 데이터는 `src/domain/catalogue.json`이며, 기존 사용자 저장을 삭제하거나 테스트 상태로 교체하지 않았다.

## 강호 진행

새 무인은 Lv.0에서 시작한다. 신규 강호는 10지역 중 중복 없는 네 지역을 난수로 정하고 각 지역을 다섯 웨이브씩 진행한다. 5·10·15·20웨이브에 해당 지역의 1·2·3·4단계 보스가 등장한다. 한 강호에서 만나는 보스는 네 명이며, 전체 생성 후보는 원문 이름을 유지한 40명이다. 같은 저장을 이어 하면 지역 경로와 난수 상태가 유지된다.

| 지역 | 현재 실제 전투 판정 |
| --- | --- |
| 청하현 | 경험치를 추가하지 않는 지원병 |
| 독무곡 | 발생 위치를 먼저 표시하는 독 지대 |
| 천검산 | 공격 준비 중인 적의 정면 방어 |
| 설산 | 중앙 온기, 외곽 이동 둔화와 빙판 |
| 폐사 | 주기적으로 강해지는 적 공격 |
| 죽림 | 궁수 매복과 옅은 안개 |
| 고묘 | 발동 전에 위치를 알리는 바닥 함정 |
| 서역사막 | 바람에 따른 적 투사체 방향 변화 |
| 혈마전 | 혈지대·회복 봉인·연속 베기 압박. 기존 제단은 [2026-10-02 변경](zone-art-v1.md)으로 삭제 |
| 팔진고성 | 위치가 바뀌는 위험 지대 |

보스는 베기·찌르기·돌진·부채꼴 투사체·원형 투사체·충격파·장판·지원병 호출을 조합한다. 보스별 순서, 단계별 속도와 반경, 체력 절반 이후의 순서 변화를 적용했다. 공격 준비 시 방향과 목표 위치를 고정하며, 예고와 실제 판정은 같은 공격 데이터를 사용한다. 호출 지원병은 추가 경험치를 주지 않는다.

완주 후 명부 등록, 현실 7일 수명, 최대 네 무공, 전투 중 소모품 사용 금지, 전투 후 가방 정리와 성장 등 최근 합의한 규칙을 유지했다. 원본과 충돌하는 예전 규칙으로 되돌리지 않았다.

## 무공과 무장

원문의 8계열·45경지 이름을 연결했다. 삼재는 Lv.10, 나머지는 Lv.5가 상한이다. 네 계열을 배우면 신규 계열 후보가 사라진다.

| 계열 | 무장 | 적용한 주요 행동 |
| --- | --- | --- |
| 화산매화검법 | 검 | 매화 표식, 교대 연격 강화, 무적이 있는 궁극 공격 |
| 무당태극검 | 검 | 공격에 붙은 반격 창, 반격 보너스, 궁극 반격 강화 |
| 천마신공 | 도 | 체력 소모 공격, 최근 손실 회복, 시간 제한 강화 |
| 삼재검법 | 검 | Lv.5 궁극, Lv.8 세 초식, Lv.9 세 적 관통, Lv.10 공격 중 이동 개선 |
| 당문독공 | 독침 | 한 침/세 침 교대, 독 중첩·전파·폭발 |
| 소림금강공 | 권갑 | 공격 중 피해 경감, 피격 뒤 강화, 금강 방어·충격파 |
| 개방취봉법 | 봉 | 200 취기, 강화 공격 두 번 예약, 연속 강화 시 혼취 |
| 제갈팔진술 | 부채 | 건진/곤진 배치, 연결 진동, 둔화와 네 점 궁극 진법 |

호환 무장을 무장 가방에 넣고 연결해야 해당 무공을 사용할 수 있다. 입문 시 호환 무장이 없으면 가방 공간을 확인해 수련 무장을 지급하고 연결한다. 보스 무장 전리품은 현재 무공에 맞는 종류를 준다. 무장을 일반 가방으로 옮기면 연결이 해제된다. 종류가 기록되지 않은 예전 검은 기존 검/도 연결을 유지할 수 있도록 처리했다.

검·도·독침·권갑·봉·부채의 수납 크기를 구분했다. 새 네 무공의 그림 아이콘과 실제 물품 그림을 적용했다. 개방의 200 취기와 예약 횟수는 HUD에 표시한다. 상세 설명은 Shift 또는 설명 버튼으로 확인한다. 한국어·영어·일본어·간체·번체에 새 이름, 경지와 설명을 연결했다.

## 원본과 현재 구현의 차이

이번 변경은 40보스의 이름·지역·단계 데이터와 실제 공격 조합을 연결한 첫 구현이다. 40명의 전용 외형과 원본의 모든 특수 기믹을 개별 완성한 상태는 아니다.

- 지역 배경은 기존 공통 전투 배경을 사용한다. 지역별 차이는 환경 판정과 표시로 구분한다.
- 보스 외형은 기존 두 그림을 공유한다. 사슬, 별도 문 개폐, 독립 소환종 등 원본의 특수 기믹은 현재 공통 공격 유형으로 각색했다.
- 화산 궁극은 범위 공격과 무적으로 구현했다. 개별 적에게 순간 이동하는 연속 동작은 남아 있다.
- 개방 혼취는 적의 추적과 방향 갱신을 방해한다. 적끼리 공격하는 원본 혼란 행동은 아직 적용하지 않았다.
- 지역 고유 물품 및 보스별 독점 드롭 표는 원문 데이터로 보관했지만, 실제 드롭은 현재 공통 전리품 규칙과 무공에 맞는 무장을 사용한다.
- 온라인 레이드·비무 서버는 이번 강호 콘텐츠 변경에 포함되지 않았다. 밸런스 수치도 실제 플레이를 거쳐 추가 조정해야 한다.

## 검증

- `npm test`: 7파일, 99개 검사 통과. 200개 강호 생성에서 40보스가 모두 등장 가능한지, 20웨이브 완주, 여덟 무공의 피해/방어와 연결 무장, 독 중첩, 취기 예약, 진법 상한, 지역 판정, 저장 호환성을 확인했다.
- 성장 선택을 지속 피해로 열었을 때 나머지 독/진법 피해와 시간이 즉시 멈추는 회귀 검사를 추가했다.
- `npm run build`: TypeScript 검사와 Vite 빌드 통과.
- Playwright의 독립 컨텍스트에서 신규 HUD·Shift 상세·개방 예약·가방 열기/닫기·무장 그림을 1440×900, 1366×768, 1093×614에서 조작했다. 다섯 언어 상세 표시와 화면 경계도 확인했다. 기존 가방·상세·전리품 성장 흐름 검사도 실행했다.
- 최종 코드에서 `npx playwright test --config playwright.content.config.ts tests/e2e/content-expansion.spec.ts`를 다시 실행해 4개 검사 모두 통과했다.
- 초기 브라우저 검사에서 입장 애니메이션 도중 측정한 경계 오차를 발견해, 정지된 배치 검사는 reduced motion 상태로 측정하도록 수정하고 재실행했다. 기존 전리품 성장 검사 한 건은 개발 서버 갱신 중 실패해 최종 코드로 재실행하여 통과했다.
- 실제 화면 캡처로 작은 화면의 HUD, 두 격자와 무장 그림을 확인했다. 이는 시각 검토이며 자동 경계 검사와 구분한다. 새 콘텐츠 관련 pageerror는 없었다. 장시간 사람 플레이나 접근성 인증을 대신하지 않는다.

증거: [HUD 1093×614](verification/content-expansion-v1/new-arts-1093x614.png), [가방 1093×614](verification/content-expansion-v1/new-weapons-1093x614.png). 전체 화면과 언어별 캡처·경계 JSON은 `docs/verification/content-expansion-v1/`에 있다.
