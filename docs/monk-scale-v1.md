# 소림 앞·뒤 보행 크기 보정 · 2026-10-04

사용자가 올린 폐사 화면의 권갑병·봉병은 앞쪽 보행 원화와 뒤쪽 방향 원화의 몸 비율이 달랐다. 기존 배율은 그림 높이에 수동 추정 비율을 곱한 단위를 맞추므로, 실제 서 있는 키까지 같아지는 것은 아니었다. 기존 단위 일치 검사가 이 차이를 검출하지 못했다.

## 적용

`scripts/calibrate-monk-skulls.mjs`는 소림 원화의 노출된 두피 위치와 신발의 지면 기준점 사이를 측정한다. 위로 올라간 봉·법장과 아래로 나온 무기 끝은 키 기준에서 제외한다. 이 방식은 머리카락·모자·가면이 있는 다른 캐릭터에 자동 적용하지 않는다.

서 있는 방향 그림 5개와 보행 그림 2개를 같은 키로 맞춘다. 소림 지역 원화 7세트와 별도 정체성 교체 원화 2세트의 총 63개 자세를 보정했다. 실제 폐사의 일반 적 3종·보스 4종을 모두 포함한다. 보스의 기본 배율 1.4는 유지한다. 전투 판정·스탯·저장에는 변경이 없다.

추가 보정은 `src/platform/monk-skull-landmarks.json`에서 관리하며 `anatomical-calibration.ts`가 기존 자료 위에 적용한다. 공격·피격·사망의 기존 단위는 유지하여 낮은 자세를 무조건 서 있는 키로 늘리지 않는다. 이미지 픽셀을 편집하거나 새 원화를 생성하지 않았다. 원화가 바뀌면 이 자료도 다시 측정해야 한다.

## 결과와 검증 자료

- 전체 단위 검사 46파일·1,224개와 프로덕션 빌드 통과.
- Canvas/WebGL 소림 보행 검사 2개 통과. 7종 × 8방향 × 두 보행 시점 × 두 렌더러의 224개 표본에서 두피부터 발까지의 렌더 배율을 확인했다.
- 보정 전 값으로 계산한 방향·보행 프레임별 키의 최대/최소 비는 권갑병 약 1.21, 봉병 약 1.12였다. 보정 후 7종 모두 약 1.00이며 기준 1.015 미만이다. 이는 리그의 호흡·발 움직임까지 포함한 모든 화면 픽셀의 높이가 같다는 뜻은 아니다. 비교 계산은 `verification/monk-scale-v1/stature-ratios.json`에 있다.
- [Canvas 실제 비교 화면](verification/monk-scale-v1/canvas.png)과 [WebGL 실제 비교 화면](verification/monk-scale-v1/webgl.png)을 직접 검토했다. 위에서부터 아래·위·오른쪽·왼쪽 방향이며, 열은 일반 적 3종과 보스 4종이다. 다른 9지역의 방향 비교판도 검토했다.
- 공유 배율 경로를 사용하는 10지역의 방향·동작 배율 검사 10개 통과. 해당 검사는 기존 단위들의 수치 일치와 에셋 등록 경로를 검사하며 독립적인 체형 품질 판정은 아니다. 소림에는 실제 두피·발 사이 길이 검사를 추가했다.

공통 역할·보스 행동 검사는 이전의 '보스도 피격 원화로 바뀐다' 기대값 때문에 실패했다. 이미 사용자 요청으로 적용한 보스 경직 면역에 맞게 일반 적은 피격 자세, 보스는 기존 전투 자세를 유지하는지 검사하도록 수정했고 10지역 모두 재실행해 통과했다. 제품의 보스 규칙을 되돌리지는 않았다. 최종 브라우저 검증은 소림 2개·지역 배율 10개·역할/보스 행동 10개, 총 22개가 통과했다.

검사는 독립 Playwright 저장과 5174 포트를 사용했다. 프로덕션 프리뷰 `http://127.0.0.1:5173/`에 최신 빌드를 반영했다. 원격 Daytona에는 배포하지 않았다.
