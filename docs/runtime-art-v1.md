# 첫 런타임 에셋

제작 도구는 내장 image_gen이다. 이전 Drive 런타임 에셋은 사용하지 않았다. 승인한 카툰 검객과 줌아웃 맵을 참고했으며 원본은 덮어쓰지 않았다.

| 파일 | 용도 |
|---|---|
| `public/art/forest-v1.png` | 승인한 맵에서 인물·UI를 제거한 배경 |
| `public/art/hero-atlas-v1.png` | 초기 8방향×5동작 시트 비교 자료 |
| `public/art/hero-atlas-v2.png` | 북서·북동 뒷모습 수정 시트 |
| `public/art/hero-nw-v1.png` | 북서 걷기·베기 방향 보완 두 프레임 |
| `public/art/enemy-atlas-v1.png` | 도·창·활 산적의 준비·걷기·공격 시트 |
| `public/art/portrait-v1.png` | 로비 투명 배경 검객 |

런타임은 원본 PNG를 유지하고 Phaser 프레임 좌표로 표시한다. 알파를 읽어 프레임마다 발 아래 기준을 맞추며, 원본을 잘라 새 PNG로 덮어쓰지 않는다. 효과·공격 예고·게이지·아이템 기호는 코드와 CSS로 구성한다. 단순한 피격 색 변화와 사망 자세 회전을 사용한다. 보스는 산적 시트의 확대·색 변형과 다른 공격 패턴으로 구분한다.

현재는 첫 플레이용 키프레임이다. 생성 이미지의 동작 중간 프레임, 무공별 고유 동작, 보스 전용 원화는 이후 품질 확장 대상이다. 실행 화면에서 베기·걷기·방향과 접지를 함께 검토한다.

## backgroundPrompt

첨부한 넓은 카툰풍 숲 공터에서 모든 캐릭터와 UI만 지워줘. 맵 구도와 카메라, 바닥과 가장자리 대나무·돌담은 그대로 유지해줘. 게임용 배경 한 장, 16:9.

## heroAtlasPrompt

첨부 검객의 게임용 2D 스프라이트 시트. 같은 카툰 화풍과 외형, 살짝 내려다보는 탑뷰. 정확히 8열×5행의 동일한 칸에 전신을 배치해줘. 열은 동·남동·남·남서·서·북서·북·북동 순서. 행은 준비 자세, 걷기 첫 걸음, 걷기 다음 걸음, 베기 준비, 베기 마무리. 각 칸에서 같은 크기와 발 기준점, 검은 한 자루. 글자·격자선 없이 투명 배경.

## enemyAtlasPrompt

같은 카툰 탑뷰 게임의 산적 스프라이트 시트. 3열×4행, 같은 크기의 칸. 열은 도를 든 산적, 창을 든 산적, 활을 든 산적. 행은 준비 자세, 걷기 첫 걸음, 걷기 다음 걸음, 공격 자세. 검객과 같은 간결한 선·색면, 어두운 갈색 복장, 전신과 무기가 칸 안에 들어오게. 투명 배경, 글자와 격자선 없음.

## heroFixPrompt

이 스프라이트 시트의 칸 배치와 모든 동작은 유지하고, 왼쪽부터 6번째 열은 북서쪽을 보는 뒷모습, 8번째 열은 북동쪽을 보는 뒷모습으로만 고쳐줘. 옷과 검, 크기는 유지. 투명 배경.

## heroFinalFixPrompt

스프라이트 시트에서 3행 6열과 5행 6열의 검객만, 같은 열 다른 칸처럼 북서쪽을 보는 뒷모습으로 고쳐줘. 각각 걷기와 베기 마무리 자세를 유지해줘. 나머지 칸과 투명 배경은 그대로.

이 수정 결과는 방향이 해결되지 않아 채택하지 않았다. 필요한 두 동작만 별도 생성해 런타임에서 해당 프레임을 교체했다. 알파 기준 높이와 발 위치를 맞춰 큰 원본도 같은 게임 크기로 표시한다.

## heroNorthwestPrompt

첨부 시트의 첫째 행 여섯째 검객을 기준으로, 북서쪽을 보는 뒷모습 두 장만 그려줘. 왼쪽은 걷기, 오른쪽은 검을 한 번 벤 마무리 자세. 같은 외형과 게임 시점, 2열 1행, 동일한 크기와 발 기준점, 투명 배경.

## portraitPrompt

첨부 검객의 외형과 자세를 그대로 유지하고 배경만 완전히 투명하게 지워줘. 머리카락과 검, 발끝까지 전신을 보존해줘.
