# 2성·4성 무공 보조 효과

2026-10-01 사용자 결정 반영. 무공을 여러 개 배우는 이점을 전환 없이도 얻도록, 2성·4성 보상을 자동 보조 효과로 변경했다. 아래 수치는 첫 구현의 조정값이며 장시간 플레이 밸런스 검증까지 완료한 것은 아니다.

## 적용 규칙

- 2성에 첫 효과, 4성에 두 번째 효과를 해금한다. 4성에서 2성 효과도 유지된다. 3성·궁극·삼재의 후반 초식은 유지한다.
- **배운 무공들의 해금 효과를 현재 무공에 함께 적용한다.** 제공 무공이 비활성이거나 무기를 연결하지 않아도 보조한다. 해당 무공의 공격·방어·궁극을 직접 쓰려면 호환 무기를 연결해야 한다.
- 제공 무공 자신에게도 각 효과가 한 번만 적용된다. 전환·재실행·무기 재연결로 중첩하지 않는다. 최대 네 무공 규칙을 유지한다.
- 성급은 기존 무공 `level`에서 계산한다. 새 저장 플래그나 아이템을 만들지 않으며 기존 무인도 현재 성급에 맞춰 즉시 적용된다.
- 비율 효과는 곱으로 합친다. 삼재·소림의 피해 경감이 함께 있으면 받는 피해가 82.8%가 된다. 무당·제갈의 충전 증가가 함께 있으면 기본 충전의 126.5%다.

| 무공 | 2성 보조 | 4성 보조 |
|---|---|---|
| 화산매화검법 | 기본 공격 간격 −8% | 이동 속도 +8% |
| 무당태극검 | 방어 재사용 −10% | 적중·반격 궁극 충전 +15% |
| 천마신공 | 체력 50% 미만에서 기본 공격 피해 +12% | 적 처치 시 체력 2 회복 |
| 삼재검법 | 기본 공격 피해 +8% | 받는 피해 −8% |
| 당문독공 | 모든 기본 공격에 독 부여, 최대 3중첩 | 독 최대 5중첩, 처치 시 주변 두 적에게 전독 |
| 소림금강공 | 받는 피해 −10% | 기본 공격 중 피격 경직 방지 |
| 개방취봉법 | 기본 공격 사거리 +8% | 공격 중 이동 속도를 평상시의 65%에서 80%로 개선 |
| 제갈팔진술 | 적중·반격 궁극 충전 +10% | 처치 시 현재 무공의 궁극 충전 +8 |

천마의 처치 회복은 최대 체력을 넘지 않으며 회복 방해를 적용한다. 경직 방지는 피해나 사망을 막는 무적이 아니다. 개방 사거리는 근접 판정과 기본 공격 투사체의 비행 시간에 적용하며 궁극 범위를 늘리지 않는다. 삼재 10성의 공격 중 정상 이동은 그대로 유지한다.

당문 보조는 기본 공격 접촉에만 독을 추가한다. 다른 무공의 독은 3초 동안 0.5초마다 `max(1, 기본 타격 피해 × 0.04)`를 주며, 당문의 독침은 기존 15% 계수를 유지한다. 5중첩에서 독의 한 번 피해가 두 배가 된다. 독 지속 피해·진동·궁극은 독을 다시 부여하지 않는다. 지속 피해는 적중 충전을 하지 않지만 처치 보상은 받는다. 전독은 160 거리 안의 살아 있는 두 적에게 중첩 절반을 올림해서 옮긴다. 마지막 기본 공격이 바로 적을 처치해도 독 부여를 먼저 처리한다. 독이 지속되는 동안에는 더 강한 독 피해를 유지하며, 만료 후에는 이전 중첩과 피해를 물려받지 않고 새 독으로 시작한다.

## 기존 성급 보상 정리

2성·4성에서 현재 무공에만 붙던 별도 보상을 보조 효과로 대체했다. 화산의 표식·교차 연계 가속, 무당의 다음 공격 강화·4성 반격 충전, 천마의 4성 교차 회복 강화, 소림의 공격 중 경감·피격 후 공격 강화, 개방의 방향 전환 무적·4성 추가 취기, 제갈의 2성 진 안 충전 보너스를 따로 더하지 않는다.

무공의 기초 성격을 유지하기 위해 천마의 최근 상처 회복은 1성부터 사용하고, 제갈의 건진·곤진 연결은 곤진을 얻는 3성부터 작동한다. 당문의 독은 1성에서 본인의 독침에만, 2성부터 모든 무공의 기본 공격에 적용한다. 4성 전독은 보조 효과로 유지한다. 원문 45경지 이름과 10지역·40보스 데이터는 수정하지 않았다.

## UI·저장

성장 후보의 보상 이름은 `보조 효과 해금`과 실제 효과로 표시한다. 기본 화면에 긴 설명을 추가하지 않는다. Shift 또는 설명 클릭으로 여는 작은 패널에서 해당 무공의 해금 보조 효과를 성급별로 확인한다. 성장 미리보기는 선택 후 성급으로 수치를 계산하며 현재 보유한 다른 보조 효과도 반영한다. 전투의 방어 재사용 원형 표시 역시 실제 보조 적용 시간을 사용한다.

지원 언어는 한국어·영어·일본어·중국어 간체·번체다. 효과 설명은 표시할 때 번역하며 저장된 무공 ID나 사용자 이름을 변경하지 않는다.

- `tests/support.test.ts`: 실제 공격·방어·이동·독·경직·처치·충전·전환·저장에 대한 회귀 검사. 비활성 제공 무공의 무기 없이도 보조하고, 직접 사용은 무기 연결을 요구한다.
- 자동 단위 검사: 220개 통과. 기존 20웨이브·40보스·물품·저장·애니메이션 검사 포함. 신규 보조 검사 21개는 독의 피해 보존·만료, 기본 검기와 궁극 검기의 구분, 선택 직후 해금도 확인한다.
- 빌드: `npm run build` 타입 검사·배포 빌드 통과.
- 브라우저 자동 검사: 신규 `support.spec.ts` 5개 통과. 1440×900·1366×768·1093×614에서 2성/4성 보상·Shift 숨김/표시·선택 후 저장·가방 설명을 확인하고, 다섯 언어의 상세·전환·재실행 및 긴 보상 카드의 경계와 텍스트 넘침을 검사했다. 기존 `content-expansion.spec.ts` 4개와 `details.spec.ts` 12개도 통과했다.
- 캡처 시각 검토: `docs/verification/support-v1/growth-1093.png`, `details-1093.png`, 다섯 언어의 `growth-*-1093.png`를 직접 열어 확인했다. 세 후보와 선택 버튼이 한 화면에 들어오고, 보조 보상은 줄바꿈되며 Shift 패널은 창 안에 배치된다. 긴 상세 읽기 스크롤은 기존 기준대로 허용한다.
- 테스트 데이터는 독립 Playwright 컨텍스트에서만 사용했다. 실제 사용자 저장은 변경하지 않았다. 자동 경계 검사와 캡처 검토를 구분하며 장시간 실전 밸런스·사용자 조작성 평가는 별도로 남는다.

코드 기준은 `src/domain/support.ts`이며 전투 수치와 설명이 같은 정의를 사용한다. 원문 기획의 이전 2성·4성 설명보다 이 문서와 최신 사용자 결정이 우선한다.
