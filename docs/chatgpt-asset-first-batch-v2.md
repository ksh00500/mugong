# ChatGPT에 보낼 첫 요청문 — 카툰풍·짧은 버전

2026-09-27. 이전 v1의 장문 요청을 대체한다. 사용자가 승인한 `../assets/concepts/cartoon-swordsman-v1.png`를 첨부한다. 아래 요청은 각각 독립적으로 복사한다. 긴 공통 블록이나 제외 목록을 덧붙이지 않는다.

## 1. 게임 시점의 준비 자세

```text
첨부한 카툰풍 검객을 무협 탑뷰 게임용 전신으로 그려줘. 외형과 화풍은 유지하고, 살짝 내려다보는 시점에서 검을 들고 편하게 선 자세로. 인물과 검 전체가 보이는 투명 배경 이미지 한 장으로 만들어줘.
```

결과의 외형·시점이 맞으면 그 PNG를 다음 요청에 첨부한다.

## 2. 한 번 베기

```text
첨부한 검객이 자연스럽게 검을 한 번 베고 원래 자세로 돌아오는 짧은 영상을 만들어줘. 같은 캐릭터와 화풍, 고정된 카메라, 단색 배경으로.
```

## 3. 걷기

베기 결과가 맞은 뒤 같은 기준 PNG를 첨부한다.

```text
첨부한 검객의 자연스러운 걷기 동작을 반복 가능한 짧은 영상으로 만들어줘. 인물은 화면 가운데 유지하고, 같은 캐릭터와 화풍, 고정된 카메라, 단색 배경으로.
```

## 수정이 필요할 때

실제로 나온 문제 하나만 짧게 지시한다. 아래 문장을 한꺼번에 모두 추가하지 않는다.

- “지금 동작은 유지하고, 검을 잡는 손만 처음부터 끝까지 같게 해줘.”
- “현재 외형은 유지하고, 발이 뜨는 부분만 자연스럽게 고쳐줘.”
- “그림은 그대로 두고, 검 끝이 잘리지 않게 여백을 조금 늘려줘.”
- “캐릭터는 유지하고, 카메라 움직임만 없애줘.”

원본 PNG와 원본 영상을 받으면 Codex가 투명 배경·프레임·동작·기준점·게임 표시 크기를 검수한다. 시점·동작·해상도 문제를 모두 생성 프롬프트에 선제적으로 늘어놓지 않는다.
