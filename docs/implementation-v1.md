# 첫 브라우저 플레이 버전 개발 기준

2026-09-28. 개발 계획의 사용자 답변을 반영한다. 이 문서의 시작·성장·수납 규칙은 이전 기획보다 우선한다.

## 사용자 확정

- 브라우저가 주 플랫폼, 이후 모바일 앱. 첫 버전은 PC 조작과 기기 내 저장.
- 첫 완료 목표는 강호 한 사이클. 맵 전체를 한 화면에 보여주는 고정 카메라.
- Lv.0에서 무공 없이 기본 공격만 사용. 캐릭터 Lv.1부터 무공을 선택한다.
- 캐릭터 레벨은 계속 오르며 레벨마다 새로운 무공 또는 보유 무공 +1을 증강 카드 형태로 선택한다.
- 전투·비급·수련품 경험치는 캐릭터 경험치로 통합한다. 독립적인 무공 경험치가 레벨 선택을 우회하지 않는다.
- 강호 완료 시 Lv.13~16, 일반 무공 최대 세 개 정도를 완성할 수 있는 투자량. 첫 네 계열은 화산·무당·천마·삼재.
- Space는 무공별 행동. 공통 회피가 아니며 입문 전에는 행동이 없다.
- 전리품은 전투 후 직접 수납한다.

## 현재 구현의 조정 가능한 기본값

- 1920×1080 논리 화면, 60Hz 규칙 계산, UI 상태 발행 최대 초당 10회. 맵은 FIT으로 전체 표시.
- 그래픽 가속 환경은 정적 CSS 배경과 화면 크기에 맞춘 Phaser 렌더링을 사용한다. 소프트웨어 그래픽 환경은 960×540 불투명 Canvas와 내부 배경으로 전환하여 투명 레이어 합성 비용을 줄인다. 논리 좌표와 전체 맵 범위는 같다.
- 최대 HP 120. 캐릭터 레벨 자체로 능력치를 자동 증가시키지 않는다.
- 레벨 L의 누적 경험치 기준: `20L + 2.5L(L-1)`.
- 런의 전투 경험치 총량은 650~920. 보스 네 번의 수련 비급은 각 20 경험치. 합계 730~1000이며 Lv.17 기준 1020 미만이다.
- 선택은 유효한 무공별 행동 중 무작위 최대 세 장. 후보가 적으면 후보 수만 표시. 선택·난수 상태를 저장해 재접속으로 다시 뽑지 않는다.
- 기본 공격 중 이동은 평소 속도의 65%. Space 행동은 준비 중인 공격을 취소할 수 있다. 궁극 게이지·기본기 순서·Space 재사용 시간은 무공별로 전환 후 유지된다.
- 무장 4×7, 일반 10×8. 수납 위치는 사용자가 지정하고 기존 물품을 자동 이동하지 않는다.
- 시작 기본 검은 호환되는 모든 첫 계열에서 사용할 수 있다. 새 무공을 배울 때 무장 가방의 검을 자동 연결하며 이후 비전투에서 연결을 바꿀 수 있다.
- 일반 전투 후에도 비전투 수납·회복·무장 변경을 허용한다. 4·9·14·19 웨이브 정비에는 추가로 의원·보급을 제공한다.
- 첫 의원은 12전으로 45 HP 회복, 금창약은 8전. 무한 경험치 획득을 막기 위해 정비 상인은 비급을 판매하지 않는다.
- 강호 성공 시 HP·장비·무공을 유지하여 등록하고 현실 7일 수명을 시작한다. 만료는 실행 중 30초 간격 및 로드 시 검사하며 물품을 창고로 한 번 회수한다.
- 첫 로컬 명부·창고는 개수 제한이 없다. 정식 온라인 단계의 수용량·초과 수령 정책은 별도 개발 범위다.

## 저장과 경계

IndexedDB의 한 레코드에 세가와 진행 중인 런을 원자적으로 기록한다. 사망·전투 처치·카드 선택·물품 이동·웨이브 진행·귀환은 즉시 저장하고, 전투 중 위치와 타이머는 약 1초 간격으로 체크포인트를 만든다. 쓰기가 실패하면 진행을 멈추고 재시도로 같은 결과를 저장한다.

브라우저 강제 종료 시 마지막 체크포인트 이후의 짧은 진행은 복구되지 않을 수 있다. 이미 저장된 사망 결과를 복원해 무인을 되살리지 않는다. Web Locks를 지원하는 브라우저에서는 동일 세가를 여러 탭에서 동시에 쓰지 못하게 한다. 온라인 서버의 권위 판정이나 로컬 파일 조작 방지는 이번 범위가 아니다.

현재 무공 효과와 수치는 첫 플레이 검증용이다. 서버·모바일 연결에 앞서 실제 사람의 플레이로 공격 리듬·증강 선택·회복 공급·보스 난이도를 조정한다.
