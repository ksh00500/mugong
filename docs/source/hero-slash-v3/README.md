# 사용자 제공 베기 참고 시트

2026-10-04 사용자가 첨부한 네 이미지의 검토용 사본이다. 원본의 이용 허락은 확인하지 않았으며 게임 실행 에셋으로 편입하지 않았다.

| 파일 | 관찰한 내용 | 이번 구현의 참고점 |
| --- | --- | --- |
| `user-reference-1.png` | 준비·베기·회수 자세와 서로 다른 방향의 검광 | 검광은 짧은 타격 구간에 집중 |
| `user-reference-2.png` | 어깨 위 준비에서 허리 높이의 횡베기로 전환, 팔과 몸이 함께 움직임 | 높은 준비 → 몸 앞을 가로지르는 베기 → 낮은 마무리 |
| `user-reference-3.png` | 타격 때 팔만 움직이지 않고 몸통과 다리가 따라감 | 작은 상체 비틀림과 체중 이동 |
| `user-reference-4.png` | 내려베기·횡베기·찌르기 등이 서로 다른 자세와 궤적을 가짐 | 기본 검·도 베기를 아래에서 위로 드는 동작과 구분 |

정지 시트에서 읽은 순서와 이를 현재 탑뷰에 적용한 타이밍·원근감은 프로젝트의 해석이다. 원본 게임의 실제 재생 속도나 타격 판정은 확인하지 않았다.

이번 수정은 기존 `hero-slash-v1`의 150개 몸체 그림을 재사용하며, 새 몸체 원화를 생성한 작업이 아니다. 실행 파일은 여전히 `public/art/hero-slash-v1/`에 있고, 손 기준점은 `src/platform/hero-slash-anchors.json`에서 관리한다. 사용자 참고 그림은 이 문서 디렉터리 안에서만 관리한다.

구현·검증: [검 베기 v3](../../hero-slash-v3.md).
