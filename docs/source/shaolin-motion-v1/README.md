# 소림 지역 7종 대표 자세 시안 · 2026-10-04

일반 적 3종과 보스 4종을 각각 6개 대표 자세로 정리했다. 6종은 내장 imagegen으로 새로 생성·수정했으며, 봉 승려는 직전 수정본을 그대로 재사용했다. 총 7개 PNG, 42개 자세다. 생성 원본을 보존하고 실제 게임 에셋·런타임·배포는 변경하지 않았다.

전체 비교판은 [overview.png](overview.png), 원본을 읽는 비교 페이지는 [overview.html](overview.html)이다. 미리보기는 모든 인물에 동일한 50% 화면 배율을 사용했다. 인물이나 공격 칸의 외곽에 맞춰 개별 축소하지 않았다.

소림의 실제 게임 지역명은 폐사, 지역 인덱스는 4다. 일반 적은 brawler, staffguard, slinger다. 기존 지역 시트만 복제하지 않고, 실제 교체 경로인 identity-directions.png의 돌 투척 승려와 주지 외형도 참조했다. [manifest.json](manifest.json)에 슬롯·보스 ID·원본 경로·대표 자세·프롬프트 이력을 기록했다.

## 검토 결과와 한계

일곱 인물의 복장·도구·대표 자세를 육안으로 대조했다. 보행·준비·공격에서 같은 인물임을 유지하도록 생성했고, 무기별 동작과 목·몸통·골반 및 손·팔의 연결을 확인했다. 픽셀 단위의 동일성이나 모든 관절의 정확성을 인증한 것은 아니다. 머리·몸통 랜드마크를 프레임마다 따로 측정하지 않았으므로 ±5% 크기 기준 통과를 주장하지 않는다.

[alpha-review.json](alpha-review.json)은 1536×1024 원본의 512×512 가상 칸에서 알파 128 이상 외곽을 측정한 결과다. 선택한 42칸 모두 해당 기준에서 칸 경계에 닿지는 않지만, 최소 여백은 권갑 31·봉 16·투척 47·공허 12·도원 18·불명 36·무진 12픽셀로 **일부 칸은 목표 24~32픽셀을 충족하지 않는다**. 게임 적용 전 공통 캔버스 확장·접지 좌표 확정이 필요하다. 무기 포함 외곽에 맞춰 공격 칸만 축소하는 처리는 사용하지 않는다.

봉 승려와 공허의 위치 수정본은 왼쪽 여백을 줄이거나 잘림을 만들어 채택하지 않았다. 도원의 위치 수정본도 최소 여백이 18→11픽셀로 줄어 원본을 선택했다. 해당 padding-attempt.png와 프롬프트는 검토 이력으로 남겼다. 무진의 첫 긴 선장은 인접 칸을 침범해 제외했고, 전체 인물 크기 수정과 공격 위치 수정 후 경계 접촉이 없는 결과를 선택했다. 물리적인 선장 길이·방향별 원근의 최종 검수는 남아 있다.

도구의 원본 미리보기에서는 알파 0 픽셀의 숨은 갈색 RGB가 배경처럼 보일 수 있다. 브라우저 비교판은 실제 알파를 적용한다. 원본의 투명·부분 투명 비율은 검수 JSON에 기록했으며, 임의로 알파를 잘라 그림을 바꾸지 않았다.

이번 묶음은 남동 방향의 대표 원화 시안이다. 연속 중간 프레임, 전 방향 동작, 피격·사망, 보스 특수기 전체, 프레임별 손/무기 좌표 및 HP바 검증을 완료한 게임용 애니메이션은 아니다. 모든 항목의 상태를 draft-review, productionApproved: false로 기록했다.
