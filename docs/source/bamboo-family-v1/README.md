# 죽림 원본·제작 이력

죽림 단도 암살자·암기수·함정꾼과 청비·노개·연청·송월의 방향별 원화다. 각 인물은 정면·앞쪽 대각선·측면·뒤쪽 대각선·후면의 5시점, 시점마다 12자세를 갖는다. 실제 게임은 좌우 반전으로 8방향을 표시한다.

`provenance.json`은 모든 후보의 내장 `image_gen.imagegen` 원본 경로와 프롬프트를 기록한다. 원본은 보존하며 이 폴더의 PNG는 원본 바이트 그대로 복사한다. `generation-jobs.json`은 실제 선택한 파일·칸을 자세별로 기록한다. 교정 후보가 있다고 모두 사용하는 것은 아니다. `generation-requests.json`, `repair-requests.json`, `second-repair-requests.json`, `third-repair-requests.json`과 각 `.prompt.txt`는 생성 요청 이력이다.

자세 0~5는 대기·왼발 걷기·중간 걷기·오른발 걷기·작은 피격·사망이며, 6~11은 초기 준비·최대 준비·타격/발사·후속·회수·복귀다. 긴 봉의 원화는 6자세씩 분리한 넓은 칸에서 제작했다. 원본이 실제로 배치된 3×4·4×3·2×3 배열은 메타데이터로 명시한다.

무기와 몸은 한 원화에 그린다. 단도·검은 위/뒤 준비에서 앞/아래로 베고, 암기는 오른손 발사 뒤 빈손이 되며, 함정꾼은 왼손 장치를 유지하고 오른손으로 배치한다. 노개는 한 개의 연속된 봉을 양손으로 잡는다. 송월은 오른손으로 부채의 뿌리를 잡는다. 투사체·함정·공격 효과는 게임에서 별도로 표시한다.

`source-scan.json`은 선택 그림의 연결 영역·공유·잘림을 검사한다. `ground-anchors.json`은 원본의 발 좌표이며 `ground-anchor-overrides.json`은 직접 검토한 보정 근거다. `selected-art-audit.json`은 선택한 420그림의 해시와 원본/복사본 일치 확인, `encoded-atlas-review.json`은 패킹 뒤 RGBA 및 여백 검증이다.

내보내기는 원본 RGBA를 1:1로 복사한다. 인물별 공통 칸과 최소 32px 투명 여백을 사용하며, 무기 길이 때문에 몸을 칸에 맞춰 축소하지 않는다. 게임 배율은 모든 프레임에서 0.225다. 몸 비율·관절·손 소유권은 직접 시각 검토하며, 연결 영역이나 해시 검사가 해부학적 정확성을 보장하지는 않는다.
