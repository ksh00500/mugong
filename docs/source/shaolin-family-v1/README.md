# 소림 나머지 6종 원화

2026-10-04. 사용자 요청에 따라 승인된 소림 시범 원화를 참고해 imagegen으로 만들었다. 권갑 승려, 돌투척 승려, 공허, 도원, 불명, 무진 각각 5시점 × 12자세 = 60장, 합계 360장이다. 앞·앞대각·옆·뒤대각·뒤 시점을 그리고 좌우 세 시점을 반전해 8방향으로 사용한다. 봉 승려 60장은 `../shaolin-staff-v1`에 있다.

PNG 실제 크기는 1448×1086, 4열×3행이다. 요청한 2048×1536과 달라 실제 크기로 분리한다. 칸에 넘친 무기라도 원본에 남아 있으면 연결된 그림 전체를 회수한다. 원본 시트 바깥이 잘린 그림은 내보내기를 거부한다. 최종 선장 옆모습의 준비 자세 경계 잘림과 회수 자세 장식 누락을 다시 생성해 수정했다. 측면에서 앞대각 자세가 남은 도원·무진, 무진 뒤쪽의 등 뒤 손 위치도 별도 수정 프롬프트로 재생성했다. 이전 시도는 `attempts`에 남긴다.

12장 순서: 대기, 왼발 보행, 지나가기, 오른발 보행, 작은 피격, 엎드린 사망, 이른 준비, 충분한 준비, 접촉/놓기, 후속 동작, 일부 회수, 경계 복귀. 캐릭터·손·무기는 같은 그림이다. 무기 위치를 자동 추적하거나 그림 전체를 무기 경계에 맞춰 확대·축소하지 않는다.

`generation-jobs.json`은 기본 생성 작업, `*.prompt.txt`는 생성/수정 요청, `generation-provenance.json`은 선택된 생성 결과와 참조·수정 기록이다. 원화 생성 참조는 앞대각에 승인 시범 원화, 앞/옆/뒤대각에 선택된 앞대각, 뒤쪽에 선택된 뒤대각이다. 수정은 해당 방향 결과를 참조했다. 이미지를 수정한 뒤 선택된 원본 PNG와 기록을 함께 보존한다.

`ground-anchors.json`에는 원본 칸 기준의 지면 좌표 360개가 저장된다. 초기 좌표는 그림의 가장 낮은 발바닥 띠에서 제안하고, 사망은 누운 그림의 중심을 사용한다. 실제 방향별 게임 캡처에서 지면 정렬을 검토했다. 이 좌표는 명시적 편집 자료이며 게임은 자동 픽셀 분석을 하지 않는다.

`scripts/export-shaolin-family.mjs`는 기존 연결 그림 분리기를 사용하고 1:1 RGBA 복사만 한다. 각 캐릭터의 60장 중 가장 큰 그림에 최소 32픽셀 투명 여백을 더한 공통 칸으로 재배치한다. 소림 전체 게임 배율은 0.225다. `export-review.json`은 원본 SHA-256·모든 불투명 연결 픽셀 보존·지면 좌표·여백을 기록한다. 글로우/그림자 효과는 그림에 넣지 않고 전투 렌더러에서 별도로 그린다.

한계: 사망은 엎드린 한 자세를 페이드하며, 보스 행동 16종마다 별개의 전체 애니메이션을 그린 것은 아니다. 각 보스의 준비·접촉·회수 원화를 사용하고 여러 번의 접촉마다 타격 그림을 다시 노출한다. 기존 돌진·잡기·종·정면 방어·광역 동작의 판정과 효과는 그대로 따른다. 생성 그림의 자세별 원근·관절 차이는 남을 수 있으며, 고정 배율은 그 원화를 숨기는 체형 보정이 아니다.
