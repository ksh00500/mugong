# 서역사막·혈마전·제갈 추가31행동 제작 자료

기존 주요24행동/750논리 프레임은 `three-special-v2`에 보존한다. 새31행동/46접촉의 1,380논리 프레임은 새110물리 자세와 기존 준비·회수·READY의 명시적 조합이다. 1,380장의 독립 원화를 생성했다는 뜻은 아니다.

- `preflight.json`: 현재 실제 키트와 기존24행동을 대조한 사막10·혈마전11·제갈10행동 및 접촉 시간.
- `contact-jobs.json`: 22공격 자세 × 원본5시점, 시트마다 남향 READY를 공통 크기 기준으로 포함한다.
- `generated/*.prompt.txt`: 내장 imagegen에 보낸 실제 프롬프트. 원본22본과 교정7본의 PNG는 제작용 외부 에셋 묶음에 보관한다.
- `references/`: 현재 적용된 기본 READY5시점과 넓은 셀 안내판. 제갈 앞사선 교정본을 입력한다.
- `selection.json`: 선택 원본22시트와 새110자세의 수동 발 중심. 발타 왼손v3·연살 왼손v2·소홍 역횡격v3·제갈현 역횡격v3를 선택한다.
- `export-review.json`: 각 선택 셀의 SHA256·원본 영역·발 좌표·시트 공통 제작 계수와 46접촉의 6단계 조합.
- `boards/`: 12인물의 READY/모든 새 접촉을 같은 배율과 접지선으로 비교한 로컬 그림.

발타 정면 장타의 공격 손, 연살 왼주먹의 공격 손, 소홍 후면의 왼손 부채, 제갈현 정면·앞사선의 오른손 깃털부채를 재교정했다. 초기 후보와 실패 교정본도 보존한다. 생성 후 손 소유·카메라·몸 비율을 읽어 선택하며, 생성 요청의 성공을 미술 검토 완료로 취급하지 않는다.

시트의 남향 READY와 기존 남향 READY 높이로 하나의 제작 계수를 정하고, 그 계수를 동일 시트의5시점에 적용한다. 가로/세로 비율을 유지하고 개별 자세에 맞춘 축소는 하지 않는다. 따라서 출력은 원본 RGBA1:1이 아니다. 생성 원본의 배경 알파0을 확인해 색상 키 제거 없이 보존했다. 연결된 이웃 인물이나 잘린 실루엣은 내보내기에서 거부하고, 포장한 각 자세 둘레에 실제32px 투명 여백을 둔다.

장화 기준점은 비교판에서 110개를 수동 저장했다. 특히 아래로 향하는 칼끝·창끝을 발로 잡지 않게 고쳤다. 런타임은 원화를 다시 분석하거나 자세별 크기를 맞추지 않고 고정0.225와 저장된 발점을 사용한다. 각 보스 HP바는 기본·주요·추가 자세 전체의 최대 높이로 고정한다.

재현: `prepare-three-complete-v3.mjs` → `prepare-three-complete-contacts-v3.mjs` → 내장 imagegen → 선택 교정 → `export-three-complete-v3.mjs` → `three-complete-boards.mjs` → `three-complete-review.mjs`. 최초 접지 교정 도구 `ground-three-complete-v3.mjs`는 한 번 적용하며 이후에는 저장된 `selection.json`을 사용한다. Node22의 `--experimental-strip-types`, Sharp용 `MUGONG_SHARP_PATH`가 필요하다. 원본·선택 파일은 검토 없이 덮어쓰지 않는다.
