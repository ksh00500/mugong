# 설산 원화 제작

설산 창 돌진병·빙술사·궁수, 설원창객 목진·빙잠녀 설란·백설노괴·빙궁주 한설의 7종을 제작한다. 각 인물은 정면·우전방·우측면·우후방·후면에서 대기·걷기3자세·작은 피격·쓰러짐·준비2자세·타격·후속·회수·복귀의 12그림을 갖는다. 총 목표는 420그림, 패킹 결과35시트다.

긴 창은 주로 이동과 전투를 각각 넓은2×3원화로 분리하고 나머지는3×4원화로 제작했다. 창병의 최종 정면은 크기 통일을 위해12자세를 한3×4원화에 다시 제작했다. 개별 수정 원화는 선택한 실제 셀 또는 직사각형을 기록한다. 인물과 무기를 프레임마다 축소하지 않고 원본 픽셀을 유지하며, 칸은 인물별 최대 동작에 맞춰 넓힌다. 게임 배율은 공통0.225, 패킹 여백은 최소32px다. 접지점은 원본 좌표로 저장한다. 원화 단계의 신체·무기 비율 오류와 칸 접촉은 image_gen.imagegen 수정 원화로 교정한다.

창은 한쪽 창날·반대쪽 평평한 자루 끝과 두 손을 유지한다. 활은 왼손 활·오른손 시위다. 빙술사는 왼손 구체·오른손 시전, 백설노괴는 오른손 장타, 한설은 오른손 부채를 아래·앞으로 휘두른다. 흰 모피는 중립 조명이며 별도 발광·입자·잔상을 원화에 포함하지 않는다.

`provenance.json`은 생성 도구와 보존된 최초PNG를 기록한다. `generation-jobs.json`은 실제 사용할 원화·자세·셀을 기록한다. 후보와 선택된 원화는 구분하며, 현재 진행은 `generation-status.json`과 `source-scan.json`에 남긴다. 게임 적용·검증 완료 여부는 그 파일의 상태를 확인한다.

설원창객 목진의 게임 ID는 `mokjin`이다. 제작 시 사용한 `mujin-*` 파일명은 보존하며 소림 방장 `mujin`의 원화와 혼용하지 않는다. 프레임 캐시는 원화 텍스처까지 구분한다.

최종 결과와 범위는 [게임 적용 기록](../../snow-family-v1.md), 자동 검사·직접 시각 검토는 [검증 기록](../../verification/snow-family-v1/README.md)에 나누어 남긴다. 로컬에만 적용하며 실제 사용자 저장을 변경하지 않는다.
