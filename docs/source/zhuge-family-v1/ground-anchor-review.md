나머지 저장 좌표는 원화별 최하단 띠를 이용한 초기 제안이다. 전체 방향의 보행·준비·타격·회수 실제 합성 캡처에서 지면 배치를 검토했다. 인체 부위의 자동 의미 인식을 구현하거나 모든 발 좌표를 수동 측량했다는 뜻은 아니다. 런타임은 저장된 좌표만 사용하고 이미지 외곽을 재탐색하지 않는다.

진괄의 공격 원화는 이후 v2로 교체했다. 위 표의 진괄 두 항목은 이전 기록이다. 현재는 다섯 시점 30장 모두 부츠 기준으로 검토한 `scripts/apply-jingwal-attack-v2.mjs`의 좌표를 사용한다. 새 원본은 3×3 격자이며 최종 좌표·선택 원본 셀은 `ground-anchors.json`과 `generation-jobs.json`에 저장한다. 원본의 칸 크기가 정수로 나누어지지 않을 때 각 경계의 내림값을 사용하며 그림 자체는 리사이즈하지 않는다.
