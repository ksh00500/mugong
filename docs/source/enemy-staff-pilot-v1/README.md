# 소림 일반 봉 승려 시안 · 2026-10-04

최신 수정본은 `staff-monk-six-poses-v3.png`, 비교판은 `preview-v3.png`다. 내장 imagegen 편집으로 3번 준비 자세를 허리 높이에서 봉을 끌어당기는 자세로 다시 그렸다. 목 뒤로 봉을 넘기는 자세를 없애고, 두 손의 직접 그립·팔꿈치·어깨와 목·몸통·골반의 연결을 함께 수정했다. 해당 프롬프트는 `correction-3.prompt.txt`다. 나머지 다섯 자세는 육안으로 대조했으며 픽셀 단위의 완전 동일성을 주장하지 않는다. v1·v2는 보존했다. 아래 v1의 프레임 측정·미승인 항목은 당시 기록이고, v3도 게임에는 적용하지 않았다.

v2에서는 3번의 톤파처럼 돌출된 손잡이를 제거하고 일자 나무봉으로 수정했으나, 준비 자세의 목·몸통·팔 연결이 부자연스러웠다. 무기 형태만 확인해서는 충분하지 않으므로 다음 시안 검토에도 관절 연결과 무게 지지 여부를 포함한다. 해당 단계의 프롬프트는 `correction-2.prompt.txt`다.

기존 소림 2행의 회색 도복·흰 깃/허리띠·나무봉 승려 한 명을 내장 imagegen으로 제작했다. 게임 교체와 배포는 하지 않았다.

- 선택 시안: `staff-monk-six-poses-v1.png` (1536×1024, RGBA).
- 원본 생성 프롬프트: `prompt.txt`. 크기·배경 수정 프롬프트: `correction-1.prompt.txt`.
- 참조: `docs/source/hostile-consistency-v3/region-4-directions.png`의 두 번째 행.
- 구성: 3열×2행, 각 가상 칸 512×512. 대기·보행·준비·횡 휘두르기·앞 찌르기·회수의 대표 자세 6개. 연속 중간 프레임 전체는 아니다.
- `preview.png`는 독립 브라우저가 원본의 알파를 적용해 밝은 배경에 렌더한 비교판이다. 원본 RGBA를 편집하지 않았다. 생성 이미지 도구 미리보기에는 알파 0인 픽셀의 숨은 갈색 RGB도 배경처럼 보였다. 파일에서는 전체 픽셀의 약 84.8%가 알파 0이다.

제작 기준의 완전한 승인본은 아니다. 알파 128 이상 기준 여섯 칸의 인물/봉 외곽은 각각 `[129,151,427,437]`, `[134,153,430,442]`, `[148,165,388,437]`, `[97,125,488,390]`, `[124,137,494,392]`, `[140,118,419,392]`이다. 가장자리 접촉과 다른 칸 침범은 없지만, 횡 휘두르기·찌르기 오른쪽 여백 24·18픽셀은 목표 32픽셀보다 좁다. 몸 높이도 처음 요청한 약 210픽셀보다 크다. 발 위치와 해부학 크기의 정확한 기준 좌표는 아직 승인하지 않았다.

몸의 원본 비율을 유지하는 공통 배율·프레임 좌표 처리를 거쳐야 실제 게임에 넣을 수 있다. 칸마다 무기 포함 외곽에 맞춰 따로 리사이즈하는 방식은 적용하지 않았다. 생성 원본 두 시도와 프롬프트를 보존했다.
