# 마지막 교정 원화의 접지 검토

2026-10-05. `final-accepted.json`의 20자세만 교체했다. 기존 원화의 검토 좌표는 유지하고, 교체 원화는 새 발 좌표를 저장한다. 자동 런타임 추적이나 자세별 배율 보정은 하지 않는다.

- 소홍 정면 6~11: 가장 아래 지지발을 확인했다. 부채는 발 높이보다 위이며 부채 손이 바뀌지 않는다.
- 소홍 뒤 대각선 6~10, 복귀 11: 지지발과 긴 치마 끝을 확인했다. 11은 경계가 온전한 기존 복귀 그림을 선택했다.
- 소홍 후면 6~9: 치마 아래 지지발, 북향 머리와 부채 쪽을 확인했다. 기존 회수/복귀 10~11은 유지한다.
- 소홍 측면 7: 기존 초기 준비 6과 다른 최대 준비 그림이다. 부채의 팔과 빈손을 분리한다.
- 연살 후면 4: 원래 걷기 1 대신 새로운 양발 고정의 작은 피격 그림을 사용한다. 첫 행 가운데를 3×3의 셀1로 선택한다. 보스 공격 중에는 이 그림으로 전환하지 않는다.
- 적천 측면 8: 독립 1086×1448 원화의 실제 양 부츠 사이 지면 `[551,920]`을 수동 지정했다. 칼끝·망토를 발로 취급하지 않는다. 기존 후속 9는 별도 그림으로 복원한다.

전체 연결 픽셀은 배율 변경 없이 1:1 패킹하고 전달 셀 바깥 32픽셀 이상 투명 여백을 유지한다. 생성 시트의 모든 그림을 채택하지 않고 지정한 자세만 사용한다. 자동 경계 검사는 머리 치수나 모든 관절의 자연스러움을 인증하지 않는다.
