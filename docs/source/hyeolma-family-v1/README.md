# 혈마전 원화 출처

2026-10-05. `image_gen.imagegen` 내장 도구로 일반 적 3종·보스 4종의 방향별 원화를 제작한다. 원본 PNG와 실제 프롬프트는 이 폴더에 보존한다. `provenance.json`에는 도구가 반환한 원본 경로와 프로젝트 사본을 연결한다.

혈도병·혈영 암살자·혈지 술사·혈도객 적우·혈마제자 연살·홍의마녀 소홍·혈마교주 적천. 일반 암살자는 실제 돌진 공격에 맞는 단검, 혈지 술사는 실제 술법에 맞는 손 동작을 사용한다. 기존 지역 원화는 외형 참고이며 다른 지역 원화는 그림체 참고다.

각 인물은 앞·앞오른쪽·오른쪽·뒤오른쪽·뒤의 5시점과 각 12자세를 갖는다. 기본 시트는 3열×4행이며 순서는 대기/왼걸음/중간걸음/오른걸음/작은 피격/사망/준비초기/준비최대/접촉/후속/회수/대기복귀다.

`generation-jobs.json`은 실제 선택한 자세별 원본을 기록한다. 사용하지 않은 수정 시트가 존재할 수 있다. 그림을 생성한 뒤 자동으로 채택하지 않으며, 잘림·이웃 연결·카메라·손 연결을 확인한다. `source-scan.json`은 선택된 그림의 연결/외곽 검사를, `export-review.json`은 선택 원본 SHA256과 1:1 패킹을, `encoded-atlas-review.json`은 저장된 WebP의 투명 여백을 기록한다.

캐릭터와 무기는 한 장의 원화다. 런타임은 저장된 발 좌표와 배율 0.225를 사용하며 자세마다 몸이나 무기에 맞춰 확대·축소하지 않는다. 프레임은 원본 RGBA를 1:1 복사하고 최소 32픽셀 투명 여백을 둔다. 생성된 그림의 신체 치수가 정확한지는 자동 연결 검사만으로 증명할 수 없으므로 실제 화면을 별도로 검토한다.

최종 선택은 53개 원본 시트의 420개 독립 그림을 420개 프레임에 사용한다. 명시적인 poseReuse는0개이며 마지막 교정으로20자세를 교체했다. 연살 뒤 시트의 실제3/4/4배치는 poseSourceCells로 선택한다. selection-summary.json에 최신 원화 수와 남은 작업0개를 기록한다.

이전에 생성 한도로 중단됐던 소홍 정면·뒤 대각선·후면, 연살 후면 피격, 적천 측면 타격을 교정했다. 소홍 측면 최대 준비도 별도 그림으로 바꿨다. 정확한 채택 자세는 final-accepted.json, 이전 선택은 generation-jobs.before-final.json과 selection-summary.before-final.json이다.

잘못된 손 연결의 초기 수정안, 불투명 배경의 combat-v9, 과대한 독립 타격v11, 옆 그림과 연결된 inward-v10 등은 채택하지 않는다. 사용되는 정확한 PNG와 셀은 generation-jobs.json이 기준이다. 마지막 프롬프트는 각 *.prompt.txt와 provenance.json에 연결하고 내장 도구의 원본 반환 경로·프로젝트 사본을 보존한다. 원본 이미지를 외부 CLI/API로 생성하지 않았다.

발 검토는 final-ground-review.md, 원본 픽셀 복사·최종 WebP 여백 검사는 export-review.json과 encoded-atlas-review.json이다. [최종 적용·자동 검사·시각 검토](../../verification/hyeolma-family-v1/README.md).
