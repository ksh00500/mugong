# 독무곡 원화 작업

일반 적: 암기수, 독창병, 독폭탄술사. 보스: 청린사왕, 독의 묵칠, 오독낭자 연화, 만독곡주 사공염.

각 인물은 다섯 시점(정면·우전방·우측·우후방·뒤), 시점마다 12자세를 갖는다. 좌우 반전으로 팔방을 표시한다. 원본 그림 안의 손·무기·관절을 함께 그리며, 런타임 무기 추종이나 자세별 자동 크기 맞춤을 사용하지 않는다.

원화는 기본 제공 `image_gen.imagegen`으로 생성·수정한다. 각 생성 명령은 `.prompt.txt`, 원본 경로는 `provenance.json`, 실제 선택은 `generation-jobs.json`에 남긴다. 카메라를 무시한 초기 결과는 사용하지 않는다. 암기수의 투척 뒤 손에 바늘이 남던 두 프레임은 `needle-release-v2.png`에서 선택한다.

원화 배열은 3열×4행이다. 순서는 대기·왼발 보행·중간 보행 / 오른발 보행·미세 피격·사망 / 준비 시작·최대 준비·접촉 또는 발사 / 후속 동작·회수·대기 복귀다. 투척은 발사 이후 손을 비우고, 창은 같은 자루를 양손으로 잡으며, 검은 내려 베기, 부채는 손잡이 회전, 지팡이는 밀기·시전으로 구분한다.

내보내기는 연결된 인물의 RGBA를 1:1로 독립 칸에 복사하고 최소 32픽셀의 투명 여백을 둔다. 그림을 확대·축소·왜곡하지 않는다. 인물별 공통 칸과 고정 배율 0.225를 사용한다. 발 접지점은 원화별 검토 좌표를 저장한다. HP바는 살아 있는 모든 자세의 최고점에 여유를 둔 인물별 고정 위치를 사용한다.

기존 보스 18개 행동의 판정·투사체·독술은 유지한다. 18개 행동 각각을 위한 별도 원화 세트는 이번 범위가 아니며, 인물별 기본 공격 주기를 실제 접촉 시점에 맞추어 표시한다. 연격은 각 접촉마다 타격 그림을 보여준다.

최종 선택은 원본 35시트와 수정 원화 12개를 사용한다. 다른 그림과 연결되거나 배경이 들어간 실패한 수정안은 선택하지 않는다. 긴 무기의 잘림과 준비 도중 무기 손이 바뀌는 자세 17개는 `selected-corrections.json`에 기록했다. 묵칠 뒤쪽 준비용 별도 원화는 인접 행을 비워 분리했으며 그 빈 행을 게임에서 사용하지 않는다.

원본 검사는 `source-scan.json`·`source-review.json`, 원본 픽셀과 여백 보존은 `export-review.json`, 저장 WebP의 실제 패딩은 `encoded-atlas-review.json`에 있다. 발 좌표는 `ground-anchors.json`이고 수동 접지 수정은 `ground-anchor-overrides.json`에 남긴다. [완료한 검증과 한계](../../verification/dokmu-family-v1/README.md).
