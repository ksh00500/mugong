# UI 최우선 수정 U01–U05

2026-10-20. [전체 감사](ui-ux-audit-v1.md)의 최우선 다섯 항목에 대한 사용자 승인 구현이다. 기준 aa1fc18, 작업 브랜치 `codex/ui-priority-v1`. 로컬 http://127.0.0.1:5205/ 는 `dist-ui-priority-v1`을 제공한다. 개인 서버 배포/main 병합은 이번 범위가 아니다.

| 항목 | 변경과 이유 |
| --- | --- |
| U01 HP 숫자 패치 | 플레이어/보스 숫자를 체력 막대 위의 별도 줄에 배치했다. 개별 먹색 사각 바탕과 이중 그림자를 제거해 흰 피해 잔량과 겹치지 않게 했다. 플레이어는 한지 위 먹색 글씨, 보스는 기존 먹색 이름표 위 밝은 글씨다. |
| U02 작은 핵심 수치 | HP11→15px, 큰HUD16px. 경험치11→12px, 큰HUD14px. HP 레이블12px, 보스 국면 최소12px. 긴 사용자 이름은 한 줄 말줄임과 기존 전체 이름 title을 사용해 수치를 아래로 밀지 않는다. 위험 표시는 `체력 !`와 전체 접근성 이름을 사용한다. |
| U03 모집 출전 잘림 | 창을 제목/닫기·후보·이름/출전의 세 영역으로 나눴다. 중앙 후보만 스크롤하고 필수 행동은 고정 노출한다. 짧은 화면은 초상화/간격을 조정하며 전체 창 축소나 필수 행동 숨김은 없다. |
| U04 성장 설명 가림 | 성장 화면에만 QuickDetails의 inline 배치를 사용한다. 설명을 카드 옆 공간에 놓고 작은 폭에서는 아래 영역으로 옮긴다. Shift/명시적 버튼/Esc와 키보드 선택·1초 오입력 방지·자동 저장을 유지한다. 가방/전투의 기존 floating 설명은 유지한다. |
| U05 로비 복귀 오류 | Phaser.Game 해제 시 카메라가 장면 cleanup보다 먼저 사라지는 경우를 처리한다. 살아 있는 카메라는 기존 흔들림 오프셋을 되돌리고, 이미 해제되었으면 지역 피드백 상태만 정리한다. 반복 cleanup도 안전하다. |

수정은 소유 CSS(`combat-hud.css`, `ui/growth.css`, `ui/recruitment.css`, `ui/quick-details.css`)에서 관리한다. Legacy에 덮어쓰기를 추가하지 않았다. React 변경은 기존 컴포넌트·구독·초점 처리를 유지했고 새 외부 라이브러리/전역 상태/매 프레임 React 렌더링을 추가하지 않았다.

실제 HP 계산·흰 잔량 시간·카메라 강도/동작 감소·전투 입력·보스 밸런스·원화 픽셀·저장 형식은 유지한다. 사용자 브라우저의 실제 저장은 읽거나 교체하지 않았고, 검사는 독립 Playwright 컨텍스트의 테스트 저장만 사용했다.

[이번 자동 검사와 직접 시각 검토](verification/ui-priority-v1/README.md). U06–U24의 버튼/입력/수치 통일·가방·상인·설정·로딩/복구/결과·미술 마감은 후속이다.
