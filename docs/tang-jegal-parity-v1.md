# 개인 레이드 당문·제갈 행동 교정

2026-10-24. 개인 무인의 실제 강호 무공 설명과 레이드 행동을 맞췄다. 표준 친선/순위전·체험은 기존 규칙을 유지한다. [공통 효과 교정](personal-effects-v1.md)에 이어지는 두 무공의 행동 이식이며, 다른 6무공까지 완성했다는 뜻은 아니다.

| 개인 무공 | 현재 동작 |
| --- | --- |
| 당문 기본 | 3단계부터 A 1발/B 3발 교대. 공격력 계수0.65, B 각 발0.6배, 각도 간격0.18rad, 속도680, 반경12, 수명0.9초×사거리 보조 |
| 당문 중독 | 한 공격·한 적당 A 1회/B 최대2회 적용. 세 발의 직접 피해는 각각 들어간다. 다른 시전자/공격과 기록을 분리하고3초/최대64개로 제한한다. 기존 최대3/5중첩·0.5초 독 피해는 유지 |

강호의 진 배치/궁극은 공통 순수 함수로 추출했고 원래 결과를 유지했다. 기본 공격은 실제 강호 tick과 투사체 수·피해·각도·출발점·속도·크기·수명을 비교했다. 보스 밀침/끌기/감속은 넣지 않아 제어 면역을 유지한다. 현재 레이드는 보스 하나이므로 향후 잡몹의 당문 전독은 여전히 미구현이다.

새 공격의 원화는 기존 건진·곤진·독안개 아틀라스를 재사용한다. 실제 설치/폭발만 표시하며 이 행동에 조준선·판정 원·부채꼴 미리보기를 추가하지 않았다. 기존 온라인 보스의 예고 도형은 이번 변경 범위가 아니다. 진은 배경보다 위·인물보다 아래에 그린다. 움직임 줄이기에서는 맥동 밝기 변화/독 폭발 확대를 끈다. 실제 판정 크기를 장식 애니메이션에 따라 바꾸지 않는다.

선택 필드로 진의 잔여 시간/회수와 투사체/중독 회수 기록을 방 사본에 직렬화한다. 기존 DB 스키마3과 이전 필드 없는 사본을 유지한다. 사망·수명 만료·귀환·새 층/종료에 진을 버리고, 다음 층에 이전 중독 기록을 넘기지 않는다. 같은 틱 접촉은 기존 협동 엔진의 동시 정산이므로 강호의 순차 판정 전체와 같다는 뜻은 아니다.

[검증·수치 변화·로컬 적용](verification/tang-jegal-parity-v1/README.md). 다음은 화산·무당을 포함한 나머지6무공의 개별 연계/궁극 정합성이다. 개별 행동을 마친 뒤 레이드 난이도·사람 플레이를 다시 검토한다.
