## 현재 동작

`src/domain/enemy-tactics.ts`를 일반 적·보스의 접근 상태에 연결했다. 대기 중 이동과 공격 진입을 개선하며 준비·타격·회복 상태의 공격 판정은 기존 상태 머신을 유지한다.

- 궁수·투척자: 선호 사거리 주변에서 횡이동하고 근접 시 후퇴한다. 벽으로 후퇴하려 하면 벽을 따라 중앙 쪽으로 이동한다.
- 암살자·기마병: 접근 시 측면 이동 비중을 높이고 공격 후 짧은 판단 대기 뒤 다시 배치한다.
- 궁수·암기·암살자·검객·빙원 추격자·환도 투척자: 접근 상태에서 0.28초 이내에 충돌할 가시 투사체에만 반응한다. 이동 속도 상한을 지키며 준비·공격 중에는 자동 회피하지 않는다.
- 원거리·측면 역할: 실제 피해가 있는 활성 제갈 진에서 벗어나려 한다. 모든 적이 모든 진을 완벽하게 피하는 정책은 사용하지 않는다.
- 보스 40종: 개인 패턴 목록을 유지하며 현재 거리에서 사용할 수 있는 초식을 선택한다. 허공 근접 공격을 줄이고 원거리·돌진·소환을 활용한다. 기존 개인 기믹과 반응 행동은 유지한다.
- 일반 적은 주변의 준비/타격자가 3명이면 기다린다. 공격 타이밍을 엇갈리게 하는 제한이며 보스에는 적용하지 않는다.
