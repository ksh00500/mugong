# 서역사막 원화 적용

2026-10-05. 현재 계정에서 기본 원화 40장을 생성하고, 아르칸 뒤 대각선의 긴 곡도에 추가 공간을 확보한 4자세 시트 1장을 더 생성했다. 선택된 원본과 교정 프롬프트는 `docs/source/desert-family-v1/provenance.json`에 기록했다.

## 게임에서 바뀐 부분

일반 적은 기마병·암살자·환도병의 독립 원화를 사용한다. 보스는 아사르·나야·발타·아르칸으로 구분하며 일반 환도병이 나야의 슬롯을 빌려 쓰던 연결을 제거했다. 보스 ID를 역할보다 우선한다.

각 캐릭터는 5시점 × 12자세, 총 420프레임이다. 검토한 우측 시점과 좌우 반전으로 8방향을 지원한다. 기마병은 말·기수의 이동과 공격을 각각 넓은 원본에 그렸다. 인간형은 원화에 무기와 손을 함께 그렸으며 런타임 무기 추적이나 Mesh 변형을 사용하지 않는다.

전체 원화는 RGBA를 유지한 1:1 패킹 후 고정 배율 0.225로 표시한다. 공격의 무기 사각형에 맞춰 몸을 확대하거나 축소하지 않는다. 프레임 사방에는 최소 32픽셀 투명 여백을 두었다. 기마병의 지면 기준은 발굽이며, HP바 높이는 살아있는 모든 자세의 최고점에 16화면픽셀 여유를 더한 고정 값이다.

뒷면 준비 자세에서 무기가 왼손으로 넘어간 암살자·환도병·아사르를 교정했다. 북쪽 기마병 접촉 자세는 칼끝이 옆 대신 전방을 향하도록 수정했다. 아르칸의 잘리는 칼은 넓은 추가 시트에서 복원하고 네 후반 자세의 원본 신체 크기를 함께 교정했다.

## 검증 범위

원화 검사: 원본 연결 요소의 공유·중복·외곽 잘림, 패킹 RGBA 보존과 인코딩된 투명 여백을 검사한다. 원본의 관절·무기 소유 손·카메라·크기는 생성 결과와 브라우저 캡처를 눈으로 검토했다. 신체 크기나 해부학 전체를 자동으로 인증한 결과는 아니다.

게임 검사: Canvas/WebGL × 일반/줄인 움직임에서 7종 × 8방향 × 7상태 × 5진행도를 렌더한다. 배율·방향·반전·HP바 간격을 확인하고 보스 18패턴의 접촉 시점에서 피격이 공격 자세를 덮지 않는지 검사한다. 실제 시뮬레이션으로 기마병·암살자의 타격과 환도병·나야의 환 발사 시점도 확인한다.

기본 시트는 캐릭터별 대표 공격 동작이다. 보스의 모든 패턴에 서로 다른 전용 원화를 만든 것은 아니며, 진각·모래 자세·근접 환격 등은 기존 판정과 접촉 시계를 유지하면서 기본 자세를 공유한다. 패턴별 시각 구분은 추가 개선 항목이다.

실제 사용자 저장은 변경하지 않는다. 브라우저 테스트는 독립 컨텍스트의 테스트 저장만 사용한다. 로컬 검토 화면: `http://127.0.0.1:5173/art/desert-family-v1/review.html`.
