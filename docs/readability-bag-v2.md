# UI 확대와 가방 개선 · 2026-09-29

사용자 요구에 따라 이전 글자 크기의 150%를 기본으로 적용했다. 웹페이지 전체에 `transform:scale()`이나 강제 브라우저 배율을 사용하지 않는다. 로비·전투 HUD·성장 선택·대화상자·설정·가방·창고·페이지 이동의 글자 토큰을 함께 변경했다. 기존 그림·게임 규칙·사용자 저장은 유지한다.

| 요소                | 이전 |  현재 |
| ------------------- | ---: | ----: |
| 기본 본문           | 14px |  21px |
| 보조 글자           | 12px |  18px |
| 창 제목             | 24px |  36px |
| 기본 행동 버튼 높이 | 44px |  66px |
| 출전 버튼 높이      | 76px | 114px |
| 가방 물품 행동 높이 | 36px |  54px |
| 기본 그림 아이콘    | 24px |  36px |

화면 공간은 탭과 재배치로 확보했다. 가방은 일반 10×8 또는 무장 4×7 격자와 큰 물품 상세를 사용한다. 전리품·정리판·창고는 별도 탭에서 한 페이지 2/4/6개 물품을 크게 보여준다. 사용 칸 수·전체 칸·남은 칸·사용량 막대와 선택 물품의 점유 크기를 표시한다. 무인 정보는 상태·무공·착용 장비를 분리한다. 성장 카드는 간결한 특성을 표시하고 원래 전체 설명은 도움말·접근성 설명에 둔다. 좁은 창에서는 후보를 페이지로 넘긴다.

드래그는 잡은 칸을 보존하며 그림 미리보기, 수납 가능/불가 경계, 영역 탭 이동을 지원한다. 선택→빈 칸 클릭, R 회전, 방향키와 Enter가 대안이다. 초점이 저장 중 비활성화나 숨겨진 영역으로 빠지는 문제를 고쳤다. 창을 닫으면 열었던 버튼으로 돌아간다.

## 자동 검사

- TypeScript와 Vite 프로덕션 빌드 성공. 도메인·저장·번역 검사 30개 통과.
- 독립 Playwright 컨텍스트에서 로컬 브라우저 26개 시나리오 통과. Daytona 전용 검사는 로컬 실행에서 제외한다.
- 1440×900, 1366×768, 1093×614 및 기존 좁은 화면 회귀 검사. 한국어·영어·일본어·간체·번체의 로비·설정·생성·가방에서 페이지/필수 행동 넘침 검사.
- 실제 마우스 드래그의 잡은 칸, 충돌 시 미이동, 회전 후 키보드 수납, 착용 시 점유량 갱신, 약 사용, 창고 보관 및 탭을 거치는 드래그 인출, 폐기 취소·확인, 닫기 초점 복원 검사.

## 시각 검토
