# 무공 설명·현지화·전리품 사용

2026-09-29. 무공 설명을 별도 창으로 열던 동선을 작은 설명 패널로 바꾸고, 전투 후 전리품 소모품을 바로 사용할 수 있도록 수정했다.

## 구현

- 성장 카드·전투 부채·가방 무공 연결·로비 무공에 마우스를 올리면 설명을 표시한다. Shift를 누르면 가리키거나 초점을 둔 무공, 없으면 현재/첫 보이는 무공을 표시한다. 성장의 `설명 Shift` 버튼은 같은 패널을 고정한다. 가방과 로비의 무공 행도 Tab으로 하나씩 읽을 수 있다.
- 새 설명은 모달을 만들거나 초점을 이동시키거나 전투를 멈추지 않는다. Esc는 설명부터 닫는다. 입력란·숨겨진 정보·다른 창 뒤에서는 열지 않는다. 화면 크기나 언어가 바뀌면 위치를 다시 맞추고 숨겨진 항목의 설명은 닫는다. 가방에서는 공간이 부족할 때 해당 무공의 옆으로 펼쳐 연결 버튼을 남긴다.
- 공격 배율·간격, 방어 조건·재사용, 반격 피해·충전, 회복, 궁극 개방 및 고급 삼재 효과를 실제 구현과 맞췄다. 반복 타격·지속 검진처럼 실제 동작과 다르게 읽히던 성장 문구를 수정했다. 전투 수치는 `src/domain/techniques.ts`에서 설명과 함께 사용하며 기존 밸런스는 유지한다.
- 약과 비급의 효과는 고정 35/20 대신 물품의 실제 품질별 `power`를 표시한다. 재료의 현재 용도, 검의 수납·연결, 장비의 효과를 짧게 설명한다. 창고 소모품에는 이동 안내, 만체력 약에는 사용 불가 이유를 설명 자리에 표시해 버튼이 밀리지 않게 했다.
- 전투가 끝나면 전리품에서 약·비급을 수납 없이 바로 사용한다. 한 번에 한 개만 소모하고 약은 최대 체력까지만 회복한다. 만체력·전투 중·창고 직접 사용은 거부한다. 비급으로 성장 선택이 생기면 성장 후 가방으로 돌아오며 결과 저장 완료를 확인한다.

## 문구·언어 검토

한국어·영어·일본어·중국어 간체·번체를 유지했다. UI·무공·물품·상태·저장 안내의 **406개 활성 소스 문구**와 **467개 전체 번역 키**를 검사했고 네 외국어 번역의 누락·빈 값·변수 불일치가 없었다. JSX 본문과 리터럴 템플릿, 저장 잠금 안내도 검사에 포함했다. [정적 검토 범위](verification/details-v4/copy-audit.json).

영어의 `1 warrior`, 무공 개수·보관 개수의 문장 순서, `1 cells` 같은 표현을 정리했다. 큰 수치는 로컬 숫자 형식을 사용한다. 플레이어가 지은 이름은 번역하거나 저장 값을 바꾸지 않는다. 브라우저 감지·수동 언어 변경·재시작·초기 로딩 안내는 기존 회귀 검사를 유지했다. 모든 번역에 대한 별도 원어민 감수를 의미하지는 않는다.

## 자동 검사와 시각 검토

- 단위 검사 **72개 통과**, 최종 TypeScript 검사·프로덕션 빌드 통과. 공개 캡처에서 발견한 좁은 영어 칸수 줄바꿈은 더 짧은 문구로 정리하고 별도 [최종 영어 검사](verification/details-v4/final-copy-local-result.json)를 통과했다.
- 전체 브라우저 실행은 **87개 통과, 공개 전용 4개 제외**였다. 새 설명의 제목을 후보 제목으로 세던 기존 검사 1개를 후보 카드만 비교하도록 수정했다. [초기 전체 기록](verification/details-v4/initial-full-result.json).
- 키보드 무공 행을 추가한 뒤 작은 가방의 기존 자식 숨김 규칙이 설명에도 적용되는 문제를 실제 계산 스타일로 확인했다. 설명 소유 CSS에 표시 규칙을 명시하고 해결했다.
- 최종 영향 범위 브라우저 검사 **16개 통과**. 세 해상도의 hover·Shift·고정·닫기, 전투 Q/E·Space와 설명 병행, 키보드 무공 이동·축소 시 닫기, 전리품 약·비급 직접 사용·개수·저장 복원·성장 후 가방 복귀, 5개 언어의 설명 및 넘침, 큰 글씨·고대비·기존 공격 성장 흐름을 포함한다. [최종 재검증](verification/details-v4/final-targeted-result.json).
- 두 실행의 각 검사항목에 대한 마지막 관찰 결과를 합치면 **89개 통과, 공개 전용 4개 제외, 미해결 실패 0개**다. 이는 새 전체 실행이 아닌 전체 실행과 영향 범위 재검증을 합친 결과다. [통합 결과와 항목별 출처](verification/details-v4/resolved-suite-result.json).

Playwright의 독립 브라우저 컨텍스트에서 실제 마우스와 키보드를 사용했다. 실제 사용자 저장을 초기화하거나 테스트 상태로 바꾸지 않았다. 자동 검사와 별개로 아래 캡처를 직접 읽어 선택 버튼·두 격자·설명창 위치·문구 줄바꿈·정보와 행동의 경계를 검토했다. 장시간 사람 플레이 결과나 접근성 인증을 주장하지 않는다.
