# 보스 이름표 위치 보정

2026-10-01. 철나한 도원 전투 화면에서 이름표가 중앙에서 벗어나고, 체력 숫자가 장식 프레임 하단에 걸친 문제를 수정했다.

## 변경

- 보스 이름표는 좌우 HUD 너비 차이와 관계없이 화면 중앙에 놓인다. 가방·일시 정지는 오른쪽 열을 유지한다.
- 이름은 프레임의 먹색 면 안에 놓고, 체력 숫자는 체력 막대 안에 표시한다. 이름과 막대를 별도 행으로 배치한다.
- 기존 HUD 그림에서 보스 전용 영역을 지정한다. 위쪽 빈 공간과 오른쪽 황동 장식을 클릭/텍스트 영역으로 취급하지 않는다. 체력 막대는 오른쪽 장식 이전에서 끝난다.
- 낮은 너비에서는 상태 HUD 아래로 이름표를 내려 간격을 확보한다. 넓은 화면에서는 상단 중앙이다.
- 예전 `.boss-panel`의 강제 패딩을 제거했다. 최종 배치 소유는 `src/combat-hud.css`, 그림 영역은 `src/ui/HudArtwork.tsx`다.

## 검증

최종 실행: 보스 이름표 9개를 포함한 관련 브라우저 검사 64개 통과. 단위 검사 243개 통과, TypeScript/Vite 빌드 성공. 한국어 큰 화면, 영어의 긴 이름, 800×600 캡처를 직접 열어 프레임과 체력 막대 사이 여백도 확인했다.

`tests/e2e/boss-nameplate.spec.ts`는 독립 브라우저의 테스트 저장으로 철나한 도원과 각 언어의 긴 보스 이름을 확인한다. 1920×1080, 1440×900, 1366×768, 1093×614, 800×600을 검사한다. 1093×614에서는 한국어·영어·일본어·간체·번체를 확인한다.

자동 검사는 화면 중심, 이름/체력 숫자의 프레임 내부 배치, 체력 막대와 황동 장식 사이 여백, 좌우 HUD 겹침, 런타임 오류를 확인한다. `docs/verification/boss-nameplate-v1/`에 전체 화면과 이름표 캡처를 보관한다. 별도로 캡처를 열어 그림의 실제 선과 여백을 검토한다. 실제 사용자 저장은 수정하지 않는다.
