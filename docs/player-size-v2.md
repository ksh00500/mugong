# 플레이어와 일반 적의 표시 크기 조정 · 2026-10-06

사용자가 50% 적용 후 플레이어가 적보다 작다고 보고 비슷한 크기로 맞추기를 요청했다. 공통 표시 배율을 0.5에서 **0.7**로 조정했다. 이전 화면보다 너비·높이가 40% 커지며, 50% 조정 전 기준으로는 70%다. 로컬 프로덕션 빌드에 적용했다. 이번 작업에서 공개 서버는 변경하지 않았다.

10개 지역의 일반 적 3종·5시점 대기 프레임의 표시 경계 높이를 비교했다. 지역별 중앙값은 약 72~83.5px이며 제갈은 78.1px다. 플레이어의 정면 기본 높이 110px에 0.7을 적용한 기준은 77px다. 경계 높이는 머리·의복·휴대 무기를 포함하며 해부학적 몸체 높이를 따로 인증한 값은 아니다. 일반 적을 기준으로 고정 배율을 정했고, 주변 적이나 동작마다 플레이어를 확대·축소하지 않는다. 원래 보스와 적 종류의 크기 차이는 유지한다.

외형 10종과 구형 저장 캐릭터, 몸체·6종 장착 무기·검광·그림자·표시상 공격 전진량에 공통 배율을 적용한다. 원본 이미지 비율, 발 기준점, 원화 선택, 손에 대한 무기 위치·각도를 유지한다. 이동 속도·공격 시간·범위·피해·피격 판정·저장 데이터는 변경하지 않았다.

Canvas/WebGL에서 외형 10종+구형 캐릭터 × 6무기 × 8방향 × 일반/움직임 감소 × 14자세·시점의 **29,568개 상태**를 1.0 배율의 기존 기준 자료와 비교했다. 몸체·무기의 너비/높이와 손 위치가 정확히 0.7배이고 원화·발 원점·반전·무기 각도가 유지됨을 확인했다. 4개 브라우저 검사와 관련 단위 테스트 28개, 타입 검사·빌드가 통과했다.

로컬 프로덕션 빌드는 1440×900, 1366×768, 1093×614에서 이동과 제갈 검토 페이지 조작을 검증했다(3개 통과). 직접 시각 검토는 Canvas/WebGL의 보라색 외형과 제갈 지역의 실전 화면을 확인했다. 모든 상태를 육안으로 개별 검수했다는 의미는 아니다. WebGL batch 0 캡처에는 테스트 일시정지 창이 겹쳤으므로 크기 육안 판단에는 batch 1 캡처를 사용했다. 테스트 저장은 독립 브라우저 컨텍스트에서만 사용했다.
