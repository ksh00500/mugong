# 보스의 이동 사격 대응 — 2026-10-06

40종 공통으로 지속 후퇴·선회에 대응하는 보법을 추가했다. 기존 185개 행동과 개별 보스의 정체성을 유지하며, 소림 전용 원화 및 다른 지역의 기본 원화를 그대로 사용한다. 로컬 빌드 적용이며 공개 서버 배포는 별도다.

## 실제 변경

- 실제 위치 변화에서 이동 방향·속도를 관찰한다. 보스의 간격이 충분히 좁혀지지 않는 이동이 0.85초 누적되면 다음 접근 구간에서 대응한다. 공격/회수 중에도 관찰하지만 대응 행동이 공격을 끊지는 않는다.
- 0.32초의 짧은 발동 표시 뒤 최대 1.8초 전진 보법을 사용한다. 유형별 속도는 원거리/설치 혼합형 365, 권갑·도 410, 나머지 근접형 440이며 기존 분노 배율은 유지한다. 발동 사이 최소 5초를 두며 재접속으로 시계를 초기화하지 않는다.
- 현재 관찰된 이동 방향의 앞쪽으로 접근한다. 이동 목적지의 예측 변위는 최대 180으로 제한하고 전장 경계 안으로 제한한다.
- 준비 초반에는 보법을 이어가되 마지막 0.4초 또는 전체 준비의 45% 중 짧은 구간부터는 이동·조준을 고정한다. 실제 공격과 회수 중에는 보법이 중단된다.
- 추격에서 이어지는 짧은 직자·횡격은 최대 95의 전진 발걸음을 가진다. 해당 공격의 저장된 `pressure.advance`만 사용한다. 원래 돌진·투척·장판·진각은 이 발걸음을 적용하지 않는다. 무기 판정 범위·너비·접촉 시점은 같고, 발걸음 중 스치기만으로 접촉을 앞당기지 않는다.
- 후퇴 속도를 고려해 근접 공격 개시 거리를 좁힌다. 접근 정지 거리도 같은 기준을 사용해, 공격할 수 없는 거리에서 보스가 멈추는 상황을 피한다.
- 원거리 보스는 투사체 속도/거리 또는 장판 착탄 시간을 고려한 선행 조준을 쓴다. 최대 예측 변위는 260이며 마지막 준비 구간 뒤에는 방향을 갱신하지 않는다. 정상적인 340 이상의 이동을 순간이동으로 오인하던 관찰 상한도 수정했다.

플레이어 피해·사거리·공격 간격·이동 속도는 이번 작업에서 조정하지 않았다. 보스의 피격/제어 면역과 작은 반동, 큰 공격 뒤의 회수 빈틈은 유지한다.

구현: `src/domain/boss-pressure.ts`, `enemy-tactics.ts`, `boss-melee.ts`, `game.ts`, `model.ts`, `src/platform/save-validation.ts`.

## 비교의 의미와 한계

40보스 각각에게 같은 사각형 경로를 이동하며 실제 연결된 당문 Lv.1 암기를 발사하는 입력을 40초씩 실행했다. 사망 때문에 관측이 끊기지 않도록 테스트 체력만 매 스텝 120으로 유지했고 보스 체력은 크게 두었다. 지역의 시간 기반 증원은 제외했으며 보스 자신의 소환·설치·상태 효과는 유지했다. 실제 사용자 저장을 사용하지 않았다.

비교군은 **새 조준·공격 개시 거리 규칙은 공유하고, 보법 및 그에 연결되는 전진 발걸음만 끈 경우**다. 변경 전 전체 버전과의 비교나 인간의 승률 측정은 아니다.

| 측정 | 보법 비활성 | 보법 활성 |
|---|---:|---:|
| 같은 경로의 무피격 보스 수 | 20 | 11 |
| 40회 누적 피해 | 1387.196 | 1913.9424 |

39종에서 해당 경로의 보법 발동을 관측했다. 나머지 제갈현은 기존 진법·원거리 공격으로 피해를 주었으며 같은 경로에서 발동하지 않았다. 별도 단위 검사는 40종 모두의 발동 조건과 시계를 확인한다.

이 결과는 보스 대응을 추가한 1차 조정이다. 11종의 무피격 경로가 남았으며 고기민·다른 무공·궁극/방어를 포함한 인간 플레이의 최종 밸런스는 아직 확정하지 않았다. 모든 회피를 막거나 모든 보스의 명중을 보장했다는 뜻은 아니다.

## 검증

- 신규 단위 8개: 40종 발동·재사용, 일반 적 제외, 최종 예고/타격/회수 유지, 전진 발걸음 접촉, 측면 회피, 빠른 보행 관찰, 저장/잘못된 시계 거부, 이동 사격 비교.
- 전체 단위 1289개 중 첫 병렬 실행에서 1287개 통과, 기존 정점/번역 검사 2개는 5초 제한 초과. 번역은 단독 재실행 통과했고 기존 정점 검사는 같은 검증을 15초 제한으로 단독 재실행해 통과했다. 검증 조건이나 기대값은 완화하지 않았다.
- Canvas/WebGL 실제 전투 검사 2개 통과. 소림 4명의 보법·공격, 기본/특별 원화, 고정 0.225 배율, 자신의 HP바 간격, 저장 유효성, 페이지 오류 부재를 확인했다.
- TypeScript·Vite 빌드 통과. 최종 로컬 빌드 파일은 `dist/`에 반영됐다.
- 로컬 프로덕션 조작 3개 통과: 1440×900, 1366×768, 1093×614. 실제 이동/공격 입력으로 발동하고, 일시정지 저장에 재사용 시계가 남으며 새로고침 후 전투가 복원된다. 가로 넘침과 페이지 오류는 없었다. 실제 전투 캡처도 직접 검토했다.

로컬 프로덕션 조작 검사는 사용자 저장과 분리된 브라우저에서 WASD 후퇴·마우스 공격·일시정지 저장·새로고침을 사용한다. 첫 검사에서 일시정지 창의 잘못된 제목을 찾던 테스트를 수정했고, 너무 가까운 초기 간격에서 1.8초 동안 입력하던 표본은 정상 공격 준비로 들어가 새 보법의 발동 조건을 만들지 못했다. 최종 표본은 더 먼 간격에서 4초 후퇴 입력을 사용한다. 이는 보법이 항상 발동해야 한다는 규칙을 추가한 것이 아니다.

실제 시각 검토는 Canvas/WebGL의 보법 발동 표시와 캐릭터·HP바의 전장 캡처를 확인했다. 모든 프레임의 미감이나 저사양 기기의 성능 인증은 아니다. [검증 자료](verification/boss-pressure-v1/)에 비교 기록, 브라우저 수치·캡처, 빌드와 테스트 로그를 저장한다.

프로덕션 조작 로그: [1440](verification/boss-pressure-v1/production-1440.log), [1366·1093](verification/boss-pressure-v1/production-final.log). 현재 로컬 게임은 `http://127.0.0.1:5173/`이며 새로고침하면 최신 빌드를 받는다. 특별 원화 검토 페이지는 전투 AI를 실행하지 않는다.
