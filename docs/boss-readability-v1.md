# 보스 크기·준비·위험 표시·전투 국면

2026-10-20 사용자 승인1–4항목. 새 그림을 생성하거나 원본을 재축소하지 않고 현재 원화/전투 시계를 사용한다. 로딩 추가 개선은 이번 범위가 아니다.

## 보스 크기

보스 ID와 구형 chief/captain만 고정1.2배다. 현대 원화의 기본0.225는 유지하고 실제 표시0.27을 모든 방향·기본/특별/사망 자세에 적용한다. 일반 적·주인공은 유지한다. 그림자·머리 위 HP바 너비/인물별 고정 높이도 같은 체급을 반영하고 절대 여유 공간은 유지한다.

고정 피격 캡슐도 보스 몸에 맞춰1.2배로 키운다. 반지름22→26.4, 세로 축의 발 기준 높이62/18→74.4/21.6이며 방향/자세와 무관하다. 투사체/근접의 보스 적중 범위가 넓어지는 실제 판정 변경이다. 공격 원점은 공통34px 평면으로 보존한다. 원점까지 높인 초기안은 창 옆 판정·대나무 반사를 깨뜨려 폐기했다. 피해량·공격 사거리/범위·준비/접촉 시간·AI·CC 면역·저장 형식은 변경하지 않는다.

## 공격을 읽는 준비

bossMotionClock은 준비의20%까지 prepare, 이후 load 원화를 유지한다(이전45% 전환). 실제 손/무기를 가진 준비 원화를 일찍 보여주며 런타임에서 팔/척추를 새로 회전하거나 매 프레임 크기를 맞추지 않는다. 연격의 기존 접촉·후속·재준비 시계는 보존한다.

## 위험 표시

사용자가 승인한 보스 예고 형태를 추가한다. 과거의 예고 원/부채꼴 숨김 방침을 이 범위에서 변경한다. 얇은 경계·옅은 바탕으로 몸/바닥을 가리지 않으며 색 외에도 형태로 구별한다.

| 공격 | 표시 | 실제 데이터 |
| --- | --- | --- |
| 베기/진각 | 부채꼴/네 방향 눈금 원 | profile의 arc/range, 지면 진각은 발 원점 |
| 찌르기 | 끝이 닫힌 좁은 통로 | 실제 선 폭/길이, 공통 공격 평면 |
| 돌진 | 화살표 통로와 끝의 공격 형태 | 저장된 시작/도착점, swept 폭30 및 종점 공격 |
| 원거리 | 실제 발사 각도의 화살표 묶음 | profile.shots의 모든 각도, 표시 길이 최대420은 방향 안내 |
| 시전/설치 | 마름모 지점 표식 | 저장된 표적/시전자 위치. 그 자체를 피해 원으로 표시하지 않음 |
| 실제 설치 폭발 | 교차 무늬 원의 진행 | 현재 zone/object.warning과 실제 반경. 문/안전지대/강화에는 위험 원을 그리지 않음 |

외곽 진행은 windup 끝이 아니라 실제 첫 접촉까지 이어진다. 연격은 이전 접촉의 후속0.18초를 보존한 후 다음 접촉 시계로 재준비한다. HP바 아래4개 눈금은 같은 준비 진행이다. 투척 비행 중에는 저장된 착탄 지점을 표시하고, 실제 장판이 생긴 뒤 그 장판의 경고 시계를 사용한다. 도형은 무기/투사체의 중심 범위이며 피격 대상 캡슐의 두께를 합친 최종 충돌 경계와 구분한다.

## 실제 전투 국면

HUD는 현재 살아 있는 보스의 교전◇·추격»·수세▣·격화◆를 표시한다. 실제 rageTime, guardTime/armourTime, pressure.warning/burst를 읽고 격화→수세→추격→교전 순으로 우선 표시한다. 새 체력50% 광폭화나 모든 보스의 새 HP 페이즈를 만든 것이 아니다. 기존 저체력 광폭/수세/추격이 시작되면 배지와0.55초 발밑 전환 고리로 알린다. 로드 시 이미 진행 중인 상태는 전환을 재연하지 않는다.

배지 이동/투명 진입200ms, 고리의 크기는 ease-out cubic이다. 무적·시뮬레이션 정지·카메라 흔들림을 추가하지 않는다. 동작 감소에서는 배지 이동을 끄고 고리는 고정 크기의 짧은 감쇠로 바꾼다. 색·문자·형태와 필수 공격 시계는 유지한다.
