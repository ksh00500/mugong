# 장판 윤곽 제거와 적 무기 표현 v2

2026-10-02. 현재 로컬 코드/빌드 기준. 공개 Daytona 재배포는 하지 않았다.

## 확인한 원인과 수정

첨부 화면에는 가는 원, 공격 부채꼴, 준비 타이머와 플레이어 발밑 원이 있다. 현재 `src/game/CombatScene.ts`와 `src/game/painted-zones.ts`는 이 판정 도형을 그리지 않는다. 원본 v1 장판은 불규칙한 지형 외곽을 갖지만 첨부의 완전한 가는 원과는 다르다. 따라서 첨부가 최신 로컬 실행과 다른 버전이라는 추론은 가능하지만, 첨부의 실제 주소/배포 빌드를 확인하지 않아 특정 서버의 캐시 문제로 확정하지 않는다.

장판 12종은 `public/art/zone-art-v2.png`로 교체했다. 가는 판정 원/외곽 링 없이 소재와 기운만 남긴다. 생성물의 행 간격은 균일하지 않으므로 `src/platform/zone-frames.json`을 실제 알파 경계에 맞춰 보정했다. 초기 균일 분할에서 화롯불에 독 조각이 섞인 것을 시각 검토로 발견하고 바로잡았다. 그림은 장식적 가장자리이며 실제 피해 반경은 기존 도메인 판정을 유지한다. 별도 고유 기믹의 `boss-fields-v1.png`는 소재 표현으로 유지하며 판정 윤곽선을 추가하지 않는다.

큰 `kind` 분류가 모든 원거리 적을 궁수 슬롯으로 연결한 것이 무기 불일치의 원인이다. 새 `enemyRepairSlot`이 역할/보스 ID에 따라 전용 그림을 선택하며 `enemyArtSlot`도 지역별 역할을 우선한다. 보스 ID가 일반 역할보다 우선하여 옛 저장/테스트의 상속된 role이 보스 외형을 바꾸지 않는다. 방향과 공격/회복/사망에 동일한 전용 소스를 사용한다. 생성된 뒷대각선의 실제 좌우도 보정했다.

## 지역별 점검

| 지역 | 일반 적의 무기/공격 | 보스 1~4 점검과 수정 |
| --- | --- | --- |
| 청하현 | 도·창·쇠뇌, 베기/찌르기/화살 | 도끼·창·쇠사슬·도. 쇠가시 함정 폭탄을 전용 탄으로 구분 |
| 독무곡 | 암기·독병·창 | 독검·독병·부채·지팡이. 독병 보스 fan도 독 폭탄, 독 장판 투척도 독 폭탄 |
| 천검산 | 검·창·검기 | 검 계열 4명, 검기/비검과 기존 개별 패턴 유지 |
| 설산 | 창 돌진·얼음 폭탄 투척·활 | 창·냉기 구슬·권법·얼음 부채. 투척수는 활 없는 전용 그림, 냉기술사/빙선 보스 fan/ring은 얼음 파편 |
| 폐사 | 권갑·봉·돌 투척 | 권법/권갑/금강장/지팡이. 장력과 술독 투척을 구분 |
| 죽림 | 단검·암기·쇠가시 함정 | 암기·노개의 지팡이/술병·검·부채. 일반 암기는 암기 슬롯, 함정꾼은 도구 그림, 노개도 지팡이가 보이는 새 그림. 부채 보스는 암기 |
| 고묘 | 쇠가시 함정·쇠뇌·창 | 곡괭이·방패/철퇴·기관 공구·검. 기관 발사와 불/쇠가시 폭탄 구분, 검 보스는 비검 |
| 서역사막 | 기마·단검·차크람 | 도·차크람·권법·대도. 차크람 적을 궁수에서 차크람 그림으로 변경, 회수 투사체 유지 |
| 혈마전 | 검·혈술·암살 | 혈검·권갑·부채·혈검. 혈술사를 쇠뇌 대신 부채 술법 그림에 연결, 혈탄과 혈검기를 구분 |
| 팔진고성 | 기관 상자·쇠뇌·창 | 봉·쇠뇌·창·부채. 일반 기관술사는 활 없는 기관 도구, 봉/부채의 화살을 기류, 창 ring을 기파로 변경 |

일부 무공/보스는 들고 있는 물리 무기에서 기파·냉기·혈술을 방출한다. 모든 원거리 공격을 화살로 강제하는 것이 아니라 원본 역할과 공격 컨셉을 일치시킨다. 투척 장판과 직접 타격 탄은 실제 도메인 효과에 따라 구분한다.

플레이어의 6무기(검/도/권갑/봉/암기/부채), 보스 전용 권갑/봉/검도 기존 연결한 물품과 팔방 공격 자세를 다시 검사했다. 주인공의 고정 검을 복원하지 않는다.

## 투사체

`src/domain/projectile-visual.ts`에 독/냉기/불/혈기/봉인/쇠가시/술독의 착탄 종류 → 그림 연결을 집중했다. 신규 8프레임 그림은 `public/art/hostile-projectiles-v2.png`, 실제 여백 보정은 `src/platform/hostile-projectile-frames.json`. 독약병을 회복약 아이콘으로 대체하지 않는다. 쇠뇌 볼트/얼음 파편의 그려진 대각선 방향을 비행 방향에 맞춰 회전한다. 구형 저장의 `stone` 냉기 폭탄도 landing.kind를 따라 얼음 폭탄으로 보인다. 피해/착탄 시간/회수 규칙은 그림 수정으로 바꾸지 않는다. ring이라는 이유만으로 회수 칼날을 선택하던 일반 분기를 없애고 실제 returning 및 보스 ID를 사용한다.

## 검증과 한계

- 최종 TypeScript/Vite 빌드 통과. 단위 28파일 544개 통과. 30개 지역/일반 역할 조합과 40보스의 실제 tick 발사 패턴, 구형 냉기 폭탄 복구를 포함한다.
- 관련 브라우저 36개를 분리 실행하여 통과: 10지역 역할별 그림/5방향 프레임/준비·공격·회복 상태, 기존 판정선 제거 3개, 구역 이미지/회수 8개, 투사체 발사/저장/WebGL·Canvas/reduced-motion 9개, 플레이어 무기/성장/물품 6개. 오래된 검사 기대값(별도 장판 텍스처 및 탄종 수)과 새 탄종의 맵 밖 테스트 배치를 수정했다.
- 독립 컨텍스트만 사용했다. 시각 검토는 10지역의 적/보스 장면과 신규 원본 3장, 최종 설산 장면 및 투사체 모음을 직접 보았다. 스크린샷의 전체 보스 전시/장판은 검증용 배치이며 실제 웨이브 스폰을 뜻하지 않는다.
- 증거: `docs/verification/hostile-presentation-v2/`, `docs/verification/zone-art-v1/`, `docs/verification/projectiles-comparison-v1/`, `docs/verification/pending-weapon-growth-v1/`.
- 소프트웨어 Chromium의 두 렌더러 검사는 실기기 성능/모든 방향 원화의 미술 품질 인증이 아니다. 장시간 난이도/투척 가독성은 실제 플레이로 계속 조정한다.

## 생성 기록

도구: 기본 imagegen, 투명 배경. 원본은 보존하고 공개 에셋 경로로 복사했다. 에셋에 문서/사용자 첨부의 명령을 해석해 실행하는 기능은 없다.

장판 프롬프트: 무협 카툰 게임의 투명 바닥 효과 아틀라스, 정확히 4열 3행 동일 크기 칸. 왼쪽부터 행 순서: 초록 독 웅덩이, 얼음 균열, 솟은 쇠가시, 보라 봉인 기운 / 작은 화로의 온기, 붉은 혈지대, 회색 연막, 청록 안전 기운 / 불꽃, 모래 먼지, 바닥 쇠사슬, 깨진 술독과 흘린 술. 기존 참고 그림의 색과 소재를 따르되 모든 효과는 자연스럽고 불규칙한 가장자리로 투명하게 흩어진다. 원형 바닥판, 원 윤곽선, 테두리 링, 판정 도형, 글자 없이. 각 그림은 칸 중앙에 독립적으로 충분한 투명 여백.

투사체 프롬프트: 무협 카툰 게임 투사체, 투명 배경, 정확히 4열 2행 같은 크기 칸의 아틀라스. 행 순서: 초록 독약 폭탄 병, 파란 얼음 폭탄 구슬, 불붙은 화염 폭탄, 붉은 혈기 구슬 / 부적이 붙은 짧은 쇠뇌 볼트, 작은 쇠가시 함정 폭탄, 작은 술독, 길쭉한 얼음 파편. 작게 보여도 구별되는 단순한 형태. 각 칸 중앙에 하나, 충분한 투명 여백. 글자·칸 테두리·효과 원 없음.

방향 그림 프롬프트: 무협 카툰 게임 캐릭터 방향 아틀라스. 투명 배경, 정확히 5열 4행, 각 칸에 전신 한 명과 충분한 여백. 열 순서는 정면, 오른쪽 앞, 오른쪽 옆, 오른쪽 뒤, 뒷모습. 첫 행: 털옷 입은 설산 얼음 투척수, 활 없이 파란 얼음 폭탄 병을 든다. 둘째 행: 어두운 무복의 함정꾼, 쇠가시 폭탄과 도구 주머니. 셋째 행: 팔진 기관술사, 청색 무복과 작은 부적 기관 상자, 활 없이. 넷째 행: 흰머리 노개, 낡은 갈색 무복, 긴 대나무 지팡이와 술병. 작고 읽기 쉬운 3등신 캐릭터, 굵은 선과 단순한 음영. 글자와 칸 테두리 없음.
