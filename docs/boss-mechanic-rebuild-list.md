# 보스 대체 동작·부분 구현 개선 목록

2026-10-02. 사용자 지시: 대체 동작은 모두 개선한다. 이 문서는 **구현 이전의 승인 목록**이다. 후속 사용자 승인으로 구현한 현재 상태와 수치는 [보스 기믹 구현 v1](boss-mechanics-v1.md)을 확인한다. 아래 '현재 동작' 열은 당시 조사 결과이며 지금 코드의 미완성 목록으로 재사용하지 않는다.

확인된 원문: `src/domain/catalogue.json`의 identity/patterns. 현재 구현: `src/domain/boss-encounters.ts`, `boss-attacks.ts`, `game.ts`, `combat.ts`, `model.ts`. '개선 방향'은 현재 개발자가 제안하는 실행 규칙이며 원문에 없는 수치를 확정된 과거 기획으로 기록하지 않는다.

## 앞선 감사의 해석 정정

- 죽림은사 송월의 원문은 **대나무 반사 투사체**다. 현재는 회수형 투사체 발사로 대체한다. 적 투사체가 대나무에 충돌해 반사되는 것을 먼저 구현해야 한다. 플레이어 투사체 탈취/반사는 원문에서 확인되지 않아 필수 원문 기믹으로 단정하지 않는다.
- 대막도왕 아르칸의 원문은 **오아시스 차단**이다. 회복하는 오아시스라는 규칙은 확인되지 않는다. 실제 오아시스 지형/영역에 대한 접근 차단을 구현하는 방향이며, 무료 회복 효과를 임의로 추가하지 않는다.
- 아래 목록은 기본 베기·찌르기 등의 공통 코드 사용 자체를 결함으로 계산하지 않는다. 원래 전투 행동이 다른데 같은 물체/피해/상태로 대신한 경우와 패턴의 핵심이 빠진 경우를 다룬다.

## 공통 표현 보완

- 적 방어 깃발 vs 위험 봉인, 플레이어 제갈 진법 vs 보스 안전지대는 서로 다른 목적/소유자가 읽히는 그림으로 구분한다.
- 팔진노사 제갈현의 안전지대는 현재 몇 개 위치로 재설치한다. 건/곤 진의 실제 역할 교대와 연속 회전까지 구현한 상태는 아니다. 문/진법 기반 이후 전용 패턴으로 확장한다.
- 오독낭자 연화의 독 종류는 독 웅덩이·둔화 연결·봉인으로 순환한다. 원문의 독침/독분/독무를 각각 만드는 경우 독 계열별 투사체·상태·해독 대응을 독립 데이터로 정해야 한다. 지금의 세 구역을 원문 세 독의 완성으로 계산하지 않는다.
- 보스 모래/연막/눈보라는 최근 실제 효과가 생겼으므로 '효과 없음'으로 되돌려 기록하지 않는다. 다만 B4의 원래 시야/잠복 콘셉트까지 완료한 것은 아니다.

## 구현 순서 및 완료 조건

1. 공통 기반: 움직이는 설치물의 이전/현재 위치 충돌, 반사 탄의 방향/횟수, 붙잡기·출혈·냉기 상태, 개체 소유권·사망 정리. 저장 검증과 과거 저장 호환을 함께 처리.
2. A1 반사·A2 체력 교환·A10 잡기. 같은 피해/장판 대신 해당 행동이 실제 실행되는지 먼저 검증.
3. 문/벽 계열 A3·A4·A5·A7·A8·A9와 곽기의 회전날. 기반을 공유해도 보스별 물체·이동·종료 행동은 구분.
4. A6 수리 드론·A11 정화초, B의 조건부 페이즈·개별 움직임/상태/음향.
5. 진영 구역 그림, 건/곤과 독 계열 구분, 보스별 실제 플레이 조정.

각 항목 완료에는 실제 판정 + 그림/동작/음향 + 대응 방법 + 다국어 설명 + 저장 재개 + 사망/선택/일시정지 정리 + 독립 브라우저 검사를 포함한다. 이름만 바꾸거나 기존 장판의 색을 바꿔 완료 처리하지 않는다. 공격 범위 테두리/조준 선은 복원하지 않는다.

현재 구현과 개선 제안을 구분한 체크리스트이며, 이번 목록 작성에서 런타임을 변경하거나 공개 배포하지 않았다. 온라인 레이드/PVP 목업은 보스 대체 패턴과 다른 큰 개발 범위다.
