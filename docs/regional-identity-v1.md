# 지역 전투 정체성과 가방 도구 v1

2026-10-02. 실제 적의 출현 구성·거리 유지·조준·돌진 판정과 40보스의 공격 순서를 수정했다. 기존 이름과 원본 기획의 고유 기믹, 강호 20웨이브·경험치 총량·드랍 규칙은 유지한다.

## UI

개방 무공 그림은 전체 아틀라스 칸을 표시한다. 성장 카드의 그림이 잘리던 안쪽 자르기와 호버 이동을 없애고 내용에 맞춰 높이를 결정한다. 자동 정리는 하단 진행 버튼과 분리해 가방 제목 옆에 큰 버튼으로 제공한다. 기존 정렬·획득 물품 수납·저장 명령을 그대로 사용한다. 작은 창에서 버튼이 격자나 물품 정보를 밀어내지 않게 한다.

## 판정과 저장

투척은 0.65초 비행한 뒤 고정한 위치에 0.2초 예고와 4.2초 지대를 만든다. 날아가는 독병이 무인에게 접촉 피해를 주지는 않는다. 준비 때와 비행 중 모두 착지 영역을 표시한다. 바닥 경고 반경은 피해/둔화의 무인 중심 허용치 18px를 함께 표시한다. 돌진은 경고한 96px 너비 경로와 도착 지점의 근접 부채꼴로 판정하며 한 번만 피해를 준다. 정면 방어 역할은 뒤에서 공격하면 방어 경감을 적용하지 않는다.

혼취된 일반 투척자의 폭탄은 다른 적에게 폭발 피해를 주며 무인에게 해로운 지대를 남기지 않는다.

역할, 연사 대기, 착지 목표는 선택 저장 필드다. 저장 검증을 통과한 이전 저장은 그대로 읽으며 새 웨이브부터 새 지역 구성을 사용한다. 사망 전 기록으로 되돌리거나 사용자 실제 저장을 바꾸지 않았다.
