# 적 이동·공격 흐름 v4

2026-10-03. `enemy-tactics-v3.md`의 정지 준비/회복 정책을 이 문서가 대체한다.

## 확인한 문제

- `src/domain/game.ts`의 enemyStep은 접근 상태에서만 움직였다. 준비는 조준만 갱신하고 회복은 전부 정지했다.
- `src/domain/enemy-tactics.ts`에서 근접 적의 적정 거리 이동 벡터가 0이 될 수 있었다. 공격 인원 제한으로 기다릴 때도 제자리였다.
- 일반 적 중 장판/기관 역할의 준비 1.2~1.3초, 회복 2.1~2.3초, 첫 대기 0.8~1.4초가 겹쳤다. 공격 횟수 제한에는 순번 보장이 없었다.
- 사용자 체감의 모든 5초 정지를 재현했다는 뜻은 아니다. 저사양 프레임, 경직 연타, 범위 밖 추격, 특수 패턴 등은 구분해서 평가해야 한다.

## 적용한 흐름

- 접근/공격 순서 대기: 적정 거리를 유지하면서 근접 적도 횡으로 움직인다. 2.4초 주기의 역할별 방향 변경으로 같은 방향 공전만 반복하지 않는다. 플레이어를 바라보며 측면 이동한다.
- 준비 초반: 이동 속도의 42%로 거리 조절/횡이동하며 이동 후 다시 조준한다. 마지막 `min(0.4, windup*0.45)`초는 조준과 위치를 고정한다.
- 타격: 추가 전술 이동을 하지 않는다. 기존 돌진 경로와 접촉 판정을 유지한다.
- 회복: 처음 0.18초는 빈틈으로 유지한다. 남은 회복에는 72% 속도로 재배치한다. 회복 중 이동은 방향 그림과 걷기 변형을 사용해 발걸음이 연결된다.
- 준비 중 움직이는 캐릭터도 원화의 공격 자세를 유지하며 작은 다리/발 움직임을 추가한다. 원화에 중복된 큰 몸체 변형은 적용하지 않는다.
- 일반 적 준비: 원래 값의 85%, 최소 0.55초. 회복: 원래 값의 70%, 최소 0.55초/최대 1.5초. 새 웨이브 첫 대기 0.25~0.75초.
- 일반 적 3명 동시 공격 제한은 유지하되 도착 순서로 슬롯을 배정한다. 사망/삭제/사거리 이탈/경직/상태 변경한 대기자를 제외한다. 보스는 일반 적 공격 순서를 기다리지 않는다.
- 순서 자료는 Run에 연결된 WeakMap으로 보관하며 저장 스키마를 변경하지 않는다. 재개하면 순서는 다시 만들어지며 이전 대기 순서를 저장하는 기능은 아니다.
- HP/피해를 더 올리지 않았다. 이전 70% 스탯 결정은 유지한다.
