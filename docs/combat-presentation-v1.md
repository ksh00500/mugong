# 범위선 없는 전투 표시

2026-10-02. 사용자 지적의 원 테두리, 공격 부채꼴, 원형 범위, 조준 경로, 머리 위 카운트다운, 착탄점 미리보기를 제거했다.

- 일반 적 21종, 40보스와 모든 설치물에 동일하게 적용한다. 플레이어 발밑 원과 적 방어·분노 원을 제거하고 자연스러운 그림자/몸의 상태 색을 남긴다. 보스·정예의 작은 등급 삼각형은 유지하되 원 배지는 제거한다.
- 제갈 진법의 판정 원과 연결 도형도 제거한다. 실제 진법 그림, 실제 쇠사슬 연결, 투사체·타격·폭발 이펙트는 유지한다.
- 독·냉기·함정·보스 구역은 발동 전 범위 그림을 숨기고 발동 후 실제 구역 그림을 남긴다. 이미지 풀 재사용 및 만료 시 회수는 유지한다.
- 삭제한 `src/game/telegraphs.ts`의 도형 코드가 기본 전투에 다시 사용되지 않는다. 관련 표시는 `CombatScene.ts`, `painted-zones.ts`, `encounters.ts`, `effects.ts`, `feedback.ts`에서 정리했다.
- 적의 준비/공격/회복 시계와 실제 피해·사거리·돌진·투척·저장 데이터는 변경하지 않는다. 준비 자세·공격 자세와 보스 준비 효과음을 유지하며 움직임 줄이기에서도 서로 다른 고정 자세를 사용한다.

## 확인

타입/빌드와 406개 단위 검사, 24개 관련 로컬 브라우저 검사를 통과했다. 실제 렌더러에서 21종 일반 적과 40보스의 준비/회복 122개 상태를 그려 범위·타이머 도형이 없는지와 그리기 전후 게임 데이터가 동일한지 확인했다. 독·냉기·함정의 준비 중 숨김, 발동 후 표시, 만료 후 제거와 이미지 풀 재사용을 검사했다.

기존 기마·암살자·혈교·얼음·창병의 공격 동작/실제 피해, 서역 환의 회수, 8방향 리그와 실제 입력 재개, 제단 저장의 무손실 이행 및 7개 지역 실제 구역 그림을 재검증했다. 검격·회피·반격·방어와 움직임 줄이기도 통과했다. 반격 검사의 무작위 지역 역할을 명시적인 근접 역할로 고쳐 방어 성공 조건을 검증했다. 테스트는 독립 브라우저에만 데이터를 사용했다.

캡처는 `docs/verification/combat-presentation-v1/`에 남겼다. 기관 보스와 설치물·실제 구역 그림이 있는 화면을 1440×900 및 1093×614에서 캡처하고 직접 확인했다. 자동 검사로 장시간 플레이 난이도나 접근성 인증을 주장하지 않는다.

Daytona 공개 배포의 보스·실제 구역 표시, 출전·전투·가방·저장 복원 2개 브라우저 검사를 통과했다. 191개 릴리스 파일과 공개 경로의 주요 파일 11개 해시를 검증했다. 배포 기록과 공개 캡처는 `docs/verification/daytona-20261002-combat-presentation-v1/`에 있다.

## 난이도 판단

이 변경은 사거리와 피해가 아닌 사전 정보량을 줄인다. 숫자상의 난이도를 함께 올리지는 않았다. 실제 공격 준비를 읽고 피할 수 있는지, 보스별 학습 가능성이 충분한지는 반복 플레이로 판단해야 한다.
