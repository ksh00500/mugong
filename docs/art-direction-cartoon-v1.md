# 무공 — 카툰풍 디자인 기준

2026-09-27. 사용자가 [카툰풍 검객](../assets/concepts/cartoon-swordsman-v1.png)을 승인하고 이 느낌으로 다시 디자인하도록 지시했다. 이전 회화적 고밀도 원화 기준보다 이 문서를 우선한다.

## 공통 방향

- 굵고 깔끔한 외곽선, 큰 색면, 간결한 셀 셰이딩.
- 캐릭터는 승인 시안의 약 5등신 비례와 또렷한 표정. 다양한 무인의 외형은 이 기준에서 확장한다.
- 옷·머리·무기는 덩어리와 실루엣으로 구별한다. 작은 장식·주름·질감을 늘리는 대신 움직일 때 읽히는 형태를 우선한다.
- 무협 복장과 검·창·부채 같은 기존 소재를 유지한다. 화풍 변경만으로 게임 규칙이나 아이템 목록을 바꾸지 않는다.
- 비스듬한 탑뷰와 중앙 전투 공간을 유지한다. 정확한 캐릭터 화면 크기와 카메라 각도는 실행 화면에서 맞춘다.

### 맵과 캐릭터 축척 — 사용자 추가 정정

이전 `cartoon-combat-v1.png`의 큰 인물과 가까운 카메라는 사용자가 너무 확대된 느낌이라고 정정했다. 캐릭터를 작게 표시하고, 한 맵은 아이작 일반 방보다 전투 공간이 약 두 배 넓게 느껴지도록 설계한다. [사용자 축척 참고](references/map-scale-isaac-reference.png)는 상대 크기의 참고이며 그래픽 복제 대상이 아니다.

사용자는 두 번째 [줌아웃 시안](../assets/concepts/cartoon-combat-wide-v2.png)의 넓은 맵과 작은 캐릭터 느낌을 승인했다. 이후 화면의 축척 기준으로 사용한다. 캐릭터 높이는 화면 높이의 약 6~8%를 검토 후보로 삼았으며 정확한 수치가 확정된 것은 아니다. 게임에서 적·효과·회피 공간의 읽힘과 함께 조정한다. 원본 캐릭터 이미지의 해상도는 충분히 확보하고 게임상 표시 크기를 작게 맞춘다.

‘약 두 배’는 사용자가 요청한 넓이의 체감이다. 가로·세로를 각각 두 배로 고정하거나 실제 월드 면적이 정확히 두 배라고 단정하지 않는다. 전체 맵 표시와 카메라 추적·스크롤 여부는 별도 구현 검토 항목이다.

승인한 검객의 검은 머리·흰 도포·먹색 바지·붉은 허리띠는 첫 캐릭터의 기준이다. 모든 무인에게 같은 복장과 색을 강제하지 않는다.

## 화면별 디자인

| 대상 | 새 방향 |
|---|---|
| 캐릭터·적 | 같은 선 굵기와 명암 단계. 복장과 색·실루엣으로 구분 |
| 배경 | 카툰풍 돌·나무·대나무·흙바닥. 가장자리는 분위기를 주고 중앙은 단순하게 |
| 무기·아이템 | 캐릭터와 같은 선과 색면. 가방·시장에 작게 표시해도 물품이 구별됨 |
| 전투 효과 | 짧고 선명한 붓획 같은 검흔과 적중 효과. 인물과 판정을 가리는 과한 빛은 줄임 |
| UI | 사용자가 앞서 승인한 와이어프레임의 UI 구성과 디자인을 유지. 새 이미지 속 임시 HUD로 교체하지 않음 |
| 로비·시장·가방 | 앞서 정리한 UI 배치·기능·디자인을 유지. 물품과 캐릭터 그림은 카툰풍 기준을 적용 |

전투 화면에는 로비 상단 메뉴가 없다. 소모품 퀵슬롯을 추가하지 않는다. 전투 하단 무공 전환 표시는 기존 규칙을 따른다.

### UI — 사용자 추가 확정

사용자는 “이미지 2번 느낌 좋다. 저 상태에서 UI는 아까 짰던 것으로 간다”고 확인했다. **맵·캐릭터·카메라 축척은 승인한 줌아웃 시안, UI는 [기존 와이어프레임](wireframes/mugong-first-draft.html)**을 결합한다. 이미지 속 좌상단 체력바와 하단 원형 아이콘 세 개의 형태·크기·개수는 UI 승인 대상이 아니다.

전투 상단의 상태·진행·보스 정보, 하단의 현재 무공·전환·궁극 게이지, 전투 중 가방과 로비 메뉴의 분리를 기존 기획대로 유지한다. 정확한 표시 크기와 여백은 넓은 맵 화면에 올려 검증한다.

## 생성 요청은 짧게

기준 이미지를 첨부하고 **대상·동작·출력 조건**만 먼저 요청한다. 공통 장문과 많은 제외 조건을 매번 합쳐 보내지 않는다. 한 요청에 한 동작을 만든다.

예: “첨부한 검객이 자연스럽게 한 번 베고 원래 자세로 돌아오는 짧은 영상을 만들어줘. 같은 캐릭터와 고정된 카메라, 단색 배경으로.”

문제가 나오면 한 번에 한 문제만 수정한다. 예: “이 동작은 유지하고 검을 잡는 손만 처음부터 끝까지 같게 해줘.”

허리·어깨·무릎·팔의 단계별 회전, 복잡한 자세 목록, 고정 프레임 수는 첫 생성 요청에 넣지 않는다. 생성기가 자연스럽게 동작을 만들 여지를 둔다. 조건이 너무 많았던 점을 바로잡되, 프롬프트 길이만이 이전 결과의 원인이었다고 단정하지 않는다.

## 결과를 검수할 기준

얼굴·복장·체격의 유지, 발 접지, 검과 손의 연결, 동작의 읽힘, 프레임 여백, 실제 게임 크기에서의 가독성은 Codex가 결과를 확인할 때 평가한다. 필요한 수정만 다음 요청에 포함한다.

## 현재 자료와 다음 제작

- 승인한 화풍: `../assets/concepts/cartoon-swordsman-v1.png`.
- 승인한 맵·캐릭터 축척: `../assets/concepts/cartoon-combat-wide-v2.png`. 이전 확대 구도를 수정한 두 번째 줌아웃 시안이다. 이미지 속 HUD는 사용하지 않고 기존 와이어프레임의 UI를 적용한다. 정확한 픽셀 크기·적 종류·체력 수치는 이미지로 확정하지 않는다.
- 이전 `prototype/`의 회화적 캐릭터 동작은 비교 자료다. 새 카툰풍 애니메이션이 이미 연결된 실행 화면으로 설명하지 않는다.
- 첫 제작은 새 기준으로 게임 시점의 준비 자세 한 장과 한 번 베는 영상이다. 맞으면 걷기와 방향을 확장한다.
