# 무기 표시·성장 선택·획득 물품 통합

2026-10-02 사용자 피드백 반영. 주인공의 고정 검, 소림 공격의 긴 봉 같은 선, 간헐적인 성장 선택 무반응, 정리판과 구매품의 별도 처리 흐름을 수정했다.

## 무기와 동작

이전 팔방 주인공 그림에는 검이 그려져 있어 권갑·봉·부채·암기를 연결해도 검을 들었다. 새 무기 없는 기본 그림에 현재 무공의 실제 호환 연결 물품을 표시한다. `activeWeapon()`은 공격력과 표시 양쪽에서 사용한다. 호환되지 않거나 연결이 없으면 무기를 표시하지 않는다. 다른 무공의 가방 속 무기를 대신 표시하지 않는다.

검·도·권갑·봉·부채·암기는 각각의 물품 그림과 길이·손잡이 위치를 사용한다. 일반 18종과 보스 전용 무기의 그림을 준비하고, 팔방의 손 위치와 몸의 메시 보간을 따라 준비·공격·회복 자세에 표시한다. 사망·장면 종료에는 표시를 정리한다. 소림의 기본 공격은 긴 직선 찌르기 그림과 선 대신 짧은 주먹 접촉 그림으로 표현한다. 공격 범위·피해·재사용 시간은 변경하지 않았다.

기본 그림은 내장 `image_gen`으로 기존 시트를 편집했다. 원본은 `public/art/hero-unarmed-v1.png`, 런타임은 `public/art/delivery-v1/hero-unarmed-v1.webp`이며 기존 그림은 보존한다. 최종 프롬프트:

> Edit this game sprite sheet: remove every sword and weapon, leaving empty closed hands. Preserve the same character, clothes, poses, exact 8 columns by 5 rows layout, and transparent background. Each character remains in its original cell. No other changes. This is an unarmed base for separately drawn equipment.

## 성장 선택

1초 보호는 유지한다. 버튼 활성 상태와 클릭 판정을 같은 잠금 상태로 통일해 별도 시간 검사에서 입력을 조용히 버리는 경로를 없앴다. 저장 중에는 선택 안내 대신 저장 상태를 보여주고, 명령이 거절되면 거절 안내를 표시한다. 연속 선택은 기존 성장 회차 키로 다시 잠그며 중복 입력과 저장 순서를 기존 store에서 보호한다.

사용자 이미지에서의 간헐적 오류가 발생한 정확한 실행 상태는 저장 원본 없이 확정하지 못했다. 확인 가능한 입력 무시 경로와 상태 안내를 수정했고, 이미지와 같은 세 업그레이드 후보를 포함한 연속 6회 마우스 선택·저장을 검증했다. 상세 설명을 열고 닫은 뒤의 성장 선택 검사도 통과했다.

## 획득 물품

정리판 영역·이동 행동·일괄 폐기 명령·닫기 제한·진행 제한을 제거했다. 구매품·드랍·가방에서 꺼낸 물품은 하나의 **획득 물품** 영역으로 간다. 강호에서는 한 영역을 전체 너비로 사용하고, 로비에서는 창고와 획득 물품을 함께 표시한다. 영역 안의 페이지 이동을 유지한다.

가방을 닫아도 획득 물품은 유지한다. 강호의 다음 웨이브·귀환에서는 미수납 물품 목록을 확인하며 승인 후에만 남겨둔다. 로비에서 닫기는 물품을 폐기하지 않는다. 선택한 획득 물품은 `폐기`로 확인 후 그 물품의 중첩만 버린다. 수납·사용·착용·회전·자동 정리·창고·강화·재료 판매를 같은 영역에 맞췄다. 전투 중 소모품 사용 제한과 물품 이동 제한은 유지한다.

이전 저장의 `board`는 유효성 검사에서 계속 읽을 수 있다. 불러온 뒤 모든 현재/귀환 무인의 해당 물품 위치만 `ground`로 옮겨 최신 결과를 저장한다. ID·수량·품질·능력·연결은 보존하고 같은 물품끼리 임의 병합하지 않는다. 과거 사망 기록으로 복구하거나 실제 사용자 저장에 테스트 데이터를 넣지 않는다. 새 런타임 `Place`에는 `board`가 없다.

획득 물품·행동·구매 안내·폐기 확인은 한국어·영어·일본어·간체·번체의 전체 문장으로 번역했다. 기본 상세 정보 구조나 추가 탭은 만들지 않았다.
