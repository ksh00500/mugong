# 투사체와 착용 전 비교

2026-10-01. 로컬 개발 화면에 적용했다.

## 투사체

기존에는 원거리 검기와 풍인이 UI 탐색 그림을 공유하고 독침은 선, 적 공격은 대부분 같은 화살이었다. 전용 그림 9종을 연결했다.

| 실제 공격 | 그림 |
| --- | --- |
| 수련 암기 / 강철 독침 / 청린 독침 | 청동 암기 / 은색 독침 / 녹색 독침 |
| 제갈 부채 공격 | 청록색 풍인 |
| 삼재 9성 검기 | 황백색 검기 |
| 삼재 10성 이기어검·궁극기·주변 검 | 날아가는 장검 |
| 궁수·쇠뇌·기관 | 붉은 깃 화살 |
| 회수 공격 | 회전 칼날; 천검산 투검 회수는 장검 |
| 폐사 돌팔매 승병 | 회색 조약돌 |

일반 원거리 적도 지역 외형에 맞춘다. 독무곡은 독침, 천검산은 검기, 죽림은 투척 암기이며 나머지 궁수·쇠뇌 적은 화살이다. 무협 카툰의 형태와 작은 전투 화면의 가독성을 우선한다. 짧은 주황색 꼬리와 위쪽 그리기 순서로 적 탄을 구분한다. 그림 크기는 공격의 판정 반지름을 바꾸지 않는다.

발사 시 `visual`을 기록하므로 비행 중 무공·연결 무기를 바꿔도 기존 탄은 바뀌지 않는다. 구형 저장은 무공·성급·회수 정보로 그림을 선택하며 변환을 강요하지 않는다. 삼재 궁극기에 시각 정보만 추가해 기존 충전·관통 규칙을 유지한다. 이미지 풀을 재사용하고 숨길 때 남은 그림을 정리한다. 움직임 줄이기는 회전 연출을 끄되 진행 방향을 유지한다.

기본 제공 `image_gen`으로 새 그림을 생성했다. 프롬프트·생성 원본 경로·전달 경로는 [생성 기록](../assets/projectile-art-v1/manifest.json)에 있다. 원본 두 PNG를 보존하며 최종 파일은 `public/art/projectiles-v1.webp`, `public/art/projectile-stone-v1.webp`다. WebP 변환은 무손실이고 생성된 알파를 유지한다. 시트 좌표는 그림의 투명 여백을 제외해 실제 모양의 종횡비로 표시한다.

독침·풍인의 발사 때 나타나던 큰 공통 찌르기 그림은 짧은 발사 표시로 교체했다. 투사체 자체의 실루엣을 가리지 않으며 일반 근접 검격은 유지한다. 전달 그림 두 파일은 합계 464,678바이트다.

## 착용 전 비교


물품을 선택하면 선택 정보 안에서 현재 장비 이름·그림과 `현재 수치 → 선택 물품 수치`, 부호가 붙은 증감을 보여준다. 별도 창이나 탭을 추가하지 않는다. 증가·감소·동일을 색과 문자로 함께 구분한다.

- 도포는 받는 피해의 고정 감소량, 장신구·무기는 공격 기여량을 비교한다. 최종 공격 피해를 미리 계산했다고 표현하지 않는다.
- 신발은 기본 이동속도 265와 장비당 속도 8을 기준으로 증가율을 한 자리로 표시한다. 증감도 표시된 두 수치의 차이를 사용한다.
- 무기는 실제로 수납되고 해당 무공에 연결된 호환 무기와 비교한다. 현재 무공을 우선하며 동일한 기존 무기는 한 묶음으로 보여준다. 연결 대상이 다르면 짧은 선택 목록으로 비교 대상을 바꾼다.
- 빈 슬롯은 0, 미연결·잘못된 무기 연결도 실제 공격 기여 0으로 비교한다. 이미 착용한 장비와 소모품에는 교체 비교를 표시하지 않는다.
- 비교는 저장 데이터를 수정하지 않는다. 착용·수납·연결 버튼과 기존 장비 보존 규칙을 그대로 사용한다. 새 문구는 한국어·영어·일본어·간체·번체를 지원한다.

## 검증

- 단위 검사 243개 통과: 실제 무기별 발사·비행 중 전환·구형 저장 호환·지역 적 발사·비교 증감·슬롯 교체 보존과 기존 전투 규칙을 포함한다.
- 브라우저 49개 사례 통과, 수정 후 재검증 포함: 비교 18개, 투사체 9개, 기존 가방 흐름 6개, 기존 무인 요약 16개. 5개 언어의 기준 해상도 1440×900·1366×768·1093×614와 추가 1000×500·800×600·390×600 비교 흐름을 검증했다.
- 실제 발사로 그림 프레임·저장을 확인하고 Canvas/WebGL에서 9종 출력·방향·남은 풀 이미지 정리를 확인했다. 발사 시 공통 큰 그림이 남지 않는 것도 검증했다. 움직임 줄이기에서 회전 칼날은 방향만 유지한다.
- 직접 캡처 검토: 기준 해상도의 비교 정보와 착용 버튼, 좁은 화면의 전리품 페이지·겹침, 전투 화면의 그림 크기·실루엣·방향을 확인했다. 390px의 초기 비교 영역 겹침은 간격을 수정해 해결했다.
- 타입 검사·프로덕션 빌드 통과. 새 React 컴포넌트는 렌더 시 비교 값을 파생하며 저장 수정이나 불필요한 효과 훅을 추가하지 않았다.

[캡처와 렌더 기록](verification/projectiles-comparison-v1/)에 증거를 보존한다. 모든 테스트 상태는 Playwright의 독립 컨텍스트에서 사용했다. 실제 사용자 저장은 변경하지 않았다. 자동 검사·직접 캡처 검토는 실제 사용자 대상 사용성 검증이나 서비스 인증과 다르다. 이번 적용은 로컬이며 Daytona 배포는 하지 않았다.
