# 메인 로비 UI·UX

2026-09-28. 승인된 카툰 검객과 넓은 숲의 분위기를 유지하면서 메인 로비 전체를 다시 구성했다.

## 화면과 동작

상단은 무공 인장과 출전·가방·창고·기록 메뉴, 음소거·조작 안내 버튼이다. 출전 준비, 검객 초상, 무인 명부를 세 열로 배치하고 아래에는 창고·세가 기록·입문 안내 바로가기를 둔다. 종이 바탕, 옥색 주요 버튼, 황동 선과 붉은 인장을 관리 화면과 통일했다.

첫 시작은 Lv.0·20웨이브·네 무공 계열을 안내하고 ‘새 무인으로 출전’을 가장 크게 표시한다. 이름 입력에는 12자 제한과 글자 수, 시작 조건을 표시하며 공백 이름을 막는다. 입력 창을 닫으면 출전 버튼으로 초점이 돌아온다.

일시 종료한 강호가 있으면 같은 출전 영역이 이어하기로 바뀐다. 저장된 이름·레벨·웨이브·체력과 스무 칸 진행표를 표시한다. 이는 완료 귀환과 구분하며 새 캐릭터를 만들어 기존 여정을 덮어쓰지 않는다.

귀환한 무인을 명부에서 선택하면 레벨·무공·남은 체력·남은 현실 수명과 가방 버튼을 표시한다. 가방과 창고는 기존 물품 이동 기능에 연결된다. 진행 중인 강호가 있거나 귀환 무인이 없으면 명부 가방 관리를 비활성화하고 이유를 안내한다. 수명과 체력 표시는 실제 저장 상태에서 읽는다.

세가의 기록은 실제 출전·완주·전사·수명 만료 횟수와 현재 명부·보관 물품 수를 표시한다. 입문 안내는 이동·공격·무공 전환·방어·가방·일시 종료와 전투 중 가방 제한, 전리품 수납을 설명한다. 음소거는 전투 화면과 같은 오디오 상태를 공유한다.

화면 너비가 줄면 명부와 바로가기가 아래로 재배치된다. 데스크톱의 높이가 짧으면 여백과 초상 높이를 줄인다. OS의 움직임 줄이기 설정을 존중한다. 작은 화면 배치 대응은 터치 전투 구현을 의미하지 않는다.

## 검증

- 규칙·저장 테스트 27개 통과.
- 브라우저 시나리오 12개 통과(50.3초). 신규 안내·기록·음소거·이름 입력·초점 복귀·강호 일시 종료 후 이어하기를 검증했다.
- 기존 실제 공격·성장·전리품·완주·명부·창고 왕복·새로고침·사망·동시 저장 잠금도 통과했다.
- 1440×900, 1366×768, 1024×768, 390×844에서 가로 넘침이 없다. 1440×900 및 1366×768의 초기 로비는 세로 스크롤도 없다.
- TypeScript 검사와 프로덕션 빌드를 확인했다.
