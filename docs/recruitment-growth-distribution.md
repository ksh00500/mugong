# 모집 후보 성장 배율 분포

2026-10-03. 사용자 요청에 따라 독립 균등 생성 대신 총합 예산을 가진 이산 정규 가중치 분포를 적용했다.

## 확정 규칙

- 기준은 네 능력치 각각 ×1.0, 합계 4.0이다. `총 추가 배율 = 네 배율 합계 − 4.0`.
- 신규 후보의 합계는 4.5~5.5(추가 +0.5~+1.5), 0.1 간격. 평균 목표는 합계 5.0(추가 +1.0), 표준편차 매개변수는 0.2이며 범위 밖은 생성하지 않는다.
- 개별 배율은 기존 하한 ×0.8을 유지하고 상한 ×2.0으로 확대했다. 합계에 맞춘 중심값(합계/4)과 표준편차 매개변수 0.22의 정규 가중치를 사용한다. 특정 능력치가 높은 만큼 나머지 배율의 예산은 줄어든다. 네 능력치의 취급은 대칭이다.
- 연속 정규 난수의 반올림이 아니라, 0.1 간격으로 정의한 값에 정규 곡선의 가중치를 준 이산 분포다. 총합 제약 때문에 개별 배율은 서로 독립이 아니다.
- 기존 출전 무인 및 이미 저장된 후보의 배율은 재추첨하거나 변경하지 않는다. 과거 합계가 새 제한을 벗어나도 기존 저장은 계속 인정한다. 저장 검증의 개별 상한은 ×2.0으로 확장했다.

## 구현

`src/domain/growth-roll.ts`에서 합계와 합계별 가능한 네 배율 조합의 누적 확률표를 한 번 계산한다. 모집 시 합계를 뽑고 해당 합계를 가진 조합을 뽑는다. 무제한 재시도나 생성 후 강제 보정이 없으며 정수(0.1 단위)로 총합을 계산한다. `src/domain/recruitment.ts`에서 새 후보를 생성할 때만 호출한다. `src/platform/save-validation.ts`는 기존 저장을 유지하면서 새 상한을 허용한다.

## 검증

고정 시드 812493으로 후보 100,000명, 개별 능력치 400,000개를 생성했다. 이는 확률표의 실측 표본이며 정확한 확률을 보장하는 수치는 아니다.

| 총 추가 배율 | 표본 비율 |
| --- | ---: |
| +0.5 | 0.869% |
| +0.6 | 2.740% |
| +0.7 | 6.444% |
| +0.8 | 12.135% |
| +0.9 | 17.893% |
| +1.0 | 19.990% |
| +1.1 | 17.662% |
| +1.2 | 12.178% |
| +1.3 | 6.566% |
| +1.4 | 2.676% |
| +1.5 | 0.847% |

추가 +0.8~+1.2는 79.858%. 개별 ×2.0은 58/400,000 = 0.0145%, ×1.9는 0.07525%. `tests/growth-roll.test.ts`는 범위, 중앙 집중, 네 능력치의 평균 대칭성, 극단값 가능성 및 ×2.0 무인의 후보→출전 저장 검증을 확인한다. 전체 단위 검사 38파일 894개 통과. 브라우저 모집 검사는 실제 카드 표시·새로고침 후 후보 유지·출전을 독립 저장 컨텍스트에서 확인한다.

프로덕션 빌드 성공. 브라우저 검사 4개 통과(1440×900, 1366×768, 1093×614 모집·저장 복원·출전 및 모집권 구매). 화면 증거는 `docs/verification/recruitment-v1/`에 기록했다. 이후 [Daytona 최신 릴리스](daytona-animation-growth-v3.md)에 반영하고 공개 모집·저장 복원을 검증했다.
