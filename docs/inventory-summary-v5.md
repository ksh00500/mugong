# 가방 요약과 수납 표시 개선

2026-09-30. 화면을 오가던 물품/무인 정보 및 상태/무공/착용 장비 전환을 없애고, 물품을 선택하는 동안에도 무인 요약을 유지했다.

- 이름과 레벨 아래 체력·수명, 무공 그림 아이콘·레벨, 착용 장비 세 칸을 함께 표시한다. 무공 이름과 설명은 hover·Shift·키보드 초점에서 읽고, 연결 무기는 아이콘의 title과 접근성 이름으로 확인한다. 검을 선택하면 무공별 연결 버튼을 바로 사용할 수 있다.
- 오른쪽 선택 물품과 두 격자, 아래 전리품/창고 및 정리판을 함께 유지한다. 작은 창에서는 요약을 상단 띠로 재배치한다. 4×7와 10×8 및 게임·저장 규칙은 유지했다.
- 드래그 칸 안의 큰 ‘수납/공간 부족’ 글자를 없앴다. 실제 점유 칸 크기의 그림·경계선으로 배치하고, 배치 가능 여부·실패 사유는 격자 위의 작은 안내에서 확인한다.
- 비어 있거나 한 페이지만 있는 영역에는 페이지 화살표·1/1을 표시하지 않는다. 여러 페이지는 해당 보관 영역 안에서 이동한다. 전리품 그림과 페이지 버튼이 표면 아래로 넘치지 않도록 맞췄다.
- 가방 hover 설명이 작은 창에서 물품 클릭을 가로막는 문제를 실제로 재현하고 수정했다. 기본 미리보기는 물품 클릭을 막지 않고, Shift를 누른 동안에는 긴 설명을 스크롤할 수 있다. 성장·전투 설명의 초점·일시 정지 규칙은 유지한다.
- 설정의 화면/소리 분류는 서로 다른 작업을 관리하므로 유지했다. 로비는 기존 출전·명부·가방/창고의 동선을 유지하며, 공통 페이지 표시 개선을 적용했다.

스타일 소유는 `src/ui/inventory-controls.css`의 `components` 계층이다. 이전 `legacy`에 새 덮어쓰기 규칙을 추가하지 않았다. `DESIGN.md`, `UX.md`, 로컬 공개 UI·UX 가이드, React 스킬의 상태·키보드·이벤트 정리 기준을 검토했다.

## 검증

Playwright 독립 컨텍스트만 사용하며 실제 사용자 저장을 바꾸지 않는다. 새 검사는 네 무공·착용 장비·선택 물품을 함께 채워 실제 수납/착용/사용/연결/드래그와 저장 결과, 패널 간 겹침, 화면 경계, 5개 언어 문구를 확인한다. 기존 검사의 전리품·창고 왕복, 폐기 확인, 키보드 설명, 초점 복귀 및 전투 입력도 재검증한다.

자동 검사와 별도로 캡처를 직접 읽어 그림 크기·칸·텍스트·버튼·여백을 확인한다. 테스트 이름을 위해 만든 `Tester`는 사용자 이름이며 현지화 대상으로 바꾸지 않는다. 서비스 품질이나 접근성 인증, 원어민 교열을 주장하지 않는다.

## 발견하고 수정한 사항

작은 창의 가득 찬 무인 요약 겹침, 영어 연결/장비 표시의 줄바꿈, 전리품 그림 높이, 페이지 화살표 글자의 넘침, 1000px 경계에서 남던 큰 물품 그림 및 마지막 행동 버튼의 전체 너비, hover 설명의 물품 클릭 차단을 수정했다. 기존 전투 검사 중 개발 서버의 이미 로드된 모듈과 별도 모듈을 관찰하던 계측 코드는 실제 로드된 URL을 사용하도록 맞췄다. 게임의 공격·방어 판정과 검사 기대값은 바꾸지 않았다.
