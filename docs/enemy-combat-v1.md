# 적 전투 알고리즘 수정

2026-10-02. 기마·암살자의 이동, 혈교 범위 조준, 서역 투척환 회수, 얼음 폭탄 피해와 창병 범위를 수정했다. 일반 적 21종과 40보스가 공유하는 준비·공격·회복, 부채꼴 경고와 실제 판정을 함께 검토했다.

## 확인한 원인과 변경

| 문제 | 원인 | 변경 |
|---|---|---|
| 기마가 제자리에서 거리를 유지하며 공격하지 않음 | 돌진 시작 거리 160보다 후퇴 기준 187.5가 멀었다 | 시작 조건에 실제 돌진 거리 포함 |
| 기마·암살자 돌진이 갑자기 점프함 | 준비 종료 때 도착점으로 바로 위치 변경 | 잠근 도착점으로 0.16~0.55초에 걸쳐 이동, 지나간 경로에서 한 번 타격 |
| 암살자가 가까운 적을 지나 멀리 이동 | 거리에 관계없이 최대 220만큼 돌진 | 목표를 조금 지나도록 실제 거리로 제한, 근접 시 불필요한 옆걸음 중지 |
| 서역 환이 바로 돌아옴 | 총 수명 3초에 남은 수명 2.8을 회수 기준으로 사용 | 외향 비행 1~1.6초 확보, 회수 시 움직이는 발사자 추적 및 수거, 벽에서는 조기 회수 |
| 조준해도 중앙이 빗나감 | 짝수 탄을 조준선 양옆으로만 발사 | 일반 적·보스의 조준 연사에 중앙 탄 포함, 서역 환은 중앙과 양옆 세 발 |
| 범위 공격이 지나간 위치를 향함 | 준비 시작부터 착탄까지 오래된 좌표 고정 | 준비 초반 추적, 마지막 최대 0.4초는 경고 위치 고정, 발사 후 추적 금지 |
| 얼음 폭탄이 피해 없이 둔화만 남김 | 착탄 피해 미사용, 차가운 지대 전체를 피해 대상에서 제외 | 착탄 후 0.2초 예고를 거쳐 폭발 피해와 연출 동시 적용, 이어서 냉기 피해와 감속; 온기 지대는 안전 유지 |
| 설산에서 얼음 지대 감속 무시 | 지형 감속이 먼저 반환됨 | 설산 기본 감속과 적 냉기 지대 감속 함께 적용 |
| 창병 공격이 너무 좁음 | 청하 창병 165·반각 0.24 | 청하 창병 220·0.42, 고성 창병 250·0.4, 이전 저장의 일반 창병 215·0.42; 경고도 같은 수치 |
| 빠른 탄의 접촉 누락 | 이동 후 한 점만 검사 | 이전 위치와 현재 위치 사이의 선분을 판정에 사용 |

근접 공격은 준비 종료 후 0.09초의 실제 접촉 시점에 타격한다. 돌진 중에는 실제로 이동한 경로만 피해를 주며, 마지막 예고 부채꼴도 유지한다. 초식을 공격 종료까지 고정해 패턴 증가가 진행 중 공격을 바꾸지 않는다. 돌진 중간 저장·재개도 동일하게 이어진다.

## 표시

기마도 일반 적처럼 연속 Mesh2D 리그를 사용한다. 앞뒤 발굽과 안장의 움직임을 분리하고 준비·돌진·회복을 실제 시뮬레이션 시계에 맞췄다. 다섯 방향 원본과 좌우 반전으로 8방향을 유지한다. 이번 변경은 새로 그린 애니메이션 시트가 아니라 기존 그림을 사용하는 연속 변형이다.

정지한 접근 상태는 제자리 걸음을 하지 않는다. 후퇴는 조준 방향을 유지하며 보행 주기를 반대로 진행한다. 암살자 은신 해제는 남은 시간에 따라 서서히 표시한다. 움직임 줄이기는 장식 변형을 끄지만 실제 돌진 위치·경고·피해를 바꾸지 않는다. 얼음 투척물과 착탄 경고는 차가운 색으로 구별한다.

## 검증

- 타입 검사와 `npm run build` 통과.
- 단위 검사 23파일·403개 통과. 일반 적 21종의 접근→준비→공격→회복과 실제 피해, 각 적의 8방향 조준, 40보스의 기존 전체 초식 실행·저장 검사, 돌진 중간 재개, 얼음 폭발 회피/지속 피해/온기 안전, 투척환 회수, 창끝 경계, 고속 탄 검사 포함.
- 브라우저 자동 검사 18개 통과: 기마·암살자·혈교·얼음·창병의 실제 렌더러, 8방향 이동/정지 리그, 독병 및 보스의 연사·독·회수·돌진, 세 화면 크기의 가방/웨이브 진행, 20웨이브 귀환, 1093×614 실제 키보드·마우스 이동/공격/가방 닫기 후 재개.
- 캡처와 상태 추적은 [전투 증거](verification/enemy-combat-v1/), [기존 지역/보스 검증](verification/regional-identity-v1/), [웨이브 진행 검증](verification/wave-progression-v1/)에 있다. 기마 경고, 혈교의 플레이어 중심 경고, 얼음 착탄 그림을 캡처로 직접 검토했다. 테스트 데이터는 독립 브라우저 컨텍스트만 사용했다.
- 자동 판정 검증과 시각 검토는 적 전체의 장시간 수동 플레이나 난이도 균형 검증을 대신하지 않는다. 창 범위와 실제 냉기 피해가 추가되어 해당 전투의 난이도는 달라진다.

## 주요 파일

`src/domain/game.ts`, `enemy-geometry.ts`, `region-enemies.ts`, `combat.ts`, `environment.ts`가 조준·이동·판정을 소유한다. `src/domain/model.ts`와 `src/platform/save-validation.ts`는 진행 중 타격과 착탄 피해를 검증한다. `src/game/CombatScene.ts`, `continuous-actor.ts`, `directional-motion.ts`, `telegraphs.ts`, `effects.ts`가 연출을 소유한다.
