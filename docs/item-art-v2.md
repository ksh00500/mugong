# 물품 전용 그림 v2

대상은 실제 물품 목록의 일반·지역 물품 52개와 원본 기획의 보스 고유 보상 40개다. 한 종류의 대표 그림을 재사용하지 않고 물품마다 별도 PNG를 생성한다. 능력치·드랍·가방 칸 수·이름은 바꾸지 않는다.

## 제작 기준

카툰은 표현 방식이며 물품의 형태는 무협 세계를 따른다. 검·도·봉·암기·권갑·부채를 구별하며 등급별로 실루엣과 재질을 바꾼다. 지역 물품은 독초·청죽·설산·서역·고묘 등의 소재를 따른다. 장식 테두리·글자·광원·배경·인물은 그림에 넣지 않는다.

사용자 검토 후 신발 7종은 다시 제작했다. 굽과 금장 버클, 현대적인 고무 밑창을 배제하고 천신·얇은 꿰맨 밑창·부드러운 가죽 덧댐·발목 천 감개를 사용한다. 유운화·비연화의 구름과 제비는 작은 자수로, 설산 장비는 털 안감으로 구별한다. 신발의 초기 시안은 원본 폴더에 남지만 런타임에는 `-v3` 수정본만 연결한다.

전체 도감의 시각 검토에서 약병 2종·수련 비급·기문반도 수정했다. 유리 포션병과 금장 책 모서리를 도자기 약병·호리병·실 제본 비급으로 바꾸고, 서양식 나침반 장미는 팔괘 방위반으로 바꿨다. 이 4종도 `-v3` 파일만 연결한다.

## 파일과 연결

- [92개 프롬프트](source/item-art-v2-prompts.json): 내장 imagegen 도구로 물품별 독립 생성. CLI/API 우회 사용 없음.
- 원본: `assets/item-art-v2/source/`. 생성 PNG와 신발 초기 시안을 그대로 보존하되 웹 배포에는 포함하지 않는다.
- 배포: `public/art/items-v2/*.webp`. 512px 이내의 UI 전달용 크기·압축만 적용한다. 92종 합계 2,887,810바이트다. 초기 시안의 WebP도 `assets/item-art-v2/drafts/`로 옮겨 배포에 포함하지 않는다.
- `src/platform/item-art-manifest.json`: 투명 여백을 측정한 실제 그림 범위. SVG는 원본을 보여주는 창으로만 사용하며 물품 그림을 새로 그리지 않는다.
- 가방 격자·착용 장비·선택 정보·드래그 미리보기·창고/정리판/전리품·상점은 동일한 `ItemArt`에서 물품 ID를 읽는다.
- 회전은 가방 규칙의 방향을 그대로 따라가며 범위와 중심을 함께 회전한다. 색상·강화·등급 때문에 저장된 물품 ID를 바꾸지 않는다.
- 기존 저장의 이름·보스 출처도 조회한다. 알 수 없는 물품과 이미지 로딩 실패는 기존 종류 아이콘으로 표시한다.
- 92개 파일을 시작 화면에서 모두 사전 로딩하지 않는다. 현재 보이는 그림만 내려받아 화면 간 브라우저 캐시를 공유한다.

## 검토 기록

자동 검사와 실제 그림 검토 결과를 구분한다. [전체 검토 화면](verification/item-art-v2/gallery.html)은 큰 그림과 36px 축소 그림을 함께 표시한다. 게임 적용은 인벤토리 그림이며 캐릭터가 쥐는 무기 애니메이션 교체는 이 작업 범위에 포함하지 않는다.

2026-10-01 최종 확인:

| 구분 | 확인 내용 | 결과 |
|---|---|---|
| 자동 데이터 검사 | 실제 물품 92종 전체 매핑·별도 파일/원본 해시·투명 영역·그림 범위·옛 저장 식별 | 물품 검사 3개 통과 |
| 자동 단위 검사 | 물품 검사 포함 전체 강호 규칙·저장·전투·애니메이션 | 14파일, 199개 통과 |
| 자동 기존 브라우저 회귀 | 드래그·충돌·경계·종류 제한·회전·연결·사용·장비 교체·여러 화면 크기·5언어 | 21개 통과 |
| 자동 전용 그림 브라우저 검사 | 세 화면 크기의 그림 범위·회전·사용·착용, 이미지 실패 대체, 전체 92종 도감 캡처 | 5개 통과 |
| 배포 빌드 | TypeScript + Vite, 배포 폴더에 원본 PNG가 없는지 확인 | 성공, 물품 WebP 92개 |
| 사람이 확인한 시각 검토 | 도감 4장으로 92종 전체 확인, 무협 복식과 소품 확인, 최종 가방 1440×900·1366×768·1093×614 캡처 검토 | 신발 7종·약/비급/방위반 4종 수정 후 확인 |

캡처는 `docs/verification/item-art-v2/catalogue-1.png`부터 `catalogue-4.png`, `bag-1440.png`, `bag-1366.png`, `bag-1093.png`다. 픽셀 범위 자동 검사와 사람의 그림 검토는 서로 다른 근거이며 서비스 수준이나 접근성 인증을 뜻하지 않는다. 36px의 긴 검·봉은 세부 장식이 작아지므로 선택 정보의 이름과 더 큰 그림도 함께 사용한다.

신규 회전 테스트의 첫 실행은 첫 저장 완료 전에 두 번째 R을 보내 실패했다. 관리 버튼이 활성화될 때까지 기다려 저장 완료와 실제 다음 입력을 확인하도록 수정한 후 세 크기 모두 통과했다. 빌드·브라우저와 동시에 실행한 기존 애니메이션 검사 하나는 5초 제한에 걸렸으며, 다른 작업 종료 후 전체 단위 검사를 단독 실행해 199개 모두 통과했다.
