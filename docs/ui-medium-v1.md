# UI·UX 보통 항목 수정

2026-10-20. 사용자 요청으로 감사 **U21–U24**를 구현·검증하고 로컬5205에 적용했다. 기준은 `83788e0328419289609b9c641701d4746a3b5927`, 브랜치는 `codex/ui-medium-v1`이다. [검증 기록](verification/ui-medium-v1/README.md)에 실제 실행 결과와 시각 검토 범위를 구분한다.

## 적용 내용

| 감사 | 변경 |
| --- | --- |
| U21 | 빈 명부에서 첫 출전·20웨이브 완주·7일 보존과 규칙 안내를 연결한다. 전사는 실제 웨이브·처치·여정 시간·이미 방문한 지역만 표시하며 잃는 물품과 유지되는 세가 자산을 구분한다. 완주는 실제 귀환 물품 수·정산·시간을 표시하고 `무인의 가방`을 주요 행동, `명부 확인`을 보조 행동으로 제공한다. |
| U22 | 공통 한지/보조/hover/선택 표면, 패널/버튼/선택 그림자와 명령 아이콘 크기를 토큰으로 정리한다. 로비·성장·모집·가방 선택·창고·설정은 각 소유 CSS에서 사용한다. 선택은 내부 테두리와 표면, 키보드 초점은 외부 윤곽선으로 구분한다. 고대비 표면은 별도 토큰을 쓴다. |

| U24 | 세 해상도의 주요21상태를 다시 촬영·측정하고, 실제 버튼 조작·저장 확인 검사를 함께 실행한다. 다섯 언어, 큰 HUD·고대비·동작 감소, 긴 이름·큰 숫자, 빈/가득 찬 가방, 이동·폐기 취소/확인, 로딩 실패·최신 사망 복구를 포함한다. 구체적 실행 수와 제외한 준비 실패는 검증 문서가 기준이다. |

결과 화면은 내용 영역만 필요할 때 스크롤하며 하단 행동은 유지한다. 이미 저장하는 정보만 사용하고, 수집하지 않는 피해 원인·평가 점수는 만들지 않는다. 실제 사망/귀환/수명 만료 규칙과 저장 형식, 가방4×7·10×8, 전투 수치는 바꾸지 않는다. 수명 만료 시 기존 규칙대로 물품이 세가 창고로 이동한다는 설명을 추가한다.

전체 회귀에서 가방의 실제 키보드 버그도 확인했다. 능력치 설명의 focusout/unmount를 관찰한 초점 복구가 기본 Tab 이동 도중 임시 `body` 초점을 유실로 판단해 첫 버튼으로 되돌렸다. 복구 판단을 다음 animation frame으로 묶고 해제 시 취소한다. 사용자의 입력 자체는 지연시키지 않는다. 세 해상도에서 능력치 사이의 Tab/Shift+Tab, 무공 설명까지 이동, 닫기 후 원래 가방 버튼 복귀를 검사한다.

## 원화 판단

보라색 원화는322×442px이다. 이전 로컬 빌드의1440×900 표시 높이는680px(약1.54배),1366×768은601px(약1.36배)였다. 이번 표시 상한은442px이며 투명 여백을 자르거나 가로세로 비율을 변형하지 않는다. 좁은 화면은 `object-fit:contain`으로 더 작게 들어간다. 외형10종과 기본 검객을 세 해상도에서 실제 디코딩해 총33회 측정한다.

이 수정은 저해상도 원본을 확대하면서 생기는 흐림을 줄인다. 새 고해상도 디테일을 생성하거나 모든 DPR에서 원본의 선명도를 보장하는 작업은 아니다. 이미지 파일과 제작 원본은 수정·삭제하지 않는다. 더 큰 로비 인물이 필요하면 동일 정체성의 고해상도 전신 원화를 별도로 제작해야 한다.
