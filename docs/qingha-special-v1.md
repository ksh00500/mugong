# 청하현 보스 특별 모션

2026-10-06 제작. 청하현 보스 4명의 8행동을 기본 원화와 함께 로컬 전투에 연결했다. 원화 40장의 경계·손·무기·관절과 20시점 표의 240발 후보를 검토하고 노진 뒷모습 3노출의 발 중심을 수동 보정했다. 최종 자동 검사와 전투 화면 검토는 아래 기록을 따른다.

| 보스            | 전용 원화 행동               | 동작 기준                                                               |
| --------------- | ---------------------------- | ----------------------------------------------------------------------- |
| 흑풍채주 마대봉 | 산채 호령 / 채주 들이받기    | 오른손 도 유지, 빈 왼손 지휘 / 왼쪽 어깨 돌진                           |
| 청하표두 노진   | 삼연 찌르기 / 청하 호위기    | 한 창의 두 지점 잡기·접촉 사이 재장전 / 왼손 지휘 후 앞쪽 창 잡기 복귀  |
| 백면포두 철무   | 쇄겸 포획 / 쇄겸 회전        | 오른손 사슬 투척·회수, 왼손 예비 사슬 유지 / 몸통·골반과 함께 수평 회전 |
| 하북패도 한무극 | 패도 축적 참격 / 패도 대회전 | 오른손 도를 올려 힘 싣고 아래로 베기 / 수평 회전 후 회수                |

각 행동은 준비·힘 싣기·판정·후속·회수·대기 6노출, 5개 원화 시점과 좌우 반전으로 8방향을 표시한다. 선택 PNG 40장, 저장 프레임 240개, 런타임 무손실 WebP 20장이다. 청하현 실제 키트 20행동 중 이 8행동에 전용 원화를 추가하고 나머지 12행동은 기존 기본 동작을 재사용한다.

노진 뒷모습 호위기의 회수 1노출은 관절이 올바른 힘 싣기 그림을 명시적으로 재사용한다(`poseReuse: 10 → 7`). 원화의 여분 팔이 남은 후보 노출은 게임에 사용하지 않는다. 240개 저장 프레임을 모두 독립적으로 새로 그린 그림 수로 해석하지 않는다.

원본 인물 픽셀은 1:1로 복사하고 인물별 모든 기본·특별 동작에 0.225 배율을 유지한다. 무기가 긴 프레임은 출력 셀을 넓히고 최소 32픽셀 패딩을 둔다. 프레임별 몸체 맞춤 축소·왜곡을 추가하지 않는다. 원화 자체의 크기·손·관절·빛·방향 오류는 후보와 실제 프롬프트를 보존한 채 재제작한다.

발 좌표는 각 프레임의 부츠와 비교해 저장하며 런타임 자동 탐색을 하지 않는다. HP바는 기본·특별 살아 있는 자세의 최대 높이에 고정 여유를 더한다. 검토 페이지도 이 최대 높이로 캔버스와 접지선을 정해 들어 올린 무기 끝이 잘리지 않게 한다.

`boss-special.ts`와 지역 0 manifest에 연결한다. 노진의 호위기는 실제 `flag` 동작이므로 방어 유지 자세를 만들지 않는다. 삼연 찌르기는 실제 0.1/0.6/1.1초 접촉을 따라 재장전한다. 무기 그림이 별도 피해 판정을 만들지는 않는다.
