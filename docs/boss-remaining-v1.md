# 네 지역 보스의 나머지 행동

2026-10-08. 소림·천검산·독무곡·청하현의 이미 등록된 16보스에서 나머지 41행동을 연결했다. 소림8·천검산11·독무곡10·청하현12개다. 네 지역 실제 kit의 73행동 모두 행동별 그림 시퀀스를 갖는다. 기존 설산 목진2행동까지 포함하면 게임 특별 그림 연결은 17보스75행동이다. 다른 지역의 검토 시안을 게임에 등록한 것으로 해석하지 않는다.

## 원화와 시퀀스

내장 imagegen으로 선택 원화18시트, 방향별 접촉 그림90개를 제작했다. 시트는 남·남동·동·북동·북의 같은 접촉 자세5개와 READY 크기 기준1개다. 반대 방향3개는 기존 방향 매핑대로 뒤집는다. 쇠권/금강장, 어깨 돌진, 지면 타격, 진각, 수평 베기, 쌍검/단검 찌르기, 술병 직접 타격, 역손 부채, 지팡이 횡소, 쇠사슬 지면 타격을 구별했다.

준비·힘 싣기·회수는 적합한 기존 기본/특별 그림을 재사용한다. 새 접촉 뒤에는 같은 그림을 후속으로 잠시 유지한다. 41행동은 연격의 각 실제 접촉마다 독립적인 6단계 시퀀스를 가져 총1,590논리 프레임이다. 이는 새 그림1,590장을 생성했다는 뜻이 아니다. 기존1,020논리 프레임과 합쳐2,610개이며 같은 그림을 여러 행동/단계가 참조한다. 실제 출처와 단계별 선택은 [내보내기 계획](source/boss-remaining-v1/export-review.json)에 보존했다.

공허 왼손 첫 시안은 다른 팔이 나와 미채택했다. 청린 찌르기의 북/북동 검끝이 옆을 향한 시안을 교정했다. 무명의 기존 돌진 후속에는 잔상 인물이 포함돼 찌르기 재사용을 철회하고, 전용 찌르기/횡소를 만들었다. 횡소 북동 시안도 측면으로 생성돼 다시 후면 사선으로 교정했다. 미채택 원본을 삭제하지 않았다.

## 크기와 접지 규칙

새 생성 시트는 마지막 READY의 실루엣 높이를 기존 남향 READY와 비교해 **시트 전체에 같은 배율을 한 번** 적용한다. 5방향과 모든 접촉 자세가 이 배율을 공유하며 낮은 자세나 긴 무기 때문에 개별 프레임을 맞춤 축소하지 않는다. 원본 PNG는 별도 보존하고, 정규화한 게임 출력은 손실 없는 WebP와32px 이상의 패딩을 사용한다. 새 출력은 생성 원본 RGBA를1:1 복사했다는 의미가 아니다. 기존 그림 재사용은 기존 픽셀과 발 좌표를 그대로 따른다.

90접촉의 발 기준점은 무기 끝/전체 그림 바닥 대신 장화 위치를 직접 보고 지정했다. 게임 표시 배율0.225는 그대로이며 HP바는 기본/특별/추가 행동의 최고 도달 높이를 모두 포함한 인물별 고정 간격을 사용한다. 자동 패딩·좌표 통과가 모든 관절/머리 치수에 대한 완전한 수동 승인이라는 뜻은 아니다. 기존 그림 뱅크의 시점별 원근·손 전환 등 세부 미술 다듬기는 별도 후속이다.

## 게임 연결

`boss-special.ts`가 기존 특별 원화와 추가 메타데이터를 합친다. `boss-motion-cycle.ts`는 시뮬레이션의 접촉 배열로 연격 N번째 접촉/후속을 유지하고 다음 힘 싣기에서 N+1로 전환한다. 마지막 회수는 마지막 타격을 따른다. 일반 공격의 피격/사망 그림을 회수로 쓰지 않는다. 기존 잡기 유지·반격 유지와 움직임 줄이기 규칙을 보존했다. 피해·CC·추격 AI·판정 시간·저장 데이터는 이번 변경 대상이 아니다.

지역0·1·2·4가 해당 지역 새 텍스처만 준비하고 실제 Phaser 프레임을 등록한다. 기존 기본/특별 원화가 같은 텍스처 안에서 추가 프레임 이름을 갖더라도 잘라낸 범위는 출처와 동일하다.

## 검증과 적용

타입 검사와 분리 빌드를 통과했다. 단위9검사, 네 지역 Canvas/WebGL×일반/움직임 줄이기16검사 후 마지막 교정이 바꾼 독무곡·천검산8검사를 다시 실행했다. 자동 검사는 실제 렌더 프레임·방향·접촉 차수·고정 배율·HP바 간격·상태 불변을 확인한다. 캡처의 무기/몸 형태를 직접 비교한 결과와 구분한다. 구체적 결과는 [검증 기록](verification/boss-remaining-v1/README.md)을 따른다.

분리 빌드의 컴파일 자산과 이번 그림 폴더만 로컬 `dist`에 복사한다. 기존 지역 검토 폴더는 보존한다. [행동 비교 화면](http://127.0.0.1:5173/art/boss-remaining-v1/review.html)과 로컬 게임에 적용하며 공개 배포는 이번에 하지 않았다. 실제 사용자 저장을 검사 데이터로 사용하거나 변경하지 않았다. 1800kB 초과 번들 경고는 남는다.
