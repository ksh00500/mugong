# 1차 화면 구조 검토

검토일: 2026-09-27

기준 기획: [게임 기획 v1](../game-design-v1.md)

대화 안의 화면 구조 시안은 `mugong-first-draft.html`이다. 실제 게임·서버·저장·경제 기능을 구현한 산출물이 아니다. 인물·체력·시간·가격·격자·배치와 전투 공간의 도형은 예시이며, 최종 그래픽과 밸런스를 뜻하지 않는다. 기존 런타임 에셋을 사용하지 않았다.

## 확인한 행동

- 로비에는 명부·가방·창고·시장 메뉴가 있고 전투·정비에는 해당 로비 메뉴가 없다. 화면을 비교하는 선택기는 제품 바깥의 검토용 컨트롤이다.
- 레이드 전투에서 가방을 열면 전투 진행·캐릭터 조작 불가·정보 확인 상태를 표시한다. 사용·정리판 이동은 비활성이다.
- 강호 전투 가방에는 강호 육성 상태와 전투 일시 정지를 표시한다. 현실 수명은 강호 완료 전 시작하지 않는다.
- 가방의 두 지혈산은 각각 한 칸을 차지한다. 두 개를 정리판으로 옮기면 한 묶음 `지혈산 ×2`로 표시한다.
- 정리판에 물품을 남기고 닫으면 목록·수량을 표시한다. 취소하면 계속 정리할 수 있고, 회수하면 수량이 줄어든다. 확인하면 시안의 물품을 버리고 닫는다.
- 레이드의 계속 도전을 선택한 후 파티원 이탈 상황을 표시하고, 3인 난이도와 재귀환 선택을 제공한다. 계속 진행 후 남은 전원이 준비하면 다음 층 화면으로 넘어간다.
- 장비 시장은 검색·종류 필터·매물 선택으로 상세 정보가 바뀐다.
- 최종 미리보기의 실행 로그에 오류가 없음을 확인했다.

## 배치 검토

로비·가방·창고·장비 시장·강호 전투·레이드 전투·강호 정비·레이드 층 사이의 8개 화면을 각각 320·736·1024px 브라우저 폭에서 확인했다. 24개 조합에서 문서의 가로 넘침과 우측으로 잘리는 버튼·입력·선택 컨트롤은 없었다. 좁은 폭에서 정보 패널을 세로로 재배치한다. 가방 화면의 실제 스크린샷으로 배치와 글자 표시도 확인했다.

이는 화면 시안의 확인이며 실제 멀티플레이, 충돌·판정, 성능, 아이템 소유권, 서버 저장, 수명 만료의 검증은 아니다. 무장 연결 설정과 테트리스 드래그, 표준 상품 호가 시장·비무 매칭·생사결 판정 등은 기획의 화면 요구사항이며 시안에서 전체 기능을 구현하지 않았다.
