# 전투 HUD 행동 조작

2026-10-22. 표시만 하던 방어 제목과 궁극 게이지를 실제 버튼으로 연결했다. [검증 기록](verification/combat-actions-ux-v1/README.md).

- 방어 제목을 클릭하거나 Space를 누른다. 궁극 게이지를 클릭하거나 전장에서 우클릭한다. HUD 클릭은 캐릭터가 바라보는 방향을 사용하며, 전장 마우스 입력은 기존 조준을 유지한다.
- 무장·수련 단계·게이지·방어 재사용·공격 후 회복·행동 불가·취기 강화 예약 한도를 실제 전투 함수와 같은 조건으로 확인한다. 사용할 수 없는 이유를 인접한 텍스트와 접근성 설명에 표시한다. 게이지가 가득 차도 실제 발동 조건이 충족되지 않으면 준비 강조를 하지 않는다.
- 버튼은 사용할 수 없는 때에도 초점을 유지해 사유를 확인할 수 있다. `aria-disabled`와 실행부 검사를 함께 사용한다. 버튼에서 Space/Enter는 해당 버튼의 기본 동작이며 별도의 방어 입력을 중복 발생시키지 않는다. 일시정지는 Escape와 닫기로도 전투에 복귀한다.
- HUD 입력은 다음 시뮬레이션 프레임에서 한 번만 소비한다. 메뉴·무공 변경·화면 숨김·로딩·여정 변경·250ms를 넘긴 입력을 취소하고, 소비할 때도 조건을 다시 검사한다. 입력 요청 자체를 저장하거나 별도의 전투 시간을 진행하지 않는다.

기존 전투 수치·적 행동·저장 형식·이미지 원본은 유지한다. 실제 사용자 저장을 읽거나 테스트 값으로 교체하지 않는다. 테스트는 독립 브라우저 컨텍스트의 합성 여정만 사용한다. 이번 작업은 전투 행동 HUD의 개선이며 전체 UI 재설계나 인간 플레이 밸런스 검증 완료를 뜻하지 않는다.
