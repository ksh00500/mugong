# 캐릭터 동작 원화 재제작 v2

2026-10-03. 이번 변경은 주인공, 10지역의 일반 적과 40보스, 전용 역할, 기병 및 드론을 대상으로 한다. 기존 캐릭터 설정을 참조해 동작 시트를 새로 제작했다. 신규 캐릭터 종류를 추가한 작업은 아니다.

## 동작과 크기

일반 적의 남쪽 및 남쪽 대각선 보행은 실제 이동 상태와 이동 거리 기반 gait에 맞춰 두 원화가 번갈아 나온다. 나머지 이동 방향은 기존 방향 원화와 리그를 사용한다. 이동 중 측면 회복에도 방향 리그를 유지하며, 정지한 회복 자세로 잘못 전환하지 않는다. 기병은 정면/사선 키 그림을 교대로 쓰지 않고 기존 방향별 말 리그로 달린다.

주인공은 이동 중 두 보행 행을 선택한다. 보행의 다리 움직임은 리그가 보완하며, 공격과 반응 원화에는 이미 그려진 굽힘을 리그가 중복 적용하지 않는다. 피격과 사망은 별도 방향 시트로 표시한다. 드론은 몸 전체를 회전시키지 않고 날갯짓 프레임만 바꾸며 작은 부유 이동을 유지한다.

프레임의 무기 끝, 높은 준비 자세 또는 누운 사망 자세의 전체 높이로 몸 크기를 정하지 않는다. 기존 `silhouetteUnit`과 `matchedPoseHeight`로 같은 인물의 불투명 몸 단위를 기준 그림에 맞춘다. 주인공 반응도 각 방향의 대기 몸 단위에 맞춘다. 전투 피해·이동·쿨타임은 기존 시뮬레이션이 계속 소유하며 원화 프레임이 판정을 바꾸지 않는다.

## 제작·보존·검수 규칙

- 기본 imagegen으로 기준 원화를 참조했다. 지역 시트의 프롬프트는 6열×7행, 같은 얼굴·복장·무기·몸 비율, 두 보행·준비·타격·피격·사망, 투명 배경과 여백을 지정했다. 과도한 장식·공격 효과·격자·글자는 요구하지 않았다.
- 검토 중 다른 무기, 사라진 수염, 타인으로 바뀐 피격, 승려의 갑작스러운 금속 장갑을 확인해 해당 시트를 다시 보정했다. 주인공의 뒤쪽 보행 칸도 보정했다. 보정 결과의 반투명 배경이 연결 요소를 오염시킨 사례를 실제 브라우저 검사에서 확인해 배경 제거를 다시 수행했다.
- 이전 `regions-v1`, `enemy-motion-v1`, `direction-v2`, 역할·identity 원본은 삭제하거나 덮어쓰지 않는다. 새 생성 원본은 `docs/source/animation-rebuild-v2/*.png`, 선택 기록은 `manifest.json`에 보존한다.
- `scripts/export-animation-rebuild.mjs`는 연결된 인물을 개별 분리해 투명 여백이 있는 256칸으로 배치하고 WebP로 전달한다. 주인공 기본 시트는 기존 손 좌표의 셀 기준을 유지한다. 이는 생성 원본의 전달 크롭/패킹이며 새 그림을 코드로 그리지 않는다.
- 전달 전 빈 칸·동일 연결 요소의 중복 선택·넓은 반투명 배경을 거부한다. `export-report.json`에는 투명도, 원본/전달 SHA-256, 크기, 프레임 경계를 기록한다. 생성 성공만으로 승인하지 않는다.
- `src/platform/character-identities.json`에 인물 ID·실제 선택 원화 경로·육안 검토 근거를 기록한다. 부적절한 행을 무기 유형이 같다는 이유로 다른 인물에서 재사용하지 않는다.

## 검증과 범위의 한계

자동 검사는 로딩·프레임 분리·보정 배율·8방향 연결·유한한 메시 좌표·보행 상태·주인공 반응·드론 회전/날갯짓을 검사한다. 직접 시각 검토는 생성 시트의 얼굴·복장·무기와 실제 크기로 렌더링한 비교표를 확인한다. 두 결과는 같은 의미가 아니다. 증거는 `docs/verification/animation-rebuild-v2/` 및 기존 방향/동작 검사 캡처 경로에 남긴다. 테스트는 독립 브라우저 컨텍스트에만 저장한다.

적의 여섯 자세는 대표 방향의 키 원화이며, 모든 방향마다 독립적으로 수십 프레임을 그린 전통적 연속 애니메이션은 아니다. 후면 세 방향과 측면 보행은 기존 방향 원화·역할별 리그로 이어진다. 최종 동작은 키 원화와 리그 보간을 함께 사용한다. 머리·복장·무기의 주요 동일성을 검토했으나 장식 픽셀 단위의 완전 일치를 보장하지 않는다. 이번 변경은 로컬 코드와 에셋 적용이며 Daytona 반영 여부와 구분한다.

### 최종 확인 기록 (2026-10-03)

- `npm run build` 성공. 단위 검사 37파일, 892항목 통과.
- 브라우저 검사 37개 고유 사례 통과: 지역 동일성 10, 방향 동작 14, 기관/주인공 1, 반응/드론 1, 이동 프레임 독립성 1, 지역별 준비·타격·회복·피격·사망 10. 마지막 지역별 10개와 반응 1개를 재실행하여 11개 모두 통과했다.
- 회복 자세 검사는 정지 상태를 명시한다. 이동 중 회복은 별도 검사에서 방향 리그와 실제 이동 상태를 확인한다. 피격·사망 검사는 직전 공격 상태에서도 공격 돌진/회전이 남지 않는지 확인한다.
- 생성 시트와 실제 렌더링 비교표를 육안으로 확인했다. 지역 6 세 번째 인물의 피격 자세에서 황동 고글이 생략된 작은 장식 불일치는 남아 있다. 추가 생성 결과가 다른 인물에도 고글을 붙여 해당 결과는 적용하지 않았다. 후속 수정은 이 셀만 변경하고 나머지 인물 보존을 다시 검수해야 한다.
