# 방향·행동별 캐릭터 크기 검토와 교정

2026-10-19. 전체10지역 일반 적30종·보스40종의 다섯 시점 READY를 동일 발 원점/비교 배율로 검토했다. 기본4,200·특별/추가6,660, 합계10,860논리 프레임의 메타데이터를 조사했다. 이 수치는 서로 다른 원본 그림10,860장을 뜻하지 않는다. 보스40종의 전체 자세 비교판도 생성했으며, 모든 관절/머리 치수를 수동 승인했다는 뜻은 아니다.

## 확인한 원인

- 현재 원화 렌더러는 항상 `pixelScale=0.225`다. 런타임이 공격마다 화면에 맞춰 자동 축소하는 경로는 사용하지 않는다.
- 원화 자체의 신체 크기가 방향별/제작 시트별로 다르다. 특히 제갈현 앞사선 특수 모션은 준비·접촉·회수 전부 기본 그림보다 컸다.
- 이전 세 지역 특별 원화 내보내기는 별도로 생성한 여러 시트를 캐릭터당 하나의 평균 계수로 보정했다. 각 시트의 크기가 다르면 평균 계수와 동일 READY 재사용만으로는 공격 중 크기 차이를 없앨 수 없다.
- 전체 알파 경계 높이는 신체 크기가 아니다. 세운 창·봉, 펴는 부채, 숙임·쓰러짐은 실루엣 길이를 바꾼다. 이 값을 프레임마다 같게 맞추면 정상적인 동작과 무기 길이를 망친다.

## 이번 교정 범위

| 대상 | 교정 |
| --- | --- |
| 제갈현 | 앞사선 부채 공격·시전의 원화 묶음을 각각 기본 READY와 비교해 보정 |
| 양기 | 지나치게 작던 후면 봉 횡격 묶음을 확대 |
| 묵연 | 작던 앞사선 기본12자세를 함께 확대하고 해당 특수 모션 묶음과 크기 연결 |
| 진괄 | 앞사선·뒤사선 수세 묶음의 과도한 신체 크기 축소; 세운 창의 높이는 별개로 유지 |
| 설산 창병 | 정면의 작은 몸과 측면/뒤사선의 큰 몸을 보정하고 앞사선/후면 전투 묶음도 비교 |

원본 파일과 이전 아틀라스를 보존했다. 생성 AI로 새 그림을 그린 작업은 아니며, 검토한 제작 보정값을 원화 묶음 전체에 적용하는 결정적 내보내기다. 새13아틀라스/100물리 셀을 만들고104물리 참조(기존 READY 복사본4개 포함)/141논리 프레임을 연결했다. 비율을 유지하지만 보간을 거치므로 RGBA1:1 출력이라고 표현하지 않는다.

`docs/source/native-size-v1/calibration.json`은 육안 비교 후 선택한 고정 제작 상수다. 해부학적 정밀 실측값이나 전체 프레임 자동 정규화 기준이 아니다. 공격마다 별도 비율을 계산하지 않고, 같은 소스의 준비·접촉·후속·회수는 한 계수를 공유한다. 후속 교정/한 장 대체는 명시한 소스 예외로 기록한다.

발 좌표는 원화와 함께 같은 제작 계수로 변환한다. 프레임 바깥32px 투명 여백과 기본 캐릭터 공통 캔버스를 유지하고, 칸에 안 들어가면 축소하지 않고 내보내기를 거부한다. 기본/특별/추가에서 재사용하는 READY와 접촉 그림 참조를 모두 갱신한다. 체력바는 인물별 고정 최대 높이를 보존/확장한다. 판정·AI·공격 시간·사거리·저장 데이터는 바꾸지 않았다.

## 재현

일치하는 원본/런타임 에셋을 복원하고 Sharp 경로를 지정한다.

```powershell
node scripts/export-native-size-v1.mjs
npm run assets:art-index
node scripts/native-size-review.mjs
node scripts/verify-native-size-v1.mjs
```

`*-before.json`과 `textures-before.json`은 처음 실행 시 보존한 안정 입력이다. 재실행으로 이미 줄인 그림을 다시 줄이지 않는다. 입력 스냅샷을 현재 값으로 임의 교체하지 않는다. 원화 제작 파이프라인을 다시 실행하면 교정 내보내기/경로 인덱스도 순서대로 갱신한다.

이번 자동 검사와 실제 렌더/직접 시각 검토·로컬 적용 여부는 [검증 기록](verification/native-size-review-v1/README.md)에 구분한다. 원화별 미세한 비례·카메라 각도 차이는 재생성 판단이 필요한 후속 미술 검토이며, 전체 게임 미술 완성이나 모든 실기기 검증을 주장하지 않는다.
