# 전투 후 웨이브 진행 UX

2026-10-01. 가방의 작은 진행 버튼과, 전투 후 가방을 닫으면 진행 방법이 보이지 않는 문제를 수정했다.

## 행동 흐름

1. 전투 종료와 저장 성공 후 가방이 자동으로 열린다.
2. 가방 하단에 다음 웨이브를 큰 주요 행동으로 표시한다. 20웨이브에서는 귀환으로 바뀐다.
3. 가방을 닫으면 전장에 `웨이브 완료 · 가방 · 다음 웨이브`가 표시된다. 별도 모달이나 설명을 읽을 필요 없이 재정리하거나 진행한다.
4. 닫기만으로 전투를 시작하거나 물품을 버리지 않는다. 남은 전리품은 기존 확인 창에서 명시적으로 선택한 뒤에만 두고 간다.
5. 정리판의 수납/폐기 확인, 정비 구간, 성장 선택, 일시 정지, 저장 오류 흐름은 유지한다. 전투·정비 중에는 전투 완료 배너가 표시되지 않는다.

## 배치와 입력

- 데스크톱 가방 진행 버튼: 높이 60px, 최소 너비 240px, 글자 24px. 자동 정리는 보조 행동이다.
- 진행 버튼이 있는 가방만 하단 높이와 격자 높이 계산을 조정한다. 진행 버튼이 없는 가방의 하단 높이는 유지한다. 낮은 화면의 무인 정보·물품 상세 여백도 함께 줄여 전리품 영역과 겹치지 않게 했다.
- 가방·필드 모두 한지 소재와 옥색 주요 버튼을 사용한다. 완료 표시는 전장 HUD의 상단/하단을 가리지 않는다.
- 필드 가방 버튼으로 다시 열었다 닫으면 그 버튼으로 초점이 돌아온다. 가방을 연 버튼은 숨겨도 DOM에 유지한다. 대화상자 초점 복귀는 React의 화면 갱신 이후 처리하여 숨김 해제를 반영한다.
- 필드 진행 버튼에서는 Tab/Shift+Tab으로 이동하고 Enter/Space로 실행한다. Tab 입력이 가방 전역 단축키로 다시 전달되지 않는다. 다른 전투 조작은 유지한다.

## 검증

최종 실행: `npm test` 243개 통과, `npm run build` 성공. 웨이브 진행 20개·보스 이름표 9개·기존 가방 6개·장비 비교 18개·대화상자/저장 보호 6개·전투 HUD 5개, 관련 브라우저 검사 64개가 모두 통과했다.

독립 Playwright 컨텍스트의 테스트 저장만 사용한다. 실제 사용자 저장은 수정하지 않는다.

`tests/e2e/wave-progression.spec.ts`는 1440×900, 1366×768, 1093×614에서 한국어·영어·일본어·간체·번체 배치와 가방 종료/재개/키보드 진행을 검사한다. 추가로 800×600, 390×600의 진행 행동을 확인한다. 남은 전리품 보호, 20웨이브 귀환 저장, 일시 정지와 전투 진입도 확인한다. 기존 가방·장비 비교·대화상자 검사를 함께 실행한다.

화면 캡처는 `docs/verification/wave-progression-v1/`에 보관한다. 자동 검사는 경계·스크롤·글자 넘침·영역 겹침과 동작/저장을 확인한다. 별도로 한국어 큰 화면과 1093×614, 일본어 작은 화면의 캡처를 열어 그림 소재, 주 행동 크기, HUD와의 어울림을 검토했다. 접근성 인증이나 실제 서비스 전체 품질을 보증하는 결과는 아니다.
