# 적 동작 그림 적용과 비율 보정 — 2026-10-03

## 적용

대상은 현재 10지역의 일반 적 21역할과 40보스다. 앞쪽 5방향 구간에서는 준비(2), 타격(3), 회복(0), 피격(4), 사망(5) 동작 그림을 실제로 사용한다. 이동은 방향 그림을 유지하여 걸을 때 앞모습으로 돌아가지 않게 한다. 공격 이미지와 실제 판정 시계는 기존 전투 상태를 따르며 피해·속도·쿨타임을 바꾸지 않는다.

전용 동작이 없었던 얼음 투척병, 덫 투척병, 기관병, 개방 봉 보스는 `public/art/enemy-role-actions-v1.png`의 4행×6열을 사용한다. 기마병은 `public/art/cavalry-actions-v1.png`의 6동작을 사용한다. 기존 역할별 도구와 복장을 유지했다. 투척 그림의 떨어져 있는 병/덫은 캐릭터 그림에 합치지 않으며 게임 투사체가 이동한다.

## 보정

- 같은 캐릭터의 얼굴 면적을 추정해 자세별 확대 차이를 제한 범위 안에서 보정한다. 얼굴이 가려진 그림은 기준 키로 대체한다.
- 발 기준점은 밝은 칼끝과 가는 봉 끝을 제외하고 아래쪽의 두꺼운 신발/옷자락을 사용한다. 무기가 발 아래로 내려와도 지면이 달라지지 않도록 한다.
- 동작 그림에 이미 들어 있는 팔 굽힘·웅크림을 다시 크게 변형하지 않는다. 리그 변형은 작은 잔여 움직임으로 줄이고, 사망 그림에는 이중 쓰러짐을 적용하지 않는다.
- 모든 프레임은 v4의 독립 칸 분리 방식으로 처리한다. 원본 파일은 보존한다.

## 제한

현재 동작 원화는 앞쪽 3/4 모습이다. 뒤쪽 3방향은 뒤를 보는 방향 그림과 공격별 리그를 유지한다. 모든 캐릭터의 팔방 동작을 새 원화로 완성한 것은 아니다. 완전한 팔방 연속 원화를 적용하려면 뒤쪽 준비·타격·피격과 연결 프레임 제작이 남아 있다. 자동 비율 보정은 캐릭터 얼굴 디자인 자체를 다시 그리는 기능이 아니다.
