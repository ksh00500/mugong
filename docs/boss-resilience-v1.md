# 보스 피격·제어 면역과 원거리 대응 검토 · 2026-10-04

2026-10-06 후속: 공통 추격 보법·전진 발걸음·선행 조준을 [보스 원거리 대응 v1](boss-pressure-v1.md)에서 로컬 적용했다. 아래의 유형별 횡스텝·전진 방어 등은 당시 설계안이며 모두 구현한 것으로 계산하지 않는다.

## 이번에 적용한 규칙

- 이름 있는 40종 보스와 이전 저장의 `chief`/`captain`은 항상 피격 경직 면역이다. 연속 근접·투사체 적중에도 준비/타격/회수 시간이 정상 진행한다. 피해 무효화는 아니다.
- 플레이어의 제갈 끌기, 취권 밀기·혼란, 일반/궁극 진법 감속을 받지 않는다. 현재 적 모델에 별도의 동결/속박 상태는 없다. 앞으로 적에게 제어 상태를 추가할 때도 같은 보스 판별을 적용해야 한다.
- 독·꽃 표식·흡혈·진법 피해는 제어 효과가 아니므로 유지한다. 일반·정예 적의 제어 규칙은 유지한다.
- 이전 저장에 남아 있는 보스 `staggerTime`/`confused`는 다음 전투 스텝에서 0으로 정리한다. 공격 상태·진행 시계·체력은 되돌리지 않는다.
- 보스는 피격 원화/큰 hurt 리그로 바뀌지 않는다. 현재 자세·크기를 유지하고 최대 0.35 전투 좌표의 반동이 0.1초 동안 감쇠한다. 기존 보스 반동은 최대 1.5/0.2초였다. 피격 색상은 0.04초이고, 움직임 감소 설정에서는 반동 0이다. 사망은 별도 연출을 유지한다.
- 큰 기술의 고유 준비·회수는 피격 경직과 별개이며 그대로 남긴다. 플레이어가 공략할 틈을 없애지 않는다.

코드: `src/domain/boss-resilience.ts`, `src/domain/game.ts`, `src/game/hostile-pose.ts`, `src/game/CombatScene.ts`.

## 코드에서 확인한 원거리 취약 요인

1. 공통 보스 접근 속도는 125이고 플레이어 기본 보행은 265에 기민/장비/배율이 추가된다. 거리 밖에서 뒤로 이동하며 공격하는 플레이어를 보통 접근만으로 따라잡기 어렵다. 실제 체감에는 공격 중 이동 배율과 지역 감속도 영향을 준다.
2. `tacticalBossMove`는 공격의 `range + dash + 18` 안에서 유효 패턴을 찾는다. 모든 패턴의 거리 밖이면 기존 순서의 행동을 반환하며 접근한다. 이것만으로 장거리 추격 상황이 해결되지는 않는다.
3. 투사체 회피는 일부 일반 역할에게만 있고 `!e.bossId`로 보스를 제외한다. 일반 적 회피를 보스에게 그대로 복사하면 동작이 떨리거나 탄을 무조건 피하는 문제가 생길 수 있다.
4. 이미 개별 돌진/긴 찌르기/가드가 있지만 모든 보스에게 동일한 수단이 있는 것은 아니다. 40종 전용 키트와 185개 행동이 구현되어 있다. 따라서 보스 개편을 새로 일괄 초기화하지 않는다.

원본: `src/domain/balance.ts`, `src/domain/game.ts` 플레이어 이동, `src/domain/enemy-tactics.ts`, `src/domain/boss-melee.ts`, `boss-wave3.ts`, `boss-wave4.ts`, `boss-wave5.ts`.

## 후속 설계 제안 — 아직 구현하지 않음

목표는 원거리 빌드를 막는 것이 아니라, 같은 방향으로 도망치며 발사하는 행동에 보스가 대응하는 것이다. 아래 수치는 튜닝 출발점이며 확정 밸런스가 아니다.

### 공통 판단

- 접근 중 플레이어가 근접 유효 거리보다 100 이상 멀리 있고 0.8초 이상 거리가 줄지 않으면 추격 상황으로 인식한다. 한 번 멀어졌다고 즉시 특수 행동을 발동하지 않는다.
- 플레이어의 관찰된 실제 이동 속도/방향으로 퇴로를 짧게 예측한다. 입력 버튼·미래 공격 명령은 읽지 않는다.
- 추격 가속은 0.6~1.2초의 짧은 구간부터 검토한다. 민첩형의 탄 회피에도 1.8초 이상 간격을 두는 방안을 검토한다. 실제 값은 보스별 이동·방어·돌진 비용과 함께 결정한다.
- 선택한 추격 행동에는 독립 재사용 시간을 둔다. 거리별 선택이 같은 돌진만 반복하지 않도록 행동 이력도 고려한다. 근거리에서는 기존 연계와 큰 기술을 순환한다.
- 준비 후반 방향 고정, 공격 중 방향 고정, 큰 공격 후 정지 회수는 유지한다. 시야에 들어온 실제 투사체만 반응하고, 타격 중에는 회피로 공격을 취소하지 않는다.

### 콘셉트별 수단

| 유형 | 원거리 상대 방안 | 플레이어의 대응 |
|---|---|---|
| 검·도·창 근접형 | 짧은 추격 보행 가속 후 준비가 보이는 돌진/보법. 긴 찌르기와 측면 베기를 이어 거리 회복 | 직선 돌진을 옆으로 회피. 빗나간 큰 공격의 회수 때 반격 |
| 권갑·중량형 | 전진 방어 자세로 간격을 좁힌 뒤 어깨박치기/짧은 전진 연타. 상시 전방 무적은 금지 | 뒤/옆으로 이동하거나 자세 종료 후 공격 |
| 민첩한 검객·살수 | 접근 중만 제한된 횡스텝으로 투사체 선을 벗어나며 퇴로 옆으로 진입. 연속 회피는 제한 | 탄 궤도를 분산하거나 스텝 직후 발사 |
| 봉·선장형 | 보법으로 접근 → 긴 봉 찌르기 → 근접 횡소. 지면 타격의 감속은 실제 적중할 때만 | 찌르기는 측면으로, 횡소는 거리로 회피 |
| 독·빙·환 등 원거리형 | 기존 발사 유지. 현재 위치만 반복 조준하지 않고 진행 방향을 제한하는 발사와 근거리 탈출 행동 혼합 | 설치가 끝나기 전에 자리 이동, 발사 후 근접 압박 |
| 기관·진법형 | 기존 설치물의 사선/배치로 도망 경로를 바꾸게 유도. 본체는 기계나 진을 활용해 위치 변경 | 설치물 파괴·사선 교차 시점 공략 |

일괄 원거리 피해 감소나 모든 투사체 반사부터 추가하지 않는다. 기존 반사/가드 보스는 그 개별 규칙을 존중한다. 무제한 순간이동·회수 취소·상시 추격 가속도 제안하지 않는다.

### 첫 구현 묶음 추천: 폐사 4종

- **공허:** 기존 어깨박치기 전에 짧은 전진 보법으로 거리 확보. 박치기 실패 후 취권을 즉시 자동 명중시키지 않고 위치에 따라 선택.
- **도원:** 금강 자세를 전진 방어 행동과 연결해 접근 → 철산고 → 가까울 때만 포획. 방어 중 옆/뒤 공격은 보상한다.
- **불명:** 금강 종 강화 중 전진 삼연장을 활용해 공간을 좁힘. 종을 파괴하면 압박 약화. 먼 플레이어에게 진각만 반복하지 않도록 선택을 분리.
- **무진:** 전진 선장세 → 장거리 봉 직자 → 가까운 적에게 횡소. 정면 방어 반격과 추격은 별도 선택으로 두며 장풍을 재추가하지 않음.

이 묶음에서 근접/원거리 빌드 양쪽의 실전 검증 후 검·도·창, 민첩형, 원거리·기관형 순으로 확장한다. 40종 각각의 수단·속도·재사용 시간은 다음 단계에서 검토해야 하며 지금 적용된 것으로 기록하지 않는다.

후속 검증은 서 있는 플레이어, 원을 그리며 사격하는 플레이어, 같은 방향으로 계속 후퇴하는 플레이어, 돌진 준비를 보고 측면 회피하는 플레이어를 따로 비교한다. 거리 밖에서 공허한 근접 공격 반복이 없는지, 접근 수단만 반복해 다른 패턴이 사라지지 않는지, 추격 실패 뒤에도 공략 가능한 회수가 있는지를 확인한다. 추격 수단의 준비 동작은 회피할 수 있어야 하며 강제 명중률을 목표로 삼지 않는다.

## 검증

- 전체 단위 검사 45개 파일 / 1,216개 통과. 신규 검사는 40종 연속 피격 시계, 이전 저장 제어 제거, 일반 적 제어 유지, 끌기/밀기/혼란/감속 제외와 독 피해 유지를 포함한다.
- TypeScript 및 Vite 생산 빌드 통과.
- 브라우저는 독립 테스트 저장으로 10지역 × 4보스 × 8방향 × 4행동 = 1,280가지 피격 전후의 원화·크기·리그·행동 유지와 반동 상한을 비교했고, 10개 검사 모두 통과했다. 정점은 Mesh2D의 실제 숫자 배열로 비교하고 모든 좌표의 유한성도 확인한다. 보고 파일/캡처: `docs/verification/boss-resilience-v1/region-*.json`, `region-*.png`.
- 브라우저 수치 검사는 공격을 덮지 않는다는 증거이고, 각 캡처의 실제 육안 검토는 별도로 기록한다. 원거리 회피/추격의 실전 밸런스를 검증했다는 의미는 아니다.
- 10지역 캡처 10장을 육안으로 확인했다. 준비/타격 원화가 유지되고 피격에 큰 자세로 교체되지 않는 것을 확인했다. 정지 캡처만으로 모든 연속 동작의 자연스러움을 보증하지 않는다.
