# 독무곡 7종 동작 적용

이번 범위는 독무곡 일반 적 3종과 보스 4종의 원화·방향·표시다. 각 인물은 다섯 원화 시점과 12자세를 사용하며 좌우 반전으로 8방향을 표시한다.

| 인물            | 준비와 접촉 동작                                     |
| --------------- | ---------------------------------------------------- |
| 암기수          | 어깨로 바늘을 당긴 뒤 앞으로 투척, 발사 후 빈손      |
| 독창병          | 양손을 같은 창 자루에 두고 허리 높이에서 전방 찌르기 |
| 독폭탄술사      | 오른손 어깨 위 준비에서 투척, 발사 후 빈손           |
| 청린사왕        | 뒤쪽 어깨에서 준비해 전방으로 내려 베기              |
| 독의 묵칠       | 독병 투척과 회수, 발사 후 빈손                       |
| 오독낭자 연화   | 부채 손잡이를 잡고 준비·전방 펼침·회수               |
| 만독곡주 사공염 | 양손 지팡이 전방 밀기·시전·회수                      |

캐릭터와 무기는 한 원화다. 동작마다 몸 배율을 맞추는 방식 대신 원본 RGBA를 그대로 분리하고 인물별 공통 칸에 최소 32픽셀 투명 여백을 둔다. 표시 배율은 0.225로 고정한다. 발 위치는 검토해 저장한 좌표이고, HP바는 살아 있는 모든 자세의 최고점보다 여유를 둔 고정 높이다.

방향 변환 요청을 무시한 초기 그림은 선택하지 않는다. 전방 투척 그림에서는 이미 던진 물체를 손에 남기지 않으며, 뒤쪽 그림의 팔·발·목표도 화면 위쪽을 따른다.

기존 독술·장판·투사체·근접 판정은 유지한다. 보스 18개 행동은 각 인물의 기본 준비·접촉·회수 원화 주기를 공유한다. 각 행동을 별도 세트로 다시 그린 것은 아니다. 연격의 두 번째·세 번째 접촉도 접촉 원화를 표시한다.

원본과 프롬프트는 [제작 폴더](source/dokmu-family-v1/README.md)에 있다. 전체 단위 검사 1,253개와 브라우저 검사 8개, 배포 빌드가 통과했고 [검증 기록과 캡처](verification/dokmu-family-v1/README.md)를 남겼다. 실제 사용자 저장은 변경하지 않았으며 자동 검증은 독립 브라우저 컨텍스트에서 수행했다.

로컬 게임은 `http://127.0.0.1:5173/`, 동작 검토는 `/art/dokmu-family-v1/review.html`에서 확인한다. 검토 페이지는 게임의 두 배 크기이며 모든 자세에 같은 배율을 적용한다.
