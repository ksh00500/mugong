# 작은 창에서 사라지는 아이콘 수정

2026-10-22. [이번 검증](verification/responsive-icons-v1/README.md).

로비 폭1,000px 이하에서 이전 레이아웃의 메뉴 SVG 숨김 규칙이 남아 있었다. 현재 로비는900px 이하에서 글자를0px로 줄이고 아이콘을 사용하지만, SVG도 숨겨져 출전·가방·창고·기록이 빈 버튼으로 보였다. 원화 다운로드 실패가 아니라 CSS 계층의 충돌이다. 현재 로비 소유 CSS가 아이콘의 표시와 고정 flex 크기를 명시해 이전 숨김을 상속하지 않게 했다.

작은 가방은 선택 물품 그림과 행동 아이콘을 직접 숨기고 있었다. 선택 그림을32px 영역에 원본 비율로 표시하고 회전 아이콘도 유지한다. 무공·장착 그림과 두4×7/10×8격자는 유지한다. 높이가 부족할 때 전체 화면을 축소하거나 필수 행동을 자르지 않는다.

좁은 배치의 정보/전리품 겹침도 수정했다. 무인 정보의 이름·상태·기본 능력·무공·장착 위치를 명시하고, 두 격자 옆에 선택 물품 정보를 놓는다. 이전 탭용 CSS의 자식 grid 좌표를 초기화해 제목·설명·품질/효과·행동이 서로 겹치지 않게 했다. 작은 화면에서 숨겨지던 효과 수치도 표시한다. 전투의 가방/일시정지 SVG는500px 이하에서도 표시하도록 전투 HUD 소유 CSS가 명시한다.

자동 정리는 좁은 화면에서 절대 위치로 떠서 무공 아이콘을 가리던 배치 대신 일반 가방 제목 안의 다음 줄에 둔다. 그림의 표시 여부뿐 아니라 조작 가능한 아이콘 위25/50/75% 위치에 다른 컨트롤이 덮여 있지 않은지도 검사한다. 포인터를 전투 화면으로 통과시키는 읽기 전용 방어 HUD는 이 hit-test 대상과 구분한다.

원화·전투 규칙·저장 데이터는 바꾸지 않았다. 사용자 브라우저 저장에 접근하지 않고 독립 Playwright 컨텍스트에서 검사했다.480px는 전투 가방/일시정지 버튼만 검사했으며 전체 게임의 모바일 지원 완료로 해석하지 않는다.
