# 지역 적의 자세 애니메이션 v1

후속 팔방 연속 동작은 [방향별 애니메이션 v2](directional-motion-v2.md)에 기록한다. 이 문서는 이전 여섯 자세 시트의 생성·검증 기록이다.

2026-10-01. 지역별 일반 적 30종과 보스 40종에 개별 자세를 추가했다. [지역 그림 v1](region-art-v1.md)의 한 자세 그림을 통째로 기울이는 표현에서 확장했다.

## 적용

70개체마다 걷기 두 자세·공격 준비·타격·피격·사망의 여섯 프레임을 연결한다. 총 420개 사용 자세다. 회복과 정지는 기존 지역별 기본 자세를 사용한다. 신규 10지역 경로에 적용하며 이전 네 지역 경로는 기존 애니메이션을 유지한다.

걷기는 초당 8번 자세를 바꾸고 개체마다 시작 프레임을 달리한다. 공격 준비는 기존 windup 상태, 타격은 실제 피해/투사체 발생과 같은 strike 상태를 읽는다. 피격은 0.12초 표시 후 진행 중인 상태로 돌아간다. 사망 자세는 0.38초 페이드 후 제거한다. 모션이 전투 타이머나 피해 판정을 별도로 진행하지 않는다.

정적인 그림의 이동 bob·공격 회전·사망 축소/회전을 실제 자세에 중복 적용하지 않는다. 짧은 준비 후퇴·타격 전진·피격 반동은 유지한다. 모션 감소 설정에서는 걷기를 첫 자세로 고정하고 후퇴·전진·반동·회전을 끈다. 공격 준비/타격/피격/사망의 상태 구분은 유지한다. 가방·정지·성장 화면에서 자세 시간이 흐르지 않는다.

## 에셋과 프레임

- 기본 10장은 6열×7행이며 행은 일반 적 3종과 원본 단계별 보스 4종이다.
- 청하현의 위 칸을 침범한 검은 v2로 보정했다. 천검산·폐사·팔진고성의 섞인 복장/장비는 v2와 별도 보정 시트로 교체했다. 보정 행이 기본 행보다 우선한다.
- 생성 도구가 만든 PNG 원본과 교체 전 파일을 모두 보존한다. [생성 기록](source/enemy-motion-manifest.json)에 프롬프트·출처·선택 파일·보정 행·전달 크기를 기록했다.
- [내보내기](../scripts/export-enemy-motion.mjs)는 같은 크기와 투명도를 유지하는 WebP 형식 변환만 수행한다. 전달 파일 13장은 8,502,310바이트다.
- 실행 시 투명 여백을 측정하고 다섯 열 경계를 함께 계산해, 생성 시트의 불균일한 간격에 맞춰 프레임을 등록한다. 각 칸의 연결된 인물 영역만 메모리 시트에 담아 이웃 칸의 떨어진 무기 조각을 제외한다. 원본 파일은 변경하지 않는다. 한 인물의 두 걷기 자세 높이를 공통 배율 기준으로 삼아 무기를 올리거나 쓰러질 때 그림 전체를 같은 높이로 찌그러뜨리지 않는다. 살아 있는 자세는 발 기준, 사망은 가로로 누운 몸 기준으로 배치한다. 좌우 반전 때 기준점을 보정한다.

현재는 두 자세 걷기와 공격 단계별 한 자세를 사용한다. 방향은 좌우 반전이며 팔방 전용 자세, 공격 사이의 연속 중간 프레임, 관절 애니메이션은 별도 확장 범위다.

## 로딩과 저장

현재 지역의 바닥·기본 자세·동작 시트와 필요한 보정 시트만 첫 진입에서 준비한다. 다음 지역은 전투 중 미리 받는다. 준비 개수는 실제 파일 수를 따른다. 다음 지역의 동작 파일이 지연되면 전투를 멈추고 로딩을 표시한다. 실패 시 같은 여정으로 재시도한다.

자세·피격 표현·사망 페이드는 렌더러의 일시 데이터다. 실제 사용자 저장을 수정하거나 죽기 전 기록을 복원하지 않는다. 테스트 상태는 Playwright 독립 컨텍스트에만 만든다.

## 검증 기록

자동 검사와 직접 캡처 검토를 구분해 기록한다.

- 단위 검사: 10개 파일, 158개 통과. 기존 전투·콘텐츠·저장 규칙, 자세 우선순위/모션 감소, 불균일한 칸 경계와 떨어진 조각 제외를 포함한다.
- 지역 브라우저 검사: 18개 통과. 10지역의 여섯 자세, 1093×614 및 1366×768·1440×900 배치, 다음 지역 로딩 대기, 파일 실패 후 같은 여정 재시도, 모션 감소·좌우 반전·피격·사망 제거를 확인했다. 실제 시뮬레이션에서도 공격 준비→타격 자세 전환과 체력 감소를 확인했다. 최종 경계 계산 수정 후 지역 17개를 실행하고 실제 피해 검사 1개를 추가 실행했다.
- 기존 전투 타격감·HUD 브라우저 검사: 10개 통과. 지역 검사와 함께 실행했으며 이후 변경은 동작 시트의 경계 계산과 검증 기록이다.
- 타입 검사·배포 빌드: 최종 `npm run build` 성공.
- 시트 구조 검사: 선택된 기본 시트 10장과 보정 시트 3장 모두 예상 프레임 수와 연결된 인물 영역이 존재한다. [검사 스크립트](../scripts/audit-motion-layout.mjs)는 경계와 인물 영역을 원본 파일에서 읽어 검사한다.
- 직접 시각 검토: 10지역 캡처에서 인물 잘림, 이웃 칸의 무기 조각, 보정 캐릭터의 복장·장비, 발 위치와 타격 자세를 확인했다. 일곱 인물을 함께 세운 화면은 에셋 확인용 테스트 장면이며 실제 보스 조우 구성과 다르다.
- [화면 캡처](verification/enemy-motion-v1/)에 각 지역의 여섯 자세, 모션 감소 상태와 실제 공격 판정을 보존한다.
