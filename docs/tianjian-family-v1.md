# 천검산 원화·방향·동작 제작

사용자 선택: 천검산. 일반 적 검객·창 수문장·검기술사와 보스 낙검객 우진·쌍검 백홍·검귀 무명·천검노인 백운을 제작한다. 기존 2번 지역·역할·전투 판정을 유지한다.

## 동작 구성

| 인물 | 기본 공격 원화 |
| --- | --- |
| 검객 | 기존 직자 판정에 맞춘 전방 찌르기, 자유 팔은 균형 유지 |
| 창 수문장 | 떨어진 양손으로 창을 잡아 허리에서 당기고 전방 찌르기 |
| 검기술사 | 뒤 어깨에서 준비한 검을 사선으로 내려 베어 검기를 방출, 반대 손은 검결 |
| 낙검객 우진 | 가드 이후 몸 회전과 함께 사선 내려 베기 |
| 쌍검 백홍 | 두 칼을 각 손으로 잡고 서로 다른 대각선으로 교차 베기, 후속에서 분리 |
| 검귀 무명 | 낮은 자세에서 몸을 돌려 전방을 가로지르는 빠른 베기 |
| 천검노인 백운 | 지지발과 허리 회전으로 내려 베기, 반대 손 검결과 기존 검기 효과 |

정면·앞 대각선·측면·뒤 대각선·후면의 다섯 원본 시점과 좌우 반전으로 팔방을 표시한다. 각 시점은 대기·세 보행·작은 피격·사망, 공격 준비·최대 준비·타격·후속·회수·복귀의 12자세다. 적용 완료 범위는 35시트·420그림이다. 원화는 기존 적 외형을 참고하고 기본 제공 `image_gen.imagegen`으로 제작했다. 원본 50 PNG 중 선택 원본 43개를 사용하며 [출처·수정 기록](source/tianjian-family-v1/README.md)을 보관한다.

## 제작·내보내기

원본은 `docs/source/tianjian-family-v1`, 소비 에셋은 `public/art/tianjian-family-v1`, 프레임 좌표는 `src/game/tianjian-family-frames.json`이다. 프롬프트·선택 원본·지면 좌표·생성 도구 출력 경로를 원본 폴더에 보관한다.

일반 적 기본 원화는 정사각 4×3, 넓게 펼치는 보스 원화는 세로 3×4를 요청했다. 실제 출력 픽셀 크기를 읽고 정수 격자 경계를 사용한다. 소스 격자와 전달 격자를 분리해 `poseSourceCells`에 명시한다. 원본 RGBA는 리사이즈·메시 변형 없이 1:1 복사하고 인물별 공통 전달 칸·최소 32픽셀 투명 여백을 사용한다. 게임 배율은 0.225 고정이다. 넓은 검격 때문에 특정 공격 프레임을 축소하지 않는다.

기존 보스의 기술별 게임 판정·접촉 시점·검기 효과는 유지한다. 이번 지역 묶음은 인물별 기본 공격 주기이며, 보스 19개 기술 각각의 독립된 원화 주기가 있는 것은 아니다. 여러 접촉이 있는 연격에서는 각 접촉마다 타격 그림을 표시한다. 보스 피격은 공격 주기를 가리지 않는다. 사망은 한 자세의 페이드다.

자동 검사는 원화 경계·출처·격자·여백·배율·방향·HP바·판정 시점 대응을 확인한다. 몸 비율과 각 손·검의 연결, 두 팔의 관절·지지발은 원화와 실제 합성 화면을 보고 검토하며 자동 인증하지 않는다. 빌드·단위 1,249개·브라우저 8개가 통과했고 로컬 배포를 완료했다. 자동 결과와 실제 시각 검토는 [검증 보고서](verification/tianjian-family-v1/README.md)에 구분했다.
