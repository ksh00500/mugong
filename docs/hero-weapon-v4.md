# 플레이어 6무기 프레임 배치 · 2026-10-04

기존 구현은 손 좌표를 갖고 있었지만 검의 방향과 길이는 공통 투영 계산식으로 바꿨다. 따라서 좌표 부착 검사가 통과해도 실제 원화의 손 위치, 검술의 궤적, 화면상의 길이를 보장하지 못했다. 이번 수정은 플레이어 10외형의 기본 공격과 무기 배치를 대상으로 한다.

## 프레임 데이터

`src/platform/hero-weapon-poses.json`에는 캐릭터·무기·방향·노출 프레임별 손 UV, 각도, 길이, 앞뒤 순서, 몸체 원화 행/방향/반전, 투명도, 부채 폭을 저장한다. 런타임은 해당 항목을 직접 읽으며 조준 방향으로 각도를 계속 회전하거나 자동으로 칼날을 단축하지 않는다. 데이터가 누락되면 오류로 처리한다. 손 좌표는 실제 몸체 메시의 같은 지점에 연결한다.

배치 수는 `10 × 6 × 8 × (대기 1 + 기존 행동 6 + 기본 공격 노출 8) = 7,200`이다. 공격 노출은 0/25/55/85/110/160/210/255ms에 전환한다. 85~160ms 동안 타격 자세를 유지하며 실제 피해 시점은 기존 90ms다. 기본 공격 280ms와 판정 범위는 변경하지 않았다. 부동소수점 오차로 55ms 경계가 이전 프레임으로 넘어가던 문제도 수정했다.

손 기준점은 원화별 데이터, 각도는 무기와 방향별로 작성한 키포즈를 사용한다. `scripts/author-hero-weapon-poses.mjs`는 이 데이터를 반복 배치표로 펼치는 도구다. **7,200개를 서로 다른 원화로 새로 그리거나 각각 독립적으로 손으로 입력했다는 뜻은 아니다.** 몸체 기본 공격은 기존 3자세 원화를 다른 순서와 유지 시간으로 사용한다. 추가로 보라색 외형의 손이 감춰진 대기 방향 원화만 보완했다.

## 무기별 동작

| 무기 | 준비와 공격 | 마무리 |
| --- | --- | --- |
| 검 | 어깨 뒤로 당겨 높은 준비, 몸 앞을 가로지르는 빠른 베기 | 낮은 끝 자세를 유지하고 대기 자세로 돌아감 |
| 도 | 검보다 큰 준비와 마무리 각, 조금 더 큰 몸의 전진 | 베기 끝 자세 유지 |
| 봉 | 창처럼 좁은 각도로 뒤로 당겼다가 내지름; 손잡이를 봉 중앙으로 수정 | 뻗은 자세 유지 후 당겨 거둠 |
| 부채 | 낮은 손에서 들어 준비하며 폭을 좁힘, 공격 때 펼쳐 휘두름 | 낮은 손으로 회수 |
| 암기 | 짧은 준비와 조준 방향의 투척 | 발사 뒤 손의 암기 그림을 숨기고 다시 준비 |
| 권갑 | 주먹을 당겨 조준 방향으로 내지름 | 뻗은 주먹 유지 후 당김 |

검광은 빠른 베기 두 노출에만 표시하며 작성된 두 각도를 잇는다. 준비·마무리·회수·동작 감소 설정에는 검광을 표시하지 않는다. 여섯 무기의 몸체 전진량도 개별 설정이다.

궁극기도 전용 0.6초 시간선에 같은 무기별 작성 자세를 연결한다. 뒷방향 궁극기가 대기 무기 자세로 고정되는 회귀를 방지하며 피해·투사체 발생 시간은 바꾸지 않는다. 외형 번호가 없는 구형 저장의 마지막 대기 프레임은 기존 몸체와 손 기준을 유지한다.

[Slynyrd의 탑다운 공격 애니메이션 설명](https://www.slynyrd.com/blog/2025/5/23/pixelblog-56-top-down-character-attack-animation)과 사용자가 제공한 연속 시트를 참고했다. 준비/빠른 공격/타격 유지/독립적인 회수 구분을 적용했으며 참고 그림을 게임 에셋으로 복사하지 않았다.

## 원화 보완

보라색 외형의 기존 옆모습은 손이 소매에 완전히 감춰져 있었다. 기존 손 좌표가 소매 중앙을 가리켜 무기가 옷에 붙은 것처럼 보였다. 내장 imagegen으로 얼굴·의상을 유지하고 손이 보이는 대기 자세를 제작했다. 원본은 `docs/source/hero-weapon-v4/guard-6.png`, 배포 그림은 `public/art/hero-weapon-v4/guard-6.webp`, 손과 크기 측정은 `src/platform/hero-guard-calibration.json`이다. 생성된 북쪽 정면 뒷모습은 손 노출이 충분하지 않아 기존 북쪽 원화를 유지한다. 앞·옆·뒤 대각선은 보완 원화를 사용한다.

## 검증 구분

전체 배치의 유효성, 타격 방향, 무기별 동작 차이는 단위 검사로 확인한다. Playwright는 실제 Canvas/WebGL 렌더에서 10종 × 6무기 × 8방향 × 8공격 노출과 대기 자세를 검사하고 120장의 비교 화면을 남긴다. 별도 연속 렌더 영상과 28물품의 일반/동작 감소 전체 시간선 부착 검사를 사용한다.

자동 좌표 검사는 그림의 자연스러움을 인증하지 않는다. `docs/verification/hero-weapon-v4/`의 무기별 화면, 전체 비교와 GIF를 직접 검토한다. 모든 시험 저장은 독립 브라우저 컨텍스트를 사용하며 로컬 테스트 포트 5174와 사용자 프리뷰 5173을 분리한다.

이번 기록은 적의 크기와 HP바 겹침 또는 남은 WebGL 조각 현상까지 해결했다는 의미가 아니다. 사용자의 우선순위에 따라 플레이어 무기 모션을 먼저 개선한다.
