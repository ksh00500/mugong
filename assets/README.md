# 첫 전투 에셋

현재 디자인 기준은 사용자가 승인한 `concepts/cartoon-swordsman-v1.png`의 카툰풍이다. `concepts/cartoon-combat-v1.png`는 이를 전투 장면으로 확장한 제안이다. `hero/`의 회화적 캐릭터와 기존 `prototype/` 동작은 이전 시안의 비교 자료다. 새 카툰풍 동작이 연결되었다는 뜻은 아니다. 제작 요청은 `../docs/chatgpt-asset-first-batch-v2.md`를 따른다.

맵 축척은 사용자의 추가 정정에 따라 넓은 구역과 작은 캐릭터로 바꾼다. 최신 검토 이미지는 `concepts/cartoon-combat-wide-v2.png`이며, 이전 전투 시안의 큰 인물 크기는 기준으로 사용하지 않는다.

새로 제작한 검증용 에셋이다. 기존 Drive 런타임 에셋은 포함하지 않는다.

제작 도구: 기본 내장 image_gen. 생성 프롬프트는 `prompts.md`에 기록한다. 원본 PNG의 알파를 보존하며, 실제 애니메이션은 화면에서 검수한다.

캐릭터 색상과 의복은 첫 검증용 시안이며 전체 캐릭터 디자인을 확정하지 않는다.

## 현재 선택한 검토용 파일

| 파일 | 용도 |
|---|---|
| `hero/swordsman-reference-v1.png` | 검사 외형·시점 기준 |
| `hero/walk-body-v1.png` | 무기를 제외한 걷기 4프레임 |
| `hero/slash-body-v1.png` | 무기를 제외한 베기 4프레임. 마지막 자세를 임시 대기로 사용 |
| `weapons/jian-v1.png` | 독립된 검. 손잡이 기준점으로 몸체에 연결 |

검과 몸체를 함께 그린 첫 시트에서 프레임별 무기 손 변경이 발생했다. 몸체에서 무기를 분리하고 별도 검을 같은 손 위치에 연결하는 방식으로 시안을 구성했다. 이름에 `trial`이 있는 파일은 비교용 미채택 시도이며 실행 샘플에서 사용하지 않는다.

`../prototype/index.html`의 검토 화면에서 실제 투명 배경·프레임 재생·검 연결을 확인할 수 있다. 프레임 사각형·손과 발 기준점·검 회전각은 `../prototype/main.js`에 기록되어 있다. 원본 PNG를 자르거나 보정해 덮어쓰지 않았다.

한 방향의 키프레임 시안이다. 다방향 원화, 호흡 동작, 중간 프레임, 체격·옷자락의 일관성 보정은 이후 제작 대상이며 양산 규격을 확정하지 않는다.
