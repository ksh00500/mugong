# 카툰 전투 UI 목업 v1

사용 도구: 내장 image_gen 이미지 편집.

입력: `cartoon-combat-wide-v2.png`. 승인된 넓은 맵과 작은 캐릭터 크기를 유지하고 `docs/wireframes/mugong-first-draft.html`의 전투 UI 배치를 반영했다.

출력: `cartoon-combat-ui-mockup-v1.png`.

정적인 검토용 목업이다. 레이드 층수, 이름, 능력치와 게이지 수치는 표시 예시이며 새 게임 규칙을 확정하지 않는다.

## 실제 생성 프롬프트

+첨부한 넓은 카툰풍 전투 화면에 기존 와이어프레임의 전투 UI를 얹은 목업 이미지를 만들어줘. 맵과 작은 캐릭터의 크기·위치·카메라는 그대로 유지하고, 기존 체력바와 원형 아이콘은 지워줘. UI는 밝은 종이색 패널, 짙은 글자, 얇은 황동색 테두리로 간결하게.
상단 왼쪽: '청하연', 'HP 62 / 100', 체력바, '남은 수명 4일 12시간'. 상단 중앙: '혈마성 수문장'과 긴 보스 체력바. 상단 오른쪽: '레이드 · 2/5층'과 '가방' 버튼.
하단 왼쪽: '현재 무공', '화산매화검법 · Lv.5', '좌클릭 기본 공격 · 우클릭 궁극 행동'. 하단 중앙: '궁극 게이지', 게이지바와 '65 / 100'. 하단 오른쪽: '무공 전환', Q와 E 사이에 네 칸 '1 매화검법', '2 태극검법', '3 팔괘진', '4 삼재검법', 첫 칸 선택 표시.
UI는 화면 가장자리에 얇게 배치해서 넓은 전투 공간을 유지해줘. 한국어는 또렷하게. 로비 메뉴와 소모품 슬롯은 넣지 말아줘.
