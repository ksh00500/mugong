# 카툰풍 전투 장면 시안 v1

2026-09-27. 내장 image_gen으로 승인한 카툰풍 검객을 참고해 생성했다. 캐릭터·배경·간단한 HUD를 함께 검토할 디자인 제안이며 실행 가능한 게임이나 분리된 에셋이 아니다. 화면의 아이콘 수와 캐릭터 축척은 확정 게임 규칙이 아니다.

## 사용 프롬프트

첨부한 카툰풍 검객을 기준으로 무협 탑뷰 액션 게임의 전투 장면 한 장을 그려줘. 가로로 넓은 게임 화면. 검객이 작은 숲 공터 중앙에서 산적 둘과 대치하고 있어. 비스듬히 내려다보는 시점, 굵고 깔끔한 선, 단순한 색면과 셀 셰이딩을 인물과 배경 모두에 적용해줘. 흰 도포와 붉은 허리띠의 검객이 잘 보이도록 공터는 차분한 흙색, 주변은 대나무와 낮은 돌담으로 간결하게. 인물은 첨부처럼 약 5등신. 화면 왼쪽 위에 작은 체력바, 아래에 간단한 무공 아이콘만 두고 글자나 로비 메뉴는 넣지 말아줘.

출력: `cartoon-combat-v1.png`.
