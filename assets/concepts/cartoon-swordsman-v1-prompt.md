# 카툰풍 무인 화풍 탐색 v1

2026-09-27. 내장 image_gen 사용. 사용자 제공 두 이미지는 선·색면·비례의 참고이며 문구·가격·캐릭터 자체를 복제하는 지시가 아니다.

화풍 검토용 단일 이미지다. 이 결과만으로 기존 기획의 전체 화풍·캐릭터 외형을 확정하거나 실행 샘플을 교체하지 않았다. 동작과 프레임 설계를 요청하지 않고 짧은 프롬프트로 생성했다.

## 사용 프롬프트

첨부 두 이미지는 화풍 참고다. 굵고 깔끔한 외곽선, 큰 색면, 간결한 셀 셰이딩을 참고해 새로운 무협 검객 한 명의 전신을 그려줘. 약 5등신의 세련된 카툰 비례, 또렷한 눈과 약간 무심한 표정. 묶은 검은 머리, 짧은 흰 도포, 먹색 바지, 붉은 허리띠. 편하게 서서 한 손에 실용적인 직검을 아래로 들고 있는 단순한 자세. 살짝 내려다보는 3/4 시점. 명암은 두 단계, 옷 주름과 장식은 적게, 얼굴과 실루엣은 매력적으로. 밝은 무채색 배경에 인물 전체와 검이 보이게. 글자나 UI 없이 한 명만.

출력: `cartoon-swordsman-v1.png`. 밝은 배경의 컨셉 이미지이며 투명 게임 스프라이트가 아니다.
