# 브라우저 검증 기록

2026-09-27, Codex in-app browser에서 `http://127.0.0.1:58973/prototype/`를 확인했다.

- 선택된 몸체·검 PNG가 로드되고 바닥 위에 투명 배경으로 표시됨.
- 대기, 걷기, 베기 버튼 전환과 각 4프레임 재생 확인.
- 멈추기, 프레임 이동, 크기 변경, 느리게, 손·발 기준점 표시 확인.
- 걷기 1·2·4 및 베기 1·2·3 프레임을 확대해 확인. 검이 동일한 화면 오른쪽 손에 연결되고 다른 프레임의 머리·발 조각이 섞이지 않음.
- 캔버스에 초점을 두고 D 입력 시 위치 표시가 600→603으로 바뀌는 것을 확인.
- 375px, 1024px 너비에서 문서 가로 넘침 없음. 일시 viewport 설정은 검증 후 초기화.
- JavaScript 구문 검사 통과, 브라우저 콘솔 오류 없음.

원화 한 방향과 키프레임 연결을 검증한 기록이다. 다방향 동작·실제 공격 판정·멀티플레이·최종 애니메이션 품질을 검증한 기록이 아니다. 아직 프레임 사이 체격과 옷자락의 변화 및 중간 동작 부족이 남아 있다.
