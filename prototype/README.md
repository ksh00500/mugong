# 검사 동작실

새 에셋의 시점·축척·몸체 동작·손과 검 연결을 확인하는 웹 샘플이다. 최종 게임 엔진이나 네트워크 스택의 선택이 아니다. 외부 라이브러리 없이 Canvas 2D로 그린다.

## 실행

저장소 루트에서 `python -m http.server 58973 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:58973/prototype/`를 연다. Python이 PATH에 없으면 설치된 Python 실행 파일의 절대 경로를 사용한다.

화면을 클릭해 키보드 초점을 맞춘 뒤 WASD/방향키 이동, 클릭/Space 베기, R 초기 위치. 상단 버튼은 동작 루프 검토, 멈추기와 이전/다음은 프레임 검토다. 느리게와 손·발 기준점으로 연결을 확인한다.

## 현재 범위와 한계

- 남동쪽 한 방향의 캐릭터 몸체와 별도 검 PNG를 재생한다. 다른 방향으로 움직여도 캐릭터 원화는 남동쪽이며 방향선만 바뀐다. 다방향 원화 제작 전 조작·방향 구현 완료로 보지 않는다.
- 걷기와 베기 각각 4개의 키프레임이다. 자연스러운 완성 애니메이션의 프레임 수가 확정된 것은 아니다.
- 검은 프레임별 손 기준점을 회전축으로 연결한다. 손 원본 영역을 검 위에 다시 그려 손잡이 가림을 시험한다.
- 대기는 베기 회복 자세 하나를 사용한다. 별도 호흡 애니메이션은 아직 없다.
- 바닥·그림자·방향선은 크기 검토용 코드 도형이다. 최종 배경 에셋이 아니다.
- 적·피격·사망·강호·멀티플레이·공격 판정·아이템 시스템은 포함하지 않는다.
- 프레임 간 그림체·체격·의복의 변화가 남아 있어 양산용 최종 에셋으로 승인하지 않는다.
